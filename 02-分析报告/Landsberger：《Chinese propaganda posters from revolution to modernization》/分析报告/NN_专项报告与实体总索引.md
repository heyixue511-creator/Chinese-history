# 第一部分：专项报告

## 专项一：全书论证方法论评估

Landsberger在本书中采用了多种学科方法的混合策略，其优势与局限如下：

**（1）艺术史方法：** 作者对海报的构图、色彩、技法、材质进行了艺术史专业水准的描述——特别是对工笔（gongbi）、写意（xieyi）、中国画（Zhongguo hua）、社会主义现实主义、插画现实主义（Illustrator Realism）等风格的区分具有专业精度。L###局限：对海报创作者的个案研究不足——除了极少数知名艺术家（如彦涵、古元、李桦）外，绝大多数海报创作者在书中没有被个体化地讨论。L###

**（2）政治学制度分析方法：** 对中宣部的组织架构、整风制度的功能、派系斗争对宣传政策的影响进行了制度层面的分析。这一方法在西方中国学研究中属于主流范式（受Teiwes, Pye等人的影响）。L###局限：缺乏对中宣部内部档案材料的引用——全书对中宣部运作的描述主要依赖二手文献，没有使用中共内部的工作报告、会议纪要或人物访谈。L###

**（3）符号学/图像学方法：** 第五章构成了全书符号学分析的高峰——对"擦窗"隐喻、收录机替代书籍、航天飞机替代拖拉机、安全帽替代鸭舌帽等符号替换进行了逐层解读。L###局限：符号学解读有时带有"过度阐释"的风险——例如对"蓝色"作为"暧昧色彩"的判断缺乏中国色彩文化的系统论证支撑。L###

**（4）田野观察法：** 作者在二十年间收集海报的过程中积累了大量的实地观察经验——新华书店的销售情况、街头广告牌的内容变化、艺术市场的运作方式。L###局限：缺乏系统的访谈记录——没有宣传画制作者（艺术家、出版社编辑、中宣部官员）或宣传画消费者（购买者、观看者）的直接访谈材料。L###

**（5）定量分析缺失：** 全书没有任何定量分析——没有海报产量年度变化曲线、没有不同主题的海报数量统计表、没有受众调查数据。作者承认这一缺失并归因于资料可得性，但这也使得全书的许多判断停留在"印象式"和"推断式"的层面。L###

## 专项二：核心概念谱系——从孔子到邓小平

本书建立了一套跨越2500年的概念谱系，可以整理如下：

```
孔子（公元前6世纪）
  │ "人可教化" → 角色示范 → 道德榜样的力量 > 武力或惩罚
  │ "五伦" → 等级化人际关系 → 对权威的从属
  │ "修身" → 自我修养 → 成为"君子"
  │
  ▼
汉代（公元前206-公元220）
  │ 儒家成为国家意识形态 → 科举制度 → "文字统治"(grammatocracy)
  │
  ▼
宋—明—清
  │ 乡约制度(xiangyue) → "六谕"公开宣读 → 地方化模型
  │ 《耕织图》《点石斋画报》→ 视觉传播的大众化
  │ 年画(nianhua) → 功利—魔法功能 → 吉祥符号体系
  │
  ▼
马克思—列宁（19-20世纪）
  │ 唯物主义 → "意识由社会存在决定" → 通过改造环境来改造人
  │ 列宁主义 → "先锋队教育群众" → 宣传是"党的教育的要素"
  │
  ▼
毛泽东（1930s-1976）
  │ 延安文艺座谈会(1942) → "文艺为工农兵服务" → 普及先于提高
  │ 刘少奇 → "修身"→"共产党员修养" → 儒家列宁主义
  │ 毛泽东思想 → "六谕"式行为规范 → "红宝书"崇拜
  │
  ▼
邓小平（1978-）
  │ "文艺不再从属于政治" → 风格多元化
  │ 四项基本原则(1979) → "宣传画不能走向公开化"的制度锁
  │ "社会主义精神文明"(1980) → 概念空洞 → 宣传内容模糊化
  │ 拒绝个人崇拜 → 领袖形象消失 → 国家符号替代
  │
  ▼
1990年代
  │ 儒家传统的回归："服从、节俭、纪律"的间接呼唤
  │ 宣传画衰亡 → 电子媒介接替 → 金钱符号替代政治符号
```

L###这一谱系揭示的核心洞见是：中国宣传的最深层结构——"使用榜样来改变行为"——不是马克思列宁主义带来的革命性发明，而是中国文化连续性中的结构性惯性。L###

## 专项三：全书未回答的十个关键问题

1. **宣传画的实际受众接受度是什么？** 全书承认缺乏受众研究数据，但未能提出如何填补这一空白的方案。

2. **约1000幅海报的搜集是否具有统计学意义上的代表性？** 作者坦诚"由于缺乏出版社目录，难以判断"，但没有讨论其私人收藏可能存在的系统性偏差（偏向易于从中国携带出境的小尺寸海报？偏向某些特定主题？）。

3. **中宣部内部对宣传画失效的讨论是怎样的？** 全书依赖外部观察推断，未能引述任何内部政策讨论文件或个人回忆。

4. **不同省份的宣传画有没有地区差异？** 作者在导论中暗示了地方宣传部门的自主权，但没有系统比较不同地区的海报。

5. **宣传画艺术家个体是如何在"党的要求"和"个人艺术追求"之间取得平衡的？** 缺乏艺术家访谈。

6. **少数民族语言版本的海报是否存在？其使用情况如何？** 完全没有涉及。

7. **海报的"效果"是否能用"发行量"和"销售额"作为替代指标？** 作者提到了印刷数量（数千到两三百万份），但没有进行系统的定量分析。

8. **1990年代之后中国宣传画是否真的"消失"了——还是转变了形式？** 作者断言"disappeared"但未观察到农村地区、公共交通空间、学校中仍然存在的宣传画。

9. **互联网时代（1995年后）中国宣传的视觉策略发生了什么变化？** 本书的写作时间限制了对此的讨论。

10. **与同期其他社会主义国家（朝鲜、古巴、东欧）的宣传画比较如何？** 仅涉及苏联公开化海报的零星比较。
