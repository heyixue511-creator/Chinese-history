# 专项报告与实体总索引

> 本文件为《设计艺术的含义》（赵江洪，湖南大学出版社 1999）的两部分专项总结：**第一部分**为语言、文风、修辞方式、史料使用方式、阐述方法、推演逻辑、文字风格的专项报告并附术语中英对照表；**第二部分**为六类实体（人物/著作作品/概念/机构/地点/事件）总索引。全部行号证据指向 `00-book\赵江洪：《设计艺术的含义》，1999_clean.md`。

# 第一部分：专项报告

## 一、语言风格专项

1. **书面语体为主，兼具讲坛色彩**：全书为规范的现代汉语书面语，句式完整、逻辑词密集（"因此""所以""事实上""值得注意的是""由此可见"高频）。同时带有教科书式的引导语气与讲稿式的亲切感（如"让我们以……为例""我们可以这样认为"），L4 丛书序、L45、L119 可见。
2. **判断句与定义句突出**：大量"……是……""……就是……"的论断句式（如"设计是一种'适应性'系统"L42；"工业设计的核心是'交流'"L45；"设计的核心是对物性的挖掘"L114），强化理论清晰度。
3. **中文为主、术语中西对照**：英文术语以括号紧随中文（如"高设计（high design）"L119、"式样（style）"L64、"物性（objecthood）"L114、"产品差异性（product differentiation）"L114），便于专业读者对照。
4. **古籍原文直引**：先秦典籍以文言原文嵌入（《墨子·辞过》《荀子·富国》《老子》《论语·子张》《易·系辞》，L15、L18），构成"文白相间"的语体层次。
5. **专名翻译不规范处**：同一人名的中文译名与英文拼写时有出入、讹误（如"罗塞尔（Russell）"L15、"维恩特里（Robertventuri）"L70、"思库顿（RogerScruton）"L140、"葛罗斯/格罗塞"L15/L201 不一致），反映 1990 年代末翻译体例尚未统一。

## 二、文风专项

- **学术随笔与通论结合的文风**：既有严格的概念定义（第二章九种设计定义），也有随性的人文观察（塑料的"孤独"L87、母亲的洗衣记忆 L105）。
- **案例叙事化**：理论观点多以完整案例支撑并以文学笔法讲述（de Havilland Comet 空难 L45、照相机换镜头的手感 L108、Porsche 宣传册 L126、SPY 散文诗 L129）。
- **意象化收束**：章末常以哲理性、意象性的句子收束（"历史的长河""师法自然""未来的市场在中国"）。
- **时代文风**：带有 1990 年代末知识界话语特征（知识经济、信息社会、全球一体化、东亚崛起），口语化与书卷气并存。

## 四、史料使用方式专项

1. **第一手典籍直引**：先秦诸子原文（《墨子》《荀子》《老子》《论语》《易·系辞》），L15、L18。
2. **设计史论著转述**：Dormer《Design since 1945》（L45）、Heskett《Philips 企业设计管理研究》（L48）、Kicherer《Olivetti》（L51）、Pye《设计本质与设计美》（L67）等，多采用"某书认为"的转述。
3. **科技史料转述**：硅材料与集成电路（L91）、超导发现（L91）、复合材料（L87-L88）、碳纳米管（L84）。
4. **经济统计数据**：中国居民收入支出（L116）、知识经济数据（L84）、品牌调查（L125）。
5. **政策与领导人讲话**：江泽民环保讲话（L84）。
6. **报刊资料**：《每周电脑报》（L21）、《解放日报》（L84）、《参考消息》（L84）。
7. **使用特点与不足**：材料来源中西并蓄、种类广泛，但部分西文文献为二手转述，个别数据出处欠精确（如海聂克《失去自由的人》出版年作 1911，实际为 1944；L75），专名拼写讹误较多，需以原文献复核。

## 五、阐述方法专项

- **定义法**：对设计、式样、工程、高设计、制度等核心概念逐一界定（L30、L64、L119、L140）。
- **历史叙述法**：以 1945 年为界叙述职业化（L45），以三次技术革命叙述观念变化（L81）。
- **比较法**：国别比较（美德意法斯堪的纳维亚日本，L54）、中西比较（L21、L84）、时代比较（先民/今人，L15）。
- **案例论证法**：每个理论均配产品案例（剪刀、波音 707、电吹风、打印机、门把手等）。
- **批判与反例法**：对现代主义、高设计、产品语意学、广告均列出批评观点（L67、L129、L114、L132）。
- **哲学提升法**：把设计问题上升到存在论（物性）、认识论（主观真实）、伦理学（设计道德）层面（L114、L111、L140）。
- **未来学预测法**：以"非物质社会""保护主义""玩具化游戏化"等预判设计走向（L27、L129、L135）。

## 六、推演逻辑专项

1. **二分—综合推演**：先设二元（科学/艺术、式样/工程、过程/结果、物质/非物质），再以"既……又……""不是……而是……"综合（如"设计艺术不是纯艺术，但设计艺术是艺术"L61）。
2. **从定义到属性**：由设计定义（L30）推演设计的过程、对象、文化与评价（第二章全章结构）。
3. **从历史到理论**：以设计史实（职业化、现代主义兴衰）作为理论命题的证据（L45、L67）。
4. **从社会到设计**：以社会经济制度（市场经济/计划经济/福利国家）解释设计形态（第五章）。
5. **从技术到观念**：以材料、信息技术的变化推演设计观念变化（第六章、第九章）。
6. **开放式论证**：多处不下定论而"拭目以待"（L114），或保留对立观点，呈现论辩张力。
