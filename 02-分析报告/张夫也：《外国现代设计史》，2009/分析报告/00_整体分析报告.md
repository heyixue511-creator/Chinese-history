## 一、著作定位与成书脉络

本书是张夫也长期在中央工艺美术学院及后来的清华大学美术学院讲授"外国设计史"公共课的教材性成果。后记自述：该课程所用教材"皆为笔者个人手书整理，编写而成"，资料搜集期"幻灯片都是一张张地拍摄，一枚枚地加边框，标图注"，耗时艰辛；因有感于"迄今为止社会上为数不少的西方现代设计史教材和书籍，都难以适合我们的学生使用，庞杂的内容，混乱的结构"，故编写本教材，力求"以有限的篇幅，勾画出一条较为清晰的外国设计发展史的脉络"（C-L680-684）。后记落款"张夫也 2008年金秋时节于北京清华园"（C-L684），与2009年3月出版时间吻合。

著者的身份背景（清华大学美术学院教授、博士生导师，曾主持"外国工艺美术史"国家级精品课程等）在本教材中的体现是：全书以**运动/风格史**为主线，兼具**国别设计史**视角，图版量极大，正文与图注并重，属典型的"图文并茂"式设计史教材（图注占据 clean 版相当篇幅）。其书末参考文献兼收西文与中文学术文献（C-L677），显示其知识来源的跨语种特性。

## 二、全书主旨与核心命题

### 全书主旨
"本书的主要内容为19世纪工业革命以来的外国近现代设计艺术发展史及风格解析"（C-L5）。全书按时间顺序梳理自19世纪中叶艺术与手工艺运动至20世纪90年代后现代主义诸风格的外国（以欧美日为主）现代设计史，核心是回答"现代设计如何从手工艺中脱胎、如何为机器时代与大众社会服务、如何形成各国独特风格"。

### 核心命题
1. **设计史是"美术与技术结合"逐步实现的历史**。从莫里斯、鲁斯金首倡"美术与技术结合"（C-L707），到威尔德"技术是产生新文化的重要因素"（C-L756），到1914年德国工业同盟关于标准化的大论战"真正在理论上消除了现代设计认识上的障碍"（C-L995），再到包豪斯"艺术与技术的统一"（C-L1010）与乌尔姆"设计就是科学技术"（C-L56），构成一条"技术/理性不断战胜"的历史线索。
2. **现代主义设计的本质是民主性、工业性与功能主义/理性主义两大内核**。"现代主义设计是民主主义的"（C-L996）、"建立在大工业机器生产之上"（C-L997）、"产生了一种全新的设计美学观，即'机械化时代的设计美学'"（C-L998），其两大内核为功能主义与理性主义（C-L999）。
3. **设计是国家发展竞争与企业生存竞争的工具**。美国"市场竞争机制在发展美国设计中起到了决定性的作用"（C-L99）；英国"政府扶持型的发展模式"（C-L216）；日本"政府对工业设计发展的扶持、干预行为，在资本主义国家是极罕见的"（C-L372）；德国"乌尔姆—博朗合作模式"（C-L81）。
4. **各国设计的民族特色是设计史的重要价值所在**。意大利"设计师的哲学或意识形态"（C-L353）、日本"现代设计与传统设计双轨并行"（C-L413）、斯堪的纳维亚"传统手工艺与现代大工业相结合"（C-L421）、西班牙"赋予设计以情怀""出自传统的现代精神""本土化与国际化并存"（C-L546-553）。
5. **设计应"为人"服务**。"设计的最终目标和最高境界是彻底解决如何使人类的生存环境和生活方式更为合情、合理"（C-L22）；德雷福斯"为人设计"（C-L119）、日本"以人为中心的设计思想"（C-L398）等反复出现。

### 主题线索（双线并行）

## 六、材料与方法

### 史料类型
1. **作品实物史料（图注为主）**：全书图版极其丰富，每幅图注注明作品、设计师、年代、国家及材质工艺（如"图7-2 福特T型轿车，亨利·福特设计，1908年，美国底特律"（C-L95）、"图8-3木质休闲椅，查尔斯和雷·伊姆斯设计，1945年，美国"（C-L170）），构成以作品为中心的实证叙述。
2. **文献与理论著作引用**：帕巴奈克《为真实世界的设计》（C-L20）、森培尔《科学·工艺·美术》与《工艺与工业美术的式样》（C-L185）、格罗皮乌斯《全面建筑观》（C-L924）、柯布西耶《走向新建筑》（C-L928）、密斯多篇论文（C-L932）、德雷福斯《为人的设计》与《人体度量图表》（C-L197）、《乌尔姆简章》（C-L63）、马尔多纳多1987年回忆（C-L67）等。
3. **机构与制度史料**：德国工业同盟1914年论战（C-L995）、英国DIA报告《现代工业设计》（C-L216）、COID三部门制（C-L216）、美国"计划废止制"（C-L161）、日本JIS标准与通产省机构（C-L367-C-L371）等。
4. **统计数据**：如罗维"冷点"冰箱5年内由15000台增至275000台（C-L138）、菲亚特1961年占意大利市场90%（C-L302）、索尼随身听"Walkman"（C-L384）、1960年日本电视产量357万台居世界第二（C-L367）等。

### 引用方式
教材式叙述，以"×××（人名，生卒年）""▲图N-M"的格式组织；重要观点常以引语形式直接摘录（如威尔德"技术是产生新文化的重要因素"（C-L756）、艾舍《包豪斯与乌尔姆》引文（C-L58）、山崎实六项建筑主张（C-L617-C-L621））。

### 论证方法
- **定义—背景—人物—作品—小结**的章内逻辑；
- 广泛使用**列表归纳**（如现代设计的范畴十项（C-L30）、计划废止制三特征（C-L162）、风格派基本原则四条（C-L943）、包豪斯成果七条（C-L1067-C-L1069））；
- 善用**比较**：德国与美国设计师之别（C-L107-C-L108）、奥地利与其他国家新艺术之别（C-L757）、装饰艺术与现代主义及新艺术之别（C-L811-C-L812）、英国与美国设计发展模式之别（C-L216-C-L219）。

## 七、核心论辩

1. **手工vs机械**：艺术与手工艺运动"将手工艺推向了工业化的对立面""使英国的工业设计革命推迟了"（C-L708）——这是全书对反机械立场的总批判；而威尔德、德国工业同盟、包豪斯、乌尔姆则代表了逐步肯定机械的正面路线。
2. **功能vs形式/市场**：美国"将现代设计提出的'形式服从功能'原则转换为'形式追随市场'"（C-L99）；"计划废止制""是设计受经济利益驱使的极端体现"（C-L162）；罗维"最美丽的曲线是销售上涨的曲线"（C-L140）——全书对美国商业性设计持明显的批判立场。
3. **国际主义vs民族特色**：德国高度理性化设计"冷漠"（C-L81）vs意大利"强烈的个性色彩"（C-L327）vs日本"周到、细腻、精致、小巧"（C-L414）vs北欧"人情味"（C-L484），构成民族风格论的核心张力。
4. **现代vs后现代**：第4章确立现代主义"民主、理性、功能"的正统价值，第14章则展示后现代主义对其"隐喻、象征、多义"的批判与解构（C-L599-C-L672），并评价新现代主义"是现代主义设计一种未来的发展方向"（C-L672）。
5. **艺术与科学的学科之争**：包豪斯"在艺术与科学技术、在造型与设计之间摇摆"（C-L57），乌尔姆以"设计就是科学技术"彻底转向（C-L56）——这一论辩贯穿第5、6章。

## 八、理论资源与学术谱系

1. **帕巴奈克设计伦理传统**：导论以帕巴奈克《为真实世界的设计》为理论支点（C-L20），与全书"为人设计""设计伦理""和谐化设计"（C-L30）一脉相承。
2. **沙利文—功能主义谱系**："形式追随功能"自1739年格林诺斯提出、沙利文确立、赖特质疑（C-L21），下接现代主义功能主义内核（C-L999），构成全书最重要的理论红线。
3. **莫里斯—鲁斯金工艺美术传统**：第1章以鲁斯金"美术必须与技术结合"、莫里斯复兴手工艺（C-L185-C-L186、C-L291-C-L294）为起点，其影响在第2、4章不断回响。
4. **现代主义大师理论**：格罗皮乌斯《全面建筑观》"功能第一、形式第二"（C-L924）、柯布西耶"机械美学"（C-L928-C-L929）、密斯"少则多"（C-L933、C-L654）。
5. **德语世界学术资源**：乌尔姆一章大量引用艾舍、马尔多纳多言论及《乌尔姆简章》，并提及阿多诺、哈贝马斯（C-L67），显示法兰克福学派批判理论的影响。
6. **中国学界参照**：书末参考文献收有王受之《世界现代设计史》、陈鸿俊《现代设计史》等国内同行著作（C-L677），可见其写作处在中国现代设计史书写初兴的知识语境中。

## 九、语言与写作风格总貌

1. **教材化、条目化**：大量"①…②…③…"编号列举（如现代设计范畴十项（C-L30）、新建筑六原则（C-L916-C-L918）、包豪斯成果七条（C-L1067-C-L1069）），便于记忆与教学。
2. **概括性定评句**：章末小结多用高度凝练的判断句，如"德国产品几乎成为优秀产品的同义词"（C-L81）、"美国是……设计教育试验的最佳土壤"（C-L145）、"意大利设计是'杰出设计'的同义词"（C-L265）。
3. **人物—作品捆绑叙述**：每位设计师以"生卒年＋代表作＋风格特征"的固定句式介绍，如德雷福斯"从内到外"设计原则（C-L114）、盖迪斯七步设计程序（C-L121）。
4. **引语点缀**：直接引语增强可读性与权威性，如威尔德"线条是一种力量"（C-L802）、罗维"销售上涨的曲线"（C-L140）、尼迈耶尔"当一种形式变为美，它即成为一种功能"（C-L626）。
5. **少量文风瑕疵**：偶见笔误与译名不统一，如"对干设计的技术层面较为忽略"（C-L20）、"波晋设计的色彩艳俗"（C-L631）、"篷车"等；人名译法前后不一（如"麦金托什/马基斯特列蒂"）。

## 十、成就与限度

### 成就
1. **体系完整**：以运动史+国别史双线贯通19世纪中叶至20世纪90年代，覆盖欧美日主要设计现象，适合教学。
2. **图版史料丰富**：数百幅作品图注（clean 版中图注占比很高），为读者提供了扎实的实物依据。
3. **概念梳理清晰**：核心运动与风格均有明确的时间界域、特征归纳与小结（如装饰艺术运动"三个结合"（C-L908）、斯堪的纳维亚风格六特征（C-L484））。
4. **批判视角明确**：对"计划废止制"、即时消费主义（C-L162-C-L163）、艺术与手工艺运动的历史局限（C-L708）有清醒批判。

### 限度
1. **原书本身的技术缺陷**：2009年版正文存在缺页（第14章章首缺失，源L264/L266"原书缺页"），且 OCR 源页码乱序，影响阅读连续性；本报告已如实标注。
2. **史实细节偶误**：如威尔德生卒标注为"1863—1905"（C-L752，实为1863—1957）；尼佐罗译名与拼写（C-L317）不一致；个别统计数据缺出处。
3. **国别覆盖面不均**：以欧洲与美国、日本为主，对俄罗斯、东欧、拉美等国着墨少；第13章西班牙篇幅相对独立，但第14章缺页使后现代主义部分不完整。
4. **理论深度有限**：作为教材，多为事实性归纳，对设计的社会—经济机制的分析以概括为主，较少展开学理争鸣。
5. **作者自谦**："目前的这一稿，并不是我最满意的一种程度""仍有不少问题尚待进一步商榷"（C-L683）。
