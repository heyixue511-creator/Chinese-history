# 00 方法与规则

**书名**：杭间《设计道：中国设计的基本问题》（2008）
**分析基准**：`00-book\杭间：《设计道：中国设计的基本问题》，2008_clean.md`，共 508 行，行号 L### 一律指 clean 版。

本文件界定"知识涌现分析"的方法论规则，作为 01-04 号报告的统一口径。分析基于逐行通读后的语义判断，全部链接、簇、命题均附 clean 版行号证据。

---

## 一、层级定义

知识涌现分析采用三级层级：

1. **知识元（Knowledge Element）**：六类实体——人物、著作/作品、概念、机构、地点、事件。每一知识元以其在文中的"语义载荷"（做什么、指什么、为何存在）为内容，不以其名称重复次数为限。六类实体清单见 `01_知识元语意分析.md`。
2. **Topic（话题簇）**：由强关联知识元构成的连通簇。判定基准：簇内任意两元之间存在语义链接（见下），且簇内链接数显著高于与簇外链接数。
3. **Theme（高层语义域）**：多个 Topic 聚合而成的高层主题域，对应全书的宏观论证板块。聚合基准：共享枢纽知识元、桥接知识元或共同的上位命题。

## 二、九种语义链接判定标准

对任意两知识元 A、B，依据以下 9 种链接类型判定关系。每条附判据与例。

| 类型 | 符号 | 判据 | 例（行号） |
|---|---|---|---|
| 因果 | A→B | A 的发生/属性导致 B 的发生/属性 | "工艺美术"退出 → 名词兴衰（L10）；机械化 → 手工艺让位（L14） |
| 条件 | A⇒B | A 是 B 成立的必要/充分前提 | 社会稳定 ⇒ "前现代的合目的性"（L62）；工业化 ⇒ 现代设计产生（L42、L105） |
| 对比 | A↔B | 两元在文中被并置对照 | 工艺史↔设计史（L104-L105）；现代主义↔后现代主义（L133） |
| 隶属 | A⊂B | A 是 B 的成员/子类 | "图案"⊂"设计"的历史译名（L19）；产品设计/视觉传达/环境设计⊂现代设计（L26） |
| 时序 | A≻B | A 先于 B，构成历史顺序 | 原始合目的性≻前现代合目的性≻现代合目的性（L57-L68）；工艺美术≻艺术设计（L10） |
| 空间共现 | A≈B | 同处一个事件/语境，无因果但同现 | 河姆渡≈殷墟≈先秦工艺（L96）；上海≈租界≈洋货（L390） |
| 属性 | A:B | B 是 A 的属性/特征 | 设计:技术维度、文化维度（L34、L36）；设计链:共生性/生态性/人的主体性（L179-L186） |
| 论证支撑 | A⇐B | B 被引用以支撑 A 的论证 | "脱域"⇐吉登斯（L123）；"消费社会"⇐鲍德里亚"摆设"（L131） |
| 同域 | A∼B | 同属一个论域、互为语境，无前 8 类明确关系 | 时尚∼风格（L322）；工具∼垃圾（L410）；数字化∼全球化（L366） |

> 规则：任一链接至少满足上述一种判据；同时满足多种判据时，取因果 > 条件 > 时序 > 论证支撑 > 其他 的优先级记录主类型，并在清单中注明兼属。

## 三、涌现指标定义

1. **节点度 k**：某知识元拥有的直接语义链接数（不区分方向）。k≥8 记为高枢纽。
2. **桥接值 b**：某知识元作为"不同 Topic 之间唯一切换点/中介点"的连接对数。b≥2 记为高桥接。度量方法：在 Topic 划分后，统计经该元连通的跨簇节点对。
3. **簇识别**：以强连通为准则——簇内任意两元至少存在一条（允许经由其他元中转的）有向语义链。人工逐簇核验后确定 Topic 边界。
4. **内聚度 c**：簇内实际链接数 / 簇内可能链接数（n(n-1)/2）的简化测度，取 0-1。
5. **涌现强度 S**：对一级涌现结构，S = 簇平均内聚度 × 簇均节点数 × 桥接覆盖因子（连接该簇与外部的高桥接元数/簇元数）。用于区分强涌现（S≥0.6）、中涌现（0.3≤S<0.6）、弱涌现（S<0.3）。
6. **一级/二级涌现**：一级涌现 = 由知识元直接构成的 Topic 及簇内组合命题（E1…En）；二级涌现 = 由 Topic 聚合成的 Theme 及其跨簇综合命题（P1…Pn）。

## 四、分析流程

1. 从全文中提取六类知识元（见 01 报告）；
2. 按九种链接类型构建语义链接清单（见 02 报告），识别枢纽与桥接；
3. 依强连通原则聚簇成 Topic，聚合 Theme，计算内聚度与涌现强度（见 03 报告）；
4. 归纳结构发现、潜在链接与跨主题综合命题，画出层级图谱（见 04 报告）。

## 五、证据规范

1. 每条链接、每个簇、每个命题均须列出 clean 版行号（单行或区间）；
2. 对原文未明确论及但语义可推的"点到未论"链接，一律标注"推断"并注明证据缺口；
3. 对原文存在内部张力或矛盾之处（如 III 章"乌有乡"既赞又批），在簇与命题中并列正反证据，不作单边裁定；
4. 全部分析为语义阅读结果，不含任何统计或程序计算，数值指标为人工枚举的简化度量，仅作相对比较。
