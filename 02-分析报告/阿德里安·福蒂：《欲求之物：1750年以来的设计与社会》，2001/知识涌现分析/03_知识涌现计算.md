## 四、一级涌现结构（E1…E5）

**E1 设计=观念物化**
生成机制：由 A 区链接（设计→观念物化，观念+物质⇒造型）及全书结语（L132、L117）直接涌现。S=40（高）。
证据：L117、L114、L132、L46、L92。

**E2 企业家决定设计**
生成机制：由 B 区链接（韦奇伍德→工业设计师、企业家→设计决策、棉布印花商、利兰）涌现。S=20（高）。
证据：L132、L212-245、L223-226。

**E3 观念由商业与设计共同建构**
生成机制：C/E 区链接的聚合（卫生观念→商品化、省力神话→设计巩固），结合 L4"当广告人、设计师和制造商开始使用卫生的图像时……"与 L46、L111。S=30（高）。
证据：L4、L46、L98、L101、L111、L114。

**E4 机构以设计建构认同**
生成机制：F 区链接（企业形象→机构认同、合并⇒统一设计、系统感知）涌现。S=18（高）。
证据：L120、L123、L126-127。

**E5 设计师话语受意识形态制约**
生成机制：H 区链接（收藏市场→设计师研究、展览→个人叙事、创作自主神话）涌现。S=20（高）。
证据：L132、L121。

## 五、二级涌现命题（P1…Pn）

| 命题 | 生成机制 | 强度 |
|---|---|---|
| P1 欲望的生产循环：观念→设计→欲望→消费→观念强化，构成"欲求之物"的自我再生产 | 组合 E1+E3+消费结构变量 | S≈24（高） |
| P2 经济结构（负荷率、电价、仆人供给、收入）是观念宣传与设计形态的约束变量 | 组合 E2+电气簇/家务簇经济链接 | S≈15（中-高） |
| P3 广告、设计、媒体、展览共同构成"意义工厂"，系统性地灌输观念 | 组合 E3+E5+话语簇 | S≈15（中-高） |
| P4 "洁净"成为现代中产阶级的身份符号并被商品化为美学 | 组合 E3+社会差异簇（阶级、性别） | S≈12（中） |
| P5 设计史的个人叙事是意识形态的产物，须以观念分析替代 | 组合 E5+话语簇（佩夫斯纳/吉迪恩对照） | S≈12（中） |
| P6 现代性通过日常物品的"未来形象"自我表征（技术进步→物品→未来许诺） | 组合 E1+乌托邦簇/技术未来主义 | S≈12（中） |

### P1 的完整生成链（示例展开）
负荷率低→电力贵（L67）→供电业需家庭负荷（L71）→生产家用电器（L71）→电器需"现代"形象（L81）→形象唤起对未来的欲求（L92）→购买电器→负荷率改善→更多资本投入→更多电器（L73）。此环把 TH2（经济）与 TH1（观念）接成闭环，涌现出"欲望的工业化循环"。

## 六、客观性核对与反例

| 涌现结构 | 反例/边界 | 说明 |
|---|---|---|
| E1 | "设计如果没有体现目标人群所普遍持有的观念，那么它就无法奏效"（L132）——观念的来源在目标人群而非纯商业 | 边界：观念不全由商业生产，消费者/公众也是观念持有者 |
| E2 | 作者承认设计师"这种能力理应受到赞许"（L132） | 边界：企业家决断不否定设计师的技巧价值 |
| E3 | "认为卫生美学的发展是单方面的事情，完全由制造商推动，这是一种谬误，因为消费者对于洁净也有恳切的诉求"（L46） | 边界：观念建构是双向的，非单向灌输 |
| E4 | "破败不堪、凑合的修补、员工中的低落士气都已经侵蚀了这种远见的力量"（L129） | 边界：企业形象的效力随时间衰减 |
| E5 | "尽管一些设计师承认传播了一些他们无法左右或者无法完全理解的观念"（L132） | 边界：并非所有设计师都沉浸于全能神话 |
| 全书性边界 | 作者批判吉迪恩"观念悬空"时，自身"观念"概念也未给出完备的生成机制（L132）；本书以英国为主的地理局限；1986 年成书未涉及数字化时代 | 认识论边界：观念概念的操作性定义留白 |

**文本内部矛盾核查**：未见与上述涌现结构直接矛盾的文本；最接近的矛盾是"消费者中心设计"部分（L113-117）中，作者既承认消费者需求真实存在，又指出这些需求常是"劝说/虚构问题"的产物（L114）——本书的处理是将其视为"真实需求与观念灌输的不可区分"，这一矛盾被作者明确意识到并如实呈现（L114"我们几乎不可能说清楚……究竟多大程度上是顾客的独立意愿，还是说这种需求是劝说的产物"）。
