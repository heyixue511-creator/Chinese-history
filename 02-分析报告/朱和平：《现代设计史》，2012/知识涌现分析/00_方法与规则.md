# 知识涌现分析：00 方法与规则

## 一、总体思路

本知识涌现分析将《现代设计史》（朱和平主编，2012）全书正文（L1-L753）视为一个**知识语义网络**，从文本中提取六类知识元（人物、著作/作品、概念、机构、地点、事件），按语义链接规则将其组织为三层结构：

- **知识元**（Knowledge Element）：六类实体，是网络的最基本节点；
- **Topic（强连通簇）**：由语义上强相关的知识元构成的高内聚簇；
- **Theme（高层语义域）**：由若干 Topic 聚合而成的高层主题域。

## 二、层级定义

### 1. 知识元（六类）
| 类别 | 定义 | 全书代表 |
|---|---|---|
| 人物 | 设计师、艺术家、理论家、政治家等 | 莫里斯、格罗佩乌斯、罗威、索特萨斯 |
| 著作/作品 | 著作、设计作品、建筑、海报等 | 《走向新建筑》、红蓝椅、雪梨歌剧院 |
| 概念 | 设计术语、思潮、方法 | 功能主义、国际主义风格、计划废止制 |
| 机构 | 设计组织、企业、学校、政府机构 | 德国工业同盟、包浩斯、百灵公司 |
| 地点 | 城市、国家、区域 | 伦敦、巴黎、威玛、米兰 |
| 事件 | 展览、运动、战争、政策事件 | 1851 博览会、1914 标准化论战、1972 被炸 |

### 2. Topic（强连通簇）
- 识别标准：簇内知识元之间至少存在 2 条以上的语义链接（强连通），簇内链接数 ≥ 节点数，且与簇外链接数相对较少。
- 全书拟识别 6-15 个 Topic。

### 3. Theme（高层语义域）
- 由语义相近、共享枢纽知识元的多个 Topic 聚合而成，全书拟识别 3-5 个 Theme。

## 三、9 种语义链接判定标准

| 类型 | 符号 | 判据 | 实例（本书） |
|---|---|---|---|
| 因果 | → | A 的发生导致 B 的发生 | 工业革命 → 现代设计产生（L23-L24） |
| 条件 | ⇒ | A 是 B 成立的前提/条件 | 接受机器生产 ⇒ 现代主义设计生命力（L266） |
| 对比 | ↔ | A 与 B 并列对照、相反或互补 | 现代主义 ↔ 后现代主义（L622） |
| 隶属 | ⊂ | A 属于 B 或 A 是 B 的组成部分 | 风格派 ⊂ 现代主义设计运动（L290） |
| 时序 | ≻ | A 在时间上先于 B | 工艺美术运动 ≻ 新艺术运动（L139） |
| 空间共现 | ≈ | A 与 B 在同一地点/区域共现 | 米兰 ≈ 孟斐斯集团（L676） |
| 属性 | : | A 具有属性 B | 包浩斯 : 双轨制教学（L381） |
| 论证支撑 | ⇐ | A 为论点 B 提供支撑证据 | 《为现实世界的设计》 ⇐ 设计目的论（L546） |
| 同域 | ∼ | A 与 B 属于同一领域/范畴 | 贝伦斯 ∼ AEG 企业形象（L287） |

## 四、涌现指标

| 指标 | 定义 |
|---|---|
| 节点度 k | 某知识元直接相连的链接数，衡量局部重要性 |
| 桥接值 b | 某知识元连接不同簇/域的链接数，衡量全局中介性 |
| 簇识别 | 用强连通条件识别 Topic |
| 内聚度 | 簇内链接数 / 可能最大链接数 |
| 涌现强度 S | 该簇/主题相对其构成知识元之和所产生的新语义增量 |
| 一级涌现 | Topic 层涌现：由知识元链接形成主题语义 |
| 二级涌现 | Theme 层涌现：由 Topic 聚合形成全书级命题 |

## 五、证据规范

- 所有链接均需标注 clean 版行号证据（L###）；
- 行号必须与源文件实际内容对应；
- 无法实证的「点到未论」链接单独标注为证据缺口（C 系列），不混入实证链接；
- 网络统计以人工计数为主，注明估算依据。
