# NN 专项报告与实体总索引

## 第一部分：专项报告

### 一、语言

- 全书以**繁体中文**撰写，为台湾五南版教材文体（L4-L5、L8）。
- 语体正式、教学导向强，句式为书面语长句，逻辑连接词密集（「一方面……另一方面」「正因如此」「因此」「然而」「综上所述」）。
- 专名处理：外文人名、机构、作品名普遍以「中文译名＋（英文原名）」并列出现（如 De Stijl、Bauhaus、Art Deco、JIDPO、G-Mark、Isotype 等，L290、L370、L478、L509），便于识别。
- 术语以两岸通行设计史术语为主，兼用港台译名（「包浩斯」「威玛」「德绍」「麦金托什」「凡·德·威爾德」「高第」「雪梨歌剧院」「庞毕度中心」等）。
- 部分用词反映中国内地学术习惯混入台湾版（如「造物」「工艺美术」「设计艺术学」），但整体保持台湾版用字。

### 二、文风

- **导读式**：每章章首设「主要内容」「本章重点」（L16、L80、L139、L181、L266、L367、L425、L516、L616）。
- **分点化**：大量使用「1.2.3.」「（1）（2）（3）」的条列式表述（如工业革命五方面前提 L85-L98、包浩斯三阶段 L385、后现代主义四特征 L622）。
- **叙述—议论结合**：以历史叙述为主，夹叙夹议，作者立场鲜明（如对工艺美术运动「前瞻性工作」与「时代局限」的并置评价，L104）。
- **案例密集**：每节嵌大量具体设计作品并附插图编号（图2-1……图9-48）。
- **总结性收束**：节末常以「总之」「纵观」「因此」收束要点。

### 三、修辞方式

- **比喻**：「设计史是一部艺术与技术的动态平衡史」「功能与装饰是设计这架天平上的两个砝码」（L16）；「庞毕度中心是一座文化工厂或文化超级市场」（L643）；「建筑是一个大机器」（L643）。
- **排比/并列**：后现代主义与后现代对比表的六维排比（L622）；绿色设计三个 RE 原则（L682）。
- **引用**：大量引设计师原话（威尔德「线条就是力量」L151、柯布西耶「住房是居住的机器」L311、罗威「最美的曲线是销售上升的曲线」L354、索特萨斯「灯诉说着故事」L534、贝聿铭「让光线来做设计」L643）。
- **反问/感叹**：末章趋势论述中语气宣讲化（「一个不重视设计的国家是没有希望的」L711）。

### 四、史料使用方式

1. **人物史料**：以设计师生平、教育经历、职务、生卒年为基本单元（如贝伦斯 L286-L287、格罗佩乌斯 L375-L376）。
2. **作品史料**：以具体设计作品为载体，配插图号（如红蓝椅 L296、巴塞隆纳椅 L405、Tizio 灯 L534）。
3. **机构与制度史料**：设计组织、院校、政府机构、奖项（德国工业同盟 L284、包浩斯 L370、COID L487、G-Mark L478、金圆规奖 L469）。
4. **文献史料**：引用设计理论著作（《小艺术》L104、《走向新建筑》L311、《建筑的复杂性与矛盾性》L625、《为现实世界的设计》L546）。
5. **事件史料**：重要设计事件与政治事件交织（1851 博览会、1914 标准化论战、1972 普艾特伊戈被炸、1961 加加林太空飞行）。
6. **经济数据**：工业产量、贸易份额、市场数据（德国钢产量 L281、日本电视产量 L540、雪佛兰车型组合 L450）。
7. **参照史料**：书末参考文献列出中英文书目（L745-L749）。

### 五、阐述方法

- **历史分期叙述法**：全书按 8 个历史时期组织。
- **国别并列法**：同一时期下逐国展开（法/比/西/奥/英/美等）。
- **因果分析法**：分析工业革命—设计变革、消费—设计、科技—审美变化的因果关系。
- **比较对照法**：工艺美术 vs 新艺术（L142）、装饰艺术 vs 现代主义（L206-L207）、现代主义 vs 后现代主义（L622）。
- **正反评价法**：对计划废止制、包浩斯、普普、后现代主义均列正反两面。
- **概念辨析法**：「设计艺术/艺术设计」（L48）、「后现代/后现代主义」（L622）、「有機設計」（L512-L513）。

### 六、推演逻辑

- **总—分—总**：绪论立纲 → 各章分述 → 末章总结趋势。
- **由因到果**：生产方式 → 设计危机 → 运动发生 → 成就与局限。
- **由理论到实践**：定义特征 → 代表人物 → 代表作品。
- **历史循环视角**：装饰 → 反装饰 → 重拾装饰的辩证摆动（L16、L266、L622）。

### 七、文字风格总体评价

全书文字**平实、规范、条理清楚，教学价值高**；但原创分析有限，叙述成分大于论证成分；部分章节（尤其末章趋势部分）偏宣讲性；OCR 层面存在少量错别字与译名不一致（如「中国」应为「全国/本國」、「鸟爾姆」应为「乌尔姆」、Bauhaus 拼写 Buahus 于 L272 等）。
