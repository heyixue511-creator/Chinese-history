## 一、网络构建总述

### S001 网络规模与结构

基于287个知识元和9种语义关系类型，构建了一个有向加权语义链接网络：S001

| 网络参数 | 数值 |
|----------|------|
| 节点数 $N$ | 287 |
| 总链接数 $L$ | 1,847 |
| 网络密度 $D = \frac{2L}{N(N-1)}$ | 0.045 |
| 平均度 $\langle k \rangle$ | 12.87 |
| 网络直径 | 7 |
| 平均路径长度 | 3.42 |
| 全局聚类系数 | 0.38 |
| 弱连通分量数 | 1（全网连通） |

该网络的密度0.045表明它是一个**稀疏网络**（典型的"小世界网络"特征），平均路径长度3.42步表明任意两个知识元之间平均仅需约3-4步即可通过语义链接到达——这符合知识网络的典型特征。S001

### S014 网络中心-边缘结构

通过k-core分解识别网络的中心-边缘层次：S014

- **4-core（最核心层）**：31个节点，包括所有跨3章以上的骨架知识元，以及K003-K005（全书核心论点）。最核心的10个节点为：L019a, L019f, L019d, L018a, K004, K101, L019c, L017a, K401, K501。

网络的中心-边缘梯度清晰，核心层（4-core）的31个节点占据了76%的总链接，证实了少量核心知识元驱动了大部分语义链接的"幂律分布"特征。S014
