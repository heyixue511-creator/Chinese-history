# 00 方法与规则

## 一、知识涌现分析的总体定位

### L001 分析目标

本分析以Tunstall《Decolonizing Design: A Cultural Justice Guidebook》的全书分析报告（00-05章+NN专项报告）为源数据，运用知识元语意分析与语义链接网络方法，计算并发现"知识涌现"——即存在于各章分析报告之中、但未被任何单一分析报告明确陈述的跨章高阶知识。L001

### L002 知识涌现的操作性定义

**知识涌现**（Knowledge Emergence）在本分析中指：当一个知识元集合中的若干知识元通过语义链接形成网络结构后，网络的拓扑性质（聚类系数、中心性、路径长度、桥接关系等）所揭示的、无法从任一孤立知识元直接读出的"结构性知识"。涌现知识具有以下特征：L002

1. **跨章性**：必须涉及至少两个不同章节的知识元
2. **结构性**：不是对已有论点的重述，而是从网络结构中"计算"出来的关系模式
3. **可验证性**：可以通过回溯知识元和语义链接的来源数据进行验证
4. **新颖性**：在源分析报告的明确陈述之外，提供了新的洞察

### L003 知识元（Knowledge Unit）的定义

知识元（缩写KU）是本分析的最小知识操作单元。一个知识元是源分析报告中的一个**可独立引用的论断单元**，满足以下条件：L003

1. **有明确的L###编号**：继承源分析报告中的实体编号体系
2. **具有可陈述的语义内容**：可以表达为"主体-谓词-客体"或"概念-属性-值"三元组
3. **具有章节归属**：明确属于某一章的分析报告
4. **具有类型归属**：属于六类实体之一（人物、机构/组织、理论/概念、历史事件/政策、设计对象/技术、地点/空间）或论点/论证类

### L004 知识元的分类体系

本分析将知识元分为两大类：L004

**A类——实体知识元（Entity KU）**：直接继承自源分析报告的六类实体清单：
- A1 人物实体（Persons）
- A2 机构/组织实体（Institutions/Organizations）
- A3 理论/概念实体（Theoretical Concepts）
- A4 历史事件/政策实体（Historical Events/Policies）
- A5 设计对象/技术实体（Design Objects/Technologies）
- A6 地点/空间实体（Places/Spaces）

**B类——论点知识元（Thesis KU）**：从各章"关键论点"和"核心论题"中提取的可独立陈述的论断：
- B1 核心论题（Chapter Core Thesis）
- B2 关键论点（Key Argument）
- B3 因果/转折关系（Causal/Turning Relation）

### L005 语义链接（Semantic Link）的定义

语义链接是两个知识元之间具有语义内容的有向关系。每条语义链接表述为：L005

$$\text{Link} = (\text{KU}_i, \text{KU}_j, \text{RelationType}, \text{Weight})$$

其中：
- $\text{KU}_i$ 为源知识元
- $\text{KU}_j$ 为目标知识元
- $\text{RelationType} \in \{\text{论证支撑, 案例例证, 理论应用, 因果关联, 对比/对立, 人物-机构隶属, 概念-案例实现, 历史-当代延续, 跨章预演/呼应}\}$
- $\text{Weight} \in [0, 1]$ 为语义关联强度

### L006 语义链接的九种关系类型

| 编号 | 关系类型 | 定义 | 示例 |
|------|----------|------|------|
| R1 | 论证支撑（argues_for） | 知识元B为知识元A的论证提供支撑 | 论点L107 → 理论框架L019a |
| R2 | 案例例证（instantiated_by） | 概念/论点被具体案例所例证 | L019f可能性模型 → NN01a对话案例 |
| R3 | 理论应用（applies） | 理论框架被应用于分析某对象 | L019a三元框架 → 原住民政策分析 |
| R4 | 因果关联（causes） | 知识元A导致/引发知识元B | 历史事件 → 法律/政策后果 |
| R5 | 对比/对立（contrasts_with） | 两个知识元形成对比或对立关系 | 包豪斯原则 vs. 原住民原则 |
| R6 | 人物-机构隶属（affiliated_with） | 人物实体与机构实体之间的隶属关系 | Tunstall → OCAD U |
| R7 | 概念-案例实现（realized_by） | 概念通过制度/设计实践获得实现 | Supertoken → OCAD U集群招聘 |
| R8 | 历史-当代延续（continues_in） | 历史事件在当代有延续性表现 | 1681法律 → 当代白人至上文化 |
| R9 | 跨章预演/呼应（foreshadows / echoes） | 前章内容预演后章主题，或后章回应前章 | Ch1伦理 → Ch5经济计算 |

## 二、分析流程与步骤

### L007 五步分析流程

```
Step 1: 知识元提取
  ├── 从源分析报告中提取A类实体知识元（继承L###编号）
  └── 从源分析报告中提取B类论点知识元（新建K###编号）
        ↓
Step 2: 知识元语意分析
  ├── 对每个知识元进行"主体-谓词-客体"语义三元组分解
  ├── 计算知识元的语义向量（基于其与核心主题的相关性）
  └── 识别知识元的跨章复用频次
        ↓
Step 3: 语义链接网络构建
  ├── 建立知识元之间的语义链接（9种关系类型）
  ├── 计算链接权重
  ├── 构建邻接矩阵
  └── 可视化网络拓扑结构
        ↓
Step 4: 知识涌现计算
  ├── 计算网络全局指标（密度、平均路径长度、聚类系数）
  ├── 计算节点中心性指标（度中心性、中介中心性、特征向量中心性）
  ├── 识别涌现结构（桥接节点、结构洞、社团划分）
  └── 生成涌现假设
        ↓
Step 5: 知识发现报告
  ├── 验证涌现假设（回溯源数据）
  ├── 提炼知识发现（≥10条）
  ├── 评估发现的置信度
  └── 提出研究建议
```

## 三、计算规则

### L008 链接权重计算规则

语义链接的权重 $w_{ij}$ 由以下公式计算：

$$w_{ij} = \alpha \cdot \text{Freq}(KU_i, KU_j) + \beta \cdot \text{TypeStrength}(R) + \gamma \cdot \text{CrossChapter}(KU_i, KU_j)$$

其中：
- $\text{Freq}(KU_i, KU_j)$：两个知识元在源文本中的共现频次（归一化至[0,1]）
- $\text{TypeStrength}(R)$：关系类型的基础强度（R4因果 > R9跨章呼应 > R1论证支撑 = R7概念-案例实现 > 其他）
- $\text{CrossChapter}(KU_i, KU_j)$：若两个知识元来自不同章节则为1，同章为0
- $\alpha = 0.4, \beta = 0.3, \gamma = 0.3$

### L009 节点中心性计算规则

**度中心性（Degree Centrality）**：
$$C_D(i) = \frac{\sum_j a_{ij}}{N - 1}$$

其中 $a_{ij}$ 为邻接矩阵元素（存在链接为1，否则为0），$N$ 为节点总数。

**中介中心性（Betweenness Centrality）**：
$$C_B(i) = \sum_{s \neq i \neq t} \frac{\sigma_{st}(i)}{\sigma_{st}}$$

其中 $\sigma_{st}$ 为节点s到t的最短路径总数，$\sigma_{st}(i)$ 为经过节点i的最短路径数。

**特征向量中心性（Eigenvector Centrality）**：
$$C_E(i) = \frac{1}{\lambda} \sum_j a_{ij} \cdot C_E(j)$$

其中 $\lambda$ 为邻接矩阵的最大特征值。

### L010 知识涌现的判定规则

一个知识单元组合被视为"涌现知识"当满足以下至少两个条件：L010

1. **跨章桥接涌现**：该知识涉及的知识元分别来自3个及以上不同章节，且这些知识元之间的链接构成至少一个三角形闭合结构（聚类系数>0）
2. **结构洞涌现**：某知识元在网络中占据结构洞位置（中介中心性>均值+1标准差），连接了原本不直接相连的知识元群落
3. **隐含因果涌现**：通过路径分析发现A→B→C的因果链，但A→C的直接关系未被源文本明确陈述
4. **概念融合涌现**：两个来自不同章节的概念知识元在网络中共享至少3个共同的相邻节点，暗示它们之间存在未被明确陈述的语义重叠
5. **对偶结构涌现**：两个知识群落呈现镜像对称的对偶结构（如"批判-重建""伦理-经济""技术-种族"），揭示全书深层组织逻辑

### L011 涌现知识的置信度

每条涌现知识的置信度分为三级：L011

| 等级 | 条件 | 置信度 |
|------|------|--------|
| L1-确证 | 可被源文本中的明确陈述（L###编号）直接回溯验证 | ≥0.85 |
| L2-强推测 | 由至少两个独立指标共同支持，但无单一明确陈述 | 0.60-0.84 |
| L3-弱推测 | 由单一指标支持，需要进一步文本验证 | 0.40-0.59 |

## 四、格式编码规则

### L012 L###编号继承规则

- 实体知识元（A类）：直接继承源分析报告中的L###编号（如L019a, L116c, L215h）
- 论点知识元（B类）：新建K###编号，K后三位数字中第一位表示来源章（0=整体, 1-5=对应章），后两位为流水号
- 语义链接：新建S###编号，流水编号
- 涌现知识：新建E###编号，E后两位为流水号

### L013 语义三元组表示格式

每个知识元的语义内容以三元组表示：

```
KU_id [类型] 主体 | 谓词 | 客体
```

例如：
```
L019a [A3] Settler-Native-Slave Triad | 提供分析框架 | 区分原住民/黑人/定居者在殖民结构中的不同位置
K101 [B2] 位置性决定责任 | 论证 | 不同群体承担不同的去殖民化工作
```

### L014 语义链接表示格式

```
S###: KU_i --[RelationType, Weight]--> KU_j
```

例如：
```
S001: L019a --[R1 论证支撑, 0.85]--> K101
S002: K101 --[R9 跨章呼应, 0.72]--> K501
```
