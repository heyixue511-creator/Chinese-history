# 22 第22章分析报告：Postmodern Design（后现代设计）

---

### 一、章节定位与功能

Chapter 22隶属Part 5，时间跨度1960年代至1990年代。在全书中，本章是对Chapter 18（国际文字排印风格）的**根本性反叛**——它记录了后现代主义如何瓦解了现代主义的"普遍主义"假设，以多元性、历史折衷、装饰的回返、"作者性"和反讽取代了瑞士风格的"客观"、"纯粹"和"秩序"。后现代设计是全书"反叙事"（counter-narrative）的最强表达。

---

### 二至三、结构与内容

| 节 | 核心人物/运动 |
|----|-------------|
| 早期迹象 | Robert Venturi——"Less is a bore"→Learning from Las Vegas |
| 瑞士后现代 | Wolfgang Weingart→从瑞士风格内部的反叛 |
| 美国后现代 | April Greiman, Dan Friedman——新浪潮（New Wave） |
| 孟菲斯 | Ettore Sottsass——意大利的反设计 |
| 克兰布鲁克 | Katherine & Michael McCoy→理论化的后现代设计教育 |
| 加州新浪潮 | David Carson, Rudy VanderLans/Zuzana Licko（Emigre） |
| 数字革命 | 计算机作为设计的工具和媒介 |

**核心论题**：后现代设计不是一种新"风格"，而是一种关于设计本身的哲学转向——它拒绝现代主义的"唯一正确"，拥抱多样性、复杂性、矛盾性和历史自反性。

**关键论点**：

| # | 论点 | 案例 |
|---|------|------|
| 1 | Weingart从瑞士风格内部引爆了反叛——他保留了网格的结构但注入了直觉性、纹理和"错误" | Weingart的Basel教学→"瑞士朋克"（Swiss Punk） |
| 2 | April Greiman将计算机和视频图像的像素化语言引入平面设计——"hybrid imagery" | Does It Make Sense? 海报折叠成小册子（1986） |
| 3 | Emigre杂志（1984-2005）是数字时代设计师作为"自出版者"的宣言 | Zuzana Licko的"粗像素"字体→"the look of the tool" |
| 4 | David Carson代表了"可读性"（legibility）让位于"表达性"（expression）的极端——Ray Gun杂志（1992-95） | 对"可读性"边界的彻底探索 |
| 5 | Katherine McCoy的克兰布鲁克教学将法国文学理论（解构主义、符号学）引入设计教育 | "the new typography of the 1980s"→"解构"字体排印 |

### 四、逻辑梳理

```
现代主义/瑞士风格（Ch.16/18）→"客观性"、"普遍性"
    → 1960s-1970s：第一波不满→Venturi "Less is a bore" (1966)
        → Weingart的"瑞士朋克"（1970s Basel）→从内部解构网格
            → 1980s：美国后现代→Greiman, Friedman→数字技术+解构
                → Cranbrook → McCoy的理论化后现代教育
                → Emigre (1984) → 自出版+数字字体
                    → 1990s：Carson/Ray Gun → "可读性的终结"
                        → 数字革命→第24章
```

### 五至七、文风摘录

**摘录1**（L199——Venturi的反叛）：
> "Architect Robert Venturi's 1966 book Complexity and Contradiction in Architecture provided a theoretical foundation for postmodernism, arguing for 'the difficult whole' rather than the simplistic unity of modernist design."

**摘录2**（L199——Weingart的教学革命）：
> "Weingart began to stretch the limits of typography: expanding letter and word spacing to the edge of legibility, overlapping type and images, and using screens and underprinting to create textural effects."

**摘录3**（L199——Carson的Ray Gun）：
> "Carson's work for Ray Gun magazine challenged the very foundation of typographic communication: the principle that type must be readable."
