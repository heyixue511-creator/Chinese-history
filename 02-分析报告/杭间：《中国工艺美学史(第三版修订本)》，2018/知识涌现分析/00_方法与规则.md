# 00_方法与规则：知识涌现分析框架（杭间《中国工艺美学史》）

## 一、层级定义

| 层级 | 定义 | 本书示例 |
|---|---|---|
| 知识元（Knowledge Atom） | 六类实体（人物/著作作品/概念/机构/地点/事件）及其语义载荷 | 墨子、文质彬彬、考工记、包豪斯…… |
| Topic（强连通簇） | 知识元间由 9 种语义链接构成的强连通簇，6-15 个 | "儒家思想簇""道家审美簇""近代转型簇"…… |
| Theme（高层语义域） | 3-5 个高层语义域，由共享/桥接知识元聚合 Topic | "道器关系域""功能与生活方式域""传统与现代转型域"…… |

## 二、九种语义链接判定标准（每条附判据与例）

| 符号 | 类型 | 判据 | 例 |
|---|---|---|---|
| → | 因果 | A 的变化导致 B 的生成/成立 | 董仲舒"独尊儒术"→谶纬装饰题材流行（L133） |
| ⇒ | 条件 | A 是 B 成立的必要/充分条件 | 民生日用→工艺存在的理由（L1） |
| ↔ | 对比 | 同一问题域中 A 与 B 构成对立/张力 | 文质彬彬↔节用非乐（L34、L55） |
| ⊂ | 隶属 | A 是 B 的子类/成分 | "工艺美学"⊂"造物的美学"（L1） |
| ≻ | 时序 | A 在 B 之前并使其成为可能 | 先秦诸子道器论≻汉代工艺实用观（L115、L124） |
| ≈ | 空间共现 | 同一时代/语境中并列出现 | 魏晋"士"的生活方式≈青瓷、麈尾（L145） |
| : | 属性 | A 具有属性 B | 宋代工艺:理学约束下的典雅（L171-L172） |
| ⇐ | 论证支撑 | A 被用作支持命题 B 的证据 | 唐诗（徐夤咏越窑）⇐ 唐代工艺美学（L157） |
| ∼ | 同域 | A 与 B 属同一论域（无方向） | 技术异化∼劳动异化（L94） |

## 三、涌现指标

| 指标 | 定义 | 本书记录方式 |
|---|---|---|
| 节点度 k | 某知识元直接连接的其他知识元数 | 见 02 报告枢纽表 |
| 桥接值 b | 某知识元连接不同 Topic/Theme 的边数 | 见 02 报告枢纽表 |
| 簇识别 | 强连通子图划分（以共享核心元为准则） | 见 03 报告 Topic 表 |
| 内聚度 | 簇内链接数/节点数比值（连通密度） | 见 03 报告 |
| 涌现强度 S | 簇内链接数×桥接权重（一级涌现用） | 见 03 报告 |
| 一级涌现 | 由知识元直接聚合形成的结构性命题（E） | E1…En |
| 二级涌现 | 跨 Topic 综合后的命题（P） | P1…Pn |

## 四、证据规范

1. 全部链接与涌现结论须附 clean 版行号（L###）；
2. 客观性核对：对每条主要命题列出反例或边界（如道家"技进乎道"之弊，L97）；
3. 不编造行号：行号必须与已逐行通读的内容对应；
4. 报告清单：00 本文件 + 01 知识元语意分析 + 02 语义链接网络 + 03 知识涌现计算 + 04 知识发现报告。
