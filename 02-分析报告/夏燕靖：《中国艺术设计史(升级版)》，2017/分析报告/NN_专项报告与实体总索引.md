# NN 专项报告与实体总索引

## 第一部分：专项报告

### 一、语言与文风

**总体特征**：全书以严谨平实的教材语体为基底，兼具史论阐释的深度与可读性。典型句式为"主体对象+时代背景+特征描述+功能分析+史料佐证"的复合长句，大量使用"其一……其二……其三"的分项铺排（如青铜礼制意义 L190、汉代漆器髹漆工艺 L689）。

**句式类型**：
1. 定义式："瓷器的发明是我们祖先对人类文明的发展作出的又一项重大贡献。"（L246）
2. 因果式："由于瓷器坚固耐用……深受民众的欢迎"（L758）。
3. 评价式："堪称是世界都市建设史上的一大奇迹"（L1035）。
4. 对比式："南方青瓷秀丽，北方青瓷浑朴；南方青瓷轻巧，北方青瓷厚重"（L762）。

### 二、修辞方式

1. **引证**：广引经史子集与诗文，如引《左传》"桀有昏德，鼎迁于商"（L187）、白居易诗（L842）、杜牧诗（L842、L1480）、《诗经》句（L402）。
2. **比喻**：以"诗意华章"喻唐代文化（L906）、"中华第一城"称良渚古城（L135）、"世界园林之母"称中国园林（L1501）。
3. **设问/反问**：章首常以设问引出主题，如"设计从何起源，这其实是一个需要推论和判断的认识问题"（L45）。
4. **排比**：如"所谓'天有时'指的是……'地有气'指的是……"（L578）。
5. **典故意象**：借"问鼎"（L224）、"衣冠禽兽"（L1426）、"拜倒在石榴裙下"（L1005）等成语典故阐释器物与服饰制度，兼具知识性与趣味性。

### 三、史料使用方式

1. **考古实证优先**：几乎每类器物都给出具体遗址、墓葬或窖藏与年代，如司母戊鼎铸痕（L202）、马王堆织物（L641）、法门寺地宫（L949、L1016）。
2. **文献互证**：考古发现与传世文献相互印证，如偃师二里头遗址+《竹书纪年》证殷墟（L265）、良渚石犁+甲骨文"犁"字（L160）。
3. **异议并陈**：对无定论问题并列多观点，如失蜡法来源（L207）、秦兵马俑归属（L723）、秧马用途（L1322-1327）。
4. **数据引证**：大量使用尺寸、成分、产量、价格等数据（如司母戊鼎重 875 千克 L202、越王勾践剑含铜 80%-83% L513、秘色瓷高 66.5 厘米 L765），增强实证感。

### 四、阐述方法与推演逻辑

1. **功能分析**：器物分析紧扣"设计功能"，如分析鼎"腹可以盛物，足可以扬火，耳可以穿抬搬运"（L219）。
2. **技术归因**：将设计变化归因于技术、材料、社会制度，如唐三彩兴盛归因厚葬之风（L952）、宋瓷发展归因斗茶风尚与海外贸易（L1087）。
3. **制度-设计互证**：礼制、官营手工业制度、行会、赋役制度如何塑造设计（L190、L910、L917）。
4. **历时比较**：同一器物的朝代演变比较，如鼎从商早期到战国的形制演变（L219、L430）、隋代与六朝陶瓷造型比较（L926）。
5. **文化传播视角**：丝绸之路（L638）、海上丝绸之路（L1470）、胡床传入（L873）、纳石失（L1251）等体现设计的中外互鉴。

### 五、文字风格

- 术语考究，遇生僻字多以括号注音释义（如"裳cháng""伽qié""窣堵坡"）。
- 知识链接专栏穿插正文，兼顾教材的知识扩展功能。
- 各章末设"名词解释+问答题"练习，具鲜明教学导向。
- 存在少量 OCR 讹误（如"考上记"应为"考工记"L184），个别段落因清洗合并而重复。
