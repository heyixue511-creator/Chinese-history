# NN 专项报告与实体总索引

**分析对象**：朱和平主编《世界现代设计史》（clean 版，759 行）
**说明**：本文件第一部分为语言、文风、修辞、史料使用方式、阐述方法、推演逻辑、文字风格专项报告，含术语中英对照表；第二部分为六类实体总索引。全部证据以 clean 版行号（L###）标注。

# 第一部分 专项报告

## 一、语言

1. **书面语体**：全书为规范的现代汉语书面语，以教材讲解口吻叙述，句式以陈述句为主，多用长句、复句（如 L100-101、L385）。
2. **术语处理**：中文术语为主，外来人名、作品名、机构名在首次出现时以括号标注外文原名，如"维克多·霍塔（Victor Horta，1867—1947）"（L157-158）、"风格派（De Stijl）"（L293）。
3. **数字与时间**：广泛使用年份、年代、产量、高度等具体数据增强实证感（如"塔高 328 米"L155、"钢产量 678000 吨"L45）。
4. **引用语**：偶用直接引语与名言（如埃科 L457、马姆斯登 L493、贝聿铭 L622）。

## 二、文风

1. **综述性**：以第三人称宏观综述为主，较少第一人称；仅在绪论与后记中出现作者立场（L69"我们采用设计艺术名称"、L756）。
2. **教喻性**：章首"主要内容/重点/难点"、章末"思考题"构成教学引导；"知识链接"提供百科式补充。
3. **平衡性**：对每个运动多作正反评价（如包豪斯的历史作用与局限 L403-404）。
4. **文学性点缀**：偶有形象化描述（"整座建筑好像一个融化时的冰淇淋"L161、"白雪公主的棺材"L435）。

## 三、修辞方式

1. **比喻**：设计=天平（L36）、装饰艺术与现代主义=孪生兄弟（L214）、风格派/构成主义（L277 三线）。
2. **对偶/排比**："一方面……另一方面……"句式反复出现（L100-101、L385）。
3. **设问**："到底是使用'设计艺术'还是'艺术设计'更为贴切呢？"（L69）。
4. **引用权威**：引《简明不列颠百科全书》（L42）、《包豪斯宣言》（L383）等增强说服力。
5. **拟人**："设计是源头，它影响和决定了后续的一切"（L45）。

## 四、史料使用方式

1. **类型**：以第二手通史综述为主；辅以第一手文献（《包豪斯宣言》L383、《走向新建筑》L315、《小艺术》L109）、辞书（L42）、人物言论（L457、L493、L622）。
2. **数据**：钢产量（L45）、贸易量（L285）、电视机产量（L470、L534）、广告营业额（L719）等。
3. **图像**：全书插图编号图 1 至图 10-28，作为实物证据。
4. **局限**：部分数据存在前后不一（如埃菲尔铁塔高度 L84 为 324 米、L155 为 328 米），个别年代笔误（L247"1727 年"应为 1927 年），需读者留意。

## 五、阐述方法

1. **历史叙事法**：按时间顺序与国别组织叙述。
2. **因果分析法**：每章难点处常作因果解释（如 L147、L191、L272、L519、L605）。
3. **对比法**：工艺美术 vs 新艺术（L150）、装饰艺术 vs 现代主义（L214）、现代主义 vs 后现代主义（L610 表）。
4. **归纳法**：从作品归纳风格特征（L109 五特征、L211 风格特征、L527 意大利文化、L588 古巴招贴三特点）。
5. **分类法**：设计形态五分类（L81）、后现代工业设计七风格（L629-648）。

## 六、推演逻辑

1. **演绎**：从"设计是艺术与技术的动态平衡"总命题演绎各章判断（L36）。
2. **归纳**：从大量人物作品归纳运动特征。
3. **辩证**："扬弃"逻辑贯穿（L147、L610）；承认成就也列局限（L404）。
4. **递进**：全书按"滥觞—肇始—演进—成熟—反思—多元"递进分期，各章以背景—展开—评价推进。

## 七、文字风格总评

全书文字**平实、系统、讲解式**，逻辑层次清楚，术语统一，适合教学；但长段落密集、信息密度高，个别处重复与数据出入，属于典型的中文教材综述文风。
