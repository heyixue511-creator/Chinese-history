## 四、一级涌现结构（E1…En）

一级涌现=由知识元+链接直接构成的可复现结构：

- **E1 起源链**：工业革命 → 生产方式变革 → 设计独立 → 工艺美术运动（L42、L101、L109）
- **E2 代际链**：工艺美术 ≻ 新艺术 ≻ 装饰艺术 ≻ 现代主义 ≻ 后现代主义（L147、L149、L191、L272、L605）
- **E3 教育制度化链**：贝伦斯（先驱）→ 工业同盟（组织）→ 包豪斯（教育）→ 乌尔姆（战后教育）→ 三大构成（模板）（L288、L373、L432、L404）
- **E4 传播链**：包豪斯关闭 → 设计师移美 → 国际主义 → 日本/意大利学习（L424、L441、L470）
- **E5 反思链**：计划废止制 → 消费主义危害 → 那达/巴巴纳克批评 → 反设计/波普 → 后现代主义（L537、L540、L531、L605）
- **E6 中国追赶链**：西化冲击 → 图案概念 → 学习借鉴 → 民族形式 → 进发（L701、L707、L713）
- **E7 设计观更替**：功能优先（现代主义）→ 功能+情感（后现代）→ 可持续（绿色/生态/循环/组合）（L277、L610、L657-660）

## 五、二级涌现命题（P1…Pn，附生成机制与强度）

二级涌现=跨 Topic/Theme 综合生成的命题。

- **P1【设计史=艺术与技术的动态平衡史】**：由 E1-E7 全链生成。生成机制：全书反复以"功能与装饰"天平（L36）统摄各运动评价。强度：高（全文主命题）。
- **P2【现代设计的成长期取决于是否拥抱机器大生产】**：由 T1、T2、T3、T5 生成。生成机制：工艺美术/新艺术因否定机器而"陨落"（L147），现代主义因承认机器而"长盛不衰"（L272）。强度：高。
- **P3【设计教育是设计现代性的制度化保障】**：由 T7、T5 生成。生成机制：包豪斯—乌尔姆—各国设计学院链（L373、L432、L452-454）。强度：高。
- **P4【设计的"大众服务"与"权贵服务"二元张力贯穿全史】**：由 T4、T5、T8、T10 生成。生成机制：装饰艺术（为权贵）↔ 现代主义（为大众）↔ 后现代（多元与人性）对比（L196、L214、L610）。强度：中高。
- **P5【设计的批判动力来自对其社会后果的反思】**：由 T9、T10 生成。生成机制：那达/巴巴纳克批评、反设计、绿色设计链（L540、L531、L657）。强度：中高。
- **P6【中国现代设计是世界现代设计史的晚到参与者，其路径为"学习—借鉴—民族化"】**：由 T12 及桥接链生成。生成机制：第10章历史分期与"越是民族的就越是世界的"（L686）呼应。强度：中。

## 六、客观性核对与反例

1. **命题 P2 的反例**：作者亦承认工艺美术运动、新艺术运动"在探索新的设计风格和方法方面作出了它应有的贡献"（L272），"昙花一现"不等于全盘否定——P2 需限定为"设计运动能否成为主流"的标准，而非价值评判。
2. **命题 P4 的边界**：现代主义"为大众服务"的理想与其实际服务资本/商业（美国样式主义）之间存在矛盾，作者对此有自我修正（L447"为利润而设计"）——P4 需并列此矛盾。
3. **数据矛盾**：埃菲尔铁塔高度 L84（324 米）与 L155（328 米）不一致；此类事实出入会影响个别知识元的证据精度，已在链接清单中如实保留。
4. **覆盖偏斜**：非欧美国家知识元稀疏，P1-P6 主要基于欧/美/日/中叙述，对非洲、拉美（除古巴）、中东的概括力有限，属于本书题材范围的客观限制。
