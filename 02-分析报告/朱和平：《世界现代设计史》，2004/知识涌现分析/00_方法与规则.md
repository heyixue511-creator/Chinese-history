# 00 方法与规则

**适用对象**：朱和平主编《世界现代设计史》（clean 版，759 行）知识涌现分析。
**证据规范**：全部语义链接、簇与涌现命题均须附 clean 版行号（L###）证据；行号必须与实际内容对应，不得编造。

---

## 一、层级定义

1. **知识元（Knowledge Atom）**：书中具有独立语义载荷的最小实体单元，即六类实体——人物、著作/作品、概念、机构、地点、事件（如"威廉·莫里斯""工艺美术运动""包豪斯""伦敦""1851 年水晶宫博览会"）。
2. **Topic（强连通簇）**：由语义链接紧密相连的一组知识元构成，簇内节点彼此直接或间接强连通（如"英国工艺美术运动"簇 = 莫里斯+罗斯金+红屋+莫里斯商行+世纪行会+1851 年博览会）。
3. **Theme（高层语义域）**：多个 Topic 聚合成的高层语义域，代表全书的核心论域（如"设计运动的代际更替"、"设计教育与职业化"、"功能与装饰的张力"）。

## 二、9 种语义链接判定标准

| 类型 | 符号 | 判定标准 | 例（本书） |
|---|---|---|---|
| 因果 | → | 前因导致/促发后果 | 工业革命→现代设计产生（L42、L101） |
| 条件 | ⇒ | 前提条件使后果成为可能 | 承认机器大生产⇒现代主义长盛（L272） |
| 对比 | ↔ | 两实体为对立/对照关系 | 工艺美术↔新艺术（L150） |
| 隶属 | ⊂ | 整体—部分、包含关系 | 装饰艺术运动⊂为权贵设计传统（L196） |
| 时序 | ≻ | 时间先后、承继关系 | 工艺美术≻新艺术≻装饰艺术≻现代主义（L149） |
| 空间共现 | ≈ | 同处一地/一体 | 包豪斯≈魏玛/德绍/柏林（L385-389） |
| 属性 | : | 实体具有的属性特征 | 流线型：象征速度与时代精神（L353） |
| 论证支撑 | ⇐ | 一实体为另一实体提供论证依据 | 图坦卡蒙墓发现⇐装饰艺术埃及借鉴（L199） |
| 同域 | ∼ | 同属一个设计领域/议题 | 贝伦斯∼AEG∼工业设计（L290-291） |

## 三、涌现指标

1. **节点度 k**：一个知识元连接的链接数（书中被提及并与它元直接关联的次数），用于识别核心枢纽。
2. **桥接值 b**：一个知识元连接不同 Topic/Theme 的链接数，衡量跨域中介能力。
3. **簇识别**：按强连通规则从链接网络划分 Topic（6-15 个簇）。
4. **内聚度**：簇内实际链接数 / 簇内最大可能链接数。
5. **涌现强度 S**：由"簇内链接数+节点度+跨簇桥接数+命题依据量"综合评定的指标，分高/中/低。
6. **一级/二级涌现**：一级涌现=由知识元+链接直接构成的结构（E1…En，如"德国理性主义设计链"）；二级涌现=跨簇综合生成的命题（P1…Pn，如"设计史=艺术与技术动态平衡史"）。

## 四、证据规范与报告清单

1. **证据规范**：每条链接标注来源行号；统计量以阅读确认为准，不作代码计算（按方法说明书"不写代码"约束）；对无法确证的链接标注"证据缺口"。
2. **报告清单**：
   - `01_知识元语意分析.md`：六类知识元语义载荷。
   - `02_语义链接网络.md`：枢纽识别、链接清单、枢纽与中介、网络特征。
   - `03_知识涌现计算.md`：Topic、Theme、内聚度与涌现强度、一级/二级涌现、客观性核对。
   - `04_知识发现报告.md`：结构发现、隐藏枢纽与潜在链接、跨主题命题、层级图谱、总体评价。
