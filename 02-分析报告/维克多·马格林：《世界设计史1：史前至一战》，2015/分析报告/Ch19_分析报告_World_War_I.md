# Ch19 第一次世界大战（1914—1918）

## 一、章目信息

- **章名**：第19章 第一次世界大战（1914—1918）
- **行号范围**：L3953–L4017（简介 L3955、武器与火炮 L3958、海上战争 L3961、空中战争 L3964、宣传 L3967、参考文献 L3975–L4017）

## 三、内容分析

### 3.1 简介（L3955–L3956）

- 1914年8月一战爆发（萨拉热窝刺杀斐迪南大公）；同盟国（德奥奥斯曼）vs 协约国（法俄意日，1917年美国参战）；800万军人+1,300万平民丧生；四大帝国崩溃。
- **第一次机械化战争**：机枪、坦克、潜艇、飞机、气球；堑壕战（雷马克《西线无战事》）。

### 3.2 武器与火炮（L3958–L3959）

- 维克斯父子公司收购马克沁机枪（1896）；1912年英军采用维氏枪；德国"机枪08"。
- **克虏伯**：贝尔莎大炮（移动榴弹炮，重1吨、射程9英里）、"长马克斯"（112英尺炮管、180吨、75英里炮击巴黎）。
- **坦克**：英国"小威利"→"马克I"（1916年索姆河首战）、"惠比特"、马克V（圆形支撑框架）；法国"焦施耐德"坦克失败。

### 3.3 海上战争（L3961–L3962）

- 德国 U 型潜艇（潜水艇）攻击商船；1915年击沉卢西塔尼亚号；UA 潜艇（1916）；协约国反潜技术（深水炸弹、地雷）。

### 3.4 空中战争（L3964–L3965）

- 飞机从观察工具发展为攻击工具；德·哈维兰 DH4 双翼轰炸机（美国生产近5,000台）；"索普维斯骆驼"；布雷盖"宝玑14"（硬铝机身，战后创办法航前身）；福克"射击电动协调装置"（Interrupter gear，福克E1 单翼机）；容克斯 J1（1916）；齐柏林飞艇（斐迪南·冯·齐柏林，1900首飞）；英国 R80 飞艇（沃利斯）。

### 3.5 宣传（L3967–L3973）

- "宣传"源自1622年天主教宣传圣会；一战首次出现全国性宣传攻势。
- **英国**：战时宣传部（马斯特曼）、信息部（比弗布鲁克、诺斯克利夫）；雷马克斯反德漫画；招募海报（利特"你的国家需要你"1916、凯利"英国女性的呼吁"、卢姆利"爸爸，你在战争中做了什么？"、布兰格温）。
- **美国**：1917年公共信息委员会（乔治·克瑞尔）、绘画宣传部（吉布森）；弗拉格"我需要你加入美军"（1917）、克里斯蒂、彭内尔；种族化宣传（罗利"野人或家庭"、诺顿、霍普斯"毁灭这只怪兽"）。
- **德国**：海报之友协会、"适当海报派"设计师（伯恩哈德、霍尔维恩、尔特、给普开斯、奥本海姆）、德国黑字母的民族认同、"鲁登道夫残疾人基金"海报。
- 其他：法国福兰、费夫雷，意大利达多维奇、莫萨恩，匈牙利比罗；结论：宣传海报仍脱离先锋派（立体主义/未来主义）的形式革新。

### 3.6 参考文献（L3975–L4017）

- 文献综述（L3977）核心：巴蒂《克虏伯的房子》、西蒙诺《装甲部队》、休斯《美国创世纪》、里卡兹《一战海报》、凡·沙克《一战中的图片宣传》（Design Issues 2006）。

## 四、逻辑梳理

```
一战（1914—1918）＝ 机械化战争 + 宣传战
  ├─ 陆地：机枪/大炮/坦克（维克斯、克虏伯、英国坦克）
  ├─ 海上：潜艇（U 型）vs 反潜
  ├─ 空中：侦察机→战斗机/轰炸机/飞艇（射击协调装置、硬铝）
  └─ 宣传：海报动员（英国/美国/德国）+ 帝国视觉话语
```

本章逻辑：一战既是军事技术设计（坦克、飞机、潜艇）的加速器，也是"宣传设计"（propaganda design）的制度化起点；马格林把武器与海报同置于设计史视野，延续其"设计涵盖军事与传播"的宽泛定义。

## 五、材料使用方式

- 军事档案与装备：马克沁机枪、贝尔莎大炮（图19.01）、马克I坦克（图19.02）、DH4（图19.03）、齐柏林飞艇（图19.04）。
- 海报实物：利特"你的国家需要你"、弗拉格"我需要你加入美军"（图19.05）、霍尔维恩卢登道夫基金（图19.06）、霍普斯"毁灭这只怪兽"（彩图71）。
- 一手文本：雷马克《西线无战事》（L3956）。
- 学术综述（L3977–L4017）：武器史与海报史。

## 六、论辩与阐述方法

- **战争作为设计语境**：把武器系统（枪炮、坦克、飞机）作为"工业设计"看待，与民用产品并列。
- **宣传的符号学分析**：海报图像（手指、国家符号、女性形象）与文字动员（"你的国家需要你"）的视觉说服机制。
- **帝国批判**：殖民地战士/主题的征用与种族化宣传（霍普斯、诺顿）。
- **先锋与宣传的断裂**：宣传海报"仍脱离了当时的先锋运动"（L3973）——为第2卷中现代平面设计与政治宣传的结合留出伏笔。
