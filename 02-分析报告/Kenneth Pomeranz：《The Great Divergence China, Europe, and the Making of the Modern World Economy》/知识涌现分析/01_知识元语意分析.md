# 01 知识元语意分析：彭慕兰《大分流》知识元语料库

## L500 阶段概述

本阶段从九份分析报告中系统提取知识元，按类别（实体H、概念G、逻辑L、证据E、论辩A）进行分类，并对每个知识元进行多维度语意标注：主题域、论证层级、关键度评分（1-5分）、支持倾向（对全书核心论点"{+1}支持/{0}中立/{-1}限制"），以及跨章引用频次。

统计概况：九份源报告共含约430个L###编号的知识元。其中实体类约180个（人物约75个，地理约55个，制度/概念约60个，产品/资源约40个），概念类约45个，逻辑类约15个，证据类约25个（含附录数据），论辩类约10个，其余为结构性/章节目录条目。本分析聚焦于与知识涌现最密切相关的核心知识元，选取关键度≥3或跨章引用次数≥2的知识元作为"高连接势能知识元"。

## L501 论证五层次模型与知识元层级定位

彭慕兰全书的论证结构可抽象为五个递进层次。每个知识元可根据其在论证中所发挥的功能定位到相应的层级：

```
层次0：默认常识层——"欧洲内部优越→工业化"是默认叙事
  │
层次1：经验消解层（第1-2章）——欧洲在基础经济生活中不特殊
  │ 核心知识元：L082各论题、L152各论题、L083-L086量化证据
  │ 论证操作：逐点检验→消解"欧洲更富裕/制度更好"的经验基础
  │
层次2：上层检验层（第3-4章）——即使有差异，也不足以解释工业化
  │ 核心知识元：L222各论题、L262各论题、L233、L266
  │ 论证操作：假设性接受→因果效力检验→限定差异的作用范围
  │
层次3：约束揭示层（第5章）——揭示共享的生态-土地根本约束
  │ 核心知识元：L312各论题、L318、L322、L325
  │ 论证操作：对称化（欧洲也面临）→边缘区分析→揭示约束的根本性
  │
层次4：替代解释层（第6章）——外部因素（煤炭+新大陆）解释突破
  │ 核心知识元：L372各论题、L375、L384、L385
  │ 论证操作：量化（鬼田计算）→机制分析（新型边缘区）→综合结论
  │
涌现空间：论证层次之间的链接和跨越层次的重组 → 知识涌现
```

每个知识元在层级间的"可移动性"（即它是否可以被重新定位到不同论证层级而产生新意义）是其知识涌现势能的重要指标。
