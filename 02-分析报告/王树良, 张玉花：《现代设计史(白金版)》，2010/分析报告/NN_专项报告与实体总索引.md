# 第一部分：专项报告

## 一、语言特征

1. **词条体与答题体双轨**：名词解释为"定义—特征—人物—作品—定评"五段式词条（如 L109-L110、L192-L193）；简答/论述为"总起—①②③—小结"答题体（如 L131、L499、L705）。
2. **判断句与定评句密度高**：大量"是……的代表人物""被誉为""被称为""无疑"等判定式（L116、L196、L279、L533、L598）。
3. **序号化**：全文以 (1)(2)(3)、①②③、（一）（二）层层编号，是显著的记忆化写作（L128、L131、L145、L409、L425、L648）。
4. **口语化讲稿风**：部分句子带讲课口吻，如"可以说'米斯的原则改变了世界都会三分之一的天际线'"（L286）、"让考生一眼就能发现考点、重点所在"（L13）。

## 二、文风特征

1. **浓缩化**：一句话交代运动全貌（L149、L259），长行将整题答案连排（L145、L579）。
2. **对称化结构**：答案常按"优点/缺点""联系/区别""原因/影响"对置（L131、L332、L681）。
3. **褒贬并举**：几乎每个运动的词条都有"成就+局限"双栏（L131、L414、L425、L582、L590）。
4. **面向考生**：穿插励志语与注音、括注，服务于自学背诵（L9-L10、L556、L587）。

## 三、修辞方式

1. **比喻**：工艺美术"象牙塔的产品"（L131）、电影院"梦的宫殿"（L273-L274）、米拉公寓"融化时的冰淇淋"（L241）、"米斯的原则改变了世界都会三分之一的天际线"（L286）、乌尔姆"战后的包豪斯"（L569）。
2. **定评排比**：人物定评"最……之一"连用（L279、L462、L468）。
3. **对照**："少即是多" vs "少就是乏味"（L609）、"形式追随功能" vs "式样追随市场"（L444、L447）。
4. **引语嵌入**：直接引述设计师名言以增强权威感（L279、L285、L530、L566）。

## 四、史料使用方式

1. **二手教材口径**：史实均承袭通行设计史教材（王受之式框架），无脚注、无一手档案（L6-L7 仅列配套书目）。
2. **年代-图注-人物三配套**：每个考点均给出年代（L106、L376、L516）、图注（图1.1-7.18）与人物（L459-L463）。
3. **案例化**：以具体作品/公司/产品佐证抽象概念（柯达相机 L459-L460、布劳恩 L529-L530、索尼 L579）。

## 五、阐述方法

1. **归纳列举**（主方法）：特征/原则/成果均拆为编号点（L128、L338、L409、L648）。
2. **比较对照**：跨章反复比较（新艺术vs工艺美术 L250-L256；装饰艺术vs现代主义 L332；国际主义vs现代主义 L681；现代主义vs后现代主义表格 L693）。
3. **谱系叙述**：人物/机构谱系化（贝伦斯→三巨头 L198-L199；工业同盟→包豪斯→乌尔姆 L590）。
4. **概念拆解**：将大概念分解为可背子概念（"有计划废止制度"三种废止 L499；绿色设计 3R L648）。

## 六、推演逻辑

1. **因果链**：工业革命→设计分离→现代设计（L145）；经济危机→式样主义→有计划废止（L447-L448、L486-L487）。
2. **兴衰周期**：每个运动均标注"起源—高潮—衰退/取代"（L110、L150、L554、L597-L598、L612）。
3. **辩证扬弃**：后一运动往往是对前一运动的反逆或补救（L332、L702）。
4. **价值评判驱动**：判断依据统一为"是否服务大众/是否顺应工业化"两轴（L277、L332、L374）。
