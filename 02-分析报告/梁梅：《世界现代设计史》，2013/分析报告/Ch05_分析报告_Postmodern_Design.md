# Ch05_分析报告_后现代设计（梁梅《世界现代设计史》2013）

## 章节定位与功能（含行号范围）

- **章标题**：第5章 后现代设计（Chapter 5, 位于 L244 行内，与第4章思考题同处一行）
- **行号范围**：L244（章标题与后现代观念绪论）— L288（章末思考题与第6章标题同处一行）；正文主体 L246-L288。
- **功能**：全书的**理论深化章**。系统阐述后现代设计观念的产生、后现代建筑实践、阿卡米亚与孟菲斯的产品设计、以及各国新设计运动，呈现后现代主义从观念到实践、从建筑到产品的全面展开，是全书的哲学与观念高潮。

## 结构分析

本章结构与内容如下：

1. **章首绪论**（L244）：后工业社会、后现代主义文化思潮兴起。
2. **1. 后现代设计观念的产生**（L246-250）：后现代主义语义、文丘里与詹克斯理论奠基。
3. **2. 后现代建筑**（L252-260）：建筑实践（SITE、摩尔、格雷夫斯、约翰逊、蓬皮杜、福斯特、盖里）、风格谱系（新古典、高技派、解构主义）。
4. **3. 阿卡米亚和孟菲斯**（L265-275）：米兰前卫设计团体的"重新设计"与功能模糊设计。
5. **4. 新设计运动**（L286-288）：德、英、法、美、日的新设计，古典语言复兴、功能模糊、装饰复兴、材料自由、手工回归。

## 内容分析

### 一、后现代设计观念的产生（L246-250）

1. **后现代主义定义**："现代主义之后"的概念，"与现代主义在观念上不同"，反对规范性、同一性、秩序性，主张多元化、反对中心权威、消解高级文化与低俗文化界限（L246-248）。
2. **设计语境**：微型处理器解放产品外形，沙利文"形式服从功能"失去意义；"后工业""产品语义学""符号学""隐喻"概念引入设计（L250）。
3. **文丘里**：1966年《建筑的复杂性与矛盾性》反对国际主义，"现代主义已经过时了"；1972年《向拉斯维加斯学习》肯定"七国建筑"的"诱人的活力与效力"（L250）。
4. **詹克斯**：把1972年圣路易市炸毁山崎实住宅区作为现代主义死亡时刻；出版《后现代主义》《今日建筑》《后现代建筑语言》；明确波普/激进设计是后现代先声（L250）。

### 二、后现代建筑（L252-260）

1. **定义**：后现代是"笼统的、复杂的，甚至是包罗万象的概念"，包括后现代、新古典、高科技、解构主义、新现代主义等（L253）。
2. **主要案例**：SITE公司Best连锁店（1975，残缺美学）；摩尔意大利广场（1975-80，古典柱式装饰）；格雷夫斯俄勒冈公益服务大厦（1980-82，"后现代第一件不朽之作"）；约翰逊AT&T纽约总部（1978-83，古典拱与三角楣）；蓬皮杜中心（皮亚诺/罗杰斯，1971-77，高技派）；福斯特汇丰银行大厦；盖里古根海姆博物馆（1998，解构主义）（L258-260）。
3. **评价**：作者指出后现代建筑"并没有找到一条类似于现代主义那样明确的设计道路"，只是"针对现代主义存在的问题探讨一些解决的可能性方式"（L260）。

### 三、阿卡米亚和孟菲斯（L265-275）

1. **阿卡米亚（1976）**：米兰工作室，创办者格历日罗；"把普通的日用品加上艳丽的色彩和重新装饰后创造出‘黄金’般的新设计"（L266）。蒙迪尼"重新设计"经典产品（Proust扶手椅、Kandissi沙发、重新设计的包豪斯钢管椅）（L266）。
2. **孟菲斯（1980）**：索托萨斯1980年离开阿卡米亚，1980年底成立；名字源于鲍伯·狄伦唱片《Stuck Inside of Mobile with Memphis Blues Again》（L268）。
3. **孟菲斯首展（1981年9月18日）**：展出31件家具、3个闹钟、10盏灯具、11件陶瓷器，参观者2500人，"功能主义和国际现代主义似乎都成为过去"（L268）。
4. **索托萨斯**：Carlton书架（无放置书籍空间）、Casablanca屏风、Agra沙发（大理石+纺织品）；"设计对我而言……是一种探讨社会的方式"（L268）。
5. **其他成员**：德·鲁克（Hi-Fi草图被索尼引用）、马都·顿（"裸鸟"壶、"芝加哥论坛报"灯）、彼特·肖尔、汉斯·霍雷因、布莱兹（L268-273）。
6. **评价**：孟菲斯"打破功能主义设计观念的束缚，强调物品的装饰性"（L268）；"把一些清新的空气带入设计界中……开始重新思考近百年来形成的功能主义的现代设计观念"（L275）。

### 四、新设计运动（L286-288）

1. **德国**：80年代与功能主义决裂，汉堡"艺术和商业"展（1982）、"消费者的休息椅"展（1983）、杜塞尔多夫"感觉-拼贴画感官的生活"展（1986）；新巴洛克倾向；"文献展"向设计师敞开大门（L286-287）。
2. **英国**：NOTO组织（1983，"今日的表现性建筑"）；让·阿德（1981年One Off公司，混凝土高保真音响）；莫里森（"无设计"概念，极简三合板家具）（L286-287）。
3. **法国**：Nemo、Totem团体；盖尔特（麦当娜奇装异服）；斯塔克（爱丽舍宫家具、柠檬榨汁机）（L287）。
4. **美国**：文丘里为Knoll设计曲木椅；卡瑟尔纪念性家具；格雷夫斯、盖里设计日用品（L287）。
5. **日本**：仓右四郎"月亮真高呀"金属椅，融合工匠技术（L287）。
6. **特征总结**：托马斯·哈福归纳新设计特点——"有意识地放弃功能主义、实验性的作品、自己生产和发行、小系列或单件作品、风格的混合……超越了艺术和设计之间的界限"（L288）。
7. **四个特点展开**：古典主义视觉语言复兴、功能模糊性、装饰复兴、材料开放（不同性质材料并置）、色彩艳俗、手工制作回归（L288）。

## 逻辑梳理

本章逻辑为**"观念→实践→全面展开"**：

1. **观念奠基**：后工业社会 + 后现代理论（文丘里、詹克斯）→ 反现代主义观念（L246-250）；
2. **建筑先声**：后现代建筑实践 → 古典语言复兴（L252-260）；
3. **产品深化**：阿卡米亚/孟菲斯 → 产品设计的"重新设计"与功能模糊（L265-275）；
4. **全球展开**：各国新设计运动 → 风格混合、材料自由、手工回归（L286-288）；
5. **总结定性**：后现代设计四个鲜明特点（古典复兴、功能模糊、装饰复兴、材料开放+色彩艳俗+手工回归）（L288）。

## 论辩与阐述方法

1. **概念辨析**：对"后现代"这一"非限定性的概括"进行语义学辨析（L246-248）。
2. **理论-实践对照**：以文丘里/詹克斯理论对应建筑与产品实例。
3. **辩证评价**：对孟菲斯既承认其"改变设计的面貌"的成就，又指出其"缺乏功能""很多成为博物馆藏品而非家庭用品"的局限（L268、L275）；对卢斯装饰观既引富勒批评，又承认卢斯的民主色彩（L288）。
4. **归纳法**：章末将后现代设计特点系统归纳为若干条（L288）。
