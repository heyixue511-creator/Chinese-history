# 00_方法与规则

---

## 一、分析框架总述

### 1.1 框架名称
**知识涌现分析框架（Knowledge Emergence Analysis Framework, KEAF）**

本框架用于对Emmanuel Cooper《Ten Thousand Years of Pottery》（2000年第四版）一书的知识体系进行系统性分析，揭示知识元（Knowledge Entities）在文本空间中的语义关系、链接结构以及知识涌现的机制与路径。

### 1.2 分析对象

| 属性 | 内容 |
|------|------|
| 原著作 | Ten Thousand Years of Pottery, Fourth Edition |
| 作者 | Emmanuel Cooper (1948-2012) |
| 出版 | British Museum Press, 2000 |
| 覆盖范围 | 全球陶瓷史，约公元前12,000年至公元2000年 |
| 结构 | 引言 + 14章 + 术语表 + 博物馆收藏名录 + 参考文献 + 插图出处 + 人名索引 |
| 分析源 | 基于14章分析报告 + 整体分析报告 + 专项报告与实体总索引（共16份源文件） |

### 1.3 分析目标

1. **知识元提取**：从全书分析报告中提取具有独立学术意义的知识单元（知识元），涵盖人名、地名、文化/文明/王朝、器物类型、技术术语、文献/典故六种类型。
2. **语义链接发现**：识别知识元之间的语义关系（跨章关联、因果关联、影响关联、对立关联、继承关联等），构建语义链接网络。
3. **知识涌现计算**：通过链接网络的结构分析，计算知识涌现的强度、新颖度和跨域度指标。
4. **知识发现报告**：基于涌现计算的量化结果，识别全书知识体系中的核心节点、关键桥接与隐藏知识模式。

## 二、知识元（Knowledge Entity）定义与编码规则

### 2.1 知识元定义

知识元（Knowledge Entity, KE）是指文本中承载独立语义信息、可被唯一标识和跨章追踪的最小知识单元。在本框架中，一个知识元必须满足以下条件：

1. **语义独立性**：具有独立的学术/历史含义，脱离上下文仍可被指认。
2. **可标识性**：在Cooper原文或分析报告中有明确的指称（专名或术语）。
3. **跨章可追踪性**：至少在分析报告中被明确提及，具有跨章关联潜力。

### 2.2 知识元六大类型

| 类型编码 | 类型名称 | 定义 | 示例 |
|----------|----------|------|------|
| KE-P | Person（人名） | 具有实质历史贡献的被专名指称的个人 | Bernard Leach, Josiah Wedgwood, Abu'l Qasim |
| KE-L | Location（地名） | 陶瓷生产中心、考古遗址或重要地理坐标 | Jingdezhen, Stoke-on-Trent, Kashan, Meissen |
| KE-C | Civilization/Culture/Dynasty（文化/文明/王朝） | 历史分期、文化标签或政治实体 | Song Dynasty, Abbasid Caliphate, Jomon Culture |
| KE-A | Artifact（器物/文物类型） | 具有独特学术意义的陶瓷品类或个体 | Tang Sancai, Iznik Dish, Greek Black-figure Amphora |
| KE-T | Technical Term（技术术语） | 陶瓷工艺核心概念 | Celadon, Tin Glaze, Lustre, Fritware, Bone China |
| KE-D | Document/Text（文献/典故） | Cooper引用的重要文本和图像证据 | Abu'l Qasim Treatise, Leach's "A Potter's Book", VOC Archives |

### 2.3 知识元编码格式

每个知识元采用统一编码：`KE-[类型编码]-[四位数字编号]`

示例：
- `KE-P-0001`：Bernard Leach
- `KE-L-0003`：Jingdezhen（景德镇）
- `KE-C-0005`：Song Dynasty（宋朝）
- `KE-A-0007`：Tang Sancai（唐三彩）
- `KE-T-0002`：Celadon（青瓷）
- `KE-D-0001`：Abu'l Qasim Treatise（14世纪）

### 2.4 知识元属性字段

每个知识元包含以下属性：

| 属性字段 | 说明 | 数据类型 |
|----------|------|----------|
| ID | 知识元唯一编码 | string |
| 名称（中文） | 中文名称 | string |
| 名称（原文） | 英文/原文名称 | string |
| 类型 | KE-P/L/C/A/T/D | enum |
| 时代/时期 | 所属历史时期 | string |
| 关联章节 | 在Cooper全书中出现的章节编号 | string[] |
| 语义标签 | 描述性关键词 | string[] |
| 重要度 | 基于出现频率和跨章次数的综合评分（1-10） | integer |
| 描述 | 简短描述（50字以内） | string |

## 三、语义链接（Semantic Link）定义与规则

### 3.1 链接定义

语义链接（Semantic Link, SL）是两个知识元之间具有学术意义的有向或非有向关系。一个链接由源知识元（Source）、目标知识元（Target）和关系类型（Relation Type）三元组构成。

### 3.2 三大链接类型

| 一级类型 | 二级类型 | 说明 | 示例 |
|----------|----------|------|------|
| SL-1 因果链 | SL-1.1 技术催生 | A技术发明催生了B器物类型的出现 | [轮制发明]→[轮制陶器] |
| | SL-1.2 文化推动 | A文化/文明推动B技术/器物的发展 | [阿拔斯王朝]→[锡白釉] |
| | SL-1.3 人物推动 | A人物推动B技术/器物/运动的发展 | [Bernard Leach]→[工作室陶瓷运动] |
| SL-2 传播链 | SL-2.1 贸易传播 | A器物/技术通过贸易路线传到B地区 | [中国青花]→[伊兹尼克青花] |
| | SL-2.2 技术转移 | A地区的技术被B地区学习/模仿 | [中国高岭土瓷]→[Meissen硬瓷] |
| | SL-2.3 移民传播 | 人口迁徙携带技术传播 | [朝鲜陶工]→[日本桃山陶瓷] |
| SL-3 结构链 | SL-3.1 继承发展 | B在A的基础上发展/改进 | [希腊黑绘]→[希腊红绘] |
| | SL-3.2 对立/差异 | A与B形成风格/技术/审美的对立 | [宋瓷静默美]↔[唐三彩热烈] |
| | SL-3.3 平行类比 | A与B在不同文明中独立发展的相似性 | [中国铅釉]⇔[罗马铅釉] |

### 3.3 链接编码格式

`SL-[一级编号]-[二级编号]-[流水号]`

示例：
- `SL-1.1-001`：陶轮发明→轮制陶器
- `SL-2.1-003`：景德镇瓷器→伊斯坦布尔托普卡帕宫
- `SL-3.2-001`：宋瓷vs唐三彩

### 3.4 链接属性字段

| 属性字段 | 说明 |
|----------|------|
| ID | 链接唯一编码 |
| 源知识元ID | Source KE ID |
| 目标知识元ID | Target KE ID |
| 链接类型 | SL-1.1 ~ SL-3.3 |
| 跨章节 | 是否跨越Cooper的不同章节 |
| 关联章节 | 涉及的章节编号 |
| 链接强度 | 基于文本证据强度的1-5评分 |
| 描述 | 链接的简短说明 |

## 四、知识涌现计算规则

### 4.1 知识涌现的操作性定义

在本框架中，**知识涌现（Knowledge Emergence）** 指当多个知识元通过语义链接形成复杂网络时，从网络结构中产生的、超出单个知识元或链接简单加和的系统性知识模式。

### 4.2 四大涌现指标

| 指标 | 编码 | 定义 | 计算公式 |
|------|------|------|----------|
| 涌现强度 | E_strength | 某知识元的语义链接密度 | E_strength(i) = Σ(LS_j) / N_total_links × 标准分 |
| 跨域度 | E_cross | 知识元跨越知识类型的程度 | E_cross(i) = N_types_connected / 6（六种类型） |
| 桥接度 | E_bridge | 知识元作为不同子图之间唯一或主要连接节点的程度 | Betweenness Centrality 归一化值 |
| 新颖度 | E_novelty | 知识元产生非预期跨域链接的程度 | Novelty = 1 - (E_expected / E_actual) |

### 4.3 涌现层级

| 层级 | 名称 | 定义 | 阈值 |
|------|------|------|------|
| L0 | 孤立知识元 | 无有效语义链接的知识元 | E_strength = 0 |
| L1 | 线性知识 | 仅存在于单一因果链或传播链中 | E_strength > 0, E_bridge < 0.3 |
| L2 | 网状知识 | 参与多个链接，形成局部网络 | E_bridge ≥ 0.3 |
| L3 | 涌现知识 | 作为多类型、多章节网络中的关键桥接节点 | E_bridge ≥ 0.6, E_cross ≥ 0.5 |
| L4 | 范式级知识 | 重新定义领域认知框架的元层级知识 | E_bridge ≥ 0.8, E_novelty ≥ 0.7 |

## 五、分析流程

### 5.1 五阶段流程

```
阶段一：知识元基础库建立
  ├── 从16份分析报告中提取所有实体
  ├── 按六大类型分类编码
  ├── 填写属性字段
  └── 输出：知识元基础库（01_知识元语意分析.md）

阶段二：语义链接图谱构建
  ├── 跨章关联发现
  ├── 三大链接类型分类标注
  ├── 链接强度评估
  └── 输出：语义链接网络（02_语义链接网络.md）

阶段三：涌现计算
  ├── 计算四大涌现指标
  ├── 涌现层级评估
  ├── 网络拓扑分析
  └── 输出：知识涌现计算（03_知识涌现计算.md）

阶段四：知识发现
  ├── 识别涌现热点
  ├── 检测隐藏模式
  ├── 发现知识盲区
  └── 输出：知识发现报告（04_知识发现报告.md）

阶段五：验证与迭代
  ├── 交叉验证涌现结果
  ├── 回溯原始文本确认
  └── 完成：五份分析文件
```

### 5.2 数据来源映射

| 分析报告文件 | 对应章节 | 主要知识元来源 |
|-------------|---------|---------------|
| 00_整体分析报告.md | 全书 | 方法论、结构知识元 |
| 01-14章分析报告 | 第1-14章 | 六类知识元的详细实例 |
| NN_专项报告与实体总索引.md | 全书 | 标准化实体总表、跨章关联 |

## 六、分析规范与约定

### 6.1 编码一致性
- 全书知识元使用统一编码体系，不重复、不遗漏
- 每一知识元在首次出现时给出完整属性
- 跨文件引用使用ID为准

### 6.2 中文为主、英文对照
- 主体文字使用中文
- 所有专名首次出现时标注英文/原文
- 技术术语使用中英对照格式

### 6.3 证据标注
- 引用Cooper原文时使用行号格式：(L7 §1) 表示第7行第1节
- 引用分析报告时使用文件引用格式：见[01_第一章分析报告 八.实体清单]
- 涌现计算结果引用使用公式标注

### 6.4 不确定性标注
- 推测性判断用"推测："前缀
- 待验证链接用星号(*)标注
- 统计结果的置信区间用±标注
