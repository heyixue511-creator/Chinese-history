## 二、Theme 聚合（高层语义域）

| Theme | 覆盖 Topic | 共享/桥接知识元 |

## 三、内聚度与涌现强度 S 计算说明

- **内聚度** = 簇内实际边数 / 完全图最大边数（n(n-1)/2）。估算基于 02 报告的链接清单。
- **涌现强度 S** = 簇内链接密度 × 跨簇引用次数。跨簇引用由枢纽知识元（南肯辛顿、Said、殖民物件、Leopold II、归还）的出现频次估算。
- 结果：S 最高的四个簇（T1/T2/T3/T9）恰是各章正文引用最密集、交叉引用最多的区域，与文本阅读感受一致。

## 四、一级涌现结构（E1…En）

一级涌现 = 知识元直接链接产生的新语义单元：

- **E1 帝国档案-物-机构三元组**：南肯辛顿（机构）+ 帝国档案（概念）+ 殖民物件（概念）→ "博物馆是殖民知识的物理化"。证据：L271、L273、L425。
- **E2 东方主义-商品化-驯化家族**：Said 东方主义 + 中国商品化（Ch3）+ 苏联驯化（Ch8）+ 象牙自然化（Ch14）→ "不同帝国以同类话语处理他者"。证据：L302、L498、L995、L2006。
- **E3 混杂性-身份-归还链**：混杂性（Ch6）+ 混血身份（Ch7）+ 毛利会堂（Ch10/11）→ "混杂既是物也是主体的生存状态，并引向归还诉求"。证据：L851、L964、L1459、L1487。
- **E4 凝视-摄影-优生学簇**：帝国凝视 + Lang 摄影 + 优生学 + 模拟 → "殖民视觉科学把差异写在身体上"。证据：L1663、L1731、L1760、L1842。
- **E5 象牙-拜物-宣传簇**：象牙 + 拜物 + Leopold II + 泰尔菲伦展 → "材料拜物成为殖民宣传的心理机制"。证据：L1868、L1922、L1957。
- **E6 归还-后殖民-当代博物馆链**：归还 + 怀唐伊法庭 + 香港移交 + 布拉德福德 → "后殖民时代帝国档案的重新处置"。证据：L255、L1101、L1489-1499。

## 五、二级涌现命题（P1…Pn）

二级涌现 = 跨簇综合、原文未直接言明但被证据支持的整体命题。

**P1：帝国博物馆是"物-知识-权力"三位一体的现代性装置。**
- 生成机制：T1（帝国档案）+ E1 三元组综合。
- 证据：L271（帝国档案定义）、L273（文化构成物）、L328（桑吉门=权威象征）、L425（象征地理）。
- 强度：高（枢纽簇，跨章重复）。
- 反例/边界：Ch9 布拉德福德证明此装置可被逆转（非殖民收藏）；Ch6 显示物也可反方向流动（屏风源于中国）。

**P2：不同帝国体系（英/苏/比）共享"他者驯化"的东方主义-拜物逻辑。**
- 生成机制：E2（东方主义-商品化-驯化家族）+ T5、T9 综合。
- 证据：L995（苏联驯化）、L1868（比利时拜物）、L437（中国商品化）。
- 强度：高。
- 反例/边界：苏联并非正式殖民地体系（L995 自注"名义上非殖民地"）；各帝国话语有本土变体（俄国"非欧非亚"自认），不可一概而论。

**P3：殖民物的"意义变形"遵循可预测的传记轨迹：仪式/日用品 → 战利品/纪念品 → 博物馆标本，其语义由处置它的机构与话语决定。**
- 生成机制：T2（宝座纪念品）+ T6（会堂归还）+ T7（传教收藏）+ "社会生命"概念综合。
- 证据：L598-604（纪念品理论）、L1639（语境转化力量）、L604（"慰藉的拜物"）。
- 强度：高。
- 反例/边界：Mataatua 的归还（L1499）与 Hinemihi 的拒绝归还（L1361）显示此轨迹并非单向不可逆；本土能动（Mbuti 模拟、毛利仪式）可在轨迹中插入反向语义。

**P4：种族作为"生物虚构"，必须靠视觉/物质技术（摄影、瓷塑、颅相、展示分类）在身体与物上持续书写才得以维持。**
- 生成机制：T4（肤色/血统）+ T8（优生学摄影）+ E4 综合。
- 证据：L1649（Gates 引）、L1663（视觉主义）、L1842（"把差异写于身体"）、L960（普查肤色标准）。
- 强度：高。
- 反例/边界：Mbuti 模拟（L1760）显示被摄者参与/颠覆这一书写过程；Ch7 显示肤色在费城 vs 圣克罗伊的判定标准不同（L962）。

**P5：后殖民博物馆伦理的核心张力在于"保存"与"归还"——机构的历史合法性恰来自其试图自我抹除的历史性。**
- 生成机制：T6 + T10 + Ch4 的"博物馆无历史"论证综合。
- 证据：L562（博物馆拒绝自我历史化）、L1361（国家信托拒绝归还）、L1487-1499（怀唐伊裁决）、L618（帝国档案沦为纪念品）。
- 强度：中高。
- 反例/边界：怀唐伊法庭的裁决"对政府无约束力"（L1489）显示归还的制度脆弱性；布拉德福德则代表"保存而不掠夺"的第三条路（L1101）。
