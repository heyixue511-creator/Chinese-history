# 08_专项报告与实体总索引

## 第一部分：专项报告

### 一、语言面貌

全书以简体中文书写，但保留大量英文人名、机构名、书名原文与注释（如 L213—L646 参考文献基本为英文条目），正文中英文术语并存（如 Trinity、proto-industrialization、putting-out system、missing market、public merchants、Solow Residual、FDI、LPI、MFA 等【L94、L48、L67、L122、L55、L15、L133、L133、L111】）。语体为学术论著与政论宣言的混合：一方面使用经济学术语（边际效用、收入弹性、规模报酬、一般均衡），另一方面大量使用形象化比喻与口号式论断（"热核反应""酵⺟菌""看不见的手指点江山"【L42、L55、L152】）。

### 二、文风特征

1. **论辩性**：全书围绕"驳斥制度经济学/新自由主义/华盛顿共识"展开，经常直接点名批评（"制度经济学家们如果不懂这一点……"【L196 注 69】）。
2. **宣言性**：大量祈使与感叹（"破译这个秘密并让所有穷国实现工业革命，是每一个经济学家的使命"【L9、L210】）。
3. **叙事性**：第六章以吴栋材创业史叙事承载理论【L166—L175】。
4. **预测性**：第四章、第七章大量未来断言（中国 2028—2048 年超越美国【L190】）。

### 三、修辞方式

| 修辞 | 例证 | 行号 |
|---|---|---|
| 比喻（军事/生物/物理） | "像无声的热核反应""胚胎发育""酵⺟菌""氧气与火的关系，纺织业就是火花" | L15、L42、L55、L91 |
| 设问/反问 | "为什么印度连玩具这样的基本日常用品都不能生产？" | L81 |

| 排比 | "被管理就意味着被监视、审查、指导、伏法……" | L158 |
| 反讽 | "西德尼·史密斯在1820年对美国表达了那样"（类比美国嘲讽中国） | L125 |

### 四、史料使用方式

1. **经典经济史著作为主干**：Landes 1999、Pomeranz 2001、Allen 2009、Mokyr 2009、Beckert 2014 等被反复征引并展开对话【L21、L81、L102、L132、L184】。
2. **档案与一手资料**：永联村协议全文【L175】、《邓小平文选》【L63】、纺织业机构名录【L87—L88】。
3. **当代数据**：世界银行、美国 EIA、IMF、WTO 数据【L63、L94、L133】。
4. **网络资料**：含大量网址链接（如 https://www.guancha.cn、archive.org 等【L63、L133】），个别处作者自注来源不明【L110】。
5. **引文方式**：章末脚注编号制，正文以 <sup>[n]</sup> 或 [n] 上标。

### 五、阐述方法

1. **历史平行比较法**：中国 vs 英国（1700—1900）、美国（1760—1920）、日本（1850—1960）【L18】。
2. **反事实推理**："如果1959年能分配多一点劳动力到粮食生产……大饥荒可能避免"【L42】；"如果当年中国有大量石油资源……很可能就不会走上原始工业化的道路"【L63】。
3. **模型化表达**：两个生产函数对比（y=n^0.5 与 y=2n−100）【L49】；效用函数种类多样化证明【L65—L66】。
4. **批判性论辩**：对高工资论、煤炭论、制度论、科学革命论逐一驳斥【L81、L102、L114、L202】。
5. **案例研究**：永联村【L165—L178】。

### 六、推演逻辑

总逻辑为"双谜题—经验归纳—理论抽象—批判—案例验证—理论总成—预测"：
1. 中国经验（第二章）→ 一般规律（第三章）→ 预测（第四章）；
2. 批判对象（第五章）与正面理论形成对比论证；
3. 案例（第六章）检验规律；
4. 理论总结（第七章）。核心推演链：市场规模→分工→规模生产→产业升级→工业革命。

### 七、文字风格摘录

- "资本（结构与设备）一旦投入，就是'免费'使用的。"【L81】
- "市场与组织密不可分，有形之手与无形之手密不可分，私人利益与集体利益密不可分。"【L144】
