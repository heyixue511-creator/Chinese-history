## 一、内容摘要

本书以解释"中国崛起"与"英国工业革命之谜"为双重目标（L20—L21），提出一套名为"新阶段论（New Stage Theory, NST）"或"胚胎发育理论（Embryonic Development Theory, EDT）"的经济发展理论（L188）。核心命题是：**市场不是天然存在、也非免费的，而是一种成本高昂的公共品，其创造者决定了一国能否完成工业化**（L9、L184）。由此，本书依次论证：中国 1978 年后的成功源于发现了正确的工业化顺序（原始工业化→第一次工业革命→第二次工业革命，即"胚胎发育"顺序）（L122、L188）；英国工业革命最先发生在棉纺织业，其秘密在于重商主义政府数百年的市场创造与全球纺织品市场垄断（L90—L92、L184）；华盛顿共识、进口替代、休克疗法与新制度经济学"把屋顶当作地基、把结果当作原因"，误读历史、因果颠倒（L21、L152、L184）。全书以第六章永联村案例（L165—L178）实证"胚胎发育"逻辑，以第七章总结理论并展望中国未来。

## 三、核心论点与关键概念

| 核心概念 | 含义 | 证据行号 |
|---|---|---|
| 市场是公共品 | "⾃由市场本⾝既不'⾃由'也不'免费'，⽽是⼀种昂贵的公共品"，其基⽯是社会秩序与社会信任 | L9、L184 |
| 市场创造 | 规模化生产有赖于大市场，大市场须由国家与商人共同创造，市场创造者缺失是发展失败的根本 | L21、L184、L188 |
| 胚胎发育理论/新阶段论（EDT/NST） | 工业化须按"原始工业化→第一次工业革命→第二次工业革命"顺序展开，每阶段为下一阶段创造市场与融资 | L21、L122、L188 |
| 原始工业化 | 工业革命前的乡村工业阶段（家庭包工制、乡镇企业），是"胚胎发育"的必经阶段 | L48、L63、L166 |
| 工业"三位一体" | 第二次工业革命起跑阶段的基础产业：能源、动力系统、基础设施 | L94、L122、L188 |
| 重商主义 | 以制造业立国的"经济民族主义"，国家扶持商业与制造业、开拓全球市场 | L25、L52、L55 |
| 干中学 | 技术进步源于生产实践而非纯科学，"卑贱者最聪明" | L63、L122、L125 |
| 华盛顿共识 | 基于福利经济学定理与新自由主义的"放松管制、私有化、市场化、自由化"药方 | L144、L152 |
| 榨取性/包容性制度 | 制度经济学核心二分法，本书认为其"因果颠倒" | L15、L18、L158、L184 |

## 五、方法论与材料

- **史料类型**：英国工业革命史、中国近代史（洋务、民国、毛泽东时代、改革开放）、美日德工业化史、荷兰经济史、印度纺织史、当代中国经济数据、永联村档案资料。
- **引用方式**：大量脚注（[1]—[93] 及第四章后以 [14] 起编号的注释），引用 Landers、Pomeranz、Allen、Mokyr、McCloskey、North、Acemoglu、林毅夫、张五常、温铁军、新望等中外文献；偶有对网络来源"作者忘记了出处"的自注【L110】。
- **论证方法**：历史比较法（中英美日工业化平行对照）、反事实推理、理论批判（针对新古典、新制度、华盛顿共识）、案例研究（永联村）、少量数学模型（企业生产函数技术对比【L49】、效用函数多样化证明【L65—L66】）。

## 六、历史地位与影响

本书是国内"发展政治经济学"领域直接以中国经验重构工业革命解释的代表性著作之一，与林毅夫新结构主义形成对话（L202—L204），并系统回击"中国崩溃论"（L23、L119）与制度经济学解释（L15、L78、L129、L158）。其"市场是公共品""胚胎发育"等概念为理解中国改革开放四十年提供了原创框架，也因强烈的政策论辩色彩引发争议。

## 七、成就与限度

- **成就**：以中国经验重新解释英国工业革命；对制度经济学因果倒置的批判具有史料支撑（如英国 1928 年才普选 L158、1830 年仅 2% 人口投票 L158、光荣革命后高税收 L184）；提出可检验的"NST 年表"；永联村案例翔实。
- **限度**：大量预测性断言（中国 2028—2048 年赶超美国，L190）缺乏实证检验；对"文化"因素着墨偏少（L18、L61 引韦伯、亨廷顿仅作批驳对象）；个别论证存在"以中国成功反推必然性"的目的论倾向；作者自注个别资料来源不详【L110】。

## 九、一句话概括

本书以"市场是昂贵的公共品、工业革命是政府主导的市场创造顺序展开的'胚胎发育'过程"为纲，用中国改革开放三十五年经验反照英国工业革命之谜，为发展政治经济学提供了一部立场鲜明的批判性纲要。
