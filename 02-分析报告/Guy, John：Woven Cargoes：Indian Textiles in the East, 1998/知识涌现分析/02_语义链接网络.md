# 02_语义链接网络：知识元之间的多类型关系拓扑

> 输入：01_知识元语意分析中的95个知识元（60 L1 + 27 L2 + 8 L3）
> 输出：语义链接网络的完整拓扑描述——节点、边、中心性、群落结构
> 方法：以知识元为节点，以语义链接为边，构建加权有向多层网络

---

## L###02.1 网络构建基础

### L###02.1.1 节点定义

本网络的节点由01_知识元语意分析中定义的95个知识元构成。节点属性：

| 属性 | 含义 | 取值范围 |
|------|------|---------|
| id | 知识元唯一标识 | KU-P01~KU-L3-08 |
| type | 知识元类型 | P/L/T/E/D/C/L2-CAU/L2-COM/L2-TEM/L2-SPA/L2-TRA/L2-EVI/L3 |
| level | 知识元层级 | L1/L2/L3 |
| source | 来源报告 | 00~NN |
| weight | 节点权重(以其为核心的知识元数) | ≥1 |

### L###02.1.2 边定义

每条边代表一个语义链接关系，方向从"源端"到"目标端"(对于非对称关系类型)。边的核心属性：

| 属性 | 含义 | 取值范围 |
|------|------|---------|
| source | 源节点KU-ID | — |
| target | 目标节点KU-ID | — |
| type | 链接类型 | CAU/COM/TEM/SPA/TRA/EVI/PAR/CON |
| strength | 链接强度(三维度合成) | 3-15 |
| cross_chapter | 跨章距离 | 1-5 |
| evidence | 证据支撑度 | 1-5 |
| frequency | 论述频率 | 1-5 |

3. **07_中国与05_印尼之间链接稀疏**：这反映了两个长时段案例的分析路径差异——中国重在制度史与长时段，印尼重在文化嬗变与仪式功能——二者之间缺少直接的比较链接，这本身就是一个"涌现"候选。
4. **03_中东与08_日本之间的"对角线空白"**：这两个位于Pires"双臂"最远端的市场之间几乎没有直接链接——它们通过01技术、05印尼等中介节点连接。
