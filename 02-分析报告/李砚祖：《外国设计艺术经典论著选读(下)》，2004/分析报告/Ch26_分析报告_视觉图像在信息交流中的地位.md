# Ch26 分析报告：视觉图像在信息交流中的地位（E.H.贡布里希）

## 章节定位与功能
- 行号范围：L248–L259（含 L250–L256 木刻图注、L258"规模有多大?"节）
- 功能：以**图像学/信息论**分析图像的表现、唤起、描述三种功能，探讨图像在信息交流中的地位与代码/内容的关系。

## 结构分析
1. 图像三种功能：表现（symptom）、唤起（signal）、描述（description）（L248 语境）；
2. 摹真与图像之分：摹真为乱真，图像为传达信息（L256）；
3. 观看者本分：解释依赖储存于心的图像（L256）；
4. 代码与内容：代码越易与内容分离越能传达信息（L256–L258）；
5. 选择性再现：地图、示意图、解剖图（达·芬奇）、家谱树（L256–L258）；
6. 图像与其他成分合作传达信息（L259）。

## 内容分析
- 核心命题：图像的真正价值在于"传达无法用其他代码表示的信息"（L259）。
- 摹真/复制/图像之辨：花卉标本不是图像，假花是图像（L256）。
- 代码与内容分离原则：黑白照片 vs 彩照（L256）。
- 引小艾文斯《图片和视觉信息交流》：古人未用印刷复制图像故科学停滞（L259）。

## 逻辑梳理
功能分类 → 摹真辨析 → 解释理论 → 代码理论 → 选择性再现（地图/示意图） → 信息价值结论。认知-信息交叉论证。

## 材料使用方式
- 大量图例（费拉拉地震木刻、庞贝镶嵌画、悉尼歌剧院、梅兰螺旋线、家谱树、先驱者号图画）（L250–L259）；
- 文献引证（小艾文斯、诺伊拉特夫妇）。

## 论辩与阐述方法
- 图例分析；
- 信息论术语（代码、信息值）；
- 认知解释学。
