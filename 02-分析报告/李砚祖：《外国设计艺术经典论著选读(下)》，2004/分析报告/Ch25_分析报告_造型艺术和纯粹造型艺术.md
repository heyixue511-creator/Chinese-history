# Ch25 分析报告：造型艺术和纯粹造型艺术（1937）——具象艺术和非具象艺术（皮特·蒙德里安）

## 章节定位与功能
- 行号范围：L247–L249（"虽然艺术无所不在……"至德文图注前）
- 功能：呈现**抽象主义理论宣言**——非具象艺术以"运动平衡"摧毁静态平衡，为纯粹造型艺术奠定理论基础。

## 结构分析
1. 编者按（查立）：蒙德里安与风格派、抽象艺术观（L247）；
2. 两种人类倾向：普遍美感的直接创造 vs 自我的美感表现（L247）；
3. 具象/非具象相对性："没有任何形式是绝对中立的"（L247）；
4. 中立形式与几何形（L247）；
5. 造型艺术的净化：非具象艺术诞生于具象艺术（L247）；
6. 运动平衡规律与直角关系（L247–L248）。

## 内容分析
- 核心命题："主题毫无价值，完全是多余的。只有线条、色彩和相互关系的运用才能表现内心生活的全部感情和理智"（L247）。
- 运动平衡：抽象艺术首要规律，"以建立运动平衡来摧毁并取代静态平衡"（L248）。
- 艺术与科学：时间"由个别朝向普遍、由主观朝向客观"的进化（L247）。

## 逻辑梳理
两种倾向 → 具象/非具象相对性 → 中立形式 → 净化论 → 运动平衡规律。纯粹造型的逻辑自洽。

## 材料使用方式
- 自我艺术实践的理论化；
- 《风格》杂志与《新造型主义宣言》背景（L247）；
- 几何形/直角的形式分析。

## 论辩与阐述方法
- 宣言体；
- 概念界定（中立、净化）；
- 形式分析（直角、斜角、平衡）。
