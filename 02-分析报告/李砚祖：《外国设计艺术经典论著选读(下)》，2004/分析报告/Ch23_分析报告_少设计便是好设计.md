# Ch23 分析报告：少设计便是好设计（迪特·拉姆斯）

## 章节定位与功能
- 行号范围：L211–L212（"我们生活的世界到处有技术的渗透……"至阿恩海姆"引言"前）
- 功能：重申**新功能主义**——设计以产品功能为出发点，外形应传导功能，"好设计便是少设计"。

## 结构分析
1. 编者按（朱孝岳）：拉姆斯身份与两大观点（L211 语境）；
2. 技术语境：技术 40 年成为人类文化本质因素（L211）；
3. 论证：外形由功能决定，谨慎、简洁、谦恭、自然、均衡（L211 语境）；
4. 口号："好设计便是少设计"（L211 语境）。

## 内容分析
- 核心命题：能传导产品内在功能的外形是合理、美的外形（L211 语境）。
- 功能主义观：技术信息（商业协会、刊物、博览会）促进先进观念与优秀设计（L211）。
- 与 Ch05/Ch06 呼应，构成拉姆斯设计哲学的三篇一体。

## 逻辑梳理
技术渗透（背景） → 功能决定外形（原则） → 少设计（口号） → 抵御嘈杂环境（目的）。
