# Ch35 分析报告：后数字化时代的设计教育（约翰·前田）

## 章节定位与功能
- 行号范围：L349–L364（小节：L351 数字化工具的人性束缚、L354 表达的均衡系统、L357 数字媒体教育、L360 美学与计算中心、L363 后数字世界的人）
- 功能：以**麻省理工学院媒体实验室**的视角倡导"以人为中心的数字化设计教育"，主张技术为人服务。

## 结构分析
1. 数字化工具的人性束缚：教育对数字媒介的无知、年轻人流失（L351–L352）；
2. 表达的均衡系统：数字技术提升创造与产量（L354）；
3. 数字媒体教育：新的教学路径（L357）；
4. 美学与计算中心：前田的机构与实践（L360）；
5. 后数字世界的人：设计教育的目标（L363–L364）。

## 内容分析
- 核心命题：约翰·前田倡导"以人为中心的技术和数字化设计教育的方法"（L351 语境）。
- 问题：教师对数字媒介知之甚少，学生转向杂志/网站自学（L351）。
- 回应：让工具为创意与人性服务，超越纯技术。
- 文末以"后数字世界的人"收束全书——设计教育指向完整的人。

问题诊断（教育落后于技术） → 方法论（人本数字化） → 案例（美与计算中心） → 展望（后数字世界）。全书收束篇。
