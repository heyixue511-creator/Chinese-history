# NN 专项报告与实体总索引

## 第一部分 专项报告

### 一、语言总体特征

本书为学术论文集，语言总体呈现以下特征：

1. **规范学术语体**：严谨的史学论文体，兼有设计学、视觉文化研究的跨学科语汇（L10、L23、L385）。
2. **第一人称介入**：大量使用"我""本文""在我看来"表述个人判断，带个人研究体温（L10、L117、L448）。
3. **口语化-书面化交织**：既有"咄咄怪事"（L136）等口语，又有"历久弥新""绵延不绝"等典雅书面语（L81）。
4. **引文密度高**：大段引录一手文献（郑午昌呈请 L87、雷圭元回忆 L194、加里宁谈话 L382 等），正文与引文交替推进。

### 二、文风与修辞方式

1. **设问引导**：以问题开启章节或段落（L81"这是为什么？"、L84、L117）。
2. **比喻与意象**：
   - 夜空与星（L14"没有那些闪亮的星，夜空是多么寡淡无味"）
   - 皮与毛（L448）
   - 空气与水（L117"金石趣味……就像梅雨时节湿润的空气"）
   - 野草与稻（L148 引朱荻"美术字却是满山的野草"）
   - 铅笔与铅火、光与电（L409）
3. **排比与递进**：如"首先……其次……最后"的论证结构频繁（L87、L111、L114、L460）。
4. **辩证措辞**：常用"既……又……""一方面……另一方面"呈现两面性（L7、L32、L309）。

### 三、史料使用方式

1. **一手材料优先**：作者自称"大部分时间都在找材料，尤其是一手材料、关键性的史料"（L7）。
2. **实物与档案并重**：字稿、讲义、呈请、邮票、宣传画、期刊实物、国徽档案（L35、L162、L309、L312）。
3. **口述史互证**："口述虽然重要，但是人的记忆在多年之后常常是不可靠的，必须把口述史和文献档案相互参证"（L17）。
4. **图文互证**："以图证史，把与设计相关的视觉图像和文字记载匹配起来"（L17）。
5. **文献考据**：对字稿、讲义、刊头字体的版本、时间逐项考证（L123、L162、L312）。

### 四、阐述方法

1. **概念界定先行**：各章开篇常先界定关键概念（L23、L120、L376、L385）。
2. **历史分期**：按时代划分叙述（L138-L150 美术字四期、L388-L397 宣传画五期、L238 期刊四期）。
3. **个案研究**：以具体人物（郑午昌、钱君匋、周令钊、刘岘）或实物（《图案法讲义》、国徽方案）为核心。
4. **比较研究**：中西、苏德、台港陆、古今对照（L303、L460）。
5. **微观史与宏观史的连接**：从"微观的字体语言"上升到民族国家意识（L81）。

### 五、推演逻辑

- **归纳-演绎结合**：从大量实物归纳类型与规律，再以理论框架演绎阐释（L385 图式分析）。
- **沿时间轴推进**：多数章节遵循时间顺序，展现"绵延"与"断裂"的辩证。
- **从史实到价值**：先考订史实，再作价值判断（L7"合理的解释和价值判断必须以此为基础展开"）。

### 六、文字风格

- **标题风格**：主标题简洁精当，副标题"以……为中心/为中心的知识考察/的讨论"标示方法（如 L157、L306）。
- **行文节奏**：长段密集，论证绵密；偶用短句点睛（L117"然而，一种字体是拯救不了一个国家的。"）。
- **术语规范**：中英术语并注（Typography、Art Deco、CIS、Schema 等）。
