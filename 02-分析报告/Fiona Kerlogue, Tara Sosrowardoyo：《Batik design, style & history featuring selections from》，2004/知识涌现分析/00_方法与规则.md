# 00_方法与规则

## 一、分析框架概述

### 1.1 任务定义

**K001** 本分析以 Fiona Kerlogue 著《Batik: Design, Style & History》（2004）的十份章节分析报告为知识源，执行四项递进操作：（1）从分析报告中提取知识元（Knowledge Unit），（2）构建知识元之间的语义链接网络（Semantic Link Network），（3）通过链接计算识别知识涌现（Knowledge Emergence）现象，（4）生成知识发现报告。

**K002** 核心命题：当知识元之间的链接密度超过阈值时，网络中会产生源文本未直接表述的新知识——这些"涌现知识"构成了本分析的核心产出。涌现知识的判定标准是：该知识在源分析报告的任何一个L###条目中均无直接陈述，但可以从多个L###条目的交叉链接中推导得出。

### 1.2 分析对象

**K003** 源知识库由以下十份分析报告构成：

| 编号 | 报告名称 | L###条目数 | 知识域 |
|------|---------|-----------|--------|
| R00 | 00_整体分析报告 | L001-L027 | 全书结构、论题、逻辑总览 |
| R01 | 01_导论章分析报告 | L001-L020 | 蜡染定义、社会功能、导论策略 |
| R02 | 02_起源章分析报告 | L001-L024 | 词源、考古证据、传播论vs内生论 |
| R03 | 03_地域传统章分析报告 | L001-L020+ | 十产地风格比较、差异因果分析 |
| R04 | 04_纹饰与意义章分析报告 | L001-L020+ | 纹饰符号学、色彩宇宙论、意义变迁 |
| R05 | 05_现代影响章分析报告 | L001-L020+ | 工业化、战争、独立后的产业转型 |
| R06 | 06_蜡染作为服装章分析报告 | L001-L020+ | 服装形制、穿着语法、身体符号学 |
| R07 | 07_蜡染作为艺术章分析报告 | L001-L020+ | 蜡染绘画、艺术vs手工艺论争 |
| R08 | 08_附属资料章分析报告 | L001-L015 | 博物馆收藏、术语表、地图、参考文献 |
| R09 | NN_专项报告与实体总索引 | SL001-SL026 | 学术谱系、文化接触模式、意义衰减机制、视觉方法论、实体总索引 |

**K004** 源知识库规模估算：约200+个L###编码条目，涵盖六大类实体（人物≥180个、地域≥40个、纹饰≥80种、技术/工具/材料≥40种、服装形制≥30种、社会组织≥50个）和四大专项报告，构成一个密集的多维知识网络。

### 1.3 核心概念定义

**K005** 知识元（Knowledge Unit, KU）：从分析报告中提取的最小可独立引用的知识陈述单元。每个KU必须：（a）对应一个L###编码或实体编号；（b）包含至少一个可验证的论断或事实；（c）可被赋予一个或多个语义标签。

**K006** 知识元的三元组分：
```
KU = (主体, 谓词, 客体)
```
其中主体/客体可以是实体（人物、地域、纹饰、技术、服装、组织）、概念（论题、论点、机制）、过程（因果链条、历史转折），谓词是二者之间的语义关系。

**K007** 语义链接（Semantic Link, SL）：两个知识元之间的有向语义关系。每个SL必须明确标示关系类型（∈{因果/CAU, 从属/SUB, 对比/CON, 时序/TEM, 相似/SIM, 互斥/DIS, 转化/TRA, 例证/INS, 条件/CND, 综合/SYN}）。

**K008** 语义链接网络（Semantic Link Network, SLN）：以知识元为节点、以语义链接为边的有向加权网络。SLN的形式定义为：
```
SLN = (V, E, W, T)
V = {KU₁, KU₂, ..., KUₙ}  // 知识元集合
E = {eᵢⱼ | KUᵢ → KUⱼ}   // 链接集合
W = {w(eᵢⱼ)}             // 链接权重
T = {type(eᵢⱼ)}           // 链接类型
```

**K009** 知识涌现（Knowledge Emergence, KE）：在SLN中，当多个知识元通过语义链接形成闭合环路或密集子图时，网络的结构本身"产生"了新的知识判断——这些判断不直接存在于任何单个知识元中，而是由节点间的结构关系推导而来。形式定义：
```
KE = { 新知识P | P ∉ ∪KUᵢ 且 P = f(SLN_subgraph) }
```
其中f是基于子图结构的知识推理函数。

**K010** 涌现强度（Emergence Strength, ES）：量化新知识的涌现程度。
```
ES(P) = α × 子图密度 + β × 链接交叉度 + γ × 跨域度
```
其中α、β、γ为权重系数（默认α=0.3, β=0.4, γ=0.3），子图密度为实际链接数/最大可能链接数，链接交叉度为不同链接类型在同一子图中的共存度，跨域度为子图跨越不同知识域的数量。

## 二、知识元提取规则

### 2.1 提取范围

**K011** 规则一（全量提取）：凡在分析报告中以独立L###编码标注的条目，均作为候选知识元。每条L###条目应产出一个主要KU加上不超过3个附属KU（如果条目包含多个独立判断）。

**K012** 规则二（实体归类）：分析报告中标示的六大类实体（P人物/R地域/M纹饰/T技术/C服装/I组织），每项实体作为一个独立的知识元节点，其知识内容为实体属性（名称、定位、特征、关联）。

**K013** 规则三（跨章追踪）：同一实体（如parang rusak纹饰）出现在多个章节分析报告中时，每个出现位置产生一个独立的"实体-语境KU"，并建立跨章同一性链接。

### 2.2 语义标注规则

**K014** 每个知识元必须标注以下属性：

| 属性 | 说明 | 示例 |
|------|------|------|
| KU_ID | 唯一标识符 | KU_00_L007 |
| 知识域 | 所属知识领域（技术/历史/社会/符号/经济/美学） | 符号域 |
| 知识层 | 认知层级（事实/解释/理论/元认知） | 解释层 |
| 确定性 | 知识的确定程度（确证≥90%/高信≥70%/中等≥50%/低信<50%/推测） | 高信 |
| 跨域度 | 该KU跨知识域的数量（1-6） | 3 |
| 核心度 | 在全网络中的结构重要性预判（1-5级） | 4级 |

**K015** 规则四（领域分配）：每KU按其主要论域分配到至少一个知识域。跨域KU可分配至两个域（如"Sultan Agung创造parang rusak"同时属于社会域和符号域），但须标注主域。

### 2.3 知识元编号体系

**K016** 编号格式：
```
KU_<来源报告编号>_<原L###或实体编号>
```
示例：KU_00_L007（来自00号报告L007条目）、KU_03_M01（来自03号报告的纹饰实体M01）。

## 三、语义链接构建规则

### 3.1 链接类型的操作化定义

**K017** 十类语义链接及其判定标准：

| 类型代码 | 名称 | 判定词 | 判定标准 |
|----------|------|--------|----------|
| CAU | 因果 | 导致/引发/造成/因此/所以 | KU_A是KU_B的原因或条件，存在时间或逻辑先导关系 |
| SUB | 从属 | 包含/属于/是...的一部分/分为 | KU_A是KU_B的子集、下层概念或组成部分 |
| CON | 对比 | 而/相比之下/与此不同/相反 | KU_A与KU_B在同一维度上存在差异或对立 |
| TEM | 时序 | 先于/后于/同时/随后 | KU_A与KU_B之间存在时间顺序关系 |
| SIM | 相似 | 类似/相似/正如/与之呼应 | KU_A与KU_B在结构、功能或形式上存在同构性 |
| DIS | 互斥 | 矛盾/冲突/排斥/不可共存 | KU_A与KU_B在逻辑上不可同时为真 |
| TRA | 转化 | 转变为/演变为/被改造为 | KU_A经历过程变化成为KU_B |
| INS | 例证 | 例如/比如/以...为例/具体体现 | KU_A是KU_B的具体实例或实证 |
| CND | 条件 | 如果/只有当/以...为前提 | KU_A是KU_B成立的必要或充分条件 |
| SYN | 综合 | 综上/综合来看/整体而言 | 多个KU的整合产生层级更高的判断 |

**K018** 规则五（显性链接优先）：优先从源分析报告的明确表述中提取链接。显性链接的标志包括：因果关系词（因此、导致）、比较词（而、相比之下）、时序词（随后、先于）、举例词（例如、典型的是）、包含词（包括、分为）。

**K019** 规则六（隐性链接推导）：当两个KU在同一个L###条目中被讨论，但条目未明确给出二者关系时，分析者可以根据知识内容推导隐性链接。隐性链接必须标注"隐性"标记，并在02号报告中说明推导理据。

**K020** 规则七（跨章链接）：同一实体或概念在多个章节的报告中出现时，必须建立跨章链接。跨章链接的权重高于单章链接（×1.5），因为它反映了知识的"复现性"——即同一知识被不同章节独立确认的强度。

### 3.2 链接权重的计算

**K021** 链接权重计分表：

| 权重因子 | 权重值 | 判定条件 |
|----------|--------|----------|
| 链接可证性 | 1.0 | 源文本直接陈述的显性链接 |
|  | 0.7 | 可从源文本推导的隐性链接 |
|  | 0.5 | 纯逻辑推导的链接 |
| 跨章确认 | ×1.5 | 同一链接在多章中被确认 |
|  | ×1.0 | 仅出现于单章的链接 |
| 实体重要性 | ×(1.0-2.0) | 基于实体在总索引中的出现频率调整 |

**K022** 最终链接权重 w = 可证性因子 × 跨章因子 × 重要性因子，归一化至[0,1]区间。

## 四、知识涌现计算规则

### 4.1 涌现的判定条件

**K023** 规则八（涌现三条件）：一个候选新知识P被判定为"涌现知识"须同时满足三个条件：

**条件一（不可约性）**：P不能从任何单一KU中直接获得。即 ∀KUᵢ ∈ V，KUᵢ ≠ P。

**条件二（结构依赖性）**：P的推导依赖于至少3个KU和至少2类不同的语义链接。即 P = f(KU₁, ..., KUₙ | n≥3, |{type(eᵢⱼ)}| ≥ 2)。

**条件三（可溯源性）**：推导P的每一步链接和推理都可以回溯到特定的KU和SL，并且每一推理步骤的逻辑类型可被明确标注。

**K024** 规则九（涌现分级）：

| 级别 | 名称 | 条件 | 示例 |
|------|------|------|------|
| E1 | 整合涌现 | n≥3, 同一知识域, 2类链接 | 从多种产地差异中整合出"风格形成的通用因果模型" |
| E2 | 跨域涌现 | n≥5, ≥2个知识域, ≥3类链接 | 从技术史+社会史+符号学中推导出"意义衰减的加速机制" |
| E3 | 范式涌现 | n≥10, ≥4个知识域, ≥5类链接 | 从全书论辩结构中识别出作者隐含的"理论立场" |

### 4.2 涌现计算流程

**K025** 知识涌现计算四阶段：

**阶段一（网络构建）**：从源分析报告中提取所有KU，建立单章SLN，再合并为全库SLN。

**阶段二（子图检测）**：使用社区发现算法（Louvain方法）识别SLN中的密集子图（社区）。每个社区代表一个"知识主题簇"。

**阶段三（环路检测）**：在每个社区内检测闭合语义环路。闭合环路的形式包括：
- 因果环路：A →(CAU) B →(CAU) C →(CAU) A（反馈回路）
- 对比环路：A →(CON) B →(CON) C →(CON) A（差异系统）
- 转化环路：A →(TRA) B →(TRA) C →(SIM) A（变异-回归）

**阶段四（涌现提取）**：对每个闭合环路或高密度子图，运行知识推理函数，提取涌现知识。推理函数包括：
- 因果链归纳：A→(CAU)B→(CAU)C ⇒ A是C的远端原因
- 对比结构抽象：A₁→(CON)B₁, A₂→(CON)B₂, ... ⇒ 存在"对立结构"的元模式
- 相似网络聚类：多个(SIM)链接聚合 ⇒ 存在"跨域同构"模式
- 时序序列综合：A→(TEM)B→(TEM)C... ⇒ 存在"发展阶段"的宏观叙事

### 4.3 涌现强度的量化

**K026** 涌现强度ES(P)的计算细则：

```
ES(P) = 0.3 × (子图密度) + 0.4 × (链接交叉度) + 0.3 × (跨域度)
```

其中：
- 子图密度 = 子图实际边数 / (节点数×(节点数-1))，上限1.0
- 链接交叉度 = 子图中不同链接类型的数量 / 10，上限1.0
- 跨域度 = 子图跨知识域的数量 / 6，上限1.0

**K027** ES取值区间及解释：
- ES ≥ 0.7："强涌现"——具有高度原创性的新知识，大概率不在任何已有文献中
- 0.4 ≤ ES < 0.7："中涌现"——具有一定原创性的补充知识，扩展了对已有知识的理解
- 0.2 ≤ ES < 0.4："弱涌现"——已有知识的重新组织，提供新的观看视角
- ES < 0.2：不视为涌现知识

## 五、知识发现报告规则

### 5.1 报告结构

**K028** 知识发现报告（04号）须包含以下必需要素：

1. **涌现知识清单**：以表格形式列出所有E1-E3级涌现知识，含涌现强度ES值
2. **每条涌现知识的详细展开**：包括构成KU链、链接类型路径、推理步骤、源文本支持
3. **涌现知识的学科意义**：说明每条涌现知识对蜡染研究/纺织史/文化研究的贡献
4. **未被实现的知识涌现**：识别出SLN中潜在但未充分实现的涌现区域（"知识空白"）
5. **方法论反思**：对本分析所用方法的局限性和改进可能性的讨论

### 5.2 报告的可追溯性标准

**K029** 规则十（全程可追溯）：04号报告中的每条涌现知识，读者必须能够逆向追溯至：
- 构成该涌现知识的具体KU编号
- 每个KU在源分析报告中的L###定位
- 每个推导步骤使用的链接类型和逻辑规则
- 可供独立验证的计算过程

### 5.3 报告质量标准

**K030** 知识发现报告的三条质量准则：

**准则一（不重复源文本）**：涌现知识不得重复源分析报告中已有的任何L###表述。如果发现"涌现知识"与某个L###条目实质一致，应降级为"确认性发现"而非涌现知识。

**准则二（逻辑完备性）**：每条涌现知识的推理链条必须完整。不允许逻辑跳跃——链中的每一环节必须对应一个独立的推理步骤。

**准则三（可证伪性）**：每条涌现知识必须伴随"反证条件"——即指明什么样的新证据可以推翻该涌现知识。这是区别"知识涌现"与"臆断"的关键防线。
