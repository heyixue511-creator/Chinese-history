# 04 知识发现报告

## 一、结构发现（网络整体特征）

1. **"公理-演绎"式知识架构**：全书以"设计=人类一切有目的的活动"（L275、L425）为公理，向下演绎出各门类设计史（T1-T7）与理论层（T8）、转型层（T9）。网络呈"单根多枝"树状，主干为"生活需求→造物→审美/制度分化"。
2. **门类隔离与理论缝合并存**：各门类簇（T2-T7）内部链接密集、簇间链接稀疏，靠"实用与审美"（L413-L421）、"礼制"（L2398）、"技术-材料"（L1270）等少数枢纽缝合——这是本书"门类分章、时间隐线"体例（L279）在网络结构上的直接投影。
3. **时序链主导微观结构**：簇内以"≻时序"链接为主（陶瓷三时期 L623-L814、纺织九段 L892-L1224、农具材质 L1814），因果链接（→）多集中在"设计缘起"段落——形成"缘起因果化、历程时序化"的固定写作语法。
4. **证据网络双轨并行**：考古实物链与古籍文献链并行不悖，交汇点稀少（如六齐 L1461 文献—司母戊鼎 L1461 实物在同一句中交汇），构成"实物证技术、文献证思想"的双轨证据结构。
5. **结构断裂带**：Ch7 理论文献（T8）与 Ch8 近现代实践（T9）之间直接链接极少，全书"古—今"转换依赖"传统与现代碰撞"（L2595）单点桥接——这是全书知识网络最薄弱的结构环节。

## 三、跨主题综合命题（对研究领域的贡献）

1. **"需求-制度-技术"三力模型（跨 TH-A/B/C）**：综合 P1-P3，可提炼中国设计史分析框架——生活方式需求（第一力）、礼制象征制度（第二力）、材料技术条件（第三力），三者权重随时代漂移（先秦重制度、唐宋重需求、明清重技术）。此模型超出原书表述，为网络涌现所得。
2. **"物用"与"礼用"的双轨史（跨 TH-B/A）**：民间日用设计（"物用之美"题眼 L3）与官方礼制设计（"礼用"）自新石器起分轨（L421 仪式性/劳动工具分化），至明清（宫廷 vs 民用家具 L2026）仍双轨并存——"物用之美"书名本身即是对"礼用"传统的偏移与补写。
3. **中国设计的"文化过滤机制"（跨 TH-E 与各簇）**：外来元素（胡服 L942、契丹瓷 L767、纳石失 L1137、景泰蓝 L1772、西式建筑 L2536）均经"本土需求+礼制框架+审美习尚"三重过滤后本土化——此机制贯通古代与近现代，是"传承与融合"（L2488）的深层结构。
4. **设计史书写的"器物中心主义"及其代价（元层命题）**：全书以"作品/工艺"为叙事单元，导致设计者（P4）、制度、市场（C4）、生态（C5）四类知识元系统性偏弱——这一发现对设计史方法论具有自反性价值。

## 五、总体评价与边界声明

1. **涌现价值**：本网络揭示出原书"门类史"表层之下稳定的"需求—制度—技术"三力结构、"物用/礼用"双轨传统与文化过滤机制——这些是单章阅读难以直接获得的跨章知识。
2. **边界一（文本依据）**：所有节点与链接均以源文件行号为证；推断命题（P1-P6、综合命题 1-4）标注了生成机制与强度，属"涌现解释"而非原文断言。
3. **边界二（方法）**：k/b/C/S 为语义化定性估算，非统计计算；链接清单以本报告 02 号文件为口径，换口径可能导致簇边界微调。
4. **边界三（文本质量）**：OCR 错字（L47、L855、L1848、L2622 等）与个别史实疑点（如部分年代、名称）已在相关报告中标注；"张让转"（L1848）按"张让传"理解，涉及该链接的判定附此说明。
5. **边界四（比较性）**：本书为"中国设计史论"单本，网络结论适用于本书内部结构；与中国工艺美学史（杭间）等其他著作的比较分析超出本次任务范围。
