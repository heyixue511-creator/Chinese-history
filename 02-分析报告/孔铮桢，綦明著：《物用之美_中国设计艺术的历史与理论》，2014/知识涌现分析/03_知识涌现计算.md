## 三、内聚度与涌现强度 S

- 内聚度 C = 簇内链接数/簇内节点数，九簇 C 介于 1.30-1.44，整体凝聚均匀；T6（民生科技）节点最多而 C 最低（1.33），反映其主题面广、链接较散。
- 涌现强度 S（定性估算 = 簇内链接密度 × 桥接数 归一化）：T2（陶瓷）、T1（发生学）、T3（服饰）、T5（金属）居首，与全书篇幅分配（Ch2-Ch5 占 L485-L1796）一致；T9（近现代）桥接少而 S 中等，与其"收束章"地位相符。
- 全网络估计：节点约 80（六类实体主要者），链接约 110-120 条（按本报告 02 号清单统计口径），平均 k≈1.4-1.5，属"枢纽稀疏、主干线性"的教材式网络。

## 四、一级涌现结构（E1…En）

- **E1（T1+T2）**：中国设计的逻辑起点是"生存需求→造物→审美分化"，其枢纽为"设计=有目的的活动"公理（L275、L425）与"造型第一性"（L494）。
- **E2（T3+T5）**：等级制度是中国古代设计的结构性变量——服饰（L884）、青铜（L1518）、建筑（L2253）、家具（L2047）同受"礼"约束，形成"礼制—象征—工艺"耦合。
- **E3（T4+T6+T7）**：材料—工具—结构构成技术演进主线：大漆（L1270）→ 夹纻（L1291）→ 榫卯（L2030）→ 斗拱（L2247）→ 龙骨水车（L1848）→ 简仪（L2135），呈现"材料属性决定工艺、工艺决定造型可能"的链条。
- **E4（T8）**：中国古代设计理论以"道/法/理/礼"为框架（L2398）、以"天时地气材美工巧"为工艺准则（L2452）、以"文质彬彬"为价值准则（L2386），形成自洽的理论元典层。
- **E5（T9）**：近现代中国设计的转型机制是"外来冲击—模仿改良—自主创新"三阶段（华生 L2630-L2632 为缩影；《点石斋画报》L2622 为观念层缩影）。

## 五、二级涌现命题（P1…Pn，含生成机制与强度）

- **P1（强，S 高）**：中国设计史的内在动力是"生活方式变迁"，而非单纯技术发明——全书各门类"设计缘起"均归因于生活需求（L492、L855、L1804、L1926、L1986、L2095、L2237），生成机制=跨 7 个 Topic 的"生活需求→"链接聚合。
- **P2（强）**：礼制是中国古代设计的"制度性筛选器"——符合礼制的设计（章服 L896、列鼎 L1518、都城形制 L2326）获得发展资源，违反者（胡服改革受阻 L942、金银平脱被禁 L1372）遭压制；生成机制=T3/T5/T7 中"礼制→"链接的跨簇同构。
- **P3（中强）**：中国设计的"材质替代链"（陶→原始瓷→瓷 L625；青铜→漆器 L1260、L1447；青铜→铁 L1447）遵循"性能-成本-审美"三维择优，可视为"适者生存"（L279）的微观机制；生成机制=T2/T4/T5 时序链的横向对齐。
- **P4（中）**：中国古代设计呈现"设计者隐身"现象——除近现代章（L2604-L2616）与个别名匠（张成 L1385、黄道婆 L1252、样式雷 L2294、李春 L2338）外，绝大多数造物无署名，与《梓人传》"设计师"理想（L2422）形成巨大落差；生成机制=人物类知识元的分布统计（古代簇人物密度远低于近现代簇）。
- **P5（中）**：文化交流的"双向性"被低估——本书详述外来输入（景泰蓝 L1772、纳石失 L1137、胡服 L942），但对输出面（缂丝外传 L2192、石拱桥传日本 L2346、指南针传欧 L2133）着墨较少，形成"输入详、输出略"的不对称网络；生成机制=T3/T5/T6 输出向链接计数显著少于输入向。
- **P6（弱-中）**：全书隐含一条"民本设计"线索——从"民以食为天"的农具（L1804）到"民生设计"总论（L1800），再到近现代"面向普通民众"（L2488），与"礼制设计"（P2）构成张力；生成机制=T1/T6/T9 中"民众需求"链接的纵向聚合。

## 六、客观性核对与反例

1. **P2 的反例**：民间设计（民间瓷窑 L700"完全从实用出发"、桃花坞年画 L2225、花旗锁 L1794）长期游离于礼制之外，说明礼制筛选器主要作用于官方设计域——P2 需限定为"官制设计域"。
2. **P3 的反例**：金银器并未被替代（L1449"长期地留存"），因其货币价值属性跳出"性能-成本"模型（L1718）——材质替代链不适用于"价值贮藏型"器物。
3. **E1 的边界**：近 200 万年的时间跨度（L277）基于考古断代，本书未讨论"设计意识"与"本能制作"的判据，起源命题存在定义弹性。
4. **P4 的边界**：明清以降文人与匠籍文献增多（《鲁班经》L2073、《髹饰录》L2472），"设计者隐身"可能是史料记录问题而非历史事实本身。
5. **数据说明**：以上 k/b/C/S 均为语义化定性估算（非统计编程），用于结构描述而非精确度量；链接数按 02 号清单手工计点，误差在 ±10% 以内。
