## 第一部分：专项报告

### 一、语言特征

1. **综述性教材语体**：全书以第三人称客观叙述为主，面向教学读者，使用"总的说来""不难看出""可以说""由此可见"等引导词（L413、L668、L1718、L2484）。
2. **长句与并列结构**：单句信息量大，常以"从……来看""无论……都""不仅……还……"构成长句（L494、L500、L1260）。
3. **引文—转释二元结构**：古籍引文后紧跟"即此意""也就是说""由此可见"的转释句（L452、L909、L1844）。
4. **术语三系统并用**：考古学（打制/磨制/类型/遗址 L391-L397）、工艺学（髹涂、盘筑、錾刻、缂丝 L508、L1291、L1106）、设计学（造型/装饰/人机工学/功能 L413-L417、L494）。

### 二、文风特征

1. **铺陈式描写**：对器物采用"尺寸—材质—工艺—纹样—功能—评价"的固定铺陈序列（如九子奁 L1339、长信宫灯 L1636）。
2. **量化密集**：精确数据遍布全书（经纬密度 L869、合金配比 L1461、城池面积 L2324、塔高 L2354）。
3. **典故与箴言点缀**：偶引诗文典故增强文采（汉武帝"泛楼船兮济汾河"L1961、陆游咏龙骨车 L1848）。
4. **四字格概括**：善用凝练短语作概念标签——"南青北白"（L679）、"遍地开花"（L700）、"衣被天下"（L1252）、"简厚精雅"（L2030）、"形纹色光"（L1772）、"墙倒屋不塌"（L2245）。

### 三、修辞方式

1. **比喻**：漆液采集"百里千刀一斤漆"（L1268）；水车板叶"极似动物的脊柱骨形态"（L1848）；楼船"水上堡垒"（L1961）；《东京梦华录》"文字版的《清明上河图》"（L2432）。
2. **对偶/排比**："从青色到白色、从单色到多色、从刻划到彩绘、从日用到陈设"（L487）；"温润的色泽、暖糯的手感、谦和的品质"（L387）。
3. **拟人**："青铜的生命是短暂的"（L1447）；"古老当青铜工艺便走上了没落的不归路"（L1447）。
4. **引用（权威/经典）**：全书记引经据典逾 60 处，覆盖经史子集（详见实体索引）。
5. **设问与悬置**：对争议问题以"目前仍无定论""颇有争议"悬置（L557、L790、L1480、L1888）。

### 四、史料使用方式

### 五、阐述方法

1. **分期叙述法**：技术/门类按时代分期（石器两期 L391、漆器三阶段 L1276、陶瓷三时期 L623-L814）。
2. **功能—形式分析法**：从使用功能解释造型（鬲袋足 L1520、甗蒸煮 L1533、官帽椅 L2085）。
3. **要素模型法**：提出分析模型（设计三因素 L496、建筑三大特征 L2243-L2255、李渔三论 L2440-L2444）。
4. **案例解剖法**：以经典案例承载论点（郑和宝船 L1982、水运仪象台 L2166、华生电扇 L2626）。
5. **制度关联法**：将设计与礼制/政治制度挂钩（列鼎 L1518、章服 L896、里坊 L2328、外八庙 L2370）。

### 六、推演逻辑

- **归纳**：实例 → 法则（石器两法则 L413；彩陶类型表 L531）。
- **演绎**：总定义 → 各门类展开（"设计=有目的的活动"L275 统领全书）。
- **因果**：生活需求 → 技术发明 → 审美分化（L496、L508、L818）。
- **类比**：古今/中西对照（人机工学 L417、记里鼓车 vs 维特鲁威 L1911、简仪 vs 第谷 L2135）。
- **辩证**：实用与审美、传统与外来、制约与推动的张力（L421、L2488、L1800）。

### 七、文字风格总评

文字工整、信息密集、学术规范性与可读性并重；以"物"证"史"、以"史"证"论"的写法使全书兼具工具书与教材功能；个别 OCR 或原书错字（L47"中国专年文版社"、L855 重复句、L1848"张让转"、L2622"晚晴"）不影响整体语义。
