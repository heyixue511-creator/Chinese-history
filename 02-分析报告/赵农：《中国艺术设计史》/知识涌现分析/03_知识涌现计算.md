## 三、内聚度与涌现强度 S 计算

1. **内聚度 C** = 簇内实际链接数 ÷ 可能链接数 n(n-1)/2（语义清点）。全书 11 簇 C 值集中在 0.21-0.29，说明各簇均为"稀疏强连通"——核心元密集互连、外围元单链挂接，符合史书"中心概念—例证实体"的写作结构。
2. **涌现强度 S** = C × 枢纽数 ÷ n。全书仅 T1（0.40）、T3（0.45）、T11（0.45）达中涌现；其余为弱涌现——因各簇枢纽元较少（1-2 个），簇内主题由"单枢纽+多例证"支撑，这正是"时代×门类"矩阵的必然结果：门类簇本身内聚，跨门类的强涌现集中在少数全能枢纽（器物、印刷、货币）上。
3. **高涌现区定位**：器物（S 综合贡献最大）、印刷术（T3 与 T5 双簇贡献）、货币（T2 全时段在场）三枢纽交汇处，即 TH1∩TH2 边界，是全书语义密度最高区（L262 道器、L522-L528 印刷、L627-L630 货币相邻共现）。

## 六、客观性核对与反例

1. **数值声明**：以上 k、b、C、S 均为语义人工清点估计，仅用于相对分级（高/中/弱），不宣称统计精度。
2. **文本矛盾如实保留**：
   - 提花机时代归属张力（L115 商代 vs L546 汉代普遍）→ 该元不入强连通簇的单一时间槽。
   - 上海县治年代（L939"1239 年"）与通行史料不符 → 标注存疑。
   - 应县木塔纪年（L747"公元51056年"）讹误 → 不采信数字。
   - 夏朝"仍然需要论证"（L115）→ 夏相关元置信度降级。
   - 鲁班传说化（L226）→ 仅取符号义。
3. **覆盖性说明**：T2、T5、T6 等"低内聚高桥接"簇的 S 值偏低并不意味主题弱，其枢纽（货币、佛教、设计管理）的桥接贡献在 Theme 聚合中权重更高——这是"轴辐网络"的固有特征，已在 02 报告网络特征节说明。
4. **作者自我设限**：第十章绪论自认"现代是一个笼统的概念"（L933），第七章结论自认"野蛮消退而文化精致之后的衰败"（L702）等，均按原文语义建链，不替作者补强论证。
