# 知识涌现分析 00：方法与规则

> 对象：周博《现代设计伦理思想史》（2014），分析基准 clean 版 591 行。

本文件定义知识涌现分析的层级、语义链接判定标准、涌现指标、证据规范与报告清单，供 01—04 各文件统一遵循。

---

## 一、层级定义

**知识元**：六类实体（人物、著作/作品、概念、机构、地点、事件），以行号证据定位，是网络的最小节点。
**Topic（主题簇）**：知识元之间形成强连通/高密度链接的簇，一个 Topic 内共享同一语义焦点（如"消费设计批判""第三世界设计"）。
**Theme（高层语义域）**：若干 Topic 聚合而成的高层语义域，承载全书的核心论域（如"设计伦理的思想史"）。

---

## 二、9 种语义链接判定标准

| 符号 | 类型 | 判据 | 本书实例 |
|---|---|---|---|
| → | 因果 | A 是 B 的原因/前提；事件先后且前者促发后者 | 60 年代环保运动→帕帕奈克生态设计主张（L92-L94、L100） |
| ⇒ | 条件 | A 成立 B 才可能；A 为 B 的充分/必要条件 | 民主制度⇒设计的平民化理想（L51）；立法⇒通用设计的实现（L214） |
| ↔ | 对比 | A 与 B 形成对立、对照、张力 | 道德话语↔消费话语（L42、L69）；真实世界↔虚假世界（L132） |
| ⊂ | 隶属 | A 从属于 B（概念包含、成员归属、组成部分） | "责任伦理"⊂"设计伦理"（L150）；"通用设计"⊂"设计伦理"实践（L214） |
| ≻ | 时序 | A 在时间上先于 B；历史先后 | 路斯装饰批判≻帕帕奈克消费批判（L48、L150） |
| ≈ | 空间共现 | A 与 B 在同一时空/语境中共同出现 | 帕帕奈克与斯德哥尔摩（L106）；乌尔姆与博朗（L78） |
| : | 属性 | A 是 B 的属性/特征/组成要素 | 设计伦理:实践理性（L235）；帕氏:社会利益立场（L147） |
| ⇐ | 论证支撑 | A 为 B 提供证据、论据、理论支撑 | 约纳斯《责任律令》⇐帕氏责任伦理观（L150）；马斯洛需要层次⇐帕氏需要论（L132） |
| ∼ | 同域 | A 与 B 属于同一主题域、互相映照但无强因果 | 通用设计∼全因素设计（L214）；可持续设计∼绿色设计（L168） |

## 三、涌现指标

1. **节点度 k**：某知识元直接相连的链接数。高 k 节点＝核心枢纽（如"帕帕奈克""设计伦理""消费设计""第三世界"）。
2. **桥接值 b**：某节点连接不同 Topic/Theme 的桥接链接数。高 b 节点＝中介/桥（如"可持续设计"桥接生态与环境、企业与伦理；"60 年代"桥接社会经验与设计话语）。
3. **簇识别**：强连通簇＝内部链接密度显著高于簇外链接的知识元集合；本报告以语义焦点人工识别，辅以链接计数。
4. **内聚度**：簇内链接数／簇内节点对。内聚度高表示该 Topic 主题聚焦。
5. **涌现强度 S**：综合考虑簇内节点数、链接数、跨簇桥接数，给出"低/中/高"定性分级。
6. **一级涌现结构（E1…En）**：由直接链接形成的涌现结构（Topic 级）。
7. **二级涌现命题（P1…Pn）**：跨 Topic/Theme 综合得到的、原文未明言但被证据网络支持的命题。

---

## 四、证据规范

1. 每条链接、每个簇、每个命题均须附 clean 版行号证据；
2. 反例与边界必须并列：对主观性强的判断（如簇归属、桥接判断）给出原文反证或边界说明；
3. 涌现命题必须与原文表述区分：命题为"分析者的综合推断"，须注明支撑与缺口；
4. 不写代码、不做统计计算，全部为语义分析。
