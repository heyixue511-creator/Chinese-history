# 语义链接网络

**本文件定位**：基于 01_知识元语意分析.md 的语义标注结果，构建全书知识元之间的形式化语义链接网络。包括节点体系、边的体系、全局网络结构、核心子网络和网络度量。

## 一、网络总览

### 1.1 规模

| 网络要素 | 数量 |
|----------|------|
| 节点总数 | 约 310 个 |
| 其中：概念节点（CN） | 57 个 |
| 其中：命题节点（PN） | 约 120 个 |

| 其中：中连接（W=2） | 约 260 条 |
| 其中：弱连接（W=1） | 约 200 条 |

### 1.2 网络类型

本网络是一个**多重有向加权语义网络**：
- 节点具有类型标签（CN/PN/SN/EN/MN）
- 边具有方向、类型和权重
- 同类型节点之间和不同类型节点之间均可建立链接
- 网络不强制连通——存在因论证领域分离而形成的自然聚类

## 四、全局网络结构

### 4.1 网络的宏观拓扑

基于节点类型和边类型的分布，网络呈现以下宏观拓扑特征：

**核心-边缘结构**：
- **核心层**（约 35 个节点，占总节点数 11%）：CN04（技术接合）、CN05（替代性路径）、CN06（错位的加总）、CN08（技术的性别维度）、CN09（技能的社会建构）、以及全书频率最高的实体节点（EN01 Crafts, EN02 Wrigley, EN06 棉纺织业, EN07 金属制品业, EN12 南兰开夏, EN14 伯明翰）。这些节点各自拥有 15-40 条边，构成了网络的"超级枢纽"。
- **半核心层**（约 60 个节点，19%）：大部分 L2 和 L3 概念、Ch1-Ch7-Ch8-Ch11 的核心命题、中等跨章实体。
- **边缘层**（约 215 个节点，69%）：仅在其出现章节内具有局部连接的实体、单章命题和修辞概念。

**论证"走廊"结构**：
- 网络中存在一条从 Ch1（数据解构）→ Ch2（产业全景）→ Ch5（区域衰落）→ Ch7（性别核心）→ Ch8（技术选择）→ Ch11（技术性别）→ Conc（收束）的高权重边"走廊"——这条路径上的所有边权重 W≥2，且边类型以 E_ELAB（展开）为主。
- 这条"走廊"之外，Ch3（理论模型）、Ch4（农业环境）、Ch6（贸易消费）、Ch9（工厂制度）、Ch10（纺织组织）、Ch12（金属制造）构成了"走廊"两侧的论证支撑。

## 五、核心子网络

### 5.1 子网络一：论辩网络（Berg vs. Crafts/Wrigley 正统）

**节点**：Berg（以 CN01-CN11 等核心概念为代表）、Crafts（EN01）、Wrigley（EN02）、Harley、Lindert/Williamson、量化证据（TFP、增长率、Hoffmann 指数）

**结构**：星形不对称结构。Berg 位于中心，多条 E_CRIT 边指向论敌节点，同时多条 E_REF 边引向同盟节点（Mokyr, Landes, Hudson）作为支撑。

**关键路径**：
```
Crafts/Wrigley 量化估计
    ↓ [E_CRIT]
CN06: 错位的加总 / CN07: 加总的遮蔽效应
    ↓ [E_ELAB]
Ch2 逐产业全景 + Ch5 区域分化
    ↓ [E_ELAB]
替代框架：CN04 技术接合 + CN05 替代路径 + CN08 技术性别维度
```

### 5.2 子网络二：性别分析网络

**节点**：CN08（技术的性别维度）、CN09（技能的社会建构）、CN20（女性劳动四个特征）、CN21（家庭工资经济）、CN24（骡机的再性别化）、EN09（珍妮纺纱机）、EN10（骡机）、EN11（水力纺纱机）、Pamela Sharpe（EN）、Judy Lown（EN）、Brenda Collins（EN）

**结构**：高度互联的紧密子网络——内部边密度为全网络最高。CN08 和 CN09 是该子网络的双核心，它们之间由高权重的 E_ECHO 边连接。

**关键路径**：
```
CN20: 女性劳动四个特征（廉价、灵活、灵巧、纪律性）
    ↓ [E_ELAB]
CN08: 技术的性别维度
    ↓ [E_ECHO] [E_ELAB]
CN09: 技能的社会建构 ←→ CN24: 骡机的再性别化
    ↓ [E_ELAB]
Ch11: 三种纺纱机的性别传记
```

**结构特征**：性别分析网络是全书论证中**最具凝聚力**的子系统——它的内部边密度远高于其他任何模块。这暗示了"性别"是 Berg 全书论证投入最密集、论证最完整的维度。

## 七、网络的动态特征：论证的"螺旋"运动

如果在网络中加入"时间"维度（按章节的线性顺序排列节点），可以观察到一种反复出现的运动模式：

```
Ch1: CN06(错位加总) → Ch2: EN06(棉纺) → Ch3: CN12(原工业化)
    ↓                                                    ↓
Ch4: CN18(有机经济) ← 对 Ch1 的农业维度的回响
    ↓
Ch5: CN10(区域去工业化) ← 对 Ch1 的区域维度的回响
    ↓
Ch7: CN08(技术性别) ← 新维度的引入
    ↓
Ch8: CN04(技术接合) ← 对 Ch1 和 Ch2 的技术维度的回响
    ↓
Ch11: CN24(骡机性别化) ← 对 Ch7 和 Ch8 的综合
    ↓
Conc: 四点结论 ← 对 Ch1, Ch7, Ch8, Ch10 的同时回响
```

这一运动模式的含义是：Berg 的论证不是逐步"覆盖"新领域的线性推进，而是每次向前推进一步后都回望前面的论证节点——每一次回望都以新的经验材料或理论透镜重新照亮同一个核心命题。这种"螺旋"不是写作风格的缺陷，而是论证结构的必然——因为全书的核心命题（"工业革命是断裂而非连续"）无法被任何单一产业、区域或分析维度的证据"一次性地"证成，它需要以不同材料不同角度反复论证。
