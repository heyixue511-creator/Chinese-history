# 00_方法与规则

## 《The Unknown Craftsman》知识涌现分析方法论

---

## 一、分析总纲

### 1.1 任务定位

本系列文件对柳宗悦《The Unknown Craftsman: A Japanese Insight into Beauty》（1972）的既有分析报告进行**知识涌现分析**（Knowledge Emergence Analysis, KEA），旨在：

- 从已完成的全书12份结构化分析报告（1份整体+10份章节+1份综合索引）中，提取知识元（Knowledge Units），构建知识元的语意类型体系；
- 基于知识元之间的多维语意关系，构建**语义链接网络**（Semantic Link Network, SLN）；
- 通过网络的拓扑计算与涌现算子，识别无法从任何单一知识元中直接读取的**涌现性知识**（emergent knowledge）；
- 输出一份独立的知识发现报告，揭示原分析中隐藏的跨域模式、深层结构与可操作洞察。

### 1.2 知识涌现的基本定义

**知识涌现**（Knowledge Emergence）指：当知识单元（KU）通过语意链接构成网络后，网络整体产生出个体知识单元所不具备的新属性、新关系、新模式或新命题的现象。

形式化表述：设知识单元集合 $K = \{k_1, k_2, \dots, k_n\}$，链接集合 $L = \{(k_i, k_j, r_{ij}) \mid k_i, k_j \in K, r_{ij} \in R\}$，其中 $R$ 为语意关系类型集合。由 $K$ 与 $L$ 构成的语义链接网络 $\mathcal{N} = (K, L)$，若存在命题 $P$ 使得：

- $P$ 不可从任意单一 $k_i$ 中推得；
- $P$ 可由 $\mathcal{N}$ 的子图结构 $\mathcal{G} \subseteq \mathcal{N}$ 通过涌现算子 $\mathcal{E}$ 导出；

则称 $P$ 为 $\mathcal{N}$ 上的一个**涌现性知识**。

## 二、知识元（Knowledge Unit）编码规则

### 2.1 知识元的定义

知识元是知识涌现分析的最小操作单元。一个知识元 $k$ 是一个三元组：

$$k = (\text{id}, \text{surface\_form}, \text{semantic\_type})$$

其中：
- `id`：知识元在本分析体系中的唯一标识符（六位码，见下文）；
- `surface_form`：知识元的自然语言表层形式（中文或原文术语）；
- `semantic_type`：知识元的语意类型（六类：PERSON / PLACE / OBJECT / CONCEPT / TIME / EVENT）。

### 2.2 知识元ID编码体系

所有知识元采用六位编码：

```
<TYPE_PREFIX><SEQ_NUMBER>
```

| 前缀 | 语意类型 | 英文 | 编码范围 | 数量 |
|------|---------|------|---------|------|
| P | 人物 | Person | P001-P036 | 36 |
| L | 地点 | Place | L001-L018 | 18 |
| O | 器物 | Object | O001-O024 | 24 |
| C | 概念 | Concept | C001-C030 | 30 |
| T | 时间 | Time | T001-T025 | 25 |
| E | 事件 | Event | E001-E022 | 22 |
| **总计** | | | | **155** |

**扩展规则**：若在语意分析中发现新的知识元（超出NN索引范围），使用 **X+三位编号**（X001-X999）表示，并在语意分析文件中标注来源。

### 2.3 知识元的属性标注

每个知识元除基础三元组外，附加五个分析属性：

| 属性 | 字段名 | 取值类型 | 说明 |
|------|--------|---------|------|
| 权重 | weight | 1-10 | 在全书中出现的章节数+论述深度 |
| 中心性等级 | centrality | core / bridge / peripheral | 在知识网络中的结构角色 |
| 跨域性 | cross_domain | 0-5 | 链接到不同语意类型的数量 |
| 极性 | polarity | positive / negative / neutral / ambivalent | 柳宗悦对该知识元的价值态度 |
| 抽象层级 | abstraction | concrete / intermediate / abstract | 从具体实物到纯概念的谱系 |

## 三、语意关系类型体系

### 3.1 关系类型定义

知识元之间通过以下八种核心语意关系链接：

| 代码 | 关系名 | 中文 | 说明 | 方向性 | 示例 |
|------|--------|------|------|--------|------|
| r_isa | is-a | 上下位 | 概念层级隶属 | 有向 | 民艺(C001) --r_isa--> 工艺 |
| r_inst | instance-of | 实例化 | 具体物对概念类的实例化 | 有向 | 喜左卫门茶碗(O001) --r_inst--> 民艺(C001) |
| r_part | part-of | 部分-整体 | 器物/事件/地点的部分关系 | 有向 | 刷毛目技法 --r_part--> 朝鲜陶艺传统 |
| r_cause | causes | 因果 | 事件/时间对事件/状态的因果 | 有向 | 工业革命(T023) --r_cause--> 工艺断裂 |
| r_asso | associated-with | 关联 | 人物-地点-器物-概念间的横向关联 | 无向 | 柳宗悦(P001) --r_asso--> 日本民艺馆(L001) |
| r_oppo | opposes | 对立 | 概念间的二元对立与张力 | 无向 | 他力(C003) --r_oppo--> 自力(C004) |
| r_deri | derives-from | 派生 | 概念/事件从另一概念/事件的衍生 | 有向 | 不二(C002) --r_deri--> 无心(C008) |
| r_analog | analogous-to | 类比 | 跨文化/跨域的类比对应关系 | 无向 | 他力(C003) --r_analog--> 基督教恩宠 |

### 3.2 关系权重

每条链接附加一个置信度权重（0-1）：

| 权重 | 含义 | 判定标准 |
|------|------|---------|
| 1.0 | 显性命题 | 原文中有明确表述的命题关系 |
| 0.8 | 强隐涵 | 可从原文多个段落中确定推得 |
| 0.6 | 弱隐涵 | 基于语意类型的合理推断，需标注 |
| 0.4 | 推测性 | 跨域类比，需在发现报告中明确说明 |

### 3.3 关系的三元组存储格式

每条链接在 `02_语义链接网络.md` 中以三元组存储：

```
(source_id, target_id, relation_code, weight)
```

示例：
```
(P001, L001, r_asso, 1.0)
(C003, C004, r_oppo, 1.0)
(O001, C001, r_inst, 1.0)
```

## 四、知识涌现算子体系

### 4.1 涌现算子定义

本分析使用五个涌现算子作用于语义链接网络，以发现涌现性知识：

| 算子代码 | 名称 | 输入 | 输出 | 说明 |
|---------|------|------|------|------|
| E_BRIDGE | 桥接涌现 | 两个或以上不直接相连的子图 | 跨域桥接命题 | 发现原本隔离的知识域之间的隐藏联系 |
| E_CLIQUE | 团簇涌现 | 高密度链接子图（clique或准clique） | 主题凝聚命题 | 从密集链接中提炼未命名的隐含主题 |
| E_CYCLE | 循环涌现 | 有向链接构成的环 | 自指悖论或自洽体系 | 发现循环论证或自洽的封闭知识体系 |
| E_HOLE | 空洞涌现 | 网络中应存在链接但实际缺失的位置 | 知识缺口命题 | 识别柳宗悦论述中的未说的、规避的或盲区 |
| E_PATH | 路径涌现 | 两个远距离知识元之间的最短路径 | 间接因果/类比链 | 发现非显而易见的远距知识关联 |

### 4.2 涌现性知识的判定标准

一个由涌现算子产生的候选命题 $P$ 被认定为**有效的涌现性知识**，须同时满足：

1. **新颖性**：$P$ 未在任何单份分析报告中以命题形式出现；
2. **可验证性**：$P$ 可由网络中的链接路径和知识元属性证成，且推理链条可追溯；
3. **非平凡性**：$P$ 不是已知命题的简单重述或直接推论；
4. **语意可解释性**：$P$ 可以用自然语言表述为有意义的学术命题。

### 4.3 涌现性知识的置信度

$$Conf(P) = \frac{1}{|links(P)|} \sum_{l \in links(P)} w(l) \times \frac{|nodes(P)|}{diameter(P)}$$

其中 $links(P)$ 为支撑命题 $P$ 的链接集合，$w(l)$ 为每条链接的权重，$nodes(P)$ 为涉及的节点数，$diameter(P)$ 为支撑子图的直径。置信度范围为 0-1。

## 五、分析工作流程

### 5.1 五阶段流程

```
[输入] 12份分析报告（.md/11章+NN索引）
  │
  ▼
[阶段一] 知识元提取与语意分类 → 输出: 01_知识元语意分析.md
  │  - 从NN索引继承155个已标注实体
  │  - 从各章分析报告中提取新增知识元
  │  - 对所有知识元进行六类语意分类与五属性标注
  │  - 进行语意类型的分布统计与结构分析
  │
  ▼
[阶段二] 语义链接网络构建 → 输出: 02_语义链接网络.md
  │  - 基于八种语意关系，建立知识元间链接
  │  - 每链接标注关系类型、权重、出处
  │  - 构建网络全局可视化与统计特征
  │  - 分类型的子网络分析
  │
  ▼
[阶段三] 知识涌现计算 → 输出: 03_知识涌现计算.md
  │  - 运行五个涌现算子
  │  - 计算每个候选涌现命题的置信度
  │  - 记录计算过程与推理链条
  │  - 对涌现命题进行优先级排序
  │
  ▼
[阶段四] 知识发现报告撰写 → 输出: 04_知识发现报告.md
  │  - 筛选高置信度涌现命题
  │  - 按主题域分组呈现
  │  - 提供每个发现的推理溯源
  │  - 给出学术贡献评估与应用建议
  │
  ▼
[输出] 一套完整的知识涌现分析报告（5份.md文件）
```

## 六、工作语言与格式规约

### 6.1 语言约定

- **工作语言**：中文（简体）
- **知识元的surface_form**：优先使用中文译名，括号附原文术语
- **关系三元组**：使用英文编码（r_isa, r_inst, ...）
- **涌现命题**：以中文自然语言表述

### 6.2 符号规范

- 知识元ID以方括号标注：`[P001]`
- 关系以箭头链表示：`[P001] --r_asso--> [L001]`
- 涌现性知识以标记 `【EK-序号】` 标注
- 知识缺口以标记 `【KG-序号】` 标注

### 6.3 数学符号

- $K$：知识元集合
- $L$：链接集合
- $R$：关系类型集合
- $\mathcal{N}$：语义链接网络
- $\mathcal{E}$：涌现算子
- $w(l)$：链接 $l$ 的权重
- $Conf(P)$：涌现命题 $P$ 的置信度
