## 一、网络构建总述

### 1.1 构建原则

本网络基于 `01_知识元语意分析.md` 中的179个知识元全集，依据八种语意关系类型（r_isa / r_inst / r_part / r_cause / r_asso / r_oppo / r_deri / r_analog），构建知识元间的多维语义链接。

每条链接满足以下条件：
- 源知识元和目标知识元均可在 `01_知识元语意分析.md` 中找到ID；
- 链接关系类型属于八种之一；
- 链接关系可追溯至原始分析报告的具体段落（权重=1.0）或可合理推断（权重≤0.8）；
- 权重标注依据 `00_方法与规则.md` 第3.2节的权重体系。

### 1.2 网络规模概览

| 指标 | 数值 |
|------|------|
| 节点总数 | 179 |
| 链接总数（估算） | 约450-550条（核心显性链接） |
| 链接类型数 | 8 |
| 平均节点度 | 约5.0-6.1 |
| 网络直径 | 6（P001→O023的最短路径长度） |
| 连通分量数 | 1（全连通网络） |

## 三、子网络分析

### 3.1 概念子网络（38节点 + 约120链接）

概念子网络是全书知识结构的"哲学骨架"：

**拓扑特征**：
- 最高密度子网络，平均节点度约6.3
- 以C002（不二）为绝对中心，直接链接≥20个其他概念节点
- C002与C003（他力）构成"双核结构"——两者之间的r_deri链接（权重1.0）是网络中最强的链接之一

**核心子图——"不二-他力"概念簇**：
```
                        ┌── C005 涩
                        │
    C015 平常心 ←── C008 无心 ←── C002 不二 ──→ C013 如如
                        │                      │
                  ┌─────┤                      ├──→ C014 即
                  │     │                      │
            C009 无碍  C010 无事          C003 他力 ──→ C028 恩宠 ──→ X018 接受
                                                      │
                                                X013 无名性 ←── C004 自力 (对立)
                                                      │
```

## 五、语义链接网络的关键结构特征总结

### 5.1 "双焦点结构"

全书知识网络呈现**利奇-西方工艺复兴**与**柳宗悦-东方佛教美学**的双焦点结构——两个焦点通过P001-P002的强r_asso链接和C028（恩宠）的r_analog链接连接，但两个焦点内部的语义链接密度远高于焦点间。

### 5.2 "明暗双轨叙事"

- **明轨**：人物-器物-地点-事件的"显性"历史叙事链（P001/L002/O001/T009/E001...）
- **暗轨**：概念-概念之间的哲学派生/对立链（C002→C003↔C004→C008→C009...）
- 两轨通过r_inst链接（如O001→C002）和r_deri链接（如E004→C017）连接

### 5.3 "三级消解"结构

柳宗悦对立关系的处理呈现三级结构：
1. **识别对立**（如C003↔C004, r_oppo=1.0）
2. **通过"不二"消解**（C002→C003, C002→C004, r_deri=0.8）
3. **通过具体器物/事件实例化"不二中的统一"**（O001→C002, r_inst=0.8）

这是柳宗悦从禅宗公案的"破-立-显"结构中借用的逻辑模板。

### 5.4 知识网络中的"沉默结构"——确定性缺口

以下位置本应存在链接但实际缺失，将成为空洞涌现（E_HOLE）的重点考察对象：
