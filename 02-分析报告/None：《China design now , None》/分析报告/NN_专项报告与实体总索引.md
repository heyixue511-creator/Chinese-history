# NN：专项报告与实体总索引

## 专项报告一：全书方法论评析

### 1.1 "展览驱动"的研究范式

《China Design Now》是一部典型的"展览驱动"（exhibition-driven）出版物。全书的研究、写作和编辑流程与V&A同名展览的策展过程深度交织——编者张红星和劳伦·帕克在致谢中坦承这项工作耗时四年（"the best part of four years"）。这一范式决定了全书的若干核心特征：

**优势**：（1）图像资料极为丰富，全书中穿插了大量设计作品、建筑摄影和纪实摄影；（2）第一手口述史料——编者对设计师、建筑师、艺术家的访谈构成了全书最珍贵的原始资料；（3）多声部叙事——全书的撰稿人涵盖策展人、学者、记者、设计师、摄影师等多种身份，形成了"众声喧哗"的知识生产景观。

**局限**：（1）展览的时间压力可能影响了学术深度——某些章节（如"中国时尚简史"）因篇幅限制而显得过于简略；（2）三城框架虽然清晰有力，但也排除了许多重要的设计城市和地区（广州、杭州、成都、重庆等）；（3）展览对"正面叙事"的需求可能淡化了对敏感问题（如政治审查、知识产权侵权）的批判力度。

### 1.2 多学科交叉的知识来源

全书的参考文献（L1566-1847）涵盖设计史（John Heskett, Clive Dilnot）、政治经济学（Joshua Cooper Ramo, Peter Nolan）、城市社会学（Saskia Sassen）、建筑理论（Mark Wigley, Charles Jencks）、文化研究（Arif Dirlik, Zhang Xudong）、经济学（胡鞍钢）和中国文学批评（张颐武）等多个领域。中文与英文文献并重，学术专著与媒体报道并行。

### 1.3 中英双语的跨文化生产

全书原文为英文，但研究对象是中国——这一"用西方语言讲述中国故事"的跨文化生产模式决定了全书的知识政治学特征：它既是对中国设计文化的"引介"（introduction to the West），也是一种"阐释框架"（interpretive framework）的构建。全书中反复出现的中文关键术语——"美工"（meigong）、"炒更"（chaogeng）、"修炼"（xiulian）、"摩登"（modeng）——都被精心保留了中文原词并附以英文解释，体现了对本土概念的尊重和翻译政治学的自觉。

## 专项报告二：三城比较分析

### 2.1 深圳-上海-北京：三种现代性模式

| 维度 | 深圳（Frontier City） | 上海（Dream City） | 北京（Future City） |
|------|----------------------|-------------------|-------------------|
| 核心隐喻 | 前沿/实验 | 梦想/欲望 | 未来/权力 |
| 时间定位 | 1980年代-1990年代中 | 1990年代中-2000年代 | 2000年代-2008及以后 |
| 主要设计领域 | 平面设计/视觉文化 | 时尚/家居/消费 | 建筑/城市/交通 |
| 驱动力量 | 市场/非正式经济 | 消费/中产阶级 | 国家/全球化 |
| 关键行动者 | 独立设计师 | 设计师+消费者 | 国际建筑师+国家 |
| 空间动力学 | 从香港学习 | 怀旧+垂直上升 | 水平帝国vs垂直资本 |
| 摄影主题 | 劳动/工厂（余海波） | 家庭/居住（胡杨） | 城市肌理（曾力） |
| 代际特征 | 先驱一代（50后/60后） | 消费一代（60后/70后） | 全球化一代（70后/80后） |

### 2.2 三城的叙事分工与互补

全书三城结构构成一种"经济基础→消费文化→上层建筑"的叙事分工：
- 深圳讲述的是设计文化的"生产端"——如何从无到有地建立一个设计行业
- 上海讲述的是设计文化的"消费端"——设计如何融入日常生活和身份建构
- 北京讲述的是设计文化的"制度端"——国家如何通过建筑和城市规划表达其现代化愿景

### 2.3 被忽略的城市和领域

广州（1980年代广告业先驱、广交会所在地）、杭州（中国美术学院、王澍）、成都（刘家琨）、重庆（直辖市实验）等城市在全书中仅作为次要参考点出现。工业设计——尽管是中国"从中国制造到中国创造"转型的核心领域——在全书中仅获得有限的直接关注（导论中的简要提及和"改变改变"中的工作坊案例）。数字设计、游戏设计、交互设计等21世纪初正快速兴起的领域也未被深入触及。

## 专项报告三：全书核心叙事线索

### 线索一：从"美工"到"设计师"——身份的政治
全书追踪了"设计者"在中国社会中的身份变迁：从毛泽东时代意识形态化的"美工"（meigong），到改革开放初期的体制内"技术人员"，到1990年代"跳入商海"的独立创业者，到21世纪"创意公民"（creative citizens）。这一线索贯穿了深圳篇（第三章、第五章）和上海篇（第八章、第十章）。

### 线索二：从"中国制造"到"中国创造"——产业升级的国家叙事
从导论中提出的"模仿文化"诊断（第02章），到深圳篇中"抄袭→追赶→国际化"的平面设计发展（第03、05章），到上海篇中"消费革命"和"品牌竞争"（第08章），到北京篇中"与国际建筑师合作"的建筑实践（第13章），到汽车工业的"合资→模仿→自主设计"路径（第15章），全书为"中国创造"的建设提供了一幅多领域并行的全景图。

### 线索三：从"集体"到"个体"——主体性的重建
全书隐含地追踪了"个体性"（individuality）在中国的重建过程：从导论中描述的"告别反对物质消费和个人需求的意识形态战场"（第02章），到深圳篇中"第一次可以自己做决定"的创业青年（第03章），到上海篇中"将时尚设计视为一种艺术"的王一扬（第08章），到韩寒的"不合作清单"（第11章），到余海波镜头中沉默的个体劳动者的面容（第07章）。

### 线索四：从"速度"到"质量"——可持续性的追问
从全书的倒数第二章（"改变改变"，第16章）向上回溯，可以发现一条时隐时现的"可持续性质问"线索：导论中对"抄袭文化"的批判蕴涵着对"速度优先"模式的质疑；深圳篇中大芬村画工的廉价复制与"设计原创性"之间的张力（第07章）；上海篇中消费者"试图一次性尝试一切"的"折衷混合"（第09章）；北京篇中城市扩张的环境代价和"宜居城市"的政策回应（第13章）；以及最终在"改变改变"中汇聚为对"跳跃式发展"战略的系统性论证（第16章）。
