**构成知识元**：KE-P002(跨文化载体命题) + KE-P902(去神圣化命题) + KE-M003(病隐喻) + KE-M001(朝圣隐喻) + KE-S004(考古证据)

| 事件 | 意图 | 非意图后果 | 历史影响 |
|------|------|-----------|---------|
| 景德镇深层瓷石枯竭 | 继续采矿 | 被迫添加高岭土→"真瓷"诞生 | 此后全球陶瓷的物质标准 |

```

推论:
  不可回收性高(瓷器) → 文化承载深度深(千年跨文化层积可考古追溯)
  不可回收性中(银器/金属) → 文化承载深度中(常被熔化重铸，文化证据丢失)
  不可回收性低(香料/茶叶) → 文化承载深度浅(消费即灭失，仅文献可追)
  可复制性高(印刷品) → 文化承载广度大但个体信息密度低

这一框架可将Finlay对瓷器独特性的物质性论证扩展为
一般性的"物质文化的耐久性-信息承载函数"。
```

```
  有: 朝鲜/日本/越南
  无: 海岛东南亚/东非(直接消费中国瓷器，无本土仿制)

                    国家控制高

                    ●   │
                        │

              │         │

              │         │

              │         │
              │  (东亚有技术基础)
              │  (东南亚/东非无)

```

**判定依据**：
