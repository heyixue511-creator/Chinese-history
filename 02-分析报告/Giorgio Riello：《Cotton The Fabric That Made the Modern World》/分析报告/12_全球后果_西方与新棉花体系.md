# 12_全球后果：西方与新棉花体系

## 一、章节定位与功能

### 1.1 在全书中的位置

本章是Part III的最后一章，承担着**整合论证和展示全球后果**的功能。它将前文分别论述的各个维度（原材料、技术、消费、贸易）统合为"向心系统"的完整运作图景，并将视线投向19世纪——展示这一系统如何"反馈"到亚洲，造成印度等地的去工业化。

### 1.2 功能

- **统合功能**：将全书分散在各章的线索（贸易网络、生产技术、原材料供给、消费模式）编织进"向心系统"的统一运作逻辑
- **后果展示功能**：展示英国和欧洲棉纺织品如何"反攻"亚洲市场——印度从出口国变为进口国
- **去工业化辩论功能**：审慎地参与关于印度"何时开始衰落"的学术争论
- **当代回响功能**：为Ch13的"从分歧到趋同"结论提供历史基础

## 三、内容分析

### 3.1 核心论题

**论题一**："向心系统"在19世纪进入全盛期——欧洲成为全球原材料的"吸收器"和制成品的"输出器"，棉花纺织品是全球贸易的支柱商品。

**论题二**：英国棉纺织品对亚洲的"反攻"是渐进的——先是棉纱（1810年代），然后是棉布（1820-30年代）。1828年一位孟加拉寡妇的证词生动地记录了廉价的机纺棉纱如何摧毁了她的手工纺纱生计。

**论题三**：关于印度"去工业化"存在学术争议——有"长时段的渐进衰落"和"殖民主义导致的突然崩溃"两种立场。Riello采取中间立场：承认欧洲竞争的影响，也承认印度产业内部的适应能力。

### 3.2 关键论点与案例

1. **Degas的交易所画作**（Figure 12.1）：1873年新奥尔良棉花交易所——"资本主义的本质不是海洋或冒险商人的世界，而是官僚的世界：记录数字、评估信息、检查商品"。这幅画捕捉了"向心系统"运作的核心场所。

2. **孟加拉寡妇的证词（1828年）**：一位22岁守寡的孟加拉妇女通过手工纺纱养活了三个女儿——直到英国机纺棉纱进入市场，价格降到原来的四分之一。"当我检查那纱线时，我发现它确实比我的好。"这是全球史中最令人心碎的个人叙述之一。

3. **英国棉布出口的两次浪潮**（Figure 12.2）：1760s-1820s以欧美大西洋市场为主 → 1820s以后亚洲市场急剧增长。到1851年英国60%的棉花产量用于出口，占全部出口商品的五分之二。

4. **Maria Graham的震惊（1808年孟买）**：这位苏格兰妇女在孟买集市上打开一包布，发现一半是英国制造——"棉花运去英国，制成成品又运回这个国家，居然比印度本地的还便宜"——她描述了"向心系统"最反直觉的特征。

5. **Table 12.1的四地区生产量比较**：1820年代印度织工数量仍是英国的四倍，但到1840年代英国产量已超过印度——这是"分歧"在生产端的量化标志。

## 四、逻辑梳理

### 4.1 论证链条

```
19世纪全球棉花贸易的图景（欧洲进口85%原棉）
→ 欧洲制成品的出口浪潮（大西洋市场→亚洲市场）
→ 英国对印度市场的渗透（棉纱→棉布）
→ 印度本地产业的反应（衰落vs适应）
→ 去工业化辩论的学术史梳理
→ 殖民政策的作用（关税条款、自由贸易的虚伪性）
→ 结论：向心系统的"不均衡发展"逻辑
```

### 4.2 关键因果转折

- **从"补充"到"替代"**：在旧棉花体系中进口补充本地生产 → 在新体系中进口摧毁本地生产
- **从"印度是竞争者"到"印度是市场"**：英国产业界从"担心印度竞争"到"把印度当市场"
- **从"自由贸易"到"殖民操控"**：Riello揭示英国鼓吹的自由贸易在殖民地实际上并不存在——关税被操纵以利英国产品

## 六、论辩与阐述方法

### 6.1 主要论辩策略

1. **多重时间尺度的并置**：年度贸易数据、十年产业变迁、百年体系转换在同一章节中交织。
2. **去工业化辩论的"平衡"立场**：既不接受纯"外部冲击"论，也不同意纯"内部衰落"论——采取"两者皆有"的中间立场。
3. **殖民主义批判的节制**：承认殖民政策的作用，但不将其作为唯一解释。

### 6.2 阐述特点

- **空间的全球化**：从新奥尔良到孟买、从阿勒颇到广州的贸易路线
- **金融-贸易-产业的连接**：不只是商品贸易，还包括了保险、金融、基础设施
- **"骨头的修辞"**：引用Marx/Bentinck"印度织工的白骨漂白了印度的平原"——分析这句著名（虽可能夸大）的话语如何被用于各种政治目的
