# 00_整体分析报告

## 一、书目基本信息

- **书名**：Cotton: The Fabric That Made the Modern World（棉花：塑造现代世界的织物）
- **作者**：Giorgio Riello（乔治·里耶洛）
- **出版信息**：Cambridge University Press, 2013
- **页数**：正文296页（含注释、参考文献、索引共约430页）
- **学科领域**：全球经济史、物质文化史、纺织史
- **语言**：英文

## 二、全书定位与核心问题

### 2.1 定位

本书是一部以棉花和棉纺织品为透镜的全球经济史著作。它既不是一本"商品的历史"（commodity history），也不限于单一国家的产业史，而是通过棉花这一纤维、商品和工业产品，审视过去一千年中世界经济格局的根本性转变——即制造业中心从亚洲（尤其是印度）向欧洲的转移，以及由此引发的"大分流"（Great Divergence）。

### 2.2 核心问题

Riello提出的核心问题是：**为什么欧洲——一个在1500年前对棉花种植、加工和消费几乎一无所知的大陆——到1800年左右成为全球棉纺织业的新中心？** 这个问题的回答将生产、贸易、消费、技术、生态和政治经济学编织进一个跨越千年的全球叙事。

### 2.3 核心论点

1. **两次棉花革命论**：Riello将全球棉纺织业的历史分为两个阶段——第一棉花革命（1000-1500年）形成以印度为核心的"离心系统"（centrifugal system）；第二棉花革命（1750-2000年）形成以欧洲为核心的"向心系统"（centripetal system）。
2. **漫长学习过程论**：欧洲的成功并非一蹴而就的技术突破，而是经历了至少两个世纪的"学习"过程——学习产品知识、消费者品味、生产技术（尤其是印花）以及全球市场运作。
3. **反向叙事论**：传统叙事站在兰开夏看世界，本书则站在全球看兰开夏——不是"曼彻斯特如何改变世界"，而是"世界如何解释了曼彻斯特的发生"。
4. **分层解释论**：反对单一因素解释（技术、文化、制度、煤炭、殖民地等），主张多因素"层叠"（layering）产生的协同效应催化了变革。
5. **分歧的漫长性论**：与Pomeranz等人主张的"突然大分流"不同，Riello认为分歧是一个绵延数个世纪的漫长过程。

## 四、核心概念与理论框架

### 4.1 "离心系统" vs "向心系统"

这是本书最核心的理论创新。两个系统的对比如下：

| 维度 | 离心系统（旧体系） | 向心系统（新体系） |
|------|---------------------|---------------------|
| 制造业核心 | 印度 | 西北欧 |
| 交换方式 | 长途但分散；海陆结合 | 长途全球化；包括大西洋和太平洋 |
| 竞争逻辑 | 进口补充，不扼杀本地产业 | 进口替代最终摧毁本地产业 |
| 产品特性 | 高度定制化 | 标准化和时尚驱动 |
| 资源来源 | 主要本地 | 从其他大洲进口 |
| 协调机制 | 松散节点连接 | 中心直接控制 |
| 利润分配 | 扩散共享 | 向核心集中 |

### 4.2 "印度学徒期"（Indian Apprenticeship）

指欧洲在17-18世纪通过东印度公司贸易，逐步学习棉花商品知识、市场知识、产品品种和消费者品味的漫长过程。这是Riello对"为什么是欧洲"问题的核心回答之一。

### 4.3 "幽灵英亩"（Ghost Acreages）

借自Pomeranz的概念，Riello在Ch11中通过反事实计算证明：如果工业革命以羊毛而非棉花为基础，英国在1820年需要现有土地面积的62%来养羊（1850年需超过全部国土）。美洲的棉花种植园为欧洲提供了"看不见的土地"。

### 4.4 "大分流"的漫长性

Riello不同意Pomeranz关于大分流发生在18世纪末的突然性判断，认为这是一个跨越数个世纪的渐进过程，欧洲的崛起始于1500年后的知识获取和市场学习。

## 五、方法论特征

### 5.1 全球史的视角与立场

- **明确的问题导向**：不是"写一切"，而是聚焦于解释一个具体的全球性转变
- **承认立场**：坦承以欧洲和南亚为焦点，以欧洲早期现代（1500-1800年）为重心
- **承认语言局限**：主要依赖英语及少数欧洲语言文献
- **协作研究模式**：依托LSE全球经济史网络的跨国学者合作

### 5.2 跨学科方法整合

1. **经济史**：贸易数据、价格序列、生产统计、GDP比较
2. **物质文化史**：大量利用博物馆藏品（织物碎片、绘画、印花样品）作为证据
3. **消费文化史**：遗嘱清单、弃婴医院记录、时装版画
4. **科技史**：技术传播路线图、生产工艺分析
5. **全球史**：跨洲际比较、关联与纠缠（entanglement）
6. **生态史**：土地承载力计算、反事实推演

### 5.3 资料来源的多样性

- 东印度公司档案（EEIC、VOC、FEIC的商业信函）
- 博物馆实物藏品（V&A、Ashmolean、大英博物馆等）
- 游记和旅行文学
- 政府档案（法国禁令执行记录、英国议会辩论）
- 植物学和农学文献
- 同时代经济学著作和小册子

## 六、全书论证线索

### 6.1 主线：从离心到向心的体系转换

```
印度主导 → 欧洲"学徒" → 欧洲学习（产品、技术、市场）→ 
原材料重构（美洲种植园奴隶制）→ 技术革新（纺纱机机械化）→ 
欧洲成为新核心 → 全球市场重组 → 亚洲"去工业化"
```

### 6.2 三条辅线

1. **消费线索**：从印度洋各文明的"意义消费"到欧洲的"时尚消费"
2. **知识线索**：从印度的缄默知识到欧洲的编码化、科学化知识
3. **生态线索**：从本地化小农种植到跨洲际种植园单一栽培

## 七、与学术史的对话

### 7.1 对话的主要学者和流派

| 学者/流派 | Riello的立场 |
|-----------|-------------|
| Kenneth Pomeranz（大分流） | 同意分流的存在，但主张时间更长、原因更多元 |
| Immanuel Wallerstein（世界体系） | 借鉴世界体系视角，但强调产品、时尚、技术因素 |
| Joel Mokyr（工业启蒙） | 认可知识的重要性，但强调外部知识（印度、中东）的贡献 |
| Prasannan Parthasarathi | 高度认同其关于印度竞争力与质量竞争的论点 |
| Maxine Berg（消费与全球史） | 共享对消费和亚洲产品影响的重视 |
| Jan de Vries（勤劳革命） | 借用概念进行中欧比较 |
| Eric Williams（资本主义与奴隶制） | 修正其论点：奴隶制不是工业革命的原因但影响其模式 |

### 7.2 主要学术贡献

1. 将"大分流"与"全球化"两个学术议题在棉花这一具体商品上统合
2. 打破"工业革命"叙事的时间框架，将欧洲棉纺织业的崛起向前追溯至16世纪的知识获取
3. 赋予消费和物质文化以与经济因素同等重要的解释力
4. 强调东方知识（印度印花技术、中东工匠）对欧洲工业化的贡献
5. 提出"离心/向心系统"作为理解全球经济格局变化的新分析框架

## 八、全书论证的优点与局限

### 8.1 优点

1. **架构宏大而逻辑清晰**：以"两次棉花革命"贯穿千年，框架简明有力
2. **证据层次丰富**：统计数据的宏观与博物馆藏品的微观相结合
3. **反欧洲中心论的努力**：从印度出发的叙事立场
4. **多因素解释**：避免单一决定论，强调"层叠"效应
5. **物质文化方法的创新运用**：将纺织品实物作为核心史料

### 8.2 局限

1. **语言和史料偏重英语文献**：对中国、日本、波斯的一手史料运用有限
2. **19-20世纪论述较薄**：全书重心在1500-1800年
3. **印度"衰落"叙事较简略**：承认未详细处理
4. **非洲作为被动角色**：非洲自身的棉纺织业叙述相对边缘
5. **劳工史相对缺席**：对生产者（织工、纺工）的社会史着墨不多

| 英文术语 | 中文译法 | 简要释义 |
|----------|----------|----------|
| Centrifugal system | 离心系统 | 资源、技术、利润从核心向外扩散的体系（旧棉花体系） |
