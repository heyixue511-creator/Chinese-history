# 03_"长在野树上的羊毛"：棉花的全球传播

## 一、章节定位与功能

### 1.1 在全书中的位置

本章是Part I的第二章，从**原材料和技术的维度**补充Ch2（贸易与消费维度）的论述。它回答了"离心系统"的一个基础性问题：棉花种植和相关技术如何在亚非欧大陆传播？

### 1.2 功能

- **补充论据链**：证明旧棉花体系不仅体现在贸易网络（Ch2），也体现在原材料种植和技术知识的广泛传播
- **技术史功能**：追索轧棉、弹棉、纺纱、织造技术的跨洲际传播路径
- **去欧洲中心功能**：通过Mandeville（英国）和日本的两则轶事，展示欧洲和日本在棉花知识上的"后来者"地位
- **比较框架功能**：为Ch4的制造业比较提供种植层面的基础

## 三、内容分析

### 3.1 核心论题

**论题一**：棉花种植从印度河流域（公元前3200年）向外扩散是缓慢的（跨越数百年），这种扩散受到基因（多年生vs一年生品种）、气候和制度因素的制约。

**论题二**：棉花的"商业化"程度因地而异。中国明代形成了高度商业化的帝国跨区域原棉贸易体系（"北棉南运"），而印度的原棉贸易商业化程度较低，欧洲则几乎完全依赖进口。

**论题三**："本地原材料"是旧棉花体系的基础性特征——与后来欧洲完全依赖美洲进口形成鲜明对比。

### 3.2 关键论点与案例

1. **"南方化"（Southernisation）**：Linda Shaffer的概念——原材料、技术和知识从南亚向亚洲其他地区和全球扩散。棉花是这一过程的核心载体。

2. **中国北棉南运体系**：明代江南成为棉织中心，但大量原棉从山东、河南经运河系统（数百英里）运往江南。Xu Guangqi（1628）记载"北方棉花便宜而布贵，南方相反"——这是前现代世界最大规模的跨区域原棉贸易。

3. **日本的"迟到"**：799年东南亚年轻人漂流至日本带来棉种，但未能成功种植，日本直到几个世纪后才掌握棉花种植——预示了后来日本成为棉纺织大国的"位置转换"。

4. **欧洲的本地劣势**：欧洲仅有塞浦路斯、南西班牙、南意大利等少数地中海生态位适合种棉，且质量低下。欧洲棉花工业从诞生起就依赖中东进口原棉——这是理解后续"向心系统"中原材料外部化的重要前提。

## 四、逻辑梳理

### 4.1 论证链条

```
Mandeville的传说 → 棉花知识的稀缺性
→ 棉花的生物传播史（五千年）
→ 制度因素的影响（伊斯兰扩张、蒙元税收政策、明初法令）
→ 种植体系比较（印度集约/粗放、中国小农、欧洲无）
→ 商业化程度比较（中国高度、印度中等、欧洲最低）
→ 结论：旧体系的基础是"本地原材料"
```

### 4.2 关键因果转折

- **基因屏障**：多年生品种（Gossypium arboreum）易于移植但适应范围有限 → 一年生品种（Gossypium herbaceum）的出现是棉花北传的关键
- **制度催化剂**：蒙元政权将棉花纳入税收体系（1296年）→ 棉花种植在中国从边缘作物变为主流
- **运河基础设施**：中国大运河系统 \> 使"北棉南运"成为可能 \> 促成种植与制造业的地区分离——但这仍在一个帝国之内，而非跨洲际

- **长时段视角**：从公元前3200年到18世纪
- **生态-经济交叉分析**：气候条件、基因品种与市场结构的综合考察

## 六、论辩与阐述方法

### 6.1 主要论辩策略

1. **轶事反差法**：以Mandeville和日本的故事开篇——英国和日本这两个后来的棉纺织大国最初都对棉花几乎一无所知。这种"后来的成功者曾经无知"的叙事策略有力地颠覆了任何先天优势论。
2. **生态决定论的审慎运用**：承认气候因素的重要性，但同时强调制度（税收、法令）和技术（品种改良）的修正作用。
3. **量化比较**：印度每亩22.5-62.5磅的产量数据与中国的种植面积数据，为比较提供硬支撑。

### 6.2 阐述特点

- **传播地图（Map 3.1-3.3）的核心作用**：空间可视化是本章最重要的分析工具
- **技术细节的精准性**：对轧棉、弹棉、纺轮等技术的详细描述
- **"制度-生态"双因素框架**：两者并重，不偏废
