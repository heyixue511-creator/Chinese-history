# 第一部分：专项报告

## 专项报告一：Riello的"离心/向心系统"理论框架解析

### 1.1 理论来源

Riello的"离心/向心系统"框架是全书最重要的理论创新。它融合了以下学术资源：
- **Wallerstein的世界体系理论**：承认"核心-边缘"结构的存在，但强调历史上有两个不同的体系（不是Wallerstein的单中心体系）
- **Pomeranz的大分流理论**：接受"分流"的基本判断，但修正其时间跨度（漫长而非突然）
- **Abu-Lughod的13世纪世界体系**：借鉴其"子系统"和"城镇群岛"概念用于描述离心系统

### 1.2 两个系统的核心差异

| 维度 | 离心系统 | 向心系统 |
|------|----------|----------|
| **时间** | 1000-1500年（延续至1750年） | 1750-2000年 |
| **核心区域** | 印度（南亚） | 西北欧（英国为首） |
| **核心逻辑** | 扩散、共享、共生 | 集中、剥削、排他 |
| **资源来源** | 本地种植+区域贸易 | 跨洲际进口（美洲） |
| **技术特征** | 熟练手工技艺 | 机械化和工厂制 |
| **贸易网络** | 多层中间商的松散节点 | 中心的直接控制 |
| **竞争模式** | 进口补充本地产业 | 进口摧毁本地产业 |
| **产品特性** | 高度定制化 | 标准化与时尚驱动 |
| **利润分配** | 相对分散 | 向核心高度集中 |
| **劳动组织** | 家庭生产+独立工匠 | 工厂制+工资劳动 |
| **原材料关系** | 本地农业-制造业整合 | 农业-制造业跨洲分离 |

### 1.3 理论意义

该框架的学术贡献在于：
1. 打破了"工业革命"叙事的欧洲中心时间框架
2. 提供了一个可应用于其他商品/产业的比较分析工具
3. 将经济史、生态史和消费文化史整合进统一的概念体系
4. 为理解当代"趋同"提供了历史纵深

## 专项报告三：Riello与主要学术对话者的立场关系

### 3.1 与Kenneth Pomeranz

| 议题 | Pomeranz | Riello |
|------|----------|--------|
| 分流的时间 | 突然（18世纪末） | 漫长（16-18世纪） |
| 分流的原因 | 偶然性（煤炭+美洲土地） | 多因素层叠（学习+资源+技术+消费） |
| 中国的角色 | 与欧洲可比的发展水平 | 可比但有不同路径（内卷化） |
| 生态因素 | 核心变量 | 重要变量之一 |

### 3.2 与Joel Mokyr

| 议题 | Mokyr | Riello |
|------|-------|--------|
| 知识的作用 | 核心解释变量（"工业启蒙"） | 重要，但大量知识来自亚洲 |
| 知识来源 | 欧洲内部（科学文化） | 欧洲内部+外部（印度、中东） |
| 知识类型 | 编码化知识为主 | 编码化+缄默知识并重 |

### 3.3 与Immanuel Wallerstein

| 议题 | Wallerstein | Riello |
|------|-------------|--------|
| 世界体系的数量 | 一个（现代世界体系） | 两个（离心+向心） |
| 体系的起点 | 16世纪 | 至少1000年 |
| 亚洲的角色 | 被纳入的边缘/半边缘 | 离心体系的"核心" |

### 3.4 与Jan de Vries

| 议题 | de Vries | Riello |
|------|----------|--------|
| 勤劳革命 | 欧洲特有的市场驱动 | 中欧均有，但结果不同 |
| 消费角色 | 驱动生产 | 与生产交互 |
| 中国差异的解释 | 未系统讨论 | 劳动力弹性+家庭结构 |
