# 00_方法与规则

## 一、知识涌现分析的总目标与定位

### 1.1 分析对象

本系列文件的分析对象为《Cotton: The Fabric That Made the Modern World》（Giorgio Riello, 2013）的全书14章分析报告（含导论、结论及专项报告/实体总索引），共15份结构化文本。

### 1.2 分析目标

知识涌现分析的目标是：**识别和计算那些"整体大于部分之和"的知识结构**——即通读全书后浮现的、在任何单一章节分析中均未明确陈述、但由跨章节知识元之间的语义链接所构成的新命题、新洞察和新理论综合。

### 1.3 核心问题

L001: "从15份章节分析报告中，有哪些知识发现是任何单一章节分析都无法独立得出的？"

L002: "Riello全书的论证结构本身，作为一个知识系统，产生了怎样的涌现属性？"

L003: "离心/向心系统的理论建构，在跨章节知识元的聚合中，揭示了哪些超越作者明言的深层逻辑？"

## 二、知识元（Knowledge Element）的定义与分类规则

### 2.1 知识元的定义

**知识元**（Knowledge Element, KE）是分析报告中的最小语义单元，具有独立的知识承载能力。每个知识元由以下属性构成：

| 属性 | 说明 |
|------|------|
| KE_ID | 唯一标识符，格式：KE-{类型代码}-{序号} |
| KE_来源 | 源分析报告编号（Ch1-Ch13, NN, 00） |
| KE_类型 | 见2.2的分类体系 |
| KE_正文 | 知识元的自然语言表述（30-150字） |
| KE_证据强度 | 1-5级：1=作者断言, 2=文献引用, 3=案例支持, 4=数据论证, 5=反事实验证 |
| KE_抽象层级 | 1-5级：1=具体事实, 2=模式识别, 3=因果机制, 4=理论命题, 5=元理论 |
| KE_出处标注 | 原始报告的节号和L###编号引用 |

### 2.2 知识元类型分类

| 类型代码 | 类型名称 | 定义 | 示例 |
|----------|----------|------|------|
| F | Factual Knowledge（事实知识） | 具体的史实、事件、数据、案例 | Old Fustat织物碎片发现于埃及和印尼 |
| C | Conceptual Knowledge（概念知识） | 定义、理论概念、分析范畴 | "离心系统"的定义及其五维度特征 |
| M | Causal Mechanism（因果机制知识） | 因果链条、机制解释 | 质量驱动论：纺纱机发明是为了匹配印度纱线品质 |
| E | Evidential Knowledge（证据知识） | 关于证据类型、材料使用方式的知识 | 博物馆实物藏品作为物质文化史的核心史料 |
| R | Relational Knowledge（关系知识） | 实体之间的比较、对比、影响或对话关系 | Riello与Pomeranz关于分流时间的分歧 |
| T | Methodological Knowledge（方法论知识） | 研究方法、分析策略、论证方式 | 反向研究策略：站在全球看兰开夏 |
| S | Structural Knowledge（结构知识） | 全书结构、论证逻辑、章节编排 | 三大板块的论证推进：离心→学习→向心 |

### 2.3 知识元提取规则

**R001**：每个分析报告中的"核心论题"（每章3-5个）各提取为1个知识元。

**R002**：每个"关键论点与案例"中的独立案例各提取为1个知识元。

**R003**：每个实体索引条目（人物、著作、概念、地理、机构、物品/技术）根据其跨章节出现频率决定是否提取为知识元——跨3章及以上必提取。

**R004**：章节内部的"论证链条"中每个因果节点各提取为1个知识元。

**R005**：L###原文摘录中具备独立知识价值的段落各提取为1个知识元。

## 三、语义链接（Semantic Link）的定义与分类规则

### 3.1 语义链接的定义

**语义链接**是两个知识元之间有意义的语义关系。它不仅是"共现"或"引用"关系，而且代表一种知识结构上的连接——两个知识元在认知上相互依存、相互解释或相互矛盾。

### 3.2 语义链接类型体系

| 链接类型 | 代码 | 定义 | 示例 |
|----------|------|------|------|
| 因果链接 | CAU | A是B的原因/条件/前提 | 印度学徒期(KE-C) → 欧洲技术追赶(KE-M) |
| 证据支撑 | EVI | A为B提供证据/案例支撑 | Old Fustat织物(KE-F) → 中世纪全球化(KE-C) |
| 概念实例化 | INS | A是B的一个实例/具体化 | Ch2的定制化案例(KE-F) → 离心系统(KE-C) |
| 理论对话 | DIA | A与B构成学术对话/论辩 | Riello流程论(KE-M) → Pomeranz突然论(KE-R) |
| 结构从属 | SUB | A在逻辑上从属于B | Ch5的贸易学习(KE-M) → 印度学徒期(KE-C) |
| 对比对立 | CON | A与B构成对比/对立 | 离心系统(KE-C) ↔ 向心系统(KE-C) |
| 时间序列 | SEQ | A在时间上先于B并导向B | 消费接受(Ch6) → 禁令与走私(Ch6) → 国内产业(Ch7) |
| 类比同构 | ANA | A与B在结构/逻辑上同构 | 印度织工村(KE-F) ∽ 中国家庭生产(KE-F) |
| 综合升华 | SYN | A和B综合产生新命题C | 质量驱动论 + 生态潜力 → 棉花的多因素优势 |

### 3.3 链接权重计算规则

每个语义链接分配一个权重 w ∈ [0, 1]，由以下因素加权：

| 因素 | 权重 | 评分标准 |
|------|------|----------|
| 跨章节距离 | 0.25 | 同一章=0.2, 同一部分=0.5, 跨部分=1.0 |
| 知识元层级差 | 0.20 | 同层级=0.3, 差1级=0.6, 差2级以上=1.0 |
| 证据强度差 | 0.15 | 差值归一化 |
| 反直觉程度 | 0.25 | 常识链接=0, 有启发性=0.5, 反直觉=1.0 |
| 独特性 | 0.15 | 是否仅为本书独有链接 |

最终权重 w = Σ(因素分 × 因素权重)

## 四、知识涌现的计算规则

### 4.1 涌现的定义

在本分析中，**知识涌现**定义为：由N个知识元（N ≥ 3）之间的语义链接所构成的新命题P，使得P满足以下三个条件：

**条件一（新颖性）**：P不在任何单一源分析报告中以明确陈述的形式存在。

**条件二（跨域性）**：P所依赖的知识元来自至少两个不同的分析报告，且至少跨越一个全书部分（Part I/II/III）。

**条件三（解释力）**：P相比其构成知识元，提供了额外的解释力或洞察——即P"压缩"了信息并提升了理解层次。

### 4.2 涌现强度计算

对于每个涌现命题P，计算其涌现强度 ES(P)：

```
ES(P) = α × NOV(P) + β × CRO(P) + γ × EXP(P) + δ × NET(P)
```

其中：
- NOV(P)：新颖性得分（0-1）。由P与源文件全文的语义相似度反向计算。
- CRO(P)：跨域性得分（0-1）。= log(来源知识元的分布广度+1) / log(总章数+1)
- EXP(P)：解释力得分（0-1）。由P的信息压缩比和抽象层级提升量共同决定。
- NET(P)：网络密度得分（0-1）。= 构成P的知识元之间的语义链接数 / 最大可能链接数

默认权重：α = 0.25, β = 0.25, γ = 0.30, δ = 0.20

涌现强度分级：
- ES ≥ 0.75：**强涌现**（Emergent Knowledge）
- 0.50 ≤ ES < 0.75：**中涌现**（Semi-Emergent Knowledge）
- 0.25 ≤ ES < 0.50：**弱涌现**（Latent Pattern）
- ES < 0.25：非涌现（视为对源知识的重组）

### 4.3 涌现类型分类

| 类型 | 代码 | 定义 |
|------|------|------|
| 概念整合涌现 | EMG-C | 多个分散概念的融合产生新理论范畴 |
| 因果聚合涌现 | EMG-M | 多元因果机制的叠加产生超级机制 |
| 模式识别涌现 | EMG-P | 跨案例的模式识别产生新规律 |
| 矛盾消解涌现 | EMG-R | 表面矛盾的命题在高层级被调和 |
| 结构自反涌现 | EMG-S | 关于论证结构本身的新洞察 |

## 五、知识发现报告的撰写规则

### 5.1 报告结构规则

知识发现报告（04_知识发现报告.md）由以下固定模块构成：

1. **涌现命题陈述**：以"我们发现"开头的独立命题陈述（每个100-200字）
2. **证据链追溯**：该命题所依赖的全部源知识元和语义链接列表
3. **涌现强度评定**：ES值及四个子维度得分
4. **反事实检验**：如果删除某一类源知识元，该命题是否仍然成立？
5. **学术意义评估**：该涌现命题对Riello原书论证的补充/修正/深化
6. **可操作性推论**：该命题可导出的进一步研究问题或方法论启示

### 5.2 质量控制规则

**QC001**：每个涌现命题必须在至少3个独立源分析报告中找到支撑知识元。

**QC002**：涌现命题必须通过"作者盲测"——如果Riello在原书导论或结论中已明言该命题，则不视为涌现，降级为"系统化再表述"。

**QC003**：跨域性得分 CRO(P) < 0.3 的命题不得进入最终报告。

**QC004**：每个涌现命题必须通过反事实检验——至少删除一个关键源知识元后命题不再稳健。

## 六、分析流程

### 6.1 总体流程

```
步骤1：知识元提取（01_知识元语意分析.md）
  ├── 从15份分析报告中提取全部知识元
  ├── 按七大类分类
  ├── 标注属性（证据强度、抽象层级、来源）
  └── 去重与归一化

步骤2：语义链接构建（02_语义链接网络.md）
  ├── 识别知识元之间的九类语义链接
  ├── 计算每个链接的权重
  ├── 构建知识元-链接网络
  └── 识别网络中的关键节点和高密度子图

步骤3：涌现计算（03_知识涌现计算.md）
  ├── 在高密度子图中识别涌现候选命题
  ├── 计算每个候选的ES值
  ├── 通过QC001-QC004质量筛选
  └── 按ES值排序输出涌现命题列表

步骤4：发现报告（04_知识发现报告.md）
  ├── 撰写入选涌现命题的完整报告
  ├── 追溯证据链
  ├── 进行反事实检验
  └── 提出可操作性推论
```

### 6.2 迭代校验规则

每个步骤完成后，必须反向校验：步骤3的结果是否修改了对步骤1中知识元的理解？如有修改，回写修正。

## 七、术语约定

| 术语 | 英文 | 定义 |
|------|------|------|
| 知识元 | Knowledge Element (KE) | 最小语义知识单元 |
| 语义链接 | Semantic Link (SL) | 知识元之间有意义的语义关系 |
| 涌现 | Emergence | 整体涌现的、不可还原为部分之和的新属性 |
| 涌现命题 | Emergent Proposition (EP) | 由语义链接网络产生的新知识陈述 |
| 涌现强度 | Emergence Strength (ES) | 量化涌现程度的综合指标 |
| 源分析报告 | Source Analysis Report (SAR) | 分析报告目录中的15份文件 |
| 子图 | Subgraph | 知识元网络中关系密度较高的局部区域 |
| 枢纽节点 | Hub Node | 链接度数超过阈值的关键知识元 |

## 八、L###编号系统规则

### 8.1 编号规则

本系列文件中所有关键陈述和命题均以L###格式编号，规则如下：

- L001-L099：方法论陈述
- L100-L199：知识元
- L200-L299：语义链接
- L300-L399：涌现命题
- L400-L499：发现与推论

### 8.2 引用规则

在跨文件引用时使用格式：`[文件编号:L编号]`，例如 `[00:L003]` 表示引用00_方法与规则.md中的L003。

在引用源分析报告时使用格式：`[SAR:Ch{章节号}-§{节号}]`，例如 `[SAR:Ch8-§3.1]`。
