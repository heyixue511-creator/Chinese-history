# 00_方法与规则

## L### 一、知识涌现分析的定义与目标

本文件定义"知识涌现分析"（Knowledge Emergence Analysis）的方法论框架与操作规则。该分析以Gennifer Weisenfeld著《Mavo: Japanese Artists and the Avant-Garde, 1905-1931》的"分析报告"系列文件为源文本库，从中提取知识元（knowledge units）、发现语意链接（semantic links）、搭建语意链接网络（semantic link network, SLN），并通过网络计算识别"涌现性知识"——即未在任何单一源文本中独立出现、仅在各知识元的交互关系中浮现的新知识。

知识涌现分析的目标不是"总结"源文本，而是**发现源文本之间的结构性关系所生产的新认知**。该分析将论证本书的七条核心论点主线如何通过在制度史、美学史、政治史、经济史、身体史的交叉张力中"涌现"出不可化约的跨领域知识。

L### 二、核心术语定义

| 术语 | 英文 | 定义 |
|------|------|------|
| 知识元 | Knowledge Unit (KU) | 从源文本中提取的、具有独立语义的最小区块，包含实体（人物、机构、概念、事件、作品、文献）和属性（关系、功能、时期、定性判断） |
| 语意链接 | Semantic Link (SL) | 两个知识元之间存在某个可被命名的语意关系（因果、对立、包含、影响、转化等） |
| 语意链接网络 | Semantic Link Network (SLN) | 所有知识元通过语意链接构成的整体网络图式 |
| 知识涌现 | Knowledge Emergence (KE) | 在SLN中通过特定拓扑结构（三元组、环路、跨层级桥接等）产生的新知识，其语义内容不为任何单一知识元所表征 |
| 源文本库 | Source Corpus | 分析报告系列文件的总和（00_整体分析报告.md 至 NN_专项报告与实体总索引.md） |
| LOT | Lattice of Topics | 主题格——知识元在主题维度上的多层级归属结构 |

L### 三、方法论框架：五阶段流程

```
阶段一：知识元提取（KU Extraction）
  ↓
阶段二：知识元语意分析（KU Semantic Tagging）
  ↓
阶段三：语意链接网络构建（SLN Construction）
  ↓
阶段四：知识涌现计算（KE Computation）
  ↓
阶段五：知识发现报告（KE Reporting）
```

### L### 3.1 阶段一：知识元提取规则

知识元提取遵循以下六项规则：

**规则1——六类全量提取**：必须覆盖以下六类实体，每类在源文本的每一章中至少提取3个。

| 类别 | 编码前缀 | 说明 |
|------|----------|------|
| 人物 | P- | 个体人物，含生卒年、身份、角色 |
| 机构/团体 | I- | 机构、团体、场所、空间 |
| 概念/术语 | C- | 理论概念、分析术语、关键词 |
| 历史事件 | E- | 有时序定位的具体事件 |
| 文献/出版物 | D- | 书籍、刊物、宣言、文本、图像 |
| 理论来源 | T- | 被引用的学者、理论体系 |

**规则2——L###四级赋码**：每个知识元编码格式为 `{类别前缀}{章节}-{序号}`，如 `P01-01`（引言第1号人物）或 `C04-03`（第4章第3号概念）。高权重知识元加注 `L###` 前缀。

**规则3——跨章重复标注**：同一实体在多章出现时，以其主要出场的章节为编码归属，但在条目中注明所有出现章节。如村山知義主要归属为 `P02-01`（第2章），但在所有章节文件中出现，标注为 `@All`。

**规则4——定性与关系并重**：每个知识元携带两类信息——(a) 属性数组（名称、编码、身份/定义、时期/位置）；(b) 关系数组（与其他知识元的语意链接）。

**规则5——密度与权重均衡**：每个源文本章节提取的知识元总数控制在30-60个之间，六类分布相对均衡。

**规则6——源头可溯**：每个知识元指明的"源文本位置"应具体到章节文件的行号范围，确保可验证性。

### L### 3.2 阶段二：语意分析规则

语意分析对每个知识元进行三个维度的编码：

**维度1——主题域归属（Domain Tagging）**

每个知识元被分配到一个或多个主题域：

| 主题域 | 编码 | 覆盖范围 |
|--------|------|----------|
| 制度史 | DOM-INS | 画坛、文展/帝展、东京美术学校、国家体制 |
| 美学/理论 | DOM-AES | 意识性构成主义、触觉主义、faktura、材料社会学 |
| 政治/意识形态 | DOM-POL | 无政府主义、Bolshevism、左翼运动、转向/tenkō |
| 经济/消费文化 | DOM-ECO | 大众出版、咖啡馆/百货店、商业设计、名人化 |
| 身体/性/剧场 | DOM-BOD | 自慰隐喻、性别越界、快感政治、舞台设计 |
| 元史学（metahistory） | DOM-MET | 方法论反思、遗产争夺、冷战文化政治 |

**维度2——语意功能标签（Functional Tagging）**

每个知识元被赋予一个语意功能标签：

| 功能标签 | 编码 | 定义 |
|----------|------|------|
| 核心论题 | FUN-THE | 直接承载全书/某章的核心论点 |
| 结构支撑 | FUN-STR | 提供论证的框架性概念或方法论工具 |
| 叙事载体 | FUN-NAR | 作为具体案例承载抽象论题 |
| 对立面/否定性参照 | FUN-ANT | 与被分析对象构成对立或否定关系 |
| 理论来源 | FUN-SRC | 引用的学者/理论框架 |
| 语境背景 | FUN-CTX | 提供历史/社会/制度背景信息 |

**维度3——关系类型（Relation Typology）**

知识元之间的语意链接分为以下九种类型：

| 关系类型 | 编码 | 方向性 | 示例 |
|----------|------|--------|------|
| 因果产生 | REL-CAU | A→B | "大地震后迫害"→"Mavo激进化" |
| 对立否定 | REL-OPP | A↔B | "构成(construction)"↔"构图(composition)" |
| 部分-整体 | REL-PAR | A⊂B | "矢桥公麿"⊂"Mavo成员" |
| 人物-创建/领导 | REL-CRE | A→B | "村山知義"→"意识性构成主义理论" |
| 理论-应用 | REL-APP | A→B | "意识性构成主义"→"《从早到晚》舞台设计" |
| 制度-规制 | REL-REG | A→B | "文展体制"→"西洋画家的职业路径" |
| 转化/演变 | REL-TRF | A→B | "FAA"→"Mavo"（团体转化） |
| 平行比较 | REL-CMP | A↔B | "村山的拼贴"↔"Schwitters的Merz" |
| 跨域折射 | REL-XRE | A↔B | "无政府主义（DOM-POL）"↔"材料的不可化约性（DOM-AES）" |

### L### 3.3 阶段三：网络构建规则

**规则7——节点即知识元**：SLN中的每个节点为一个知识元，携带其全部属性数组。

**规则8——边即语意链接**：SLN中的每条边为一个语意链接，携带关系类型、强度（1-5）、方向性。

**规则9——层级结构保持**：SLN内嵌一个七层主题格（LOT），将知识元按章节归属与主题域归属交叉组织。

**规则10——核心节点识别**：度数中心性（degree centrality）最高的20个节点被标记为"核心知识元"，它们在网络中是知识涌现发生的主要场址。

### L### 3.4 阶段四：涌现计算规则

知识涌现的计算依赖于对SLN拓扑结构的分析。以下六种拓扑结构被定义为"涌现计算子"（Emergence Operators）：

**算子1——三元组闭合（Triadic Closure）**：若三个知识元 A-B-C 两两之间存在语意链接，且三者分别来自三个不同的主题域（如DOM-AES, DOM-POL, DOM-BOD），则在三元组的"空中心"处标识为一次知识涌现。该涌现的知识内容 = "A、B、C在结构上的不可分性所揭示的矛盾/统一关系"。

**算子2——跨域桥接（Cross-Domain Bridging）**：若某个知识元同时属于两个或以上主题域，且它是其所在局部网络中唯一连接这些主题域的节点，则该节点被标识为"桥接涌现点"。该知识元本身可能不包含新知识，但其"桥接功能"揭示了域间结构性关系——该关系未被任何单一源文本明确陈述。

**算子3——环路共振（Loop Resonance）**：若SLN中存在长度为L>=4的环路，且环路遍历了至少三个主题域，则该环路被视为一个"论证闭环"——其涌现性在于：论证的起点与终点虽被环路"闭合"，但路径的遍历（即中间过程）生产了不可省略的新认知。

**算子4——层级跳跃（Hierarchy Jump）**：若一个低层级知识元（如一个具体作品）直接联结到一个高层级知识元（如一个跨章概念）而跳过所有中间层级，则该跳跃标识了一次"微观→宏观的直接映射涌现"。

**算子5——缺失链接推论（Missing Link Inference）**：若两个知识元A和B在源文本中均与同一个第三方C有强关联，但A与B之间未被源文本明确建立链接，则推断A-B之间存在"隐语意链接"。该隐链接标识了源文本中未被明说但结构性存在的关系——这是一类重要的知识涌现。

**算子6——矛盾并置（Contradiction Juxtaposition）**：若两个知识元携带了逻辑上不可调和的命题（如"Mavo反资本主义"vs."Mavo深度参与消费文化"），且它们在SLN中通过至少两条不同的路径被链接（即它们之间的"矛盾"不是孤立的，而是结构性地被嵌入多个论证线索中），则该矛盾并置本身标识了一次知识涌现——其涌现内容是"不可化约的结构性悖论"。

### L### 3.5 阶段五：报告生成规则

知识发现报告的生成遵循"五栏格式"：

| 栏位 | 说明 |
|------|------|
| 编号 | KE-NN |
| 涌现定位 | 在SLN中的拓扑位置（涉及的知识元、算子类型、所在环路/三元组） |
| 涌现内容 | 用自然语言表达该涌现所产生的知识 |
| 源文本证据 | 引用具体的源文本行号和段落作为支撑 |
| 新颖性等级 | 1（在个别源文本中已有暗示）→ 5（必须通过网络计算才能发现） |

报告最终将所有涌现性知识按"学术贡献的新颖程度"排序，形成等级化的发现清单。

L### 五、分析边界与限制声明

1. **封闭性**：本分析仅以以上10个文件为源文本库，不引入任何外部文本或文献。知识涌现的计算严格基于源文本库的内部关系。

2. **非生成性**：本分析不"产生"源文本中不存在的概念或事实。所有的知识涌现均来自对源文本之间关系的计算性重组，而非AI的自由联想。

3. **可验证性**：每个涌现性知识必须能回溯到其依赖的知识元和链接关系，具有可检验的计算路径。

4. **开放终局**：本分析得出的知识发现并非"终局性"的——随着更多分析报告的加入（如补充其他章节的专项报告），SLN将扩展，新的涌现可能发生。

5. **权重一致性**：本分析对"专著作者Gennifer Weisenfeld"的学术判断保持高度尊重。知识元的定性和链接关系的判定以源文本中的分析报告为准——因为分析报告本身已经是对Weisenfeld原始论证的深度解读，本分析是在此"第二层解读"的基础上进行"第三层计算"。

L### 六、与"分析报告"系列的关系说明

本系列（00_方法与规则.md, 01_知识元语意分析.md, 02_语义链接网络.md, 03_知识涌现计算.md, 04_知识发现报告.md）与"分析报告"系列（00_整体分析报告.md 至 NN_专项报告与实体总索引.md）构成以下层级关系：

```
第一层：Weisenfeld原始专著《Mavo》
  ↓ 解读
第二层：分析报告系列（对原始专著的逐章深度解读）
  ↓ 计算
第三层：知识涌现分析系列（对分析报告的结构化计算与重组）
```

本系列不重复分析报告中的具体内容（如章节摘要、实体清单、材料分析），而是将分析报告视为一个"可计算的对象"，对其执行知识元的提取、网络的构建和涌现的计算。
