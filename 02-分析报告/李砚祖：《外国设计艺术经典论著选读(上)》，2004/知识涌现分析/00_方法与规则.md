# 知识涌现分析 00：方法与规则

## 一、分析对象与数据基础

- **书目**：李砚祖编著《外国设计艺术经典论著选读（上册）》（清华大学出版社，2006）
- **文本基准**：《2004_clean.md》915 行；**前半部分（L1-440）为语义网络分析的唯一正文来源**，后半部分（L442-915）为重复段（L913-915 为 PDF 元数据），在链接计数中**只计一次**。
- **语义单元**：全书按 21 篇选文（Ch01-Ch21）+ 序跋（总序/编者前言）切分为语义单元；每篇内再按小节（clean 版 `##` 标题）细分。

## 二、层级定义

| 层级 | 定义 | 判定说明 |
|---|---|---|
| 知识元（Knowledge Element） | 六类实体：人物、著作/作品、概念、机构、地点、事件 | 以 clean 版行号为唯一证据；每元需至少 1 处行号证据 |
| Topic（强连通簇） | 由语义链接紧密互连的知识元子集（6-15 个簇） | 簇内链接数显著高于簇间；通过语义相关性人工聚类 |
| Theme（高层语义域） | 3-5 个聚合多个 Topic 的高层主题域 | 以"共享知识元/桥接知识元"连接多个 Topic |

## 三、9 种语义链接判定标准

每条链接 = 源知识元 → 目标知识元（带类型与证据行号）。

| 类型 | 符号 | 判据 | 例 |
|---|---|---|---|
| 因果 | → | 一个知识元为另一知识元的结果/原因，文本存在因果表达 | 工业革命→机器时代确立（L33-34） |
| 条件 | ⇒ | 一方是另一方的发生前提/条件 | 理性抽象可衡量⇒机器可精确制造（L61） |
| 对比 | ↔ | 文本将其对立、比较、对照 | 人文主义艺术↔抽象艺术（L45-46） |
| 隶属 | ⊂ | 一方是另一方的组成部分/子类/成员 | 工业美学⊂设计美学（L319） |
| 时序 | ≻ | 事件/作品按时间先后排列 | 包豪斯（1919）≻乌尔姆（1953）（L363、L382） |
| 空间共现 | ≈ | 在同一地点/空间语境中共现 | 雷蒙·罗维≈纽约（L296） |
| 属性 | : | 一方是另一方的属性/特征/谓词 | 设计：复杂职能（L221） |
| 论证支撑 | ⇐ | 一方为另一方的论据、引语、例证 | 黄金分割⇐希腊陶瓶（L48） |
| 同域 | ∼ | 属同一论述领域/同一主题家族 | 技术美∼工业美学（L245、L319） |

## 四、涌现指标

| 指标 | 定义 | 本报告应用 |
|---|---|---|
| 节点度 k | 知识元连接的链接数 | 识别核心枢纽（k 值排序） |
| 桥接值 b | 连接不同 Topic/Theme 的链接数 | 识别跨主题中介 |
| 簇识别 | 强连通子图（Topic） | 语义聚类 |
| 内聚度 | 簇内链接数 / 簇内节点对总数 | 衡量簇的紧密度 |
| 涌现强度 S | 一级涌现（E）与二级涌现（P）的综合强度 | 以"新命题的证据覆盖数与跨主题广度"分级 |
| 一级涌现 E | 由知识元直接组合产生的结构性认识 | 见 03 报告 E1…En |
| 二级涌现 P | 由多个 Topic/Theme 综合推出的全书级命题 | 见 03 报告 P1…Pn |

## 五、证据规范

1. 所有知识元、链接、簇、主题均须引用 clean 版行号（前半部分优先）。
2. 客观性核对：对每项涌现结论，须列出可能削弱该结论的文本反例或边界条件。
3. 反例与边界：如"机器能否制造最高级抽象艺术"本文未决（L61-67），即不能断言"机器艺术=抽象艺术"。

## 七、与整体分析的关系

本涌现分析以《分析报告》各篇（Ch01-Ch21 实体清单与论点）为基础语义输入，但重新以"知识元-链接-簇-主题"网络视角组织，产出超出单篇文本的新认识（E/P 命题），属于对原书的**知识图谱式重读**。
