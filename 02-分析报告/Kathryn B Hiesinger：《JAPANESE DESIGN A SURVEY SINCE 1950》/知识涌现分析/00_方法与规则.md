# 00 方法与规则：知识涌现分析的框架与操作规程

## L001 分析目标定位

本系列文档是对《JAPANESE DESIGN: A SURVEY SINCE 1950》分析报告（共15份章节报告）进行**知识涌现分析**（Knowledge Emergence Analysis）的工程文档。其核心目标为：从已完成的文本分析报告中提取可计算的知识元（Knowledge Unit, KU），构建语义链接网络（Semantic Link Network, SLN），通过定量与定性结合的方法识别知识涌现现象，最终产出可验证的知识发现报告。

知识涌现分析区别于传统的文本分析之处在于：它不满足于对"文本说了什么"的描述性复述，而是追问"知识元之间如何通过链接关系产生系统层面不可还原的新属性"——即**涌现**（Emergence）的机制与程度。

## L002 核心概念定义

### L002-1 知识元（Knowledge Unit, KU）

**定义**：知识元是构成设计史话语体系的最小自足语义单元，具有独立的概念内涵与外延，可在语义网络中被唯一标识、被链接、被度量。

在本书的知识域中，知识元满足以下形式条件：
- **原子性**：不可再分（再分则丧失独立的语义完整性）
- **标识性**：可以被一个唯一的标签（Label）命名
- **可链接性**：可与至少一个其他知识元建立有向或无向的语义链接
- **可域化**：粒度划分为四个层级——哲学层（$L_1$）、制度层（$L_2$）、技术—材料层（$L_3$）、产品—事件层（$L_4$）

### L002-2 语义链接（Semantic Link, SL）

**定义**：语义链接是两个知识元之间的有向关系，携带关系类型（Type）、强度（Weight）、时间跨度（Time Span）和方向性（Direction）四重属性。

本文采用七类基础语义链接类型：

| 代码 | 类型 | 方向 | 数学表示 | 示例 |
|------|------|------|----------|------|
| CAU | 因果链接 | $A \rightarrow B$ | $\text{CAU}(A,B,t)$ | "制度先行论" → "G-Mark制度" |
| HIE | 层级包含 | $A \supset B$ | $\text{HIE}(A,B)$ | "日本设计" ⊃ "日本现代" |
| TEN | 张力/对立 | $A \leftrightarrow B$ | $\text{TEN}(A,B)$ | "模仿" ↔ "原创" |
| EVO | 时序演化 | $A \leadsto B$ | $\text{EVO}(A,B,\Delta t)$ | "成型合板" ↝ "Butterfly stool" |
| ANA | 类比映射 | $A \approx B$ | $\text{ANA}(A,B)$ | "和服平面构造" ≈ "三宅一生一片布" |
| TRA | 翻译/转换 | $A \xrightarrow{\tau} B$ | $\text{TRA}(A,B)$ | "design" → "デザイン" |
| INS | 实例化 | $K \xrightarrow{i} P$ | $\text{INS}(K,P)$ | "Good Design" → "TR-610收音机" |

### L002-3 语义链接网络（Semantic Link Network, SLN）

**定义**：SLN是一个有向加权异构图 $G = (V, E, T, W)$，其中：

$$G = (V, E, T, W), \quad V = \{KU_i\}_{i=1}^{n}, \quad E \subseteq V \times V, \quad T: E \to \{\text{CAU, HIE, TEN, EVO, ANA, TRA, INS}\}, \quad W: E \to [0, 1]$$

- $V$ 为知识元节点集
- $E$ 为有向边集，每边 $e = (v_i, v_j)$ 表示从 $v_i$ 到 $v_j$ 的语义链接
- $T$ 为边的类型函数
- $W$ 为边的强度函数，取值 $[0, 1]$

### L002-4 知识涌现（Knowledge Emergence）

**定义**：知识涌现是指，当SLN中知识元的链接密度、跨域桥接度和时序迭代度超过临界阈值时，系统层面产生原有知识元本身所不具备的"新知识属性"——表现为新的概念簇、新的因果关系、新的类比结构或新的范式框架。

涌现度 $E(G)$ 定义为：

$$E(G) = \alpha \cdot D(G) + \beta \cdot B(G) + \gamma \cdot T(G)$$

其中：
- $D(G)$：网络密度函数，度量知识元之间的全局链接紧密度
- $B(G)$：跨域桥接函数，度量不同知识域之间的跨界链接强度
- $T(G)$：时序迭代函数，度量知识演化链条的长度与分支度
- $\alpha, \beta, \gamma$ 为权重参数，默认取 $\alpha = 0.3, \beta = 0.4, \gamma = 0.3$

## L003 操作规程

### L003-1 知识元提取规则

**规则1（原子性检验）**：提取的每个KU必须回答"这个单元能否在不损失语义完整性的前提下被进一步分解？"若答案为"是"，则继续分解；若为"否"，则该KU满足原子性条件。

**规则2（多源锚定）**：每个KU应至少出现在两个分析章节中（跨章节的复现性），或在同一章节中以超过两次引用的频率出现。仅出现于单一章节孤立段落的概念不被提取为独立知识元。

**规则3（分层归属）**：每个KU被分配到四个语义层之一：

$$
L = \{L_1, L_2, L_3, L_4\}
$$

- $L_1$（哲学—美学层）：涉及世界观、价值观、审美范式、文化模式的知识元
- $L_2$（制度—组织层）：涉及政府政策、行业协会、教育体系、市场机制的知识元
- $L_3$（技术—材料层）：涉及材料科学、制造工艺、技术转移、形式语言的知识元
- $L_4$（产品—事件层）：涉及具体产品、人物、事件、展览的知识元

**规则4（权重分配）**：每个KU携带语义权重 $w(KU)$，基于三项指标：

$$w(KU) = w_f(KU) \times w_c(KU) \times w_d(KU)$$

- $w_f$：引用频率权重（该KU在分析报告中出现的总频率/最大频率，归一化至[0,1]）
- $w_c$：跨域连通度（该KU链接到的不同域的数量/总域数）
- $w_d$：深度权重（该KU所属的层级：$L_1=1.0, L_2=0.8, L_3=0.6, L_4=0.4$）

### L003-2 语义链接构建规则

**规则5（类型判定）**：两个知识元之间的语义链接类型由两者之间的语义关系决定，判定顺序为：时序→因果→层级→类比→张力→翻译→实例化。若满足多个类型条件，选择优先级最高的类型。

**规则6（强度计算）**：每条语义链接的强度 $w(e_{ij})$ 由以下公式计算：

$$w(e_{ij}) = \frac{1}{2}\left(\frac{co\_occur(i,j)}{max\_co\_occur} + sim(i,j)\right)$$

其中 $co\_occur(i,j)$ 为两个知识元在同一段落或论证链条中共同出现的次数，$sim(i,j)$ 为两者的语义层相近度（同层=1.0，跨一层=0.5，跨两层=0.25，跨三层=0.1）。

**规则7（方向确定）**：链接方向由语义关系本身决定：
- CAU（因果）：因 → 果
- HIE（层级）：上位概念 → 下位概念
- TEN（张力）：无主次，双向
- EVO（时序）：前驱 → 后继
- ANA（类比）：两个方向均成立（类比关系天然对称），但在本文中以"源域→目标域"标注
- TRA（翻译）：源语言 → 目标语言
- INS（实例化）：抽象概念 → 具体实例

### L003-3 知识涌现计算规则

**规则8（网络密度计算）**：SLN的全局密度 $D(G)$ 定义为实际边数与最大可能边数之比：

$$D(G) = \frac{|E|}{|V|(|V|-1)}$$

其中 $|E|$ 为实际有向边数，$|V|$ 为知识元节点数。$D(G) \in [0, 1]$，越接近1表示知识元之间链接越密集。

**规则9（跨域桥接度计算）**：跨域桥接度 $B(G)$ 衡量不同语义层之间的链接强度：

$$B(G) = \frac{1}{|L|(|L|-1)/2} \sum_{1 \leq i < j \leq 4} \frac{|E_{L_i, L_j}|}{|V_{L_i}| \cdot |V_{L_j}|}$$

其中 $E_{L_i, L_j}$ 是连接第 $i$ 层与第 $j$ 层知识元的边集合，$V_{L_i}$ 是第 $i$ 层的知识元集合。

**规则10（时序迭代度计算）**：时序迭代度 $T(G)$ 度量EVO链接构成的知识演化链条的深度：

$$T(G) = \frac{1}{|V|} \sum_{v \in V} \frac{1}{1 + e^{-\lambda \cdot out\_evo(v)}}$$

其中 $out\_evo(v)$ 为从知识元 $v$ 出发的EVO类型出度，$\lambda$ 为缩放参数（本分析取 $\lambda = 0.5$）。

**规则11（涌现阈值判定）**：当涌现度 $E(G) > \theta_e$（本分析取 $\theta_e = 0.35$）时，SLN达到"涌现临界"状态，在此状态下生成的跨域连接和概念簇可被定性为"涌现性知识"。$E(G) > 0.60$ 时为"强涌现"，$0.35 < E(G) \leq 0.60$ 时为"中等涌现"，$E(G) \leq 0.35$ 时为"弱涌现"。

## L004 分析流程

```
[15份分析报告]
       │
       ▼ 规则1-4
[知识元提取] ──→ KU池 {KU₁, KU₂, ..., KUₙ}
       │
       ▼ 规则5-7
[语义链接构建] ──→ 边集 {e₁, e₂, ..., eₘ}
       │
       ▼
[SLN构建] ──→ G = (V, E, T, W)
       │
       ▼ 规则8-11
[涌现度计算] ──→ E(G), D(G), B(G), T(G)
       │
       ▼
[涌现阈值判定] ──→ 强涌现/中等涌现/弱涌现
       │
       ▼
[涌现性知识簇识别] ──→ 聚类分析 + 社区发现
       │
       ▼
[知识发现报告] ──→ 新发现 + 意外连接 + 结构模式 + 知识缺口
```

## L007 分析限度声明

1. **源数据偏差**：本分析基于的15份分析报告是对Hiesinger原书的结构化阐释，而非直接对英文原文的计算。因此，知识元的提取和链接构建携带了一定的"阐释中介"效应。
2. **粒度选择**：知识元的粒度划分（四层）是对连续光谱的离散化近似，位于层间边界的概念可能被强行归入某一层。
3. **强度参数**：链接强度的权重系数和涌现度的权重参数为启发式设定，其取值需在后续研究中通过敏感度分析验证。
4. **语言转换损失**：中文报告中的术语选择（如"デザイン"在本文中保留片假名而不用"设计"替代）可能对语义链接的类型判定产生影响。
5. **时间静态性**：本SLN是对1994年出版时刻的"快照"分析，不反映后续二十余年日本设计史研究对本书的再阐释。
