## 三、枢纽与中介分析

1. **双枢纽结构**：Art Deco（C）与 modernity（C）构成"概念双塔"——所有主题区都经二者获得统一（证据：全书术语约定 L7012–7015 与结论 L7007）。
2. **事件—空间枢纽**：1925 博览会（E）与巴黎（L）是叙事的中转站：源头区（A）经博览会汇入消费区（B），再经传播区（D）与全球区（E）扩散（证据：L2120–2122 的 PART 3 划分、L6065 的东亚缺席对照）。
3. **桥接元**（跨区链接者）：
   - Cassandre（P）：连接平面区（D）与交通区（C）（L4789–4799、L13001–13006）；
   - 流线化（C）：连接交通（C）、产品（C）、理论（C）三区（L5026–5036、L5881、L6044–6049）；
   - 移民设计师（P 群）：连接欧洲（A/B）与美国（C/D）（L5459–5461、L5613–5616）；
   - 好莱坞（I）：连接媒体（D）与消费（B）、全球（E）（L5210–5243、L6234）；
   - Object List（W 群）：连接全部主题区的"证据底层"（L11540–13502）。
4. **反例与边界**：
   - Airflow 失败（L5980–5983）反证"流线化→成功"链接（C 区）；
   - Cubic 滞销（L5556）反证"先锋→市场"链接；
   - Normandie 亏损（L5154–5156）反证"奢华→成功"；
   - 南非案例（L6919–6923）表明"本土化"链接在南非**断裂**（拒绝同化）——边界条件明确。

## 四、网络整体特征

1. **星形—链式混合**：概念枢纽（星形）与叙事链（因果链式）并存；
2. **强互文性**：章节间"see Chapter/plate"引用（L3926、L4107）构成元链接层；
3. **证据锚定**：Object List 与 Notes 为全部链接提供实物与文献锚点（L7009–13502）；
4. **开放性**：全球章节（Ch35–39）引入大量新增实体（王公、本土母题、种族制度），使网络向"世界"方向扩张。
