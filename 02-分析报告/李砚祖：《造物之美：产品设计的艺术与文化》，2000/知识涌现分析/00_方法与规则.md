# 00_方法与规则：知识涌现分析框架

## L001 本模块的定位与目标

本模块"知识涌现分析"是对李砚祖《造物之美：产品设计的艺术与文化》（中国人民大学出版社，2000；分析基准：`00-book/李砚祖：《造物之美：产品设计的艺术与文化》，2000_clean.md`，共 171 行，行号 L###）所产出的 10 份分析报告（00 整体 + Ch01-Ch08 + NN 专项索引）进行二次知识加工。

与"分析报告"模块的逐章研读不同，本模块将全书视为一个知识系统，用语义网络与涌现计算的方法揭示章际、实体际、论点际的结构关联，发现单章阅读不可见的"涌现知识"。核心问题：（1）全书知识系统的内部结构为何？（2）哪些实体/概念构成枢纽节点？（3）语义链接如何分布与聚类？（4）可计算哪些涌现模式（密集区、稳固区、断裂带）？（5）可产生哪些超越线性阅读的知识发现？

## L002 "知识涌现"的操作性定义

- **知识元（KU）**：分析报告中可独立识别、语义完整的知识片段。本模块采用说明书规定的**六类实体**（人物/著作作品/概念/机构/地点/事件），不另设命题类。
- **语义链接（SL）**：两个知识元之间经由原文与分析报告明确建立的关系，按说明书采用 **9 种类型**（见 L005）。
- **知识涌现（EM）**：知识元网络中子结构（三元组、强连通簇、主题域）产生出不能归约于其节点之和的特征或信息，即发生涌现。依据指标见 L006。

## L003 方法论步骤

1. **方法与规则（本文件 00）**：定义层级、链接类型、涌现指标、编码体系。
2. **知识元语意分析（01）**：六类实体全文语义载荷分析，先总述五种论证功能，再按类分表，附行号证据。
3. **语义链接网络（02）**：枢纽识别（节点度 k、桥接值 b）、按主题区组织的链接清单、枢纽与中介分析、客观性核对。
4. **知识涌现计算（03）**：Topic 簇识别、Theme 聚合、内聚度与涌现强度 S 计算、一级/二级涌现结构、反例。
5. **知识发现报告（04）**：结构发现、隐藏枢纽与"点到未论"潜在链接、跨主题综合命题、完整层级图谱、总体评价与边界声明。

## L004 层级定义

- **知识元（KU）**：六类实体（人物 E1、著作/作品 E2、概念 E3、机构 E4、地点 E5、事件 E6），编码 `E<类别号>-<序号>`。
- **Topic（主题簇）**：语义链接强连通的知识元簇，6-15 个。
- **Theme（高层语义域）**：由若干 Topic 聚合成的高层域，3-5 个，含共享/桥接知识元。

## L005 语义链接类型学（9 种，附判据与例）

| 类型 | 编码 | 判定标准 | 例（本书） |
|---|---|---|---|
| 因果 | → | A 在文本中被明确表述为 B 的原因/前提 | 工业革命 → 设计危机（L113） |
| 条件 | ⇒ | A 是 B 成立的必要/充分条件 | 人的需要 ⇒ 造物行为（L145） |
| 对比 | ↔ | A 与 B 在文本中被对照比较 | 中国"饰极返素" ↔ 西方功能主义（L50） |
| 隶属 | ⊂ | A 是 B 的子类/成员/组成部分 | 产品设计 ⊂ 设计范畴五类（L41） |
| 时序 | ≻ | A 在时间上先于 B | 打制石器 ≻ 制陶（L8、L14） |
| 空间共现 | ≈ | A 与 B 在同一地理/空间语境中共现 | 景德镇 ≈ 青花瓷（L67） |
| 属性 | : | B 是 A 的性质/特征/参数 | 明式家具 : 简洁理性（L108） |
| 论证支撑 | ⇐ | A 为 B 提供证据/论据 | 考古实物 ⇐ 造物即文化论（L8、L70） |
| 同域 | ∼ | A 与 B 属于同一论域/共同主题但无上述强关系 | 功能美 ∼ 技术美（L160、L164） |

## L006 涌现指标

- **节点度 k**：节点直接链接的其他节点数。
- **桥接值 b**：节点处于多少对节点之间的最短通路上（中介性），衡量"桥"作用。
- **簇识别**：强连通分量法（有向）与 k-核（无向）结合。
- **内聚度 c**：簇内实际链接数 / 簇内最大可能链接数。
- **涌现强度 S**：S = 簇内链接密度 × 簇内节点多样性（六类实体覆盖率）× 跨章链接率。
- **一级涌现 E1**：由强连通簇直接产生的结构命题（Topic 内部）。
- **二级涌现 E2/P**：跨簇、跨 Theme 整合产生的命题（P1…Pn，附生成机制与强度）。
- **反例与边界**：每项涌现命题须附客观性核对与反例。

## L007 编码体系

- 实体类 KU：`E1-001`（人物）、`E2-001`（著作/作品）、`E3-001`（概念）、`E4-001`（机构）、`E5-001`（地点）、`E6-001`（事件）。
- 语义链接：`SL-<类型编码>-<序号>`，如 `SL-因果-01`。
- Topic：`T01…Tn`；Theme：`TH1…THm`。
- 涌现：`EM1-01…`（一级）、`P1…Pn`（二级命题）。

## L008 质量规则

1. **证据全覆盖**：每条链接、每个涌现命题必须有 clean 版行号证据（L###），不得编造。
2. **审慎性**：文本以"似乎/可能/推测"表述处，只作同域（∼）或条件（⇒）链接，不作确定性断言。
3. **客观公正**：涌现命题必须附反例与边界声明。
4. **不写代码**：全部为语义阅读与人工核算，指标基于人工清点与估算，公开估算口径。
5. **中文写作**：简体中文，术语首次出现附原文，Markdown、UTF-8。
6. **可复现性**：03 号文件中公开簇划分、链接计数与 S 值估算方法。
