## 三、方法

1. **语义复读**：逐组读四册原文窗口，按行号定点回查，确认候选 payload 与正文一致后才落笔；`sources[].location` 可回溯到行。`xdup-0060` 的候选 payload 把"卿七鼎"与"商代"写入 notes，与田自秉原文（周代、《何休解诂》作"诸侯七"）不符，本批以原文为准，未沿用该条 notes。
2. **差异记录而非裁决**：来源之间的冲突（年代、件数、分类体系、名称由来、工艺归属）原文并列保留，写入 `## 核心内容` 并标注出处，不做偏好性裁定。
3. **状态链**：canonical 走 `needs_evidence → ready_for_review → approved → applied`；同组其余 3 条走 `needs_evidence → rejected`，reason 中写明 canonical 目标。
4. **追加式台账**：`candidate-decision-ledger.jsonl` 共 72 行（12×3 + 36），覆盖 48 个唯一 `candidate_id`，只以 transition 叠加，不改写历史 R1 台账。
5. **类型化写回**：`apply-plan.jsonl` 为 12 条 `create`，无 `update`、无 `delete`；逐条重算 `sha256 / bytes / lines` 并与磁盘核对。
