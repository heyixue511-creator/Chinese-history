# 跨书候选重复组召回（2026-10-25）

## 目标

知识库尚无 KU，摄入时的 `knowledge_match` 只能对空的 `04-knowledge/` 判断，无法发现六本书之间的大量同实体候选。本工作包在写回前提供确定性的跨书召回，供 Agent 逐组语义裁决。

## 结果

- unit 候选：3976
- 召回组：523（成员行 1304）
- 跨书组：517（成员行 1292）
- 按类型：{'event': 10, 'institution': 38, 'person': 80, 'place': 41, 'procedure': 13, 'publication': 68, 'term': 197, 'work': 76}
- 规模分布：{2: 357, 3: 104, 4: 39, 5: 16, 6: 7}

## 方法

- 精确 `(unit_type, proposed_slug)` 与规范化 `(unit_type, title)` 双通道召回；标题去空白、书名号、括号与常用标点后比较。
- 输出 `duplicate-groups.jsonl`，每组保留成员、doc_id、标题、slug 与召回依据。
- 只做召回，不做同实体判断、合并、批准或写回。

## 边界

- 召回不完整：异名同实体、译名差异、上下位关系与 OCR 异文不在机械匹配范围内。
- claim 候选（1363）未做文本级分组，需语义审查。
- 组内可能是同实体、上下位或异实体；不得按组自动合并。
- 本工作包不改变任何候选状态。
