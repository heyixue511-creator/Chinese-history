# 内容索引说明

本目录保存面向知识消费与检索的浏览导航，不是权威知识层，也不是系统状态目录。

## 作用

- 提供知识元类型入口：persons、places、publications、works
- 提供全库入口页 `index.md`
- 为写作、查询与浏览提供快速入口

## 边界

- 导航页只回答“去哪里找”，不回答“什么是最终事实”。
- 数值快照必须与 `06-runtime/state/current-health.json` 对齐；无法稳定维护的数值应删除。
- 本目录不保存 Hook、治理、审查或脚本运行日志。
- 权威事实仍以 `04-knowledge/` 下的知识文件与权威索引为准。
