## 一、著作定位与成书脉络

本书是高等院校设计学各专业方向的必修课程"中国艺术设计史"的配套教材（L9），其核心任务是把贯穿于历史发展过程中的设计形态和观念"以修史见识的方式揭示出来，并按朝代演变的历史逻辑，系统地阐述从原始社会直至现当代中国设计发展的特点与成就"（L10）。

再版序言（L10）集中交代了本书的修史立场，可归纳为三点推进：
1. **强化"设计"观念**：用设计视角审视造物活动，重视地域文化与生活特性，反映生活方式与设计发展的相互关系（L10）；
2. **引入实证论述**：围绕"可证性"这一逻辑起点判断设计史发展脉络（L10）；
3. **以史学研究为主线**：在"通变""观变""明变"中寻找核心价值，纳入技术与艺术发展规律的探究（L10）。

作者明确将本书与"工艺美术史"划界：中国艺术设计史"侧重于设计与功能"，工艺美术史"侧重于工艺与欣赏"（L10）。因此玉器、刺绣、抽纱、编结、地毯、雕刻、面具、灯彩等陈设欣赏性工艺品不列入重点叙述范畴，而饮食炊具、家具物件、农用工具、运输舟车、城镇布局、建筑构造、室内陈设、庭园布置等"蕴含着丰富多彩的生活内容、生活方式和生活哲理"的器物则被列为重点内容（L10）。

## 二、全书主旨与核心命题

**全书主旨**：以朝代更迭为纵轴，以"生活—造物—设计"为横断面，重建中国艺术设计从史前到当代的连续性叙事，论证"中国设计自古有之，且连绵不断，始终有着自身的原发力和继发力"（L10）。

**核心命题**：
1. **设计起源的"工具—需要"命题**：设计起源于超越人自身能力范围的劳作需要，石器是人类最早的造物产品，拣取到加工石器的过程即设计意识的萌生（L45）。
2. **"以史为鉴、修史见识"的方法命题**：历史记载与考古实证并重，重新整理历史上出现或发生过的设计事件与史迹，挖掘"具有原真性的记载史料"（L10）。
3. **功能主义的设计史观**：设计史关注的是设计与功能的关系，而非装饰欣赏；器物设计"从实际使用的要求出发，实用性……得到了特别的关注"（L114）。
4. **礼制/社会制度与设计互构命题**：从"藏礼于器"（L190）到营国制度、衣冠等级，设计始终是权力秩序与礼制观念的物化载体。
5. **多元民族与中外交流推动设计演变命题**：胡服骑射（L834）、北魏汉化政策（L819）、唐代对外文化交流（L920）、元代多民族文化交融（L1216、L1262）、明清贸易瓷（L1463）等反复印证设计发展的开放性。
6. **近现代转型命题**：中国近代设计是"伴随着近代手工业和对外贸易萌生和发展"（L1554），洋务运动是"我国工业设计和现代设计孕育的土壤"（L1631）。

## 三、分析框架（人物/主题/结构线索）

- **人物线索**：以历代著名匠师、设计者、理论家串联，如奚仲造车（L257）、欧冶子/风胡子/干将（L501）、鲁班（传说）、马钧（L795）、宇文恺（L1035）、李春（L1035）、李诫（L1943）、王祯（L1327）、郭守敬（L1330）、黄道婆（L1273）、计成（L1497）、朱碧山（L1317）、沈寿（L2030）、陈之佛/李有行/柴扉（L1578）、庞薰琹（L1678）、黄道婆等，构成"人物—技艺—时代"的叙事网络。
- **主题线索**：按"衣（服饰）—食（炊食器/陶瓷）—住（建筑/家具/园林）—行（车船）—用（工具/金属器/漆器）—艺（商业美术/印刷/纹样）"六大生活主题组织每章内容。
- **结构线索**：严格按"原始社会→夏商西周→春秋战国→秦汉→魏晋南北朝→隋唐五代→宋辽金西夏→元→明清→近现代→新中国"的朝代顺序推进，形成"缘起—规制—自觉—发展—变迁—繁荣—纷繁—交融—渐变—更新—进步"的演进叙事。

## 六、材料与方法

**史料类型**：
1. **考古实物**：遍布各章，如仰韶尖底瓶（L114）、司母戊鼎（L202）、越王勾践剑（L501）、曾侯乙编钟（L336）、马王堆丝织品（L641）、法门寺秘色瓷（L949）、南海一号沉船（L1079）等；
2. **传世文献**：《考工记》（L565）、司马迁《史记》、班固《白虎通》（L1931）、贾思勰《齐民要术》（L803）、陆羽《茶经》（L951）、李诫《营造法式》（L1943）、王祯《农书》（L1327）、宋应星《天工开物》（L1973）、文震亨《长物志》（L1979）、计成《园冶》（L1997）等；
3. **方志档案**：明清丝纺织文献三大类（正史、专门科技文献、地方志与档案，L1385）、《清宫内务府造办处档案总汇》（L2036）；
4. **诗文笔记**：《诗经》《左传》《东京梦华录》（L1946）、《梦粱录》（L1952）等，用于复原生活场景与审美风尚；
5. **现代研究论著**：李约瑟《中国古代科技史》（L641）、王世襄《明式家具研究》（L1521）等。

**引用方式**：广引原文并作白话疏解，如引《韩非子》《礼记》解释原始服饰（L146），引《左传》证青铜鼎的政权象征（L187）。**论证方法**：以考古实证为核心，辅以文献互证；对存在争议处并置不同观点，如失蜡法西域传入与本士创造之争（L207）、良渚石犁是否用于犁耕之争议（L160）、秦兵马俑归属之疑问（L723）、秧马用途之争（L1322-1327）等，体现客观性。

## 七、核心论辩

1. **艺术设计史与工艺美术史的划界之辩**：前者重功能与生活，后者重工艺与欣赏（L10）。这是全书的方法论前提，贯穿各章选材（如陈设性工艺品被排除）。
2. **设计起源的时间与属性之辩**：设计是否伴随人类造物即已存在，作者持"造物活动即设计活动"的宽泛定义（L40、L45）。
3. **技术传播与本土创造之辩**：失蜡法（L207）、冶铁术（L314）、青花料来源（L1452）等均呈现"外来/本土"两说并陈。
4. **近代设计转型的外生/内生之辩**：我国近代机器工业"并不是在资本主义萌芽的基础上自然地发展起来的，而是在欧风美雨的刺激下产生的"（L1560），但设计意识又有本土传统底蕴。
5. **保护与创新之辩**：面向21世纪，工艺美术既要保护传统技艺，又需创新，需处理"传承与创新"及"技艺失传和后继无人"问题（L1719）。

## 八、理论资源与学术谱系

- **古代设计/工艺理论**：从《考工记》的"材美工巧""六齐""匠人营国"到《营造法式》的模数制与工料定额制（L1170），再到《园冶》的"因借"造园法（L1501），构成古代造物理论谱系。
- **诸子思想**：孔子"文质兼备"（L524）、墨子"节用""器完而不饰"（L535）、老子"有无"空间观（L541）、荀子"天人相分"（L581）、韩非子"好质而恶饰"（L560）等，为设计思想提供哲学基础。
- **现代学术资源**：李约瑟科技史（L641）、王世襄家具研究（L1521）、沈从文服饰研究（L1277）、庞薰琹工艺美术思想（L1678）等。
- **作者自身学术语境**：作者研究方向为"艺术史与艺术史学研究、艺术教育研究"（L7），其"以史带论"（L10）的方法与其史学训练直接相关。

## 九、语言与写作风格总貌

- **句式**：以陈述性长句为主，多为"主体+特征描述+功能分析+考古/文献佐证"的四段式；章节导言常先述时代背景再转入手工业状况。
- **术语**：大量使用器物专名、工艺专名（如"泥条盘筑法""覆烧""芒口""虹吸原理"），并常以括号注音释义（如"裳cháng""伽qié"）。
- **修辞**：多用引证、例证、对比（如南北青瓷"南方秀丽、北方浑朴"，L762），偶用诗文人典渲染（如"陵阳公样"L963）。
- **文风特征**：叙述严谨平实，兼具教材的条理化（每节设"知识链接"与练习思考题）与史论的阐释深度。

## 十、成就与限度

**成就**：
1. 以"设计"为本位重构中国造物史，成功摆脱工艺美术史以"欣赏"为中心的旧框架（L10）；
2. 史料与考古并重的实证方法，覆盖面广，兼顾汉族中原与辽金西夏等少数民族政权（L1175-1208）；
3. 兼顾制度史（官营手工业、行会）、经济史（贸易、包买主）、生活史（服饰、家具、园林）多维视角；
4. 附录（对照表、大事年表、文献索引、参考书目）为学习者提供实用工具。

**限度**：
1. 因教材篇幅所限，各章叙述密度不均，近现代与当代部分明显简于古代部分；
2. 个别论断依赖二手转引（如达尔文参考《齐民要术》"据说"L803），史料考订仍有待深化；
3. 对"设计"概念的界定偏重器物功能，对近代以来设计职业化、设计教育等系统的理论化处理相对有限；
4. OCR 文本中存在少量讹误（如"考上记"应为"考工记"，L184；"窃窳"等），行文偶有重复段落。

## 十一、一句话概括

本书是一部以"设计"与"功能"为本位、以朝代更迭为经、以衣食用行造物活动为纬、贯通史前至当代的中国造物与设计通史教材，其核心命题在于论证中国设计自古有之、连绵不断，并在与礼制、民族交流、中西交往的互动中持续演变。
