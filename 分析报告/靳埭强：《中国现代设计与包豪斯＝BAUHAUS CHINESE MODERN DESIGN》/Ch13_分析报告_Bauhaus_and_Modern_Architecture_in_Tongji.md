# Ch13 分析报告：包豪斯及现代建筑思想在同济

## 章节定位与功能（含行号范围）
- 行号范围：L1899–1969（标题 L1899；正文 L1905–1968）。
- 作者：殷正声，同济大学建筑与城市规划学院（L1901、L1903、L2515–2517）。
- 功能：全书"建筑教育机构史"篇，以同济大学（含前身圣约翰大学）为个案，讲述包豪斯及现代建筑思想如何通过黄作燊与"八国联军"教师群在中国落地。

## 结构分析
1. 开篇（L1905–1907）：20 世纪初西方建筑风格从沿海城市进入中国，但基本上是复古主义；装饰艺术风传到中国（上海法国俱乐部、和平饭店）；邬达克设计的国际饭店与大光明电影院。
2. 黄作燊与圣约翰大学建筑系（L1909–1953）：黄作燊 1915 年生于天津，剑桥留学、伦敦 AA 建筑学院学习五年；1933 年包豪斯被纳粹封闭后格罗皮乌斯携布鲁耶到 AA 执教，黄作燊聆听前包豪斯校长讲课并与布鲁耶成好友；常接触密斯、阿尔托，拜访柯布西耶；1937 年随格罗皮乌斯到哈佛，与贝聿铭同为门徒；被《西行漫记》感动，1942 年受圣约翰大学邀请回国建系，任首任系主任；引进包豪斯式现代建筑教学体系（鲍力克教室内设计、A.J.Brandt 教构造、Hajek 教西洋建筑史）；1946 年制定大上海规划；1950 年代李德华主持同济工会俱乐部、黄毓麟等设计建筑系主楼（体现现代建筑五原则）。
3. 冯纪忠与现代建筑思想（L1955–1964）：冯纪忠 1915 年生，圣约翰读测量，后到维也纳留学，广泛接触柯布西耶、格罗皮乌斯、阿尔瓦·阿尔托；50 年代同济德国教授雷台尔；罗维东师从密斯；谭垣培养戴念慈、张开济、吴良镛。
4. "八国联军"与教学（L1966）：圣约翰及同济教师多为海归，"专业课一直是用英语讲授"；罗小未（博士导师，美国建筑院士）用牛津《Modern Architecture》教材。
5. 50 年代后（L1968）：黄作燊不断被批、冯纪忠建筑空间学遭批；2000 年世界建筑大会后冯纪忠设计的松江方塔园引起轰动。

## 内容分析
- 核心论点：包豪斯作为系统的现代建筑思想与教育体系对中国的影响始于 20 世纪 40 年代同济大学的前身圣约翰大学（L1907）。
- 关键人物：黄作燊（圣约翰）、冯纪忠（维也纳）、罗小未（师承谱系）。
- "八国联军"现象：多国海归教师群（L1966）。
- 传承之痛：50 年代后现代主义建筑思想遭批判（L1968）。

## 逻辑梳理
背景（复古主义/装饰艺术）→ 黄作燊留学与建系 → 圣约翰教学体系 → 大上海规划与作品 → 冯纪忠/罗小未等 → 八国联军教学 → 50 年代命运。逻辑是"个人经历-教育制度-思想命运"。
