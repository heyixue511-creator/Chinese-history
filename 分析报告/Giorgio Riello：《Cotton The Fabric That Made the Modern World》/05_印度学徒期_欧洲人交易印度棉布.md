# 05_印度学徒期：欧洲人交易印度棉布

## 一、章节定位与功能

### 1.1 在全书中的位置

本章是Part II（学习与连接：使棉花全球化，1500-1750年）的首章，承担着**"欧洲从何处开始"的叙事功能**。它追踪欧洲人如何从印度洋贸易的"后来者"逐步积累关于棉纺织品的知识——这是Riello"漫长学习过程论"的第一环。

### 1.2 功能

- **转折功能**：从Part I的"亚洲中心"叙事转向"欧洲介入"叙事
- **知识史功能**：详述欧洲东印度公司如何学习棉花贸易——品种知识、品质控制、市场匹配、产品定制化
- **修正功能**：纠正"贸易只是资本积累"的传统解释——Riello强调贸易本身就是知识获取的过程
- **预设功能**：为Ch6（欧洲消费）和Ch8（欧洲印花技术）提供"知识的贸易来源"

## 三、内容分析

### 3.1 核心论题

**论题一**：欧洲东印度公司的贸易不仅是资本积累，更是一个**知识获取的过程**——学习品种、品质、市场价格、消费者偏好。Riello称这为"印度学徒期"（Indian Apprenticeship）。

**论题二**：欧洲贸易的"学习"包含两个方向——在印度学习如何购买，在欧洲（及非洲、美洲）学习如何销售。两个市场的信息通过跨洲际通信系统连接。

**论题三**：定制化（customisation）是连接印度生产和欧洲消费的关键实践。欧洲公司不仅是"被动接收者"，而是积极介入产品设计——尤其是在颜色（白色背景偏好）和尺寸规格方面。

### 3.2 关键论点与案例

1. **EEIC的"衬衫惨败"（1682年）**：EEIC从马德拉斯订购20万件成衣衬衫和内衣以替代欧洲亚麻衬衫——这是早期现代最大的"服装投机"之一。结果完全失败：消费者因"棉布不适"而拒绝购买。这个案例完美展示了"学习"过程中的重大挫折。

2. **红色背景vs白色背景的审美转向**：印度传统生产面向东南亚和中东的是深红或深蓝背景的棉布（Figure 5.6）→ EEIC在1643年要求"更多白色背景"（Figure 5.7）→ 这一审美偏好无意中为欧洲印花业的发展打开了大门（白底印花在技术上更昂贵，欧洲人后来找到了工业化解决方案）。

3. **"乔治布"（George cloth）的命名**：西非市场将一种流行的印度棉布称为"George"——很可能源自马德拉斯的圣乔治堡——这种"商品地理命名"反映了贸易网络的全球互联性。

4. **荷兰的batik仿制失败（1680年代）**：VOC委托科罗曼德尔织工仿制爪哇蜡染布（batik），结果质量更差但价格却是五倍——"学习"过程的又一失败案例。

5. **Peter Floris的"窄白边"教训**：英国商人发现马来消费者因为布边有"一小条窄白边"而拒绝购买——这"如此微小的瑕疵竟造成如此巨大的降价"令他震惊。

## 四、逻辑梳理

### 4.1 论证链条

```
葡萄牙先驱 → 其他欧洲公司跟进
→ 信息系统的建立（跨洲际通信）
→ 学习品种（从50+种聚焦到8个核心品种）
→ 失败中学习（衬衫、batik、窄边）
→ 产品定制化（颜色、尺寸、设计）
→ 质量控制的困难（织工独立性、季节性）
→ 政治控制的出现（1757年后英国支配孟加拉）
→ 结论：贸易=知识积累=欧洲棉业发展的前提
```

### 4.2 关键因果转折

- **转折一**：从"随便买"到"聚焦买"——EEIC在1690年代后从交易50+种布匹缩小到8个核心品种（Figure 5.5），标志着从学习者到专家
- **转折二**：从"亚洲贸易"到"亚洲+大西洋贸易"——认识到非洲和美洲是更大的市场
- **转折三**：从"商人"到"制造商的前身"——英国公司开始直接介入生产管理

## 六、论辩与阐述方法

### 6.1 主要论辩策略

1. **失败叙事**：强调欧洲公司的多次失败（衬衫、batik、窄边、法国财务崩溃）——对抗"欧洲天生会做生意"的隐含假设。
2. **知识作为关键变量**：将"知识"提升到与资本、技术同等的解释地位。
3. **多层次学习**：不仅学习"买什么"，还学习"怎么买""怎么运""卖给谁"

### 6.2 阐述特点

- 信息密度极高（大量品种名称、地点、人物）
- 以公司为单位的比较式推进
- Figure 5.11的价格-利润曲线是经济史量化方法的经典应用
