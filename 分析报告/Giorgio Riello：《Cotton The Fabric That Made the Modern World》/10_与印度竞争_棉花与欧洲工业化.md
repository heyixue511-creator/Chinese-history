# 10_与印度竞争：棉花与欧洲工业化

## 一、章节定位与功能

### 1.1 在全书中的位置

本章是Part III的核心章节之一，处理的是全书最"经典"的主题——工业革命与技术革新。但Riello的目标是"拆解"（unpack）传统叙事：将技术从"原因"重新定位为"工具"，将"生产力"与"质量"并置为同等重要的驱动因素，并将其置于全球竞争的语境中。

### 1.2 功能

- **修正功能**：反对技术决定论，主张技术革新是为了追赶印度产品的**质量**而不只是提高**产量**
- **比较功能**：将欧洲（英国）与中国置于平行比较，解释为什么"勤劳革命"在中国未导向工业革命
- **解释功能**：回答"为什么是英国先实现工业化"——不是"例外"而是"极端"

## 三、内容分析

### 3.1 核心论题

**论题一**："质量驱动论"——欧洲机械化的首要动力不是降低成本，而是**提升纱线质量**使其能用作经线，从而实现纯棉布的生产以匹敌印度产品。Arkwright的water frame使棉纱足够强韧以用作经线——这是纯棉布（而非混纺fustian）成为可能的关键。

**论题二**："勤劳革命"在中国和欧洲产生不同结果——中国因劳动力供应弹性大（人口众多、妇女就业机会少）陷入了"内卷化商业化"（involutionary commercialisation），欧洲则因劳动力相对稀缺和妇女有更多就业选择而走向了节省劳动的技术创新。

**论题三**：工厂制不仅是技术变革，更是**社会关系的革命**——从印度织工村的独立生产者到欧洲工厂的被管理者，从基于技能到基于规程的转变。

### 3.2 关键论点与案例

1. **Arkwright被妻子砸坏模型**的日本版画（Figure 10.1）：19世纪日本版画将Arkwright的故事纳入"值得了解的四件事"——技术叙事的跨文化传播本身就值得分析。

2. **Montaran的印度工匠移民计划（1784-87年）**：法国政府花费41,000里弗尔将50名科罗曼德尔工匠（12名织工、25名纺工、1名染工）带到巴黎郊区→结果只生产了价值12,000里弗尔的布料→工匠被送回印度。这一失败证明"人力资本的直接移植"不可行——必须通过技术替代。

3. **Rouen制造商的价格分析**：法国Rouen制造商计算出garras比印度贵70%、Guinea布贵30-40%、baftas贵20%。结论是即使原材料无法降价，也必须降低制造成本——这直接催生了对省力技术的需求。

4. **纯棉布的突破**：在1770年之前，欧洲只能生产fustian（麻棉混纺），因为手纺棉纱不够强韧用作经线 → Arkwright的water frame解决了这个问题 → 1774年他游说废除1721年禁令，声称他的机器生产出"完全由棉花制成的、品质优于现有麻棉混纺织品"的产品。

5. **斯温森·伯利棉纺厂1834年版画**（Figure 10.8）vs 印度织工的Sonnerat版画（Figure 10.7，1782年）——两张画仅仅相隔五十余年，展示了从"孤独的工匠"到"机器主导的集体生产"的转变。

## 四、逻辑梳理

### 4.1 论证链条

```
技术革新是工业化的核心吗？（是，但不充分）
→ 为什么需要新技术？（追赶印度产品的质量）
→ 中国为什么没有走同样道路？（劳动力弹性+家庭结构）
→ 新技术改变了什么？（不只是成本，更是品质和组织）
→ 新技术的本质是什么？（集中化、标准化、去技能化、去自然化）
→ 为什么是英国？（不是"例外"是"极端"；第一个行动者的优势+战争）
→ 法国、西班牙为什么落后？（政治动荡+英国的先发优势）
```

### 4.2 关键因果转折

- **从"降低成本"到"提升品质"**：这是Riello挑战传统工业革命叙事的核心转向
- **从"中国也可以"到"中国为什么不"**：采纳Pomeranz的比较框架但给出不同答案
- **从"技术发明"到"技术采纳的社会条件"**：发明本身不是关键，关键是整个社会的组织重构

## 六、论辩与阐述方法

### 6.1 主要论辩策略

1. **Arkwright叙事的去神话化**：以日本版画揭示"发明英雄"叙事本身就是一种文化建构。
2. **"质量派"与"数量派"的建构**（Figure 10.2）：创造清晰的二分法来组织学术辩论。
3. **失败案例的论证力量**：Montaran计划的失败比成功故事更有解释力——它证明了为什么"人的移植"不如"技术的创造"。

### 6.2 阐述特点

- 工业革命的"去浪漫化"：不以英雄叙事讲述技术突破，而是将其置于全球竞争和消费需求的压力下
- 工厂空间的"厚描述"：从建筑结构（多层、铁柱、蒸汽动力传动）到劳动实践（规则、工时、性别分工）
- 设计/知识产权的出现作为一个重要但常被忽视的维度
