# Ch07_分析报告_国家设计策略

## 一、章节定位与功能（含行号范围）

- **行号范围**：L151（第七章标题与开篇，含刘兆玄清华演讲）—L161（L160 尾部含第八章标题；正文主体 L153-L160）
- **章节标题**：第七章 国家设计策略
- **功能**：国家维度章。论证设计如何从行业力量上升为国家形象塑造与国策组成部分，以"设计认同国策的形成""北京奥运会的国家设计构思""世博会中的'中国元素'"三大主题展开，对应"国家—视觉形象"线索（L1）。

## 二、结构分析

第七章分三节（据目录 L51）：

1. **设计认同国策的形成**（L153-L155）：国际参照（英、美、德、意、日战后设计认同策略）；中国入世（2001）后文化创意产业的启动；2005年十一五规划"自主创新"、2006年"文化创意产业"流行语；六大文化产业集群；许平《创意产业的中国崛起》。
2. **北京奥运会的国家设计构思**（L156-L158）：奥运设计系统四大类（基础视觉元素、应用环节、建筑公共艺术、特许商品）；陈绍华申奥标志；日本东京奥运、韩国汉城奥运、西班牙巴塞罗那奥运的参照；北京奥运设计中的中国符号（中国印、祥云、金镶玉、福娃）；"中国印"会徽之争（《美术观察》报道、陈汉民与陈绍华的批评）。
3. **世博会中的"中国元素"**（L159-L160）：中国设计界对2008奥运与2010世博的期望；杭间《设计的民主精神》的批评；潘鲁生世博述评；《装饰》2010年第10期《设计之"觞"》对中国省区市联合馆的批评（主题定位、设计语言无整体性、"古董"频繁出现）；中国设计夹击中的处境。

## 三、内容分析

- **国策部分**：彭妮·斯帕克论英国设计委员会、美国"优良设计"与文化产业、德国设计委员会与博朗/博世、意大利/日本抵制福特模式（L154）；中国入世催化文化产业（L154）；2005年10月十一五规划"自主创新"、2006年7月《新京报》报道"文化创意产业"成十大流行语之一、六大产业集群（首都/长三角/珠三角/滇海/川陕/中部）（L154）；许平"创意产业与中国崛起"（L154）。
- **奥运部分**：奥运设计四大类（基础视觉元素、宣传景观仪式、城市公共艺术、特许商品）（L157）；陈绍华申奥标志（"中国结"与"太极拳人形"）（L157）；东京奥运（1964）龟仓雄策、汉城奥运（1988）三星、巴塞罗那奥运（1992）加泰罗尼亚品牌重塑（L157）；北京奥运中国符号：中国印会徽（印章+书法）、祥云火炬（传统雕漆）、金镶玉奖牌（龙纹玉璧）、篆字体育图标、福娃（五行）（L157）；"中国印"会徽之争——《美术观察》2003年第9期报道、陈汉民"四要素"评价、陈绍华批评"评委会选择就是选择文化方向"（L157）。
- **世博部分**：杭间批评"轻视设计的价值观之痛"（L160）；潘鲁生世博述评"传统智慧的寻根之旅"（L160）；《设计之"觞"》批评三缺失：主题定位错误、设计语言无整体性、"古董"频繁出现（螳螂白菜、香樟木根雕清明上河图）（L160）；彭妮·斯帕克"设计在创建国家认同中的作用"（L160）。

## 四、逻辑梳理

论证链条：**国家形象依赖设计策略（国际参照：英美德意日）→ 中国入世与文化产业启动 → 十一五"自主创新"上升为国策 → 北京奥运设计系统与"中国元素" → 世博会中国馆的成就与批评 → 设计作为国家形象策略的"夹击"处境**。全章从国策文本到重大事件，完成了"设计—国家"关系的制度史与事件史双重叙述。

## 五、材料使用方式

- **国际文献**：彭妮·斯帕克《设计与文化导论》、滕守尧《知识经济时代的美学与设计》、王受之《世界现代平面设计史1864-1997》。
- **政策文件**：十一五规划建议、北京市十一五规划纲要、上海2004-2010文化发展规划纲要、《新京报》报道。
- **展览与报道**：《装饰》2008年8月"奥运设计"特别策划、《美术观察》2003年第9期"中国印"讨论报道、《装饰》2010年第10期《设计之"觞"》、潘鲁生《中国文化报》述评。
- **国际案例**：东京/汉城/巴塞罗那奥运设计经验。

## 六、论辩与阐述方法

- **国别比较法**：英美德意日设计认同策略的系统比较（L154）。
- **系统分类法**：将奥运设计系统划分为四类（L157）。
- **批评文本并置**：对"中国印"会徽、世博中国馆，将官方赞扬与专业批评并置（L157、L160）。
- **夹击隐喻**：以"现在的中国正处在这样的夹击中"（L160）概括国家设计策略的理想与现实落差。

## 七、语言文风摘录（附行号）

- "中国当前对包豪斯现代设计的思考是不容忽视的……包豪斯不是一种风格，而是一种本质的现代性。"（L1，格纳德序）
- "以政府与工业联手，融入民族文化，打造全新本土形象的成功案例，还有1992年巴塞罗那奥运会之后的西班牙。"（L157）
- "2008年的奥运设计是一个集中国历史文化符号之大成的实践。"（L157）
- "如果像网络上所说的那样不看遗憾看了更遗憾'，那一定不是花去人生宝贵五六小时的人民大众之错，而是普遍存在于我们内心的轻视设计的价值观之痛。"（L160，杭间语）
- "现在，无论从概念及文本上已经开始大力提倡和扶持文化产业，但另一方面在实践中又缺乏合理的操作机制、客观的评价体系以及相应的好的'品味'。"（L160）
