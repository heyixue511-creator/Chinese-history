# NN_专项报告与实体总索引

> 依据《设计史·知识元》书籍分析统一方法说明书撰写。全部行号（L###）以 clean 版（共 420 行）为准。

## 第一部分：专项报告

### 一、语言与文字风格

1. **学术随笔文体**：全书在严格学术注释之外，保留大量第一人称叙事——"我自己曾有这样的体会：一次在朋友家中接触到电子游戏机"（L94）；"我小时候，因听了《干将莫邪铸剑》的传说，对宝剑很着迷"（L241）；乡村用字纸糊墙的记忆（L277）。作者自述"保留了我当年写作时自然、感性的风格"（L420）。
2. **概念史起笔**：多数章节从词语或文献公案进入——"工艺美学"的提出（L3）、"大器免成"与"大器晚成"（L87）、"由王返朱"（L207）、"一个名词兴衰的背后"（L351）、"藏"在何处（L262）。
3. **古今对译并行**：直引古文字随即白话转述，形成"原文—译文—评点"三段式（如 L64、L79、L244）。
4. **对称概括句**："汉之深沉宏大、魏晋之秀骨清相、唐之雍容典雅、宋之理学主流、明之经世致用"（L1）；"质、动、紧、味"（L121）；"清、秀、神、俊"（L145）；"厚、清、真"（L199）；"错彩镂金"与"初发芙蓉"（L145）。
5. **术语习惯**：核心术语为"工艺美学、工艺美术、造物、器用、生活方式、道器、文质、功能、适用、装饰、设计"；"适用"专取王朝闻说（L1）；"造物"作为工艺的哲学化表达贯穿全书。

### 三、史料使用方式

1. **经史子集并重**：先秦经典（《老子》《庄子》《墨子》《论语》《荀子》《韩非子》《考工记》《周易》）、正史（《史记》《汉书》《周书》《元史》）、笔记（《世说新语》《西京杂记》）、子书（《淮南子》《新语》《新书》）。
2. **工艺文献为独立证据层**：《天工开物》《闲情偶寄》《髹饰录》《幼学琼林》《陶说》《景德镇陶录》。
3. **民间文献升格**：传说（《磁州窑的传说》《吴越春秋》）、艺诀、行业神崇拜被赋予与经典同等的证据地位（L22、L241）。
4. **实物证据**：长信宫灯（L127）、唐三彩（L157）、明式家具（L193）、宋瓷（L172）、西善桥砖刻（L139）。
5. **现代学术文献**：李泽厚、宗白华、敏泽、田自秉、王朝闻、冯友兰、赵汀阳、宁稼雨等，作为对话与论辩对象（L22、L46、L145）。
6. **引用规范**：方括号[数字]注码，章末连排；全书末 A-Y 拼音书目（L363-L419）。作者对考证采取"存而不问"策略（L43）。

### 四、阐述方法与推演逻辑

1. **思想史—工艺史互证**：从哲学思想推演造物风格（理学→宋瓷，L171-L172；玄学→青瓷，L139-L145）。
2. **中西对话**：墨子↔莫里斯（L52）、墨子↔卢斯（L55）、韩非↔苏格拉底（L115）、道家异化↔马克思（L94）、人体工学↔《黄帝内经》（L316-L319）。
3. **正反辩证**：对每个命题同时给反例——道家"技进乎道"之美与其"走入神秘"之弊（L97）；人体工学的"点"与整体（L316）；曼菲斯的诘难与"适应性"（L325）。
4. **自我修正**：公开修订早年"理学害技艺"的判断（L171）。
5. **归纳概括**：六大特征（L22-L34）、八型传说（L247）、七受力点（L322）、成朝晖七法（L271）。
6. **实证统计**：碗的历代尺寸比例（L313）、形声字占比 27.24%→87.39%（L268）。
