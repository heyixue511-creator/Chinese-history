# NN 专项报告与实体总索引

## 第一部分：专项报告

### 一、语言

全书以现代简体中文学术随笔体写成，但保留了大量的**繁体原文引文**（如《校印四部备要缘起》《考工八咏》《四部备要缘起》等，L1、L56）与**日文混排**（图注与引文，L18、L24），形成"现代叙述语言+历史文献原貌"的双轨语体。语言庄重而富于温度，常以"笔者"现身（L24、L62），兼具考据的严谨与随笔的亲切。

### 二、文风

- **史论结合**：判断句与事实陈述交织，如"聚珍仿宋是20世纪中国最美、最经典的一款仿宋字，没有之一"（L56）。
- **比喻丰富**：以日常意象阐释字体美学，如"兰亭宋是雅致的书生，博雅宋便是写字楼里的白领"（L189）。
- **第一人称叙事**：作者个人的收藏经历、访问见闻频繁入文（L40、L117、L223）。
- **批判性保留**：对争议问题（毛泽东时代、达达与锦灰堆、傅德雍作品）采取辩证与谨慎态度（L123、L101、L133）。

### 三、修辞方式

| 修辞手法 | 例证 | 行号 |
|---|---|---|
| 比喻/拟人 | "兰亭宋是雅致的书生，博雅宋便是写字楼里的白领" | L189 |
| 递进 | "首先是……其次……然后……最后……" 多用于分项论述 | L135 |

| 引用典重文 | 全录《考工八咏》、行政院训令等 | L56、L109 |

### 四、史料使用方式

1. **实物图版优先**：每一论点均配图版（"图N"），来源注明"作者自藏""××图书馆藏""××提供"（全书遍在）。
2. **一手文献全文征引**：陆费逵《校印四部备要缘起》（L1）、丁善之《考工八咏》（L56）、蔡元培启示（L6）、行政院训令（L109）、陆梅僧《广告》引文（L101）。
3. **口述史**：徐学成、何远裕等访谈（L227）、钱焕庆回忆（L2、L40）。
4. **学者研究征引**：苏精（L24）、周有光（L2）、西野嘉章（L99）、小宫山博史（L18）、俞佳迪（L56）、Meggs（L2）。
5. **档案与行业文献**：《印刷活字研究参考资料》（L2、L153）、《印刷活字字样调查》（L8、L52）、《上海印刷字体字稿汇编》（L153）、《字模与铅字》（L143）。
6. **网络资源**：个别图版来源为网站（L121、L223）。

### 五、阐述方法

1. **图史互证法**：图版即论证，图注即史料说明。
2. **个案-通论结合**：以聚珍仿宋、汉文正楷等个案推及字体族类与时代。
3. **比较法**：中日、大陆台湾、民国与现代对照。
4. **谱系追踪法**：字体与师承谱系（徐锡祥→周焕斌→钱焕庆；谢培元→齐立）。
5. **制度史视野**：文字改革、公私合营、国家行为等制度解释。
6. **媒介技术史**：雕版→铅活字→照排→点阵→PostScript→屏显。

### 六、推演逻辑

- 因果链：技术（铅活字/网格/PostScript）→ 字体形态与审美（易木为铅/坐标格纸/屏显）→ 文化意义（民族意识/现代性）。
- 影响链：外来影响（日本/苏俄/西方）→ 中国本土转化（书法篆刻基质性）→ 中国特色（居中、金石味、复兴经典）。
- 价值链：字体设计从"专业话题"升华为"超越于视觉的社会和文化现象"（L42）。

### 七、文字风格

简洁明快、名词性判断多、术语密集；善用"所谓……其实就是……""表面上……事实上……"等解释句式；标题多为短语（"## 香港字""## 金石味"），节奏明快。
