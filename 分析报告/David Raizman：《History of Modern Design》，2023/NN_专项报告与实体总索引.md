## 专项报告一：全书核心论题跨章追踪

本报告将全书六大核心论题（见00_整体分析报告 L001-L006）在各章中的展开情况进行追踪，形成"跨章主题索引"。

### L001 生产与消费的互动关系

| 章 | 表现形式 |
|---|---|
| Ch.1 | Louis XIV的国家工坊：生产服务于政治消费（视觉权威的展示） |
| Ch.2 | Wedgwood：生产服务于市场消费（中产阶级的趣味需求） |
| Ch.3 | 工业革命：蒸汽动力+机械化→生产规模化→消费市场扩展 |
| Ch.5 | Morris批判：工业生产→消费的异化（产品失去创造的意义） |
| Ch.7 | Fordism：流水线生产→工资提高→工人成为消费者 |
| Ch.10 | 工业设计师：生产+广告→消费欲望的创造和操纵 |
| Ch.11 | "Good Design"：生产标准→消费教育（paternalism） |
| Ch.12 | Detroit styling：生产→消费→再消费（Planned Obsolescence） |
| Ch.14 | Pop Design：生产/消费的图像被回收为"反消费"的艺术 |
| Ch.16 | 循环经济：生产→消费→回收→再生产（Cradle to Cradle） |

## 专项报告五：全书论证方法类型学

| 方法类型 | 典型表现 | 示例章节 |
|---|---|---|
| 个案深描法 | 通过单一案例（个人、产品、企业）折射时代 | Ch.2 (Wedgwood), Ch.5 (Morris), Ch.7 (Behrens/AEG) |
| 国别比较法 | 多国并置呈现，不做优劣排序 | Ch.6 (Art Nouveau的国际变体), Ch.11 (各国战后路线) |
| 制度分析法 | 学校、博物馆、展览等机构作为设计标准的制定者 | Ch.4 (Cole, V&A), Ch.9 (Bauhaus), Ch.11 (MoMA) |

| 对立并置法 | 同一时期对立的路线同时呈现 | Ch.8/9/10 (Art Deco vs Bauhaus vs 美国工业设计), Ch.11/12 (Good Design vs Styling) |
| "资产负债表"框架 | 会计隐喻评估改革运动的得与失 | Ch.4 (A Balance Sheet of Reform), Ch.9 (Taking Stock) |

## 专项报告六：第三版修订要点与学术贡献评估

### 六大修订要点

1. **Global Inspiration六篇**：最显见的去中心化行动，每篇覆盖一个非西方/边缘化的设计传统
2. **性别议题的扩展**：从个别女性设计师的提及到系统性讨论设计中的性别政治（如厨房设计的性别化、时尚中的女性形象）
3. **种族议题的深化**：奴隶制、殖民主义与原住民设计传统的纳入（Ch.3的棉花-奴隶制关联、GI III的非洲）
4. **COVID-19的当代回应**：第16章纳入疫情作为"设计的历史事件"
5. **AI和数字技术的更新**：当代设计的最前端讨论
6. **话语自觉（canon critique）**：明确讨论设计史正典的建构性

### 学术贡献

该书确立了"生产-消费"互动关系作为设计史分析的主轴，将平面设计、工业设计和装饰艺术统一在同一叙事中，通过第三版的"去中心化"策略回应了全球化时代的学术需要。其作为设计史通论的权威地位由其被纳入美国NASAD课程标准和被翻译为中文（第一、二版）等事实所证实。
