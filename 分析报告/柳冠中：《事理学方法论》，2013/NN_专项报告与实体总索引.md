# NN 专项报告与实体总索引

## 第一部分：专项报告

### 一、语言与文字风格

全书以规范现代汉语书面语为主，辅以文言引文（古籍直接引文）与口语（访谈问答体）。语言特征：

1. **命题式判断句**：大量"……是……""所谓……就是……"句式构成定义网络。例："事是物存在合理性的关系脉络"（L130）、"设计是人的基本活动"（L452）。
2. **辩证对举**：善用"一方面……另一方面……""既……又……""与其……不如……"展开张力。例：有限理性论述（L170、L538）。
3. **比喻修辞**：医学类比（"望闻问切""对症下药"L134、L146）、音乐类比（交响乐/独唱 L231、天使交响乐 L472）、建筑类比（四根柱子 L269、L401）、生态类比（鸡蛋与白切鸡 L313）。
4. **排比与对偶**："历史铭刻了先民的业绩。历史也湮没了腐朽的渣滓。历史指出后者的道路。历史与未来无休无尽。"（L315）
5. **口语化表达**：访谈篇（L199–L269）保留"老柳""把戏""侃""花头"等口语词，富现场感（L205、L237）。

### 三、史料使用方式

1. **古籍文献直接引证**：《考工记》（L567–L569）、王祯《王祯农书》（L50–L64）、宋应星《天工开物》（L46–L64）、徐光启《农政全书》（L46–L56）、培根《新工具》（L560）、李约瑟《中国古代科技史》（L562）。
2. **西方文献转述＋注释**：诺曼（L117）、西蒙（L458、L510）、鲍德里亚（L459、L477）、赫胥黎（L476）、泰勒（L486）。
3. **考古与文物证据**：甲骨文金文"车"字（L566）、长沙西汉墓蝶形轮（L573）、陶寺铜铃（L74）。
4. **政策与数据证据**：《关于中国发展工业设计的若干指导意见》（L251）、照度测试数据（L279–L283）。
5. **参考文献**：两处列出中英文文献（L387、L403）。

### 四、阐述方法

1. **定义法**：先界说核心概念再展开（"事""物""目标系统""生活方式形态模型"）。
2. **案例解剖法**：杯子（L265、L7）、轮子（L560–L574）、升水器械（L38–L72）、钟钺（L74–L80）、木拱桥（L142）、冰箱（L229）。
3. **历史比较法**：中外车轮演变对照（L573–L574）、东西建筑精神对照（L492）。
4. **理论互释法**：以西蒙"适应性系统"释"天时地利人和物宜工巧"（L92–L96）。
5. **层次分析法**："表层—中层—深层"三层面分析历史时期（L299–L315）。
6. **正反辩证**：既肯定中国古代设计思维的整体性与联系性，又指出其缺乏分析性与可操作性（L90）。

### 五、推演逻辑

全书遵循"本体论（设计是什么）→ 认识论（如何认识）→ 历史证成（中国古代案例）→ 方法论（事理学）→ 应用（生活形态、商品评价、国家战略）"的演绎路径；章内多用"定义 → 结构 → 例证 → 应用"的递进，附录论文采用"摘要 → 分节论述 → 结论"的归纳—演绎混合结构。
