# Ch05_分析报告_附水·附录

## 一、章节定位与功能（含行号范围）

- **行号范围**：L196-L208（目录"附水"项见 L17-L18；正文自 L196 末尾"杭间，在艺术的'原乡'"访谈起，至 L208 初版后记与版权页止）
- **章节标题**：附水（附录：访谈录 + 初版后记）
- **功能**：以《中国文化报》记者冯智军的访谈录为主体，回顾杭间的学术人生（从"文学青年"到工艺美术史论学者、编辑、策展人、设计史家），并以初版后记收束全书，落实"自我田野"与"手艺人的后代"的自我定位（L1、L208）。此部分既是作者个人的思想自传，也是理解全书各篇写作语境的背景文献。

## 二、结构分析

本章含两部分：

1. **访谈录：杭间，在艺术的"原乡"**（L196-L208）——由《中国文化报》记者冯智军访谈，分小节：
   - 当代艺术中的"文学青年"（L198-L199）：1983 年考入中央工艺美院史论系、创办《工艺美术史论》学生刊物、为雕塑家吴少湘写评论、《中国美术报》《美术思潮》撰稿、1987 年毕业留校《装饰》编辑、"89 现代艺术大展"《美术》杂志责编。
   - 转向工艺美术和设计（L201-L202）：1991 年考取田自秉博士生、论文《中国工艺美学思想史》获首届全国百篇优秀博士论文奖、何燕明带其拜访文化名家、《装饰》获首届国家期刊奖、1999 年回史论系任首任主任。
   - 清华出走（L204-L205）：2003 年借调汕头大学与靳埭强、王受之创办设计学院、美国康奈尔大学访学、清华美院副院长、2012 年调任中国美术学院（包豪斯设计博物馆）。
   - 寻找中国设计（L207-L208）：从《在现实和内心之间：新具象艺术》到《设计的善意》《原乡·设计》，论"本土设计""中国设计要适合中国人"、中南论坛（中国—南非本土知识体系研讨会）的反思。
2. **初版后记**（L208）：作者自陈"我是个手艺人的后代"，回顾十年写作的自我小结，谈对怀旧的警惕与对乡土手艺的"纯净的力量"。

## 三、内容分析

- **访谈录**：访谈以"延长生命"之喻开篇（"多做些有意义的事……等于延长自己的生命"，L196），作者自述性格"不太安于现状""不愿意做重复的事情"（L196）。回忆 1983 年进入中央工艺美院史论系、写吴少湘评论"逼着我要去学习了解西方雕塑的发展历史"（看赫伯特·里德的《现代雕塑史》）（L199）；"89 现代艺术大展"侧记被巫鸿收入纽约现代艺术博物馆英文文献集（L199）；1991 年师从田自秉做博士论文（"按说博士论文是不可能做通史的，这是过渡时代的产物"，L201）；何燕明带其拜访艾青、楼适夷、丁玲、曹辛之等（L201）；2003 年汕头大学、2012 年调中国美院（L205）。论设计时强调"原创的东西怎么来？不是新鲜就是原创，而是把真正让中国人用得合适而外国人又没做到的做出来，这个才是原创"（L208）；中南论坛上"猛然发现，我说的问题及观点，自己在十年前就已说过了"的失落（L208）。
- **初版后记**：作者自陈"我是个手艺人的后代……我仍未离开我的祖辈曾作为谋生手段的手工艺"（L208）；"我常常问自己，我对手工艺的感情是否流于怀旧？"（L208）；"遇到那些灰头土脸、布满生活痕迹的乡土手艺时，还是禁不住由衷地喜悦，并感到一种纯净的力量"（L208）；落款"2000年10月18日于北京延庆清华大学三堡绿化基地"（L208）。

## 四、逻辑梳理

- 时间线：1983 年入学 → 1987 年留校《装饰》 → 1991 年博士 → 1999 年史论系 → 2003 年汕头大学 → 2007 年清华副院长 → 2012 年中国美院。
- 主题线：当代艺术（文学青年、现代艺术展）→ 工艺美术与设计（博士论文、编辑）→ 设计教育与策展（汕头大学、包豪斯博物馆）→ 本土设计（《设计的善意》、中南论坛）→ 手艺原乡（初版后记）。

## 五、材料使用方式

- **口述材料**：访谈录由记者与作者对话构成，含大量直接引语（L196-L208）。
- **个人著述**：杭间著作的自我梳理——《工艺美术史论》刊物、《中国现代艺术展侧记》《在现实和内心之间：新具象艺术》《中国工艺美学思想史》《手艺的思想》《设计的善意》《原乡·设计》（L199-L208）。
- **机构文献**：中央工艺美院、汕头大学设计学院、清华大学美术学院、中国美术学院、包豪斯设计博物馆（L199-L205）。
- **引用方式**：访谈直引为主，篇末以初版后记（L208）与版权信息收束。

## 六、论辩与阐述方法

- **访谈体**：记者提问与作者自述交织，具口语化、现场感。
- **自我叙事法**：以个人学术履历串联中国工艺美术史论学科与设计教育四十年变迁。
- **反身自省**："我的认识和研究没有深入下去吗？回答当然是肯定的。"（L208）
- **策展—研究互证**：展览策划（上海艺术设计展、何香凝美术馆"从制造到设计"展、首届北京国际设计三年展）与著述互相印证（L196、L208）。
