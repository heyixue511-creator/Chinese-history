# Ch15 其他各个地区的初步工业化（1750—1900）

## 一、章目信息

- **章名**：第15章 其他各个地区的初步工业化（1750—1900）
- **行号范围**：L2975–L3190（简介 L2975、平面艺术 L2978、墨西哥 L2981、巴西 L2982 区域、古巴 L3021、阿根廷 L3018 区域、德川时代晚期和明治时代早期的日本 L3024、版画和书籍 L3027、中国 L3033〔中国工业化之初 L3035、印刷出版广告 L3038〕、香港地区 L3041、奥斯曼土耳其帝国和阿拉伯世界 L3044、印刷期刊和书法 L3047、波斯 L3052、参考文献 L3055–L3190）

## 三、内容分析

### 3.1 简介（L2975–L2976）

- "世界中心"（快速工业化国家+中产阶级消费文化）与"边缘"（殖民地、前工业化国家，靠出口原材料为生）的分野。
- 借丹尼尔·布尔斯廷"消费群落"概念描述中间地带（拉丁美洲、日本、中国、奥斯曼）的不稳定工业化。
- 拉丁美洲缺乏基础设施；日本四处搜寻发展模式；中国有出口经验而无政令；奥斯曼军工业有优势而无消费文明基础。

### 3.2 拉丁美洲（L2978–L3022）

- 印刷传统：教会印刷所→世俗文学（法国/美国革命刺激）；迪渡字体与英国装饰字体。
- **墨西哥**（L2981–L2982）：甘布里多（《墨西哥专辑》1849）、**何塞·瓜达卢佩·波萨达**（1852—1913，骷髅 calavera、锌版蚀刻、《现代评论》鲁拉斯）。
- **巴西**（L2982–L3016）：若昂六世皇家印刷所（1808《里约热内卢公报》）、弗朗西斯科·德·保拉·布里托、恩里克·弗洛伊斯《图画周刊》（1860）、阿格斯蒂尼《图画评论》（1876）；累西腓平版印刷与雪茄商标。
- **古巴**（L3021–L3022）：雪茄商标（阿隆尼1837，11色平版印刷、西方艺术经典图像）。
- **阿根廷**（L3018–L3019）：1900年"巴黎"香烟海报国际大赛（马格瑞特组织、科利瓦迪诺第四名）、新艺术字体输入（吉玛德式）。

### 3.3 日本（L3024–L3031）

- 佩里1853年打开国门；明治维新（1867）全面西化（福泽谕吉）；复制西方产品为基本战略；人力车（jinrikisha，1869）；1873年维也纳世博会96卷报告；**纳富介次郎**（1844—1918，金沢工业学校、香川县工艺学校，日本第一代设计教育家）。
- **版画和书籍**（L3027–L3031）：浮世绘（铃木春信、广重、歌麿、北斋）；瓦版画；福泽谕吉《西洋事情》（1866）等书籍介绍西方衣食住；看板（商店招牌）、引札（商业木刻版画）、番付（剧院海报）；1874年平版印刷启用；《太阳》杂志（1895）。

### 3.4 中国（L3033–L3039）

- **中国工业化之初**（L3035–L3036）：1793年马戛尔尼使团遭拒；鸦片战争与《南京条约》（1842）五口通商；洋务运动（1861—1895，冯桂芬、曾国藩、李鸿章、江南制造局1864—1865）；康有为与《马关条约》（1895）后的口岸工厂；**1910年南京南洋劝业会**（中国首届世博会）。
- **印刷、出版、广告**（L3038–L3039）：《申报》（1872，梅杰兄弟）、《点石斋画报》（1884—1898，吴友如）、月份牌（1888年《申报》灶君月份牌）、1873年首幅带插图报纸广告。

### 3.5 香港地区（L3041–L3042）

- 1842年成为英国殖民地；珠江三角洲外销陶瓷中心；**关伟农**（"月份牌之王"）、《南华早报》美术指导（1911）；1906年香港第一届工业艺术展。

### 3.6 奥斯曼土耳其帝国和阿拉伯世界（L3044–L3050）

- 穆罕默德·阿里（1805年夺权埃及）改革；军事现代化（蒸汽船、被服厂、毡帽厂、铸炮厂）；铁路（阿卜杜拉哈米德二世 1880s 提速）；电报。
- 本土工艺：纳尔吉尔水烟管、安那托利亚织毯业（东方织毯公司1897）。
- 东方主义展演：1867年巴黎博览会清真寺/住宅/浴室三类型；1889年巴黎"开罗街"；1863年伊斯坦布尔奥斯曼博览会（本国现代化强调）。
- **印刷、期刊和书法**（L3047–L3050）：《描述埃及》（1809起20卷）；布拉奇印刷所（1820，穆罕默德·阿里）；《政府公报》（1828）；Yaqub Sanu 漫画杂志（1877）；妇女画报；书法传统（Kadiaskar Mustafa Izzet Effendi、Sami Efendi）。

### 3.7 波斯（L3052–L3053）

- 恺加王朝（1794—1924）纳歇尔-丁国王改革；首相阿米尔·卡比尔建 Dar-al Fonoun 大学与工艺技术学校；Sani-al-Molk（1814—1866）引入平版印刷、出版周报；传统陶瓷受欧洲廉价工业品冲击。

### 3.8 参考文献（L3055–L3190）

- 文献综述（L3057）分国：拉丁美洲（贝瑟尔剑桥史、鲍尔）、日本（莫里斯-铃木、藤田晴彦论纳富介次郎）、中国（福伊尔沃克、格特、立普特）、奥斯曼（奎塔特、泽伊内普·切利克）等。

## 四、逻辑梳理

```
初步工业化地区（1750—1900）：中心—边缘格局中的"消费群落"
  ├─ 拉丁美洲：印刷/海报吸收欧洲风格（波萨达、雪茄商标）
  ├─ 日本：复制西技→快速工业化（人力车、设计教育、印刷）
  ├─ 中国：洋务运动→通商口岸→印刷广告（申报、月份牌）
  ├─ 香港：外销陶瓷与月份牌
  ├─ 奥斯曼：军事现代化 + 印刷改革 + 东方主义展演
  └─ 波斯：恺加改革 + 平版印刷
```

本章逻辑：以"消费群落"为理论透镜，说明边缘地区的设计发展受制于殖民—贸易格局，同时通过印刷、广告与博览会形成有限的现代化与本土图像语言。

## 六、论辩与阐述方法

- **中心—边缘框架**（布尔斯廷"消费群落"）：解释边缘地区工业化的不稳定性。
- **"复制—学习"战略**：日本复制西方产品（L3025）；中国"师夷长技以制夷"（L3036）——两种现代化路径对照。
- **东方主义批判**：奥斯曼在西方博览会上的"清真寺—住宅—浴室"展演与"开罗街"（L3045–L3046）。
- **印刷与民族认同**：波萨达的墨西哥大众版画、月份牌的中国图像本土化、波斯平版印刷。
