# 近现代家具：人造材料、公共器具与竹作

## 研究问题

三条各执一端——人造材料家具讲材料替代与结构转型，公共器具讲使用场合与配置，章水泉讲小竹片拼椅面——「家具在近代的变化，在六册里是被写成一条工业化的连续叙述，还是三处互不相干的片段？」

## 边界

- 只收三条：人造材料家具（`terms/renzao-cailiao-jiaju`）、公共器具（`terms/gonggong-qiju`）、章水泉（`persons/zhang-shuiquan`）。
- 不重复收板式结构：`terms/banshi-jiegou` 已以结构侧挂入 B.14.3；其材料侧（人造板、钢管、塑料替代天然木材）出自同一段来源，本 Topic 不另立条、不重复挂载，只在人造材料家具条内作证据引用。
- 不收竹编工艺体系：`procedures/zhubian-yishu-jiagong`（竹编艺术加工方法）尚未挂载，本 Topic 只取章水泉个人的拼竹做法；竹编工艺的方法与工具留待传统工艺线（B.4）或后续批次，不据本 Topic 补写。
- 不收文具本体：铅笔、钢笔、圆珠笔、橡皮、尺子、削刀、墨水只作赵农「办公用品范围」的列举，不另立 KU，也不据此判断文具是否属家具。
- 不收器物形制：办公桌椅、文件柜、沙发、折叠椅、电脑桌、影剧院座椅、屏风等只作类别列举，本 Topic 不据列补形制、尺寸或图式。
- 不收工业组织与生产体制：工厂、产量、采购与配置制度归 D 维度（D.1 洋务企业与近代工业组织、D.5 传统工艺的近代组织、展赛与政策），本 Topic 只取家具侧的材料、场合与做法。
- 不收明清器物与风格：明式、清式、三大名作归 B.14.5；红木、漆木家具、木画归 B.14.4。

## 理论支撑

- **三条对应三种判断，彼此不引**：人造材料家具判断「材料→结构→效果」的因果（材料替代导致框式转板式，导致省工轻便简洁明快），公共器具判断「场合→配置→社会化」，章水泉判断「材→拼法→风格」（小竹片拼椅面、竹枝牙拼图案，得端庄雅致）。三条无一处互相引用，也无一册同时讨论三者。
- **人造材料条是全 Theme 唯一给出「材料—结构」因果链的条目**，也是唯一写到现代技艺综合生产过程的条目（钢管圆型、方型、异型与电镀、深冲、冷弯、静电喷涂、红外烘烤）。但工艺只到工序名，无板材规格、无性能数据、无品种清单与产量；「省工、轻便、简洁明快」是效果断语而非实测比较。
- **公共器具条是全 Theme 唯一按使用场合分类家具的条目**，也是唯一列出「木材、塑料、压缩板材」这一现代材料清单与「家具社会化」这一判断的条目。分类的目的是列举而非界定：两类各有清单，但无定义式界说，无单件器具的形制，无使用人数、荷载或尺度标准。
- **章水泉是 B.14 全 Theme 唯一的人物条目，也是唯一以竹为材的家具条**。其「用小竹片拼成椅面」是全 Theme 唯一写出「拼」这一装配方式的近代条目（另一处「拼」见板式结构的人造板，属材料而非做法），但拼法的接缝、胶料、竹片规格与工序全无。
- **三条的「近代」不在同一时点**：人造材料条以「解放后」为界，公共器具条无年代、只称「现代」，章水泉条无年代、只有产地沿革（蕲州之称、韩愈诗、《群芳谱》）。三条无法排成一条时间线，只能并列为三种片段。
- **竹作与工业化两条线方向相反**：竹作以小竹片拼合维持手工与地方材料（野五里竹），工业化以人造板、钢管、塑料替代木材并求省工。六册从未把二者对照，也没有一册判断手工竹作在工业化之后的处境——「广济竹器」与「人造板家具」在来源中分属不同章节、不同叙述目的。

## 未解决问题

- 章水泉与公共器具两条都无年代：前者只有「广济，古称蕲州」的沿革与两句古诗，后者只有「现代」一词；三条无法排成时间序列，「近代家具」这一提法由此只能指三种片段而非一个时期。
- 人造材料条的材料判断无任何支撑数据：人造板五类的性能与规格、钢管型材尺寸、塑料种类、构件连接方式与板材厚度全无；「更省工、轻便」是断语，没有与之比较的对象。
- 板式结构的材料侧与结构侧出自同一段来源（田自秉 L5367），无法分开计证：结构侧挂 B.14.3、材料侧挂本 Topic，两处的证据其实是同一句，读者若分别查证会重复读到同一段。
- 公共器具条无设计者、无尺度标准、无采购与配置制度：列举了十几个场所与二十余种器具，却没有一件的形制、尺寸或使用方式；「家具社会化」只有一句判断，无对象、无年代、无规模。
- 办公文具（铅笔、钢笔、圆珠笔、橡皮、尺子、削刀、墨水）被列入「办公用品的范围」，但文具是否属家具、为何与文件柜同列，来源未界定；本 Topic 照录不裁。
- 章水泉无生卒、无师承、无作品目录、无家具尺寸与制作年代；「野五里竹」的植物学归属、竹片规格、拼合方式与图案母题全无，唯一的具体做法是「用小竹片拼成椅面，用竹枝牙拼成图案」一句。
- 竹作与工业化两条线在六册中从未被对照：既无一处判断手工竹作在 1949 年后的处境，也无一处说明人造材料家具是否取代了竹家具；本库并列而不合成。
- 本 Topic 与 B.14.3 的分工只在证据侧成立、在叙述侧不成立：来源没有把「材料」与「结构」拆成两段，本库的拆分是读法；若要追溯「框式向板式」的完整证据链，必须同时读两个 Topic。
- 来源最薄：3 条中 2 条出自同一册同一章的不同节，另一条出自另一册的现代设计章；无一条经过第二册复核，与 B.14 器物层 36 条的双册／多册结构形成反差。
