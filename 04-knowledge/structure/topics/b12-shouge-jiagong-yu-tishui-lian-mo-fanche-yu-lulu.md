# 收割、加工与提水：镰、磨、翻车与辘轳

## 研究问题

六册把收割、粮食加工与提水三件事写在同一类「器具」里，却从不说明它们之间的关系：石镰与青铜镰停在图题与出土记录，石磨盘与磨棒停在石器种类名单，石磨给出砂岩石直径约五十五厘米的唯一尺寸，翻车、辘轳、桔槔只有运转方式而无部件与传动结构。这三组器具是同一条农业技术链的三个环节，还是三组互不连通的条目？

## 边界

- 只收「庄稼收下—粮食加工—把水提上来」三组器具的 KU：石镰、青铜镰、石磨盘和磨棒、裴李岗石磨盘石磨棒、石磨、翻车（龙骨水车）、辘轳、桔槔，共八个。
- 不收耕作与播种器具：耒耜、骨耜、犁、耧等归 B.12.1；本 Topic 从收割起，不写翻土与下种。
- 不收农书：四部农书归 B.12.3。
- 不收兴修水利：都江堰、郑国渠、灵渠、西门渠是灌溉工程，归 v1.44 的 Theme B.15 或 B.3；本 Topic 只取单件提水器具，不取渠堰工程。
- 不收近代提水与加工机械：抽水机、碾米机与近代磨粉设备归 B.1 与 B.4。
- 不收磨制石器工艺：`procedures/mozhi-shiqi` 是一般石器工艺，只作石镰、石磨盘的制作前提引用，不入。
- 不收陶器与瓷器中的粮食容器：仓、囷、罐、瓮归 B.5；本 Topic 只取加工与提水器具，不取储藏器。
- 石磨与石磨盘、磨棒分立而不合并：`terms/shi-mo` 记战国出现、汉代流行的旋转石磨，`terms/shimopan-mobang` 记新石器时代的磨盘与磨棒，来源未把二者连成一条加工技术线，本 Topic 照录为两条。

## 理论支撑

- **三个环节各有各的证据形态，不能互证**：收割组（石镰、青铜镰）的证据是图题与出土地点，加工组（石磨盘与磨棒、裴李岗图版、石磨）的证据是石器种类名单与一处尺寸，提水组（翻车、辘轳、桔槔）的证据是运转方式描述。三组没有一条共同证据，把它们放在同一个 Topic 内是因为它们同属农业作业，不是因为它们构成一条技术线。
- **只有石磨一件给出尺寸**：砂岩石制、直径约 55 厘米，是全 Topic 唯一的量化数据；石镰、青铜镰、石磨盘、翻车、辘轳、桔槔都没有尺寸、重量或容量。因此「器具」在本 Topic 里首先是一个名目，其次才是可比较的形制。
- **提水器具分属三种原理**：桔槔用杠杆配重，辘轳用轮轴缠绕，翻车用链式提水。来源对三者的描述都停在动作层面（一升一落、缠绕滑动、运转灌溉），没有一处说明原件的材料、连接方式与功率，因此三者的「省力」与「提速」不可横向比较。
- **石磨的两处记载分属两章**：战国出现与汉代流行出自赵农第三章「铁器」与第四章「农具」两节，同一器物在两个章节里承担不同功能（加工方式变革／粮食加工器具）。本 Topic 不合并这两处，只并列。
- **名实不统一照录**：翻车一条的标题作「龙骨水车」而正文作「翻车」，同一器在同段两种称法并存；石磨盘（新石器）与石磨（战国以后）名称相近而器物不同，两条分立不合并。

## 未解决问题

- 三组器具之间没有过渡叙述：从收割到加工、从加工到提水，六册未写出任何一件器具的衔接方式（如收获后的干燥、脱粒、筛分），本 Topic 的分组因此是作业环节分组，不是技术链。
- 石磨盘、磨棒与石磨的关系未澄清：新石器时代的磨盘与磨棒是研磨式，战国以后石磨是旋转式，来源只分别记两处，未说明二者是否有承继关系。
- 石磨的两处记载归属不一：第三章「铁器」与第四章「农具」各记一次，前后两次的说法是否指同一批实物未说明；直径约 55 厘米只给出下扇磨身，上扇与磨眼结构无载。
- 翻车的部件与传动结构完全无载：只有「运转方式」与「灌溉效果」两句引文，链条、刮板、齿轮、踏板与出水量的信息全无；标题「龙骨水车」与正文「翻车」两种称法未统一。
- 辘轳的「产生滑动省力的效果」未给力学说明；大冶铜绿山两件战国至西汉辘轳的形制、尺寸与木构件保存状态无载。
- 桔槔的配重比例、横木长度与支点位置无载；「《墨子》中以桔槔为守城必备的战斗武器」一句与农用桔槔的关系未说明，二者是同器异用还是两种装置不明。
- 镰与铚的分工只有用途描述（铚割谷穗、镰割禾秸），二者的装柄方式、刃部角度与效率差异无载。
- 图版未核三条，均为本 Topic 唯一的视觉证据；不据图补写形制、纹样与尺寸。
- 本 Topic 无一跨册 KU，全部为单册来源，文献互证为零；提水三器仅赵农一册记载，其可靠性未由第二册确认。
