# B.8.4 史前玉器与玉礼器的起源：良渚、红山与龙山

## 研究问题

本 Topic 处理史前玉器的三段材料：良渚的玉礼器群、红山与龙山的玉器与玉材、以及介于大汶口与良渚之间的花厅墓地。

良渚一段的证据最集中。赵农记良渚文化遗址中发现钺、琮、璧等玉器重物，并给出三项象征分工：玉钺是兵权，玉琮是神器，玉璧是财富；他据此判断玉器一开始便成为政治权力和个人财富的表现，又在论礼器时引《周礼·春官》「以苍璧礼天，以黄琮礼地」，称良渚发现的玉琮、玉璧等祭祀器具「证明了这个原理」。李立新补玉琮的形制与观念：内圆外方、柱形中空，有学者指出玉琮象征天地贯通；他更把内圆解为天穹、外方解为大地，判断「天圆地方」的造物设计观念始于原始设计时期。夏燕靖 2016 给出数量与工艺：仅反山墓地就出土 1100 余件组，按单件计 3200 余件，分为仪仗的斧钺、宗教法事的琮璧、装饰的璜珠项饰佩饰手镯带钩，加工有线割、锯切、管钻、抛光，有学者判断高档玉器上可能用了砣具。

红山一段的证据最薄。田自秉记红山文化玉器多动物纹，有龙、虎、龟、鱼、鸟、蝉，其中大玉龙最为精彩，呈 C 型，长 42.2 厘米，系绿玉佩饰品；除这一句外，六册没有给出红山玉器的墓葬、组合与工艺。赵农、李立新只给「曲体玉龙」「玉雕龙」的图题，名称与田自秉的「大玉龙」不统一。

龙山与长江下游提供的是生产与流通的侧面。田自秉记山东日照两城镇和龙山文化遗址曾发现成坑的半成品玉材，其中一件玉锛厚 0.2～0.5 厘米，顶端刻着极为精细的花纹；他又记玉圭由石斧、玉璧由环状石斧、玉璋由石刀演变。北阴阳营出土玉和玛瑙制品 280 多件，璜多出于颚下、玦多出于耳旁，田自秉据出土位置判断为项饰与耳饰。花厅墓地处于大汶口与良渚交界，出土斧、钺、锛、琮、锥形器、琮形管、璜、环、珠、管、指环、耳坠等 500 余件玉器，「与良渚所产也完全相同」，李立新据此讨论交换与掠夺两种可能。

三段材料各自回答了不同的问题：良渚回答玉器被赋予什么意义，红山回答玉器做成什么形状，龙山与花厅回答玉材与成品如何流动。但没有一处同时给出器物的尺寸、玉料鉴定与出土层位，象征解释与器物记录之间因此缺少可复核的中间环节。本 Topic 追问：史前玉器从工具与装饰转为礼器的过程，究竟能由哪一类证据支撑？

## 边界

- 纳入：良渚玉钺、玉琮、玉璧的象征分工与玉琮形制；反山墓地的玉器数量与加工手段；红山文化玉器群与大玉龙；龙山文化两城镇的成坑半成品玉材与玉锛；北阴阳营的玉石玛瑙制品与璜、玦佩饰方式；花厅墓地的良渚风格玉器与交换判断；「天圆地方」观念与玉琮方圆象征。
- 排除：周代瑞玉六器、命圭与陪葬制度归 B.8.1；本 Topic 不把良渚玉琮直接等同于《周礼》六器中的黄琮，只登记来源的追溯句。
- 排除：琢玉五工序、铊子／砣机、套裁巧色与陆子冈归 B.8.2；本 Topic 只在反山加工手段处引用工序名，不重复工具定义。
- 排除：商代玉器分类、佩璜与妇好墓玉器归 B.8.5；本 Topic 止于商代以前，不把二里头与殷墟材料拉入史前线。
- 排除：巨型玉器与宫廷用玉归 B.8.3；本 Topic 不建立从史前到元清的玉器演化线。
- 排除：神人兽面纹、龙纹、鸟纹的母题意义与构图分析归 C；本 Topic 只取纹样的著录事实，不解释其宗教含义。
- 排除：玉料贸易、玉石之路与和田玉运输归 E.2；本 Topic 只取「成坑半成品玉材」「与良渚所产完全相同」两类来源判断。
- 排除：玉器在服饰中的佩戴制度归 B.2／E.5；本 Topic 只取璜、玦的出土位置作为器类判断。
- 排除：良渚、红山、龙山文化的分区、陶器与聚落归 B.5.2；本 Topic 只取三文化的玉器与玉材内容。
- 边界说明：良渚与红山、龙山不是一条连续发展线，三者各有年代与地域，六册未给三者之间的工艺传承记录；「天圆地方」是李立新的解释框架，不是良渚人的自述。

## 理论支撑

以「器物记录—象征解释—礼制追溯」三层整理史前玉器材料。器物记录层回答某件或某批玉器是什么、有多少、怎样加工（反山 3200 余件、大玉龙 42.2 厘米、玉锛 0.2～0.5 厘米、花厅 500 余件）；象征解释层回答玉器被赋予什么意义（玉钺兵权、玉琮神器、玉璧财富，琮的内圆外方象征天地）；礼制追溯层回答这些意义是否已构成制度（《周礼》苍璧礼天、黄琮礼地）。三层的证据强度依次递减：器物记录有数量与尺寸，象征解释是来源的判断，礼制追溯则把晚出的文献投射到史前器物上。

框架的第一条限度是「数量不等于组合」。反山 3200 余件是按单件计的库存，来源未给每座墓的随葬组合、器类比例与等级差异；用总数讨论「良渚社会」的玉器分配，会把墓葬群的总和当成单一社会的平均值。第二条限度是「象征不等于用途」。兵权、神器、财富是赵农的三项概括，来源未说明玉钺的装柄方式、玉琮用于何种祭祀、玉璧如何充当财富；三者是否成套使用、是否同出一墓，六册未载。第三条限度是「追溯不等于同时」。赵农引《周礼》「以苍璧礼天，以黄琮礼地」称良渚玉琮、玉璧「证明了这个原理」，但《周礼》成书晚于良渚两千余年，来源自己也说「以玉祭天地四方，是西周以下的礼仪」；本框架因此把礼制追溯当作后世的解释，不当作良渚制度的直接记录。

框架的适用限度：史前玉器的年代序列、玉料检测与墓葬分级均不在六册范围内；若后续批次出现良渚或红山的发掘报告与玉料分析，应以「器物记录」层为重写对象，象征解释与礼制追溯两层可保留为史学史材料。

## 未解决问题

- 史前玉器的年代序列未给：良渚、红山、龙山三文化的绝对年代、玉器分期与最早器物均无，六册只在考古文化层面叙述。
- 玉器从工具与装饰转为礼器的过程无中间环节：田自秉给「玉圭由石斧、玉璧由环状石斧、玉璋由石刀演变」的形制推导，但没有一件过渡器物、墓葬组合或使用痕迹。
- 玉钺、玉琮、玉璧的尺寸、玉料、纹饰、出土单位与数量全无；「兵权／神器／财富」是来源的概括，未说明三器是否成套、同出一墓或分属不同等级。
- 反山 1100 余件组、按单件 3200 余件是墓地群总数，来源未给每座墓的组合、器类比例与等级差异；「琮王」只有名称与纹样描述，无尺寸、节数与出土编号。
- 神人兽面纹的构图分层、刀法与宗教含义未给；高丰的「氏族徽记」说与李立新的「人、虎、鸟三者组合」说并存，来源未互相引证。
- 红山玉器的墓葬、组合、工艺与年代全无；大玉龙只有 C 型、42.2 厘米、绿玉佩饰品三项，出土地点、年代测定与藏地未载。
- 红山玉器的名称在六册中不统一：「大玉龙」（田自秉）、「曲体玉龙」「玉龙」（赵农图题）、「玉雕龙」（李立新图题）；这些名称是否指同一件器物，来源未说明。
- 龙山文化两城镇的玉材坑只有「成坑的半成品玉材」一句，坑口尺寸、数量、玉材种类与作坊关系全无；玉锛只有厚度，长宽、玉料与纹样细部未载。
- 北阴阳营的 280 多件玉和玛瑙制品无器类分类与各件数量；璜、玦的佩饰判断只据出土位置，无共存关系与穿戴复原。
- 花厅墓地的 500 余件玉器无逐件比对、玉料检测与工艺分析；「与良渚所产也完全相同」是来源的判断，交换与掠夺两说均无直接证据。
- 「天圆地方」的最早文献出处、观念年代序列与从玉琮到青铜器的传承环节未给；「始于原始设计时期」是李立新的判断，无器物序列支撑。
- 良渚、红山、龙山三者之间的玉器工艺传承与工匠流动无记录；本 Topic 不建立「中国史前玉器谱系」。
