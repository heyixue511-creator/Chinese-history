# 木作工艺与结构：榫卯、攒边与板式

## 研究问题

三条里，榫卯只有一句「干栏式建筑采用了榫卯结构」加一处河姆渡遗址年代，攒边是六册中唯一写出榫头—通槽装配关系的条目，板式结构只给「由传统的框式向板式结构发展」而不给节点；连接方式在这三条里是以一种做法被描述，还是以一次结构转型被描述？

## 边界

- 只收木构连接与板材结合三式：榫卯结构（干栏式建筑木构件的连接方式）、攒边（明式家具四边 45 度格角榫加芯板入通槽）、板式结构（新中国由框式向板式的结构转变）。
- 不收木构建筑本体：干栏式建筑的形制、抬梁／穿斗／井干三式、拼合梁与拼合柱归 B.3；榫卯条只取「木构件以此连接」与河姆渡遗址年代两句。
- 不收具体家具器物：椅、凳、墩、榻、屏风、几、案的形制归 B.14.1／B.14.2；明式家具的风格、用材与器类归 B.14.5。
- 不收表面装饰与镶嵌：木画、螺钿、平脱、金银绘等归 B.14.4；攒边「不露截板纹」只作工艺的视觉后果引用，不展开装饰体系。
- 不收材料名与材料史：红木、硬木树种、天然木材与人造板的品类归 B.14.4；板式结构条只取结构转变与材料前提两句，不列人造板品类。
- 不收近代家具整体线：人造材料家具（`terms/renzao-cailiao-jiaju`）、公共器具（`terms/gonggong-qiju`）、章水泉竹家具（`persons/zhang-shuiquan`）已由 v1.43 的 B.14.7 承接，本 Topic 只取板式结构这一结构侧条目。

## 理论支撑

- **三条构成连接方式的三级证据，而三级之间是跳跃的**：榫卯是一句概述（两册各一句，无类型、无部位、无工具、无工序），攒边是六册中唯一写出装配关系的条目（四边 45 度格角榫、中心板四周出榫入通槽、三项作用），板式只有结果判断（「由传统的框式向板式结构发展」）而无节点。从「一句提及」到「一段装配描述」再到「一次结构转型」，中间没有中间态：六册既不写榫卯有多少种，也不写攒边之外的其他榫法。
- **榫卯条的证据对象不是家具，而是干栏式建筑**：其唯一的建筑史判断是「奠定了未来木构架建筑的雏形，揭开了中国建筑设计的序幕」，河姆渡遗址与距今约 7000 年只由田自秉补给。把它挂进家具 Theme，依据是攒边条的「45 度格角榫」与明式家具「以榫卯结合、少用钉少用胶」同属榫卯谱系，而不是榫卯条自身的文本。这一跨越属本库取舍，在本 Topic 与 Theme 两处显式登记。
- **攒边的三项作用是本 Theme 唯一的机制性说明**：结构加固、伸缩余量、不露截板纹——它同时解释了结构、材料变形与视觉三者，也因此是「明式家具为什么不施重漆」唯一可能的工艺解释。但它只由田自秉一册给出，且三项作用各只有一句，没有金工、干燥或装配参数的支撑。
- **板式结构是结构线的终点，也是本 Theme 唯一 1949 年以后的条目**：它把结构变化直接绑定材料变化（人造板、钢管、塑料代替天然木材），并把设计效果写成「更省工、轻便」「简洁、明快」。这条同时是 B 维度（结构）与 C 维度（视觉取向）的条目；本 Topic 只取结构侧，其 C 维度留在 KU 的 `secondary_themes`。
- **三条不共享任何来源段，链是本库读法**：榫卯由夏燕靖 2016 与田自秉给出，攒边与板式都只由田自秉给出——田自秉一册同时提供了这条链的中段与末端，却从未在同一段里把「榫卯—攒边—板式」写成一条演变链，也没有把明式家具的榫卯与干栏式建筑的榫卯作比较。

## 未解决问题

- 榫卯条的证据对象是干栏式建筑而非家具，榫卯类型、构件部位、加工工具与制作步骤全无；本 Topic 靠攒边条的格角榫与明式家具的「以榫卯结合」把榫卯接进家具线，这一接法属本库取舍，来源未作此连接。
- 攒边只给装配关系与三项作用，不给榫头尺寸、通槽宽深、芯板树种与含水率、拼板与穿带做法、工具与工序次序；「攒边」是否为明式家具通例（抑或只用于桌面、柜门等板面构件）来源未说。
- 板式结构只给「框式向板式」的结果与效果，不给节点做法、连接件与板材厚度；它与人造材料家具（`terms/renzao-cailiao-jiaju`）的界线未划，本 Topic 只取结构侧；材料侧已由 B.14.4（用材）与 v1.43 的 B.14.7（人造材料家具）承接，两处仍无跨 Topic 对照。
- 三条不共享任何来源段，田自秉一册同时提供攒边与板式，却从未把二者写成一条结构演变链；「榫卯—攒边—板式」的三段线是本库读法，不是六册的叙述。
- 板式结构是本 Theme 中唯一 1949 年以后的条目，使 B.14 的结构线跨过一次断代跳跃；近代家具整体线（人造材料家具、公共器具、章水泉竹家具）已由 v1.43 的 B.14.7 承接。
- h50 登记的「唯一结构判断（梁柱式框架结构代替箱形壶门结构）不在任何器物条落地」只能部分改写：攒边给出了一种具体连接做法，但「箱形壶门结构」的形制、年代上限与被替代时点仍无，两条结构判断之间（壶门结构—框架结构—板式结构）没有过渡证据。
- 图版：无。三条均无图号、无图注、无实测图或榫卯线图。
- 三条全部为单册来源或双册来源，无一条有三册以上交叉；榫卯与攒边之间、攒边与板式之间的技术承接，只有来源未作比较的一句「以榫卯结合」可援。
