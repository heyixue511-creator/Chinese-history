# structure/topics

Topic 是五级主干的 Level 4，表达可研究、可回答的具体问题。每个 Topic 必须声明 `parent_theme`，并由不同类型 KU 通过 `topic_memberships` 以明确 role 提供材料。

当前已有 14 个 `pilot` Topic：B.1 下 2 个（机器纺织与造纸技术；造船、铁路与近代工程），B.2 下 2 个（近代纺织品与染织图案；刺绣、缂丝与服装工艺），C.1 下 2 个（月份牌与商业广告；报刊广告与机构标识），C.2 下 3 个（石印、铅印技术与出版机构；书装家群体与封面设计；书籍形态与阅读文化），D.1 下 3 个（洋务军工与造船企业；近代纺织企业与实业家；交通、电信与金融组织），D.2 下 2 个（剪辫易服与服制改革；中山装与国家礼服）。

Topic 不是 KU 的排他父目录；同一 KU 可以支持多个 Topic。王才运即以 B.2.2 为主挂载、D.2.2 为次挂载。

C.1 的两个 Topic 按媒介分工：C.1.1 承接月份牌形式、画家、英美烟草公司与《良友》画报广告；C.1.2 承接《申报》《上海新报》、书刊广告、幌子、招贴与铁路/机器局标识。两 Topic 不把同一 KU 重复计入主挂载。

C.2 的三个 Topic 按“技术／机构—作者—形态”分工：C.2.1 承接石印、铅印、铜版、照相制版与 5 家出版机构；C.2.2 承接 10 位书装家；C.2.3 承接 8 个书籍／期刊样本。三者不重复计数同一 KU。
