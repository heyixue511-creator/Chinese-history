# 卧具、屏风与承具：床榻、屏风、几案桌椅

## 研究问题

十六条里，卧具四条（架子床、拔步床、罗汉床、清式榻）构成一条以「封闭性」为轴的线，承具六条（案、几、凭几、壶门案、折叠桌、抽屉桌）却只给出用途与样式、不给形制；礼器两条（铜禁、俎）以「家具雏形」入内，陈设两条（隐囊、承尘）各只有一句定义。这些条目是以器物形制被记录，还是以用途与空间关系被记录？

## 边界

- 只收卧具、屏风、承具、储具与起居陈设五类：卧具（架子床、拔步床、罗汉床、清式榻）、屏障（屏风）、承具（案、几、凭几、壶门案、折叠桌、抽屉桌）、储具（储具一类目）、陈设与礼器（铜禁、俎、隐囊、承尘）。
- 不收坐具与坐姿：跽坐、胡床、高型家具、榻、枰、杌凳、凳墩、椅凳各条归 B.14.1；榻因「实际是一种小床」与床相邻，本 Topic 只收清式榻这类明确以卧为主的形制，汉榻与魏晋榻不重复计入。
- 不收木作工艺：榫卯、攒边、板式结构、红木、漆木家具、木画；几「由几面、腿、足座三部分以榫卯结合」一句在本 Topic 只作形制描述引用，不展开工艺。
- 不收漆器髹饰与镶嵌技法：清式榻「运用螺钿镶嵌」、屏风「铜构件镶嵌」、马王堆漆屏风的谷纹璧与龙纹云纹装饰均只作器物描述引用，漆工技法体系归 B.11。
- 不收纺织与屏风织物：夹缬屏风、宋锦、壮锦、八达晕等归 B.2／C；本 Topic 只取屏风的器物形制与空间功能。
- 不收青铜器与铸造本体：云纹铜禁（`works/yunwen-tongjin`）作为青铜冶铸例证归 B.9.2；本 Topic 只以 `terms/tongjin` 与 `terms/zu-ritual-vessel` 两条器类条表示「礼器已有家具雏形」，不并入青铜器谱系。
- 不收建筑与室内营造：应县木塔、干栏式建筑、紫禁城归 B.3；屏风「延伸到室内空间的分割」与承尘的悬挂构件只作器物功能引用，空间制度不入。
- 不收图像本体：《清明上河图》《备餐图》（山西文水北峪口元墓壁画）、图 5-40（西魏敦煌壁画）、图 6-36（唐代壶门案、腰圆凳）只作条目内证据引用，不为图像补建 KU，不据图补写形制。
- 不收风格评价与文献：《燕几图》《鲁班经》《闲情偶寄》《明式家具研究》与明式、清式风格评价留待本 Theme 后续 Topic。

## 理论支撑

- **卧具四条的轴是「封闭性」，而不是形制或尺寸**：来源把明式床的总体判断写成「在制形上趋于封闭，完全成为私密性空间」，四条由此成序——架子床以床上高架与三面床围把睡眠围起来；拔步床加上围廊、平台与踏廊，「体形巨大」「豪华富丽」，并把封闭性直接读成「明代社会心态的封闭性以及对享乐生活的追求」；罗汉床反向保留「明代以前床的开放性特征，仅三面围屏作为遮挡」，是休闲会客场所；清式榻则把榻面加大加宽到「几乎与大床相似」，使罗汉床与榻「混淆一体」，同时用五、七、九扇背屏与山字形轮廓把围合做成等级形式。这条线是四条的公共判断（且四条的「封闭—开放—再围合」并不单调），但它由赵农一册给出，无第二册交叉。
- **承具六条不给形制，只给本义、用途与样式**：案给出的是词义（「本义为木制盛食物的矮脚托盘」）与一句《考工记》引文（「案十有二寸」）加一串材料分类；几给出的是部件构成（几面、腿、足座）与三个来源互不相同的定性；凭几给出的是使用方式（扶倚分散压力）与两件实物要点；折叠桌给出的是原理（利用胡床）；抽屉桌给出的是图式（两抽屉带拉环）；壶门案只有图注。六条中唯一可称结构描述的是折叠桌的「利用胡床的原理」，而它未说明折叠构件如何做。
- **礼器两条把「雏形」当成家具史的开端，而界线未划**：俎「历史最久」，为后世桌、案、几、椅、凳「奠定基础」；铜禁「功能相当于后世的箱、橱、柜」。两条都由功能类比得出家具身份，而非由形制。二者以 `boundary_case` 挂载，是因为它们同时是祭器与家具雏形——若按功能归入家具，则青铜礼器整体都应入内；若按性质归入礼器，则家具史没有起源条。本 Topic 选择并列挂载而不裁决，界线仍空。
- **陈设两条暴露了本 Topic 的证据下限**：隐囊与承尘各只有一句到两句，且都是从别的条目（凭几、陈设一节）里带出来的功能性说明；二者都不是家具本体而是起居配置物，却被来源安排在同一个叙述段落里。它们能进入本 Topic，靠的是「与三件几配套使用」「床榻上方悬挂」这两句空间关系，不是形制。
- **屏风是唯一横跨礼制、空间与工艺三层的条目**：西周称「扆」「黼扆」并张于主人座位之后（礼制位次），汉代「屏其风也」并用来遮蔽与分隔（空间功能），春秋战国置于床后、附彩绘并镶铜构件（工艺），魏晋南北朝有完整制法与六种形态（围屏、座屏、板屏、插屏、挂屏、折屏）。三层在一册之内并列，不经分层，也不给器物尺寸；马王堆两件漆屏风是本 Topic 唯一有出土实物、有尺寸描述（长方形、下有足座承托）与装饰内容（谷纹璧、龙纹云纹）的条目。
- **「储具的使用是社会生活富裕的象征」是一句功能—社会判断，其下五类无一件实物**：橱、柜、匣、箱、箧并列且明确「五类并列、不互相替代」，但每一类都没有尺寸、出土地与图像细节；这句判断因此只由类目本身支撑，不由任何器物支撑。它与拔步床的「社会心态」判断属同一类推理：由器物存在推出社会状态，中间无材料。
- **本 Topic 全无尺寸**：十六条无一条给出可换算的尺度（马王堆漆屏风只到「长方形」「下有足座承托」，凭几只到「几面扁平」「高矮两对足」）。这与 B.14.1 只有一处推测尺度相比更薄；两 Topic 合计三十余条，可用的尺度只有汉榻一条。家具史的量化基础在本 Theme 范围内基本为零。

## 文献支撑

## 未解决问题

- 全 Topic 十六条无一处尺寸、无一件完整实测器物：架子床、拔步床、罗汉床、清式榻均无构件名称与尺度；案、几、凭几只有部件构成；壶门案与腰圆凳、长方凳同属图注条目。家具形制的可比基础在本 Topic 内为零。
- 卧具四条全部单册（赵农 2009），「封闭性」这条轴无第二册交叉；拔步床的「社会心态」判断由器物直推社会状态，中间无材料，本 Topic 只登记不采信。
- 罗汉床与清式榻的界线来源自己已宣告混淆：「榻面加大加宽，几乎与大床相似，罗汉床与榻混淆一体」；本 Topic 按来源分两条挂载，但二者在形制上是否可分立，来源未裁定。
- 承具的功能分化（案→书案、平头案；几→凭几；桌→方桌、长方桌、折叠桌、抽屉桌）只在名词层面成立，来源未给任何一条分化路径的实物序列或年代序列。
- 案的本义（矮脚托盘）与后期长形承具（书案、平头案）之间如何过渡，来源只有「后演变为」三字；《考工记》「案十有二寸」的单位与所指（长度？高度？）未说明，照录不裁。
- 几的三种定性并存：夏燕靖两版以凭几为核心（横跗单足、栅形直足两式），赵农以「放置东西或者可以倚伏在上面」为主并强调战国墓出土较多、多带漆绘，2016 册以《说文》《周礼》界定几、案、桌、俎的差别。三套定性未合并，本 Topic 并列。
- 铜禁与俎的「家具雏形」身份未划界：若按功能类比，青铜礼器整体皆可入家具史；若按性质，家具史失去起源条。本 Topic 以 `boundary_case` 挂载，界线仍空，须后续显式裁决。
- 隐囊与承尘各只有一句到两句证据，是否应留在家具 Theme 内属本库取舍：二者是织物靠垫与悬挂席板，既非木作也非承具，仅因空间配置关系而入。
- 储具为类目条，五个子类（橱柜匣箱箧）并列而无一件实物、无尺寸、无出土地；「储具的使用是社会生活富裕的象征」这句话的证据基础未给。
- 壶门案与抽屉桌为 low：「壶门」的轮廓、做法与流行年代在本 Topic 内无解释（仅 B.14.1 的枰条提到「足间呈壶门形」）；抽屉桌的抽屉与拉环做法只见壁画图式，无实物。
- 图像证据全部未核：图 5-40（西魏敦煌壁画）、图 6-36（唐代壶门案、腰圆凳）、图 8-57 一类元墓壁画《备餐图》、《清明上河图》虹桥段、马王堆漆屏风图版，本 Topic 不据图补写形制、纹样与尺寸。
- 屏风的两件马王堆漆屏风同时是漆器条目（`simajinlong-mu-qi-pingfeng` 等）与家具条目，漆器侧归 B.11、家具侧在本 Topic，二者不互相替代；相关 KU 的「相关知识元」另有一处误称（见存量债务）。
- 与本 Topic 相邻而落在边界外的三组：坐具与坐姿（B.14.1）、木作工艺（榫卯、攒边、板式结构、红木、漆木家具、木画）、风格与文献（明式、清式、三大名作、《燕几图》《鲁班经》《明式家具研究》《闲情偶寄》）。
