# 耕作与播种：从耒耜到曲辕犁

## 研究问题

六册把耕作与播种写成一条从耒耜、骨耜、石犁、青铜犁铧到犁壁、曲辕犁、铁搭、踏犁的器形序列，又把耦犁的二牛三人、三脚耧的一次三行、踏犁的脚踏记为三次操作组织变化；但序列里只有三脚耧一句效率判断、良渚石犁一处明确争议，其余各条都没有尺寸、装柄方式与作业效率。这条序列是农具形制的连续改进，还是赵农一册的叙述顺序？

## 边界

- 只收「把土地翻开、把种子播下」两个作业环节的 KU：耒耜、骨耜、神农氏、刀耕火种、良渚石犁、装柄石铲复原图、青铜犁铧、犁壁、犁刀、曲辕犁、耦犁、赵过、三脚耧、铁制农具、青铜锄、铁搭、踏犁与原始农具，共十八个。
- 不收收割与加工器具：石镰、青铜镰、石磨盘与磨棒、石磨归 B.12.2；本 Topic 只到播种为止，不写收获与粮食加工。
- 不收提水器具：翻车、辘轳、桔槔归 B.12.2；翻车虽属农具，作业对象是水而非土，不并入耕作线。
- 不收农书：四部农书归 B.12.3；本 Topic 只据农书引用王桢《农书》「兼有耙镢之效」一句，不展开文献面。
- 不收兴修水利：都江堰、郑国渠、灵渠、西门渠是灌溉工程，归 v1.44 的 Theme B.15 或 B.3，不入本 Topic。
- 不收冶铁工序：生铁冶铸、柔化、炒钢、百炼钢、灌钢归 B.9.7；铁制农具与铁搭只取器形与使用效果，不重复工序。
- 不收农政与礼俗：赵过以搜粟都尉推行耦犁耧车的官职与推广组织、井田制、男耕女织、先农坛归 D 维度；本 Topic 只把赵过作为农具设计主体挂载。
- 不收一般石器工艺：`procedures/mozhi-shiqi` 是石器制造工艺而非农具，只作石铲、石犁的技术前提引用，不入。

## 理论支撑

- **按作业环节而不按材料排**：本 Topic 的十八条都落在「翻土—开沟—下种」这一环节内，材料（石、骨、青铜、铁）是各条的属性而不是分组依据。若按材料排成石—骨—青铜—铁四段，骨耜（骨）会排到石犁（石）之后，而来源叙述的顺序恰好相反；因此本 Topic 的次序只表示作业环节内的条目顺序，不表示技术演化。
- **形制层与操作组织层是两套证据**：形制层（耒耜的耜冠捆绑、犁壁的翻土、曲辕犁四部件重组、铁搭的四齿六齿、踏犁的横木）的证据是部件名加功能句；操作组织层（耦犁二牛三人、三脚耧一次三行、踏犁脚踏）的证据是分工描述。两层不互相推导：曲辕犁「一牛耕犁取代二牛抬杠」是形制变化带来的操作变化，这一句是例外，其余各条都不说明形制与人力、畜力配置的对应关系。
- **全 Topic 只有一个效率判断**：三脚耧把开沟、下种、覆盖三道工序合并于一机，来源据此称其为「现代播种机的雏形」。除此之外没有任何一件农具给出效率、工时或对比数据；犁壁「提高了耕作效率」、铁制农具「廉价高效」都是无数据的形容。
- **争议与断言并存而不是分级**：良渚石犁一条既有「我国最早实现犁耕的地区」又有「学界尚有争议」，两句在同一 KU 内并列，本 Topic 不裁；青铜犁铧、青铜锄、青铜镰各只有一句或一件，却与有多次出土的骨耜、石犁并列在同一张表里。表的并列关系不等于证据等级相同。
- **人物与器物分开记**：神农氏是传说的发明者，赵过是有官职可考的设计与推行者；二者都以 `key_person` 挂载，但神农氏一条只有文献转引（confidence 为 low），赵过一条的核心是三册分工差别而非生平。

## 未解决问题

- 材料线是断语：良渚石犁是否用于犁耕学界有争议；商代青铜犁铧只有一句且无器形、尺寸与出土地；西周青铜锄只有湖北蕲春一件、青铜镰只有江苏仪征一件；铁制农具的推广只有种类名单而无分布与数量。「石—骨—青铜—铁」的递进由六册的叙述语序支持，不由器物证据支持。
- 耒耜与骨耜的关系未澄清：赵农写耒「最初是木棍—改进为双齿—耜冠与木棍捆绑—成板状刃具」是一条自制器形演变，河姆渡 170 余件骨耜只作数量证据，二者未在同一段对读。
- 所有耕犁条目都缺尺寸与结构参数：曲辕犁的辕、箭、梢、底只有组合方式与效果，无尺寸、重量与材料配比；耦犁无犁体结构与铁犁铧形制；犁壁的「形式多样」未列举形式。来源明言不据图补写。
- 犁刀与曲辕犁的关系未说明：两处都提到江东犁的结构改进，但犁刀出现于宋代、曲辕犁定型于唐代，二者是同一次改进的两个方面还是两次，来源未交代。
- 三脚耧的构造只到「三道工序合并于一机」：无斗容、耧脚间距、下种量调节方式与牵引方式；「现代播种机的雏形」是类比而非技术比较。
- 赵过的两说分工未裁：夏燕靖两版作三脚耧设计者，赵农作耧车与耦犁推行者；「代田法」在六册中一次也未出现，而通行农史叙述通常把它与赵过并称，该缺口不能由本 Topic 补足。
- 神农氏一条只有文献转引（confidence 为 low），「斲木为耜，揉木为耒」的归属在神农氏与耒耜两条中重复出现，两处引文一致但承担的解释不同。
- 铁搭的「四齿和六齿」是两种规格还是同一器的两面未说明；踏犁「原为石器时期耒耜样式的流传」只有一句判断，无中间环节。
- 耕作与农政的分界：赵过的官职、推广组织与代田法归 D 维度与另行评估，本 Topic 未物化该线，两处交叉仍无落点。
