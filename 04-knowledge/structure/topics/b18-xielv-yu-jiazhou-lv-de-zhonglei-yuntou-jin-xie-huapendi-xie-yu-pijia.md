# 鞋履与甲胄：履的种类、云头锦鞋、花盆底鞋与皮甲

## 研究问题

四条分处汉（舄、屦、屐按用途三分）、唐（云头锦鞋的晕絰彩条里衬）、清（旗女高木底鞋的绸缎绣花与镶珠宝）与春秋战国（皮甲的合甲、七札与甲札串联），只有汉代那一条按用途写、其余三条全按材料与工艺写，且四条无一给尺寸——足服与护具在六册里是按用途分的一条线，还是按材料与工艺分的一条线？

## 边界

- 只收四条：履的种类、云头锦鞋、花盆底鞋、皮甲。
- **皮甲归本 Topic 而不归 B.9.6，是本批的判断**：Theme B.9「青铜与金属」的主题边界以材质为名，B.9.6「兵器与甲胄」已收汉代铠甲、明光铠、筒袖铠三种金属铠甲与造甲工序；皮甲以皮革合制、以皮条串联，材质不属金属，且 Theme B.18 的标题「冕服、深衣、袍衫、裙制与甲胄」本就以甲胄为一项，皮甲是其中唯一在库的甲胄条目。B.9.6 的边界「甲胄与服饰等级的关系归服饰 Topic」是同向的处置。
- 不收金属铠甲与造甲工序：汉代铠甲、明光铠、筒袖铠、造甲归 B.9.6；本条只以皮甲的制革与串联与它们对照，不据皮甲条回填铁甲结构。
- 本条不把「甲胄与服饰等级的关系」当作主题：两裆衫「形制缘起于铠甲」归 B.18.3，本条只在皮甲条的串联方式上与它相互对照，不重复挂载。
- 不收衣装本体：深衣、袍服、圆领袍衫、襦、袄、比甲归 B.18.2 与 B.18.3；花盆底鞋条同段所及的旗女服饰整体形制不展开。
- 不收首服与妆饰：幅巾、幞头、顾姑冠、假髻、佛妆、帔子归 B.18.5；花盆底鞋条同段的旗女发式与妆饰不收。
- 不收缠足史与身体改装：弓鞋与汉族缠足对旗女的影响只作背景照录，身体改装归 E.6，制度与习俗问题归 D。
- 不收织造工艺本体：晕絰的色条组织与锦的织法归 B.2 与相关工艺 Theme；云头锦鞋只取「里衬用蓝、绿、浅红彩条晕絰锦」这一句用料记载。
- 不收图版本体：图 9-21（花盆底鞋）、图 3-6 与图 3-7（铜戈，非皮甲图）均未视觉核验，不据图补写鞋式与甲式。

## 理论支撑

- **四条按「用途」与「材料工艺」分成两种写法，而用途写法只有汉代一条**：履的种类以用途三分——祭祀（舄）、家居（屦）、雨天践泥（屐）——是六册中唯一以场合为分类标准的足服记载；其余三条都按材料与工艺写：云头锦鞋给里衬用料（蓝、绿、浅红彩条晕絰锦），花盆底鞋给底形与饰（前圆后方的马蹄底、内弧线、绸缎绣花与镶珠宝），皮甲给制革与串联（合甲层数、切皮成片、皮条按身体部位串联）。因此「足服与护具是否成序列」的答案在本 Topic 内是：能成一条材料工艺线，不能成一条用途线——用途线只有起点一条。
- **尺寸在四条中全缺，可数的只有层数**：皮甲的「七甲／七札」是唯一数量，且属传说（「传说秦穆公穿的就是七甲」）；履的三种无尺寸，云头锦鞋无鞋长，花盆底鞋无木底高度。四条中唯一被给出的度是「数层」与「最多七甲」，其余全是定性的「高」「小片」「彩条」。
- **皮甲与两裆衫共用「连缀」一词，是衣裳与甲胄的第二处连接**：B.18.3 已记两裆衫「前后为两片布衣，在肩部用布带连缀，形制缘起于铠甲」，本条的皮甲作「将牛皮切割成小片，然后用皮条串联起来……其连缀方法与竹简书札相似」。两处都以「连缀」述结构，且都按身体部位配置——这是 Theme 原先只记「形制缘起于铠甲」一句之外的另一处可对照点；但两册分属不同作者与不同章节，来源从未互引，本库只并列不合并。
- **名与物在两条上都不对等**：花盆底鞋的「马蹄底」与「花盆底」是同一双鞋的两个说法（前圆后方／侧面内弧线），来源自己给出两个名称；云头锦鞋的「云头」是名称所指，来源未释义鞋头结构。两处都说明本 Topic 的名目不能当形制描述读。
- **工艺层的证据密度高于形制层**：皮甲一条给出合甲、切皮、串联、甲札、彩绘铜饰、产地之别与马甲实物，是四条中信息最厚的一条（`confidence: medium`）；而三条足服条目全部 `confidence: low`，其中履的种类只有一句。足服的形制知识在六册中比护具更薄。

## 文献支撑

- 赵农《中国艺术设计史》（2009）L3063：汉代鞋履三分（舄为祭祀用鞋、屦为家居用鞋、屐为雨天践泥的木制鞋）；同段亦为 B.18.2 禅衣条的出处，本条只取履的种类一句。
- 赵农《中国艺术设计史》（2009）L1884-L1886：皮甲的合甲与七甲七札、切皮成片与皮条串联、甲札、彩绘铜饰、吴甲楚甲之地别、战国马甲与曾侯乙墓马甲实物。原文在「兵器」一目之下，与戈、矛、戟、殳、弩同段，本条按材质与 Theme 边界取用。
- 田自秉《中国工艺美术史（修订本）》（2010）L3220：阿斯塔那出土一双云头锦鞋，里衬用蓝、绿、浅红彩条晕絰锦；同段即晕絰提花锦裙的出处，两件同出一地。
- 夏燕靖《中国艺术设计史（升级版）》（2016）L4308：清代旗女天足、高木底鞋、前圆后方为马蹄底、侧面内弧线又称花盆底、绸缎面绣花纹并镶珠宝，以及汉族缠足弓鞋对旗女的影响；图 9-21 未核。

## 未解决问题

- 用途分类只有一条且只有一句：舄、屦、屐三分的分类标准是服用场合，但三条的形制、尺寸、材质（仅屐明言木制）与等级规定全缺；汉代以后鞋履如何分类，六册不载。
- 尺寸全线缺失：无鞋长、鞋宽、底高、鞋头高度，也无甲片尺寸与甲片数量；唯一数量「最多七甲」是皮革层数，且与「七札」是否为同一制度来源未说明。
- 皮甲与金属铠甲的关系未裁：皮甲（赵农「兵器」段）与汉代铠甲、明光铠、筒袖铠（B.9.6）分处两个 Theme，六册从未把皮革甲与铁甲并列比较；合甲层数与铁甲甲片的差异、两种甲的时代接替均无记载。本 Topic 的处置依据是 Theme B.9 的材质边界与本 Theme 的甲胄项，属结构判断而非来源结论。
- 「七甲」与「七札」是否同指未裁：来源作「最多时可以有七甲」「传说秦穆公穿的就是七甲，亦称七札」，先言层数、后言札数，两个计量对象的单位不同，来源未调和。
- 云头锦鞋只说得出里衬：鞋长、鞋宽、鞋头结构与鞋面鞋底材料全缺，「云头」的鞋头云形是据名理解而非记载；它与同出的晕絰提花锦裙共用一种织锦，但两件的关系（同墓、同批、同工）来源未述。
- 花盆底鞋的两名同物需靠来源自证：「前圆后方为马蹄底」与「侧面为内弧线，又称花盆底」是同一双鞋的底面与侧面两种描述，来源未明说二者同物，本库按上下文并列；若他书以此为两种鞋式，本条的合并需重估。
- 足服与护具之间无一条连接：四条中各说各的，履的种类不讲甲、皮甲不讲鞋；Theme 层能连起来的只有「连缀」一词（皮甲与两裆衫），足服一侧完全没有对应。
- 图版未核且不对题：花盆底鞋的图 9-21 未核；皮甲条所引图 3-6、图 3-7 是铜戈图而非皮甲图，不能作甲式证据；履的种类与云头锦鞋无图。
- 断代不连续：四条各占春秋战国、汉、唐、清一段，秦汉之间、魏晋至明四段零覆盖，无法排出足服的连续序列。
- 覆盖最薄且低置信：三条来源、四条全为单册，低置信 3/4；本库只记「本批未见」，不记「原书未载」。B.18 六个 Topic 中本 Topic 的证据强度最低。
