# 家具用材与装饰：红木、漆木与木画镶嵌

## 研究问题

四条里，红木是「明清以来对稀有硬木的统称」而非某一树种，漆木家具是以「木为胎、髹漆为饰」定义的类别并带着全 Theme 最集中的尺寸，木画是以染色象牙、鹿角、黄杨木镶嵌的唐代工艺，木画棋局是它唯一的具体实例；家具是以材料被人认识，还是以装饰被人认识？

## 边界

- 只收用材名、以材料定义的家具类别与镶嵌装饰工艺：红木（明清硬木统称与当代复原义）、漆木家具（春秋战国以木为胎、髹漆为饰的几案床箱屏风）、木画（唐代染色象牙、鹿角、黄杨木镶嵌工艺）、唐代木画棋局（日本正仓院藏实例）。
- 不收结构与连接工艺：榫卯、攒边、板式结构归 B.14.3；漆木家具条中「由三块木板榫接而成」「中间用格带加固」只作器物描述引用，不展开做法。
- 不收漆器技法体系：描金、戗金、雕漆、螺钿、金银平脱、密陀僧绘、夹缬、蜡缬归 B.11；本 Topic 只取家具表面装饰与家具品类的关系，漆器产品条不入。
- 不收器物形制谱系：几、案、床、屏风的形制与起居关系归 B.14.1／B.14.2；漆木家具条中的信阳长台关漆木床、江陵望山漆座屏、曾侯乙彩绘漆几与漆案、平山方案与屏风只作该条的品种、尺寸与工艺证据，不另立器物条。
- 不收风格与流派：明式、清式、三大名作归 B.14.5；红木条中「20 世纪末期重新出现的传统家具时尚」只作材料名的当代义，不作风格判断。
- 不收文献：《燕几图》《鲁班经》《明式家具研究》《闲情偶寄》归 B.14.6。
- 不收纺织织物与夹缬屏风：宋锦、壮锦、八达晕、夹缬屏风归 B.2／C。

## 理论支撑

- **两条不同粒度地用材料定义家具**：一条是材料名（红木，明清以来对稀有硬木的统称，来源明言「从一开始就不是某一特定树种」），一条是材料加工艺的类别（漆木家具，「以木为胎、髹漆为饰」，且「装饰上完全采用漆器的装饰手法」）。两者都不是形制分类：红木可以做成任何器形，漆木家具可以包含几、案、床、箱、屏风五类。材料与工艺在这里承担了分类功能，形制反而不承担。
- **漆木家具是本 Theme 唯一尺寸密集的条目**：三条尺寸（床 218×139×44、方案 47.5×36.2、屏风 224×90 厘米）与一组构件细节（铜合页限位 86 度、屏座插榫、格带加固）同时成立。这与 B.14.1／B.14.2 三十余条只有一处推测尺度形成反差——反差不是来源的进步，而是高丰这条把「家具种类」写成了「考古器物著录」，赵农一系的器物条则写成形制与风格评语。
- **木画与红木分别代表装饰与用材的两端**：木画的用材（染色象牙、鹿角、黄杨木）是嵌片而非家具本体，其功能是表面纹样；红木的材性与纹理则直接构成家具的可见面（不施重漆）。前者以加法装饰，后者以减法显露，两条合起来说明同一件事——六册对家具表面的解释，几乎全部落在材料上，而非落在工艺步骤上。
- **木画棋局是本 Theme 唯一「装饰—机构」合写的实例**：木画纹样（雉、雁、狮、象、鹿、胡人牵驼）与联动抽屉（一方开启则另一方同时打开、屉内龟形盒）在同一段内并列，且是少数被来源直接评为「构思巧妙」的条目。它同时是唐代娱乐家具的形态证据（「棋局和双六局，是唐代流行的一种娱乐用的家具」）。
- **红木条的两种指义未合并**：明清义是硬木统称（夏燕靖 2016），当代义是 20 世纪末重新出现的传统家具时尚与实木消费（赵农）。两义在同一 KU 内并列，本 Topic 不合并、不评判哪一义为正。

## 未解决问题

- 漆木家具三条尺寸的出处与测量方式未注；「平山方案与屏风是否同墓所出」来源只作「在同一个墓地」，未给墓号；箱类只列名，无实例、无尺寸。
- 漆木家具的胎体做法（斫制、卷制或榫接的具体方式）与榫卯类型未载，「曾侯乙彩绘漆几由三块木板榫接而成」是全条唯一一句工艺描述。
- 木画只给定义、三类用材与两件正仓院实例，不给工序、胶料、嵌片厚度、产地与匠人；「唐代创造」的判断无年代证据，也无唐以前同类工艺的对照。
- 木画棋局无尺寸、无木质、无棋盘道数、无抽屉数目、无入藏经过；「中有机关」的机构原理未述。
- 红木的树种清单、物理性能与产地全无；明清义与当代义是否指同一批材料未裁；「性脆、味酸」与「细腻近紫檀」在同一段内并列而未见树种区分。
- 图版未核：图 3-28（战国漆案，湖北随县曾侯乙墓出土）、图 3-29（战国错金银青铜龙凤案，河北平山出土）；木画与木画棋局无图号。
- 与 B.11 的分工：漆木家具同时是漆器产品条（`terms/qi-erbei`、`terms/qi-jiuju-baozhuang-he` 同批建档），髹饰技法归 B.11，家具类别与尺寸归本 Topic，二者不互相替代；本 Topic 不据漆器工艺流程补写家具胎体。
- 「以材料定义家具」这条线只有红木与漆木家具两条支撑，硬木与柴木之分、楠木樟木榆木榉木等柴木类目均未建档，材料谱系仍不完整。
