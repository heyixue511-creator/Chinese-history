# B.3 近代建筑、室内与建造技术

## 核心问题

1840–1949 年间，钢筋混凝土、钢架、砖石承重与新型建材如何进入通商口岸建筑，外来式建筑与中国固有式建筑又如何组织立面、内部空间与纪念性？本 Theme 关注“空间如何被建造与装饰”的造物侧变化，不把城市制度、建筑教育或规划管理作为主问题。

## 边界

- 纳入：上海砖瓦锯木厂所代表的近代建材工业，上海汇丰银行与沙逊大厦所代表的外来式商业建筑，中山陵所代表的纪念建筑，吕彦直、梁思成所代表的建筑师与建筑史研究，中国固有式建筑术语，以及《中国建筑史》所代表的建筑史书写。
- 排除：上海、南京、广州等通商口岸城市史，中国营造学社、朱启钤、盖茨公司与上海市市中心区域规划，归后续 D 维度城市与建筑制度 Theme。
- 排除：外来式建筑术语本身主维度为 E，待 E 类 Theme materialize 后再挂载；本 Theme 只通过汇丰银行、沙逊大厦两个 B 维度器物条目观察外来式建筑。
- 排除：1949 年后的人民大会堂、北京十大建筑、国徽设计与 1961 年《建筑和建筑艺术》主张；梁思成条目中的抗战时期建筑史研究是本 Theme 的锚点，1949 年后内容只作边界说明。
- 排除：斗拱、紫禁城、苏州园林、明式家具等古代建筑与室内条目；它们属于前近代营造谱系，不并入近代建筑转型。
- 与 D 维度城市与建筑制度 Theme 的分工：B.3 解释材料、结构、立面、内部空间与纪念性如何形成；D 维度解释城市制度、职业机构、规划与装饰业如何组织。两者互为 `secondary_themes`，不合并、不重复计数。

## 支撑结构

- 理论支撑：以“材料/结构—立面/风格—内部空间/纪念性”三层分析近代建筑，避免把“外来式/中国固有式”简化为西化与复古的二元对立。
- 实证/材料支撑：8 个 KU，覆盖 institution、person、work、term、publication 五类；通商口岸建筑与室内 3 个，民族形式与纪念建筑 5 个。
- 文献支撑：夏燕靖 2009/2016 的近代建筑与室内设计章节、赵农 2009 的近代建筑与建筑师章节；具体行号见各 KU 的 `sources`。

## 未解决问题

- 建筑图版、外滩建筑群照片与中山陵竞图图纸均未视觉核验；沙逊大厦“锥字体屋顶”疑为“锥形”之讹，照录存疑。
- 中山陵的征图年份（1927）与赵农所记设计年份（1929）不相合，钟形平面的“木铎警世”与“晨钟暮鼓”两种释义并存；本 Theme 不代为排定年表。
- 盖茨公司、亚平艺术装饰公司、上海市市中心区域规划等 D 维度材料尚未挂载，室内装饰业与规划制度的关系留待后续 Theme。
- 外来式建筑术语主维度为 E，E 类 Theme 尚未 materialize；本 Theme 不越权挂载。
- 1949 年后的建筑与室内发展不在本 Theme 范围。
