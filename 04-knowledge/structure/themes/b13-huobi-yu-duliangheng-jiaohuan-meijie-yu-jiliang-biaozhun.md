# B.13 货币与度量衡：交换媒介与计量标准

## 核心问题

本 Theme 十条规定了一个共同问题：**一件标准物靠什么取得可信度**。纸币的可信度写在票面上——金代交钞「外为阑，作花纹」，左书「某字料」、右书「某字号」，外加篆书「伪造交钞者斩，告捕者赏钱三百贯」；元代纸币以丝为本、后改银本位，长方形、制型较大、蒙汉两文并书。银元的可信度写在重量与统一性上——龙洋「重 7 钱 2 分，与流行的墨西哥鹰洋的重量一致，也可互为通用」，袁大头「质量稳定，币型统一，便于交易」，而钱商打戳会把银圆变成「烂板」。度量衡的可信度写在诏书上——秦始皇廿六年诏「法度量则不壹歉疑者，皆明壹之」被刻在各种衡器与量器上，「近年山东出土的秦陶量，上面就有诏书」；秤器则靠杠杆原理本身，长沙楚墓出土春秋等臂秤具实物。

第二个问题是**这本 Theme 完全出自一册**。十条中十条全部来自赵农 2009，高丰、夏燕靖两版、田自秉与李立新对货币与度量衡均无关联条目。也就是说，货币与度量衡在六册中不是共同对象，而是赵农一册的叙述对象；本版不据此判定其余五册「漏收」，只把单册覆盖登记为结构事实。这在本库此前的 Theme 中尚无先例——此前最偏的 B.12 也是 21/30，本 Theme 是 10/10。

第三个问题是**器物面与制度面在来源中从未分开**。交钞的发行机构、面额序列、印版尺寸全无；元代各钞的发行年份与印版尺寸全无；大清银币的宣统年份、版别、重量、成色、铸造局全无；袁大头的重量、成色、版别、铸造局、设计者全无；秦量的单件容量实测与尺寸全无；秦权的单件尺寸与铭文全无；商鞅方升的尺寸、容积、铭文字数与现藏全无。十条之中只有两处量化：龙洋「重 7 钱 2 分」与秦制换算「一尺相当于今 23 厘米，一斤相当于今 250 克，一升相当于今 200 毫克」（末项原文疑为毫升）。因此本 Theme 能回答的不是「标准物怎样被设计」，而是「六册在什么层面把标准物写清楚了」。

## 边界

- 纳入：货币六条（金代交钞、元代纸币、大清银币、墨西哥鹰洋、袁大头、人民币）与度量衡四条（商鞅方升、秦量、秦权、权衡秤器），共十条。
- 排除：杠杆（`terms/lever`）与滑轮（`terms/pulley`）是力学原理与起重器具，不是计量标准；二者的概念雏形只在本 Theme 作参照引用，主归属留待简单机械线。
- 排除：铸币与铸造工艺——合范、浑铸、分铸、失蜡、叠铸、铁范与六齐归 B.9.2 与 B.9.7；本 Theme 只取币面形制与流通事实，不重复工序。
- 排除：铜镜（B.9.3）与青铜容器（B.9.1），虽同属铜器但不属交换或计量器具。
- 排除：货币制度、金融史与财政政策——纸币的发行机构、通货膨胀的成因、币制改革的制度史归 D 维度；本 Theme 只取票面、重量、诏书与器物。
- 排除：农具与工具——翻车、辘轳、桔槔、犁锄等归 B.12；桔槔与秤同用杠杆原理，但对象是提水而非计量。
- 排除：票证、证券与邮票等近现代印刷品，归 C 维度；本 Theme 不收非货币的印刷凭证。
- 排除：近代机器制造与交通工具（自行车、人力车、汽车、磁悬浮、神舟五号）虽同在赵农册第十章，与本 Theme 无共同问题，不入。

## 支撑结构

- 理论支撑：以「器物形制—量化数据—可信度装置—制度叙述」四层读标准物。器物形制层（交钞的阑与花纹、元代纸币的长方形与蒙汉两文、袁大头的头像、秦量的铜陶两类容量序列）有描述而无实测；量化数据层只有两处（龙洋 7 钱 2 分、秦制三项换算）；可信度装置层是本 Theme 最厚的一层（伪造者斩的篆书、印押、重量一致可通用、质量稳定币型统一、廿六年诏书刻于器上、杠杆原理与等臂秤实物）；制度叙述层全部停在名称（交钞库、丝本位、银本位、铜辅币、铸币与纸币两种形式、诏丞相状绾）。四层不互相支撑：有可信度装置的条目没有尺寸，有尺寸的条目没有器物描述。
- 实证/材料支撑：两个 Topic 合计主挂载 10 个 KU（term 6、work 4），无次挂载；role 分布为 `term_anchor` 6、`representative_work` 3、`boundary_case` 1。B.13.1 六条、B.13.2 四条。全部为单册来源（赵农 2009），无一条跨两册及以上；confidence 为 medium 8、low 2；consensus 全部 tentative。
- 文献支撑：赵农《中国艺术设计史》（2009）是本 Theme 的唯一来源。其第三章「工具」提供权衡秤器与秦量秦权，第四章提供商鞅方升，第八章提供金代交钞与元代纸币，第十章提供大清银币、鹰洋、袁大头与人民币。高丰 2004、夏燕靖 2009、田自秉 2010、李立新 2011、夏燕靖 2016 对本 Theme 十条均无关联条目；一手文献（《金史·食货志》《元史·食货志》《史记·秦始皇本纪》《战国策·秦策》《墨子·墨经》）全部经赵农转引，原本未见。

## 未解决问题

- 本 Theme 十条全部来自赵农一册，其余五册零覆盖：货币与度量衡在六册中是赵农的叙述对象而非共同对象，该结构事实使本 Theme 的结论无法由第二册交叉确认。
- 全部条目缺核心参数：纸币无印版尺寸、面额序列与印造机构；银元无重量、成色、版别、铸造局与设计者（龙洋的 7 钱 2 分是唯一重量）；秦量无单件容量实测，秦权无单件尺寸与铭文，商鞅方升无尺寸、容积、铭文字数与现藏。
- 交钞与元代纸币的形制描述全部来自《金史》《元史》摘引，未见实物，也未给钞版或票面摹本；来源自己在证据边界中说明不据引文复原票面版式。
- 元代纸币的本位两说并存：初以丝为本（《元史》「每银五十两易丝钞一千两」），后改以白银为本位，两种本位之间的转换时点未载。
- 交钞的七年期限与无限期拖延只有一句制度叙述，票面上的期限标记是否存在、格式如何，来源未载。
- 墨西哥鹰洋只作龙洋重量的比较对象出现，成色、版别、铸造年代与流入数量全无；其在中外贸易中的角色归 D 维度且未物化。
- 秦量的铜量与陶量对应关系未说明（铜量为 1/2、1/3、1/4 斗，陶量为半斗、一斗、一斛），两套容量序列是否同一进位系统未载。
- 权衡秤器的「铢秤」只有名称与「后来发展成」一句，形制、年代与使用方法全无；等臂秤与不等臂杆秤的关系未说明。
- 杠杆与滑轮两条落在本 Theme 之外：二者的原理与权衡概念相连，但作为力学原理与起重器具不属于计量标准；简单机械线已由 v1.45 的 Theme B.16 承接（杠杆、滑轮主挂 B.16.1），本 Theme 不重复挂载。
- 制度面全部未物化：交钞库、印造机构、铸造局、币制改革与统一度量衡的行政执行均归 D 维度，D 维度前近代线目前只有 D.6 官府手工业六点，货币与计量制度不在其中。
