# B.14 家具与起居方式：坐卧具、屏风与承具

## 核心问题

本 Theme 五十三条围绕一个共同问题：**家具的高度变化是器物史，还是起居方式史**。六册的家具叙述几乎都以坐姿改变为轴：汉代「尚无椅、凳，人们只是席地而坐」，汉代后期胡床自北方传入，「很像后世的交椅」；隋唐「椅子的出现」被称为最重要的现象，「广泛使用改变了中华民族的生活习惯」；宋代家具「属高型家具，并且这类家具在民间得到普及使用」，其结构判断是「以梁柱式的框架结构代替了以前的箱形壶门结构，而成为家具结构的主体」。器物层的条目（椅、凳、墩、榻、屏风、几案）则几乎不提结构，只写部件名与使用感受。因此本 Theme 要读的不是一条从矮到高的进化线，而是「坐姿叙述」与「器物叙述」两个层面如何在同一批条目里彼此脱节。

第二个问题是**器物层极厚而数据层极薄**。五十三条中可用的尺度总共五处：汉榻「长 75－100 厘米、宽 60－100 厘米、高 12－28 厘米」一处，且明言是「据文献、出土文物与汉代壁画、画像砖、画像石中榻与人的比例」推测；漆木家具条三组著录尺寸（信阳长台关漆木床长 218、宽 139、通高 44 厘米；平山战国方案长 47.5、高 36.2 厘米；屏风屏扇长 224、高 90 厘米）；清式太师椅座高 50-52 厘米（对照明式椅与现代椅的 44 厘米）。其余四十八条一律无尺寸、无构件清单、无用材比例，多条形制的唯一依据是一条图注（壶门案、腰圆凳、长方凳）或一句定义（承尘、隐囊）。三组尺寸集中出自两条（漆木家具、清式家具），且都只用来说明「低矮」或「不舒适」，不构成长度序列。

第三个问题是**「家具」在六册中没有独立的位置**。它散在建筑（汉代竹木作业、木构架）、漆器（漆木家具、马王堆漆屏风）、起居（席地而坐与胡床）与工艺（明式清式）几类叙述里，因此本 Theme 的边界不是由来源划定的，而是由本库为读清家具史而划定的——凡「供坐、卧、承、屏」的器物入内，建筑、绘画、纺织与礼器本体不入。

## 边界

- 纳入：坐具与坐姿（跽坐、胡床、高型家具、榻、枰、杌凳、凳墩、长方凳、椅、交椅、太师椅、官帽椅、玫瑰椅、罗涡椅、鹿角椅、安乐椅、龙墩、高束腰凳、腰圆凳）与卧具、屏风、承具（架子床、拔步床、罗汉床、清式榻、屏风、案、几、凭几、壶门案、折叠桌、抽屉桌、储具、铜禁、俎、隐囊、承尘）。
- 纳入：木作工艺、用材、装饰、风格与文献五层——榫卯结构、攒边、板式结构（B.14.3）；红木、漆木家具、木画、唐代木画棋局（B.14.4）；明式家具、清式家具、清代家具三大名作（B.14.5）；《燕几图》《鲁班经》《明式家具研究》《闲情偶寄》（B.14.6）。
- 纳入：近代材料、场合与竹作三条——人造材料家具、公共器具、章水泉竹家具（B.14.7），以 1949 年后的人造板钢管塑料、按场合分类的办公与公共场所器具、以及蕲州竹家具名手的拼竹做法为证据。
- 排除：建筑与营造——应县木塔、干栏式建筑、拼合梁、紫禁城归 B.3；榫卯结构虽以干栏式建筑为证据对象，其「木构件连接方式」这一抽象面已挂入 B.14.3，建筑本体仍在 B.3。
- 排除：绘画与图像本体——《高逸图》《消夏图卷》《萧翼赚兰亭图》《孔子圣迹图》《捣练图》《簪花仕女图》《清明上河图》不作 KU 挂载，只在条目内作图像证据引用；家具的图注证据（壶门案、腰圆凳、长方凳）随其器物条入内。
- 排除：纺织与屏风织物——宋锦、壮锦、八达晕、几何纹凤鸟纹锦、夹缬屏风（`works/shuxia-liyang-tu-jiaxie-pingfeng`）归 B.2／C；本 Theme 只取屏风的器物形制。
- 排除：漆器技法体系与漆器产品——描金、戗金、雕漆、螺钿、金银平脱、密陀僧绘、夹缬、蜡缬等技法与同批漆器产品条归 B.11；漆木家具作为家具类别挂入 B.14.4，髹饰工序不入。
- 排除：礼器与青铜器本体——`works/yunwen-tongjin`（云纹铜禁）是青铜冶铸例证归 B.9.2；只有 `terms/tongjin` 以 `boundary_case` 入本 Theme，表示「礼器已见家具雏形」。
- 排除：交通器具——轿子（`terms/jiaozi-litter`）是代步器具，不入。
- 排除：近代家具的材料侧不再另行立条——板式结构只以结构侧（框式向板式的转变）挂入 B.14.3，其材料侧出自同一段来源，随人造材料家具条挂入 B.14.7，不重复挂载；工厂、产量与配置制度归 D 维度。
- 排除：竹编工艺体系——`procedures/zhubian-yishu-jiagong` 未挂载，本 Theme 只取章水泉个人的拼竹做法（B.14.7），竹编方法与工具留待传统工艺线。

B.14 的七个 Topic 分两层。器物层两个：B.14.1 回答人怎样坐、坐具怎样随坐姿变高；B.14.2 回答人怎样卧、怎样围合空间、怎样承放器物。二者在来源中不是两条分开的线——床榻与坐具常在同段并列（榻本身「实际是一种小床」），本库按「坐／卧与承」切开，是因为坐具条承载了坐姿变化的全部叙述，而承具条只写形制与用途。解释层四个：B.14.3 回答家具靠什么连接、连接方式怎样随材料变化；B.14.4 回答家具以材料还是以装饰被认识；B.14.5 回答风格由时代、宫廷还是产地界定；B.14.6 回答家具知识如何被写成文本、文本又提出什么判准；B.14.7 回答家具在近代由材料、场合与手工三条路径各自变成什么。器物层与解释层之间没有共享来源段：讲坐姿的条目不描述结构，讲结构的条目不描述器物，讲风格的条目不引器物尺寸，讲文献的条目与器物条无一条对应——七刀都是本库的取舍，不是来源的分组。B.14.7 与 B.14.3 的分工是唯一在证据侧不彻底的一刀：板式结构的材料侧与结构侧出自同一段来源（田自秉 L5367），本库按「材料／结构」拆开挂入两个 Topic，读者若分别查证会重复读到同一段。

## 支撑结构

- 理论支撑：以「坐姿叙述—器物形制—结构判断—数据」四层读家具。坐姿层最完整（席地而坐、跽坐、胡床传入、垂足而坐、椅子改变生活习惯、宋代高型家具普及），且集中在少数条目的总论段；器物形制层最厚（椅凳墩榻屏风几案的部件名与样式分类），但基本不带尺寸；结构判断层原有三条（高型家具的梁柱式框架结构代替箱形壶门结构、攒边的格角榫与芯板入槽、框式向板式），其中后两条由 B.14.3 落地，第一条仍无器物条复现；数据层共五处（汉榻推测、漆木家具三条、太师椅座高一项）。四层互不贯通：讲坐姿的条目不描述具体器物，描述器物的条目不解释结构，唯一的总结构判断不在任何器物条里落地；解释层的四条（工艺、用材装饰、风格、文献）则各自成线，不引用器物层的任何尺寸。
- 实证/材料支撑：七个 Topic 合计主挂载 53 个 KU（term 44、work 2、procedure 2、publication 4、person 1），无次挂载；role 分布为 `term_anchor` 39、`source_publication` 4、`procedure` 3、`boundary_case` 2、`historical_context` 2、`representative_work` 2、`key_person` 1。B.14.1 二十条、B.14.2 十六条、B.14.3 三条、B.14.4 四条、B.14.5 三条、B.14.6 四条、B.14.7 三条。confidence 为 medium 44、low 9；consensus 全部 tentative。来源分布（按 KU 计，可重复计入）：赵农 2009 30、夏燕靖 2016 17、高丰 2004 13、田自秉 2010 10、夏燕靖 2009 5、李立新 2011 2。有出土实物对应的条目集中在早期（江陵九店几、马王堆漆屏风与龙纹漆几、朱然墓黑红漆几、河南郸城西汉石榻明器、南京东晋陶榻、辽宁义县商代青铜俎与安阳大司空村石俎、淅川下寺楚墓云纹铜禁、信阳长台关漆木床与漆案、平山战国方案与屏风、河姆渡遗址），宋以后各条基本无实物、无图版。
- 文献支撑：六册的家具叙述分散在建筑、漆器、起居、工艺与文献各章，本 Theme 以赵农与夏燕靖 2016 两册为骨干（器物分类、风格描述与三部文献的引用），高丰提供早期尺度、马王堆漆屏风、清式分期与《闲情偶寄》，田自秉提供攒边、板式、木画与明式清式的工艺判断，夏燕靖 2009 提供汉代竹木作业、胡床与三大名作，李立新只参与两条（胡床、长方凳）；B.14.7 三条只出两册（田自秉两条、赵农一条），是七个 Topic 中来源最薄的一处；一手文献《考工记》《说文》《周礼》《器物丛谈》及《燕几图》《鲁班经》《明式家具研究》《闲情偶寄》均经六册转引，原本未见。

## 未解决问题

- 器物层与解释层之间无一共享来源段：B.14.3 的三条不引任何器物尺寸，B.14.4 的漆木家具虽带三组尺寸却不引形制谱系，B.14.5 只在太师椅一处引尺度，B.14.6 的四部文献与器物条无一条对应。因此本 Theme 仍不能回答「具体某件家具是怎样做的」。
- 五十三条中可用的尺度共五处：汉榻一处推测、漆木家具三组著录尺寸、清式太师椅座高一项。三组尺寸的出处与测量方式未注，太师椅座高只用来说明「不舒适」，汉榻明言为按人榻比例推测；长度序列、构件尺寸与用材比例仍全无。
- 总结构判断（梁柱式框架结构代替箱形壶门结构）仍只出现在高型家具一条；B.14.3 只提供攒边与框式→板式两条具体做法，「箱形壶门结构」的形制、年代上限与被替代时点仍空，三条结构判断之间没有过渡证据。
- 榫卯条的证据对象是干栏式建筑而非家具，其榫卯类型、构件部位、工具与工序全无；把它挂入 B.14.3，依据是攒边条的格角榫与明式家具「以榫卯结合」，这一接法属本库取舍。
- 攒边与板式结构的证据都只出自田自秉一册，无第二册交叉；攒边是否明式家具通例、板式节点如何做，来源均未说。板式结构是唯一 1949 年以后的条目，使结构线跨过一次断代跳跃。
- 明式家具的概念史只有「20 世纪 30 年代杨耀最早提出」一句；清式分期（康熙前期／康熙晚期至乾隆／嘉庆道光以后衰落）只有高丰一册；苏作评价两说不裁（宫廷苏式「明式风格已几乎丧失」与「苏作大体继承明式」）；三大名作的三作差异全部来自田自秉与高丰的清式条，与夏燕靖两版的合称不是同一批来源。
- 《燕几图》《鲁班经》《明式家具研究》《闲情偶寄》四部原书均未核，各自只有一段引用（《燕几图》一句、《明式家具研究》一段鸡翅木、《鲁班经》两段成书与卷数、《闲情偶寄》卷目与判准），家具知识文本化的线索未成序列；《鲁班经》作者「年荣」与《闲情偶寄》书名「寄／记」两处异写照录不裁。
- 坐姿变化线的四处不一致全部保留：胡床的传入方向、改称「绳床」的时点、绳床与胡床是否同物、胡床的社会评价，六册四处互不相同，赵农一册内部亦不自一致。
- 家具的断代多以「某代新出现」的断言给出（抽屉桌为元代新创造、高束腰凳与罗涡椅为元代新设计、安乐椅为晚清出现），而支撑多为一条图注或一句风格评语，无实物、无墓例、无款识。
- 图像证据大量依赖图注而未核：壶门案、腰圆凳、长方凳三条的唯一依据是图注，图 5-40（西魏敦煌壁画）亦未核；本 Theme 不据图补写形制。
- 承尘、隐囊两条证据各只有一句定义，confidence 为 low；二者是本 Theme 中「起居配套物」而非家具本体，是否应留在 Theme 内属本库的边界取舍。
- 铜禁与俎以 `boundary_case` 入内：二者是礼器，造型「已具有后世几、案、桌类家具的雏形」这一判断来自来源，但「雏形」与「家具」之间的界线来源未划。
- 家具的制度与阶层面未物化：宝座「是权力、地位和身份的象征」、清式家具「宫廷权势压过实用」等判断均指向 D 维度，D 维度前近代线目前只有 D.6 官府手工业，家具使用等级不在其中。
- B.14.7 三条无一被第二册复核，且无一年代可定：人造材料条以「解放后」为界、公共器具条只称「现代」、章水泉条只有蕲州产地沿革，三条无法排成时间序列，「近代家具」在本 Theme 内只是三个片段的合称。
- 竹作与工业化两条线在六册中从未被对照：既无一处判断手工竹作在 1949 年后的处境，也无一处说明人造材料家具是否取代了竹家具；章水泉的「小竹片拼椅面」与板式结构的人造板同属「拼」，但一为做法、一为材料，来源未作区别。
- 公共器具条无设计者、无尺度标准、无采购与配置制度，只列举十余场所与二十余种器具；办公文具（铅笔、钢笔等）被列入办公用品范围，文具是否属家具来源未界定。
- 板式结构的材料侧与结构侧出自同一段来源（田自秉 L5367），两处证据其实同一句，无法分开计证；人造板材的性能、规格与产量，钢管型材尺寸与连接方式全无。
- 家具与建筑、漆器、纺织三线的分工是本库取舍：六册从未把家具作为独立门类立章，本 Theme 的边界为读清家具史而设，不表示六册有同样的分类。
