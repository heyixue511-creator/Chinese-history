# B.8 玉石与治玉：礼制、工艺与巨型玉器

## 核心问题

玉石在六册中先是一种材料，然后才是一套制度。赵农给的定义是「玉石也称美石」，分硬玉与软玉，硬玉又称翡翠，原始制玉多以软玉为主，软玉是透闪石、阳起石；玉石被视为原始先民在大量石器制作中发现的「不同于普通砾石的美石」。这个定义把玉放回石器传统，玉器不是从观念开始，而是从选石开始。

第二个问题是礼制化。田自秉记周代玉器因与伦理道德直接联系而受社会特别重视，成为修身的标准与等级名分的标志；《周礼·大宗伯》以玉作六器，苍璧礼天、黄琮礼地、青圭礼东方、赤璋礼南方、白琥礼西方、玄璜礼北方；璧、琮、圭各有形制，圭又分大圭、琬圭、琰圭、穀圭，命圭以镇圭尺有二寸、桓圭九寸、信圭七寸、躬圭六寸定天子、公、侯、伯；陪葬按圭左、璋首、琥右、璜足、璧背、琮腹放置。这些规定全部出自《周礼》《考记工》，来源未给成套实物、组合数量与年代序列。礼制文本与出土玉器之间，是直接对应还是后人追述？

第三个问题是治玉。赵农记商周玉器的特点是选料、切割、磨制、钻孔、雕刻技术的提高；商代玉器以绿、青、褐色为主，材质大多是新疆和田玉与河南南阳玉；金属工具已广泛使用，铊子又称砣机，是安装在车床上、用脚踏产生转动的圆形工具；西周延续商代晚期技术，阴刻、浮雕、圆雕、透雕并用。田自秉另记玉雕的高度技巧在「套裁」与「巧色」：套裁利用刻制器物的余料再刻成器体部件，链条的玉材是从瓶腹内挖出来的；巧色根据玉石里外不同色泽表现不同形象，去瑕显瑜、因材施艺，整个制作过程也就是设计过程。工序名与工具名都有，但掏膛、链条环数、接口与选料标准全无。

第四个问题是巨型玉器。元代渎山大玉海高 70 厘米、口径最宽 182 厘米、重 3500 公斤，是中国古典玉器之最，经多次修磨已非元代旧貌；清乾隆大禹治水图玉山高 2.24 米、宽 0.96 米、重约 7 吨，历 13 年而成，青玉采自和田密勒塔山，运京约三年，以《大禹开山图》为蓝本，造办处制模型出坯后运至扬州由玉雕工人制作；白玉嵌金红宝石碗以和田白玉错金嵌 180 颗红宝石，碗心刻乾隆诗，来源据《高宗御制诗集》注判断为御殿赐奶茶之器。三件的玉料、工匠、工序与费用记载详略不一，巨型玉器的设计与制作分工因此无法统一。

第五个问题是史前与商代的证据基础。良渚反山墓地出土玉器按单件计 3200 余件，玉钺、玉琮、玉璧被分别解为兵权、神器与财富；红山文化大玉龙呈 C 型、长 42.2 厘米；龙山文化两城镇留下成坑的半成品玉材；花厅墓地出土 500 余件与良渚所产完全相同的玉器。商代一侧，妇好墓的玉器数目有 426 件、755 件与近 600 件三种说法，赵农按礼仪用品、生活用品、装饰物品三分，李立新以 755 件判定刮摩治玉技术已经成熟，田自秉记一件高 7 厘米的跪坐玉人。库存、分类与单件各自成立而互不校验，史前与商代的玉器因此只能分层记录，不能连成一条自史前到周代的礼制演化线。

## 边界

- 纳入：玉石材料定义（美石、硬玉／软玉、透闪石／阳起石）；周代玉礼器与瑞玉六器；璧、琮、圭的形制与等级；琢玉工序与铊子／砣机；套裁与巧色；陆子冈；渎山大玉海、大禹治水图玉山、白玉嵌金红宝石碗；史前良渚、红山、龙山的玉器与玉材；商代玉器三分、佩璜与妇好墓玉器。
- 排除：史前玉器归 B.8.4、商代玉器归 B.8.5；本 Theme 不把史前玉器、商代玉器与周礼六器直接连成一条演化线。
- 排除：良渚、红山、龙山文化的分区、陶器与聚落归 B.5.2；本 Theme 只取三文化的玉器与玉材内容。
- 排除：玉器纹样母题（神人兽面、龙凤、穀纹、蒲纹）的意义解释归 C；本 Theme 只取器形、工序与制度。
- 排除：玉料贸易、玉石之路与和田玉运输路线归 E.2；本 Theme 只取来源所记「和田玉」「南阳玉」的材料判断。

- 排除：造办处的机构沿革、编制与匠役归 D.6.6；本 Theme 只取其在巨型玉器制作中的角色。
- 排除：玉器鉴定、拍卖与当代市场归 D.1；本 Theme 只取来源所记工艺与器物。

## 支撑结构

- 理论支撑：以「材料—制度—工艺—巨型器物—史前与商代证据」五层组织玉石材料。材料层回答玉是什么（美石、软玉／硬玉），其证据是定义而非检测；制度层回答玉如何变成等级与礼仪（六器、命圭、陪葬位置），其证据是文献规定而非成套实物；工艺层回答玉如何被加工（选料、切割、磨制、钻孔、雕刻、套裁、巧色），其证据是工序名与工具名而非工艺痕迹；器物层回答巨型玉器如何被组织生产（玉料运输、造办处出坯、扬州雕琢），其证据是三件器物的尺寸、重量与制作周期；史前与商代层回答礼制之前与礼制之外的玉器能证到什么程度（反山 3200 余件、红山大玉龙 42.2 厘米、两城镇半成品玉材、花厅 500 余件输入、妇好墓 426／755／近 600 三说），其证据是库存、器名与单件著录而非分类统计。五层的证据强度依次为「定义—规定—工序名—单器记录—库存数字」，没有一层能单独证明另一层。
- 实证/材料支撑：五个 Topic 合计挂载 27 个 KU（B.8.1 五个、B.8.2 四个、B.8.3 三个、B.8.4 十个、B.8.5 五个），覆盖 term、procedure、person、work、place 五类；`term_anchor` 10（瑞玉六器、璧、琮、圭、周代玉礼器、玉石、玉钺玉琮玉璧、天圆地方、商代玉器分类、佩璜）、`procedure` 2（琢玉、玉雕套裁与巧色）、`key_person` 2（陆子冈、妇好）、`representative_work` 7（渎山大玉海、大禹治水图玉山、白玉嵌金红宝石碗、神人兽面纹玉琮、大玉龙、玉锛、妇好墓玉人）、`historical_context` 2（良渚文化、红山文化）、`geographical_context` 3（两城镇、北阴阳营、妇好墓）、`boundary_case` 1（花厅墓地）。
- 文献支撑：田自秉提供周代玉礼器的伦理与等级、璧琮圭的形制与命圭等级、陪葬位置、套裁与巧色、陆子冈、巨型玉器、红山大玉龙、两城镇玉材、北阴阳营玉石器与妇好墓玉人；赵农提供玉石定义、瑞玉六器与五色四方、商周治玉与铊子、渎山大玉海、商代玉器三分与妇好墓 426 件；李立新提供砣机旁证、玉琮方圆象征与天圆地方、花厅墓地、妇好墓 755 件与刮摩技术成熟；夏燕靖两版提供佩璜、反山 3200 余件与神人兽面纹玉琮图版；高丰提供反山「琮王」与神人兽面复合纹的氏族徽记说。具体行号见各 KU 的 `sources`。

## 未解决问题

- 玉石的矿物学判据未给：赵农只称「美石」、硬玉／软玉、透闪石／阳起石，无成分、硬度、比重与检测数据；玉与石、玉与玉髓、玉与玻璃的边界无法由六册判定。
- 玉器起源只有「原始先民在石器制作中发现美石」一句，无遗址、年代与最早器物；玉石被视为材料的过程没有考古证据。
- 瑞玉六器全部出自《周礼·大宗伯》，来源未给成套实物、组合数量、使用场合与年代序列；六器与良渚玉琮、玉璧之间是否同一系统，六册未说明。
- 璧、琮、圭的形制只有文献定义（璧羡度尺、好三寸、肉倍好；琮外方内圆；圭分四类），无一件的实测尺寸、玉料、出土单位与年代。
- 命圭的等级（镇圭尺有二寸、桓圭九寸、信圭七寸、躬圭六寸）只有文本，来源未给对应的实物或墓葬组合；天子纯玉、上公四玉一石、侯三玉二石、伯玉石各半的配比亦无实物验证。
- 周代玉礼器的陪葬位置（圭左、璋首、琥右、璜足、璧背、琮腹）只有《周礼》一句，无墓葬实例与摆放图。
- 商周治玉的工序名（选料、切割、磨制、钻孔、雕刻）与工具名（铊子／砣机）都有，但无工序顺序、工具材质、转速、磨料与工时；「金属工具已广泛使用」无出土工具佐证。
- 商代玉料的「大多是新疆和田玉石以及河南南阳玉」是单源判断，无玉料检测、产地溯源与比例数据；西周玉料来源未给。
- 套裁的掏膛方法、链条环数、接口强度与余料利用率全无；巧色的选料标准、色泽分层与去瑕方法亦无；「整个制作过程也就是设计过程」是田自秉的判断，不是工序记录。
- 陆子冈只有徐文长诗、茶晶花插、青玉明月松泉图方盒与琴式小盒数条，无生卒、字号、师承、作品清单、款识与纪年。
- 渎山大玉海的制作年代、玉料产地、雕刻工匠与纹饰内容未给；高 70 厘米、口径 182 厘米、重 3500 公斤是现存状态还是元代原状，来源未说明；多次修磨改动了什么亦无记录。
- 大禹治水图玉山的「造办处制模型出坯后再运至南方，由扬州玉雕工人制作」只有一句，无分工图、工匠名、运输路线与费用；13 年是否含运输时间未说明。
- 白玉嵌金红宝石碗的错金工艺、宝石镶嵌方法与桃形耳成形法全无；「御殿赐奶茶之器」是据《高宗御制诗集》注的判断，无使用场景的旁证。
- 史前玉器的年代序列未给：良渚、红山、龙山三文化的绝对年代、玉器分期与最早器物均无；玉器从工具与装饰转为礼器的中间环节只有「玉圭由石斧、玉璧由环状石斧、玉璋由石刀演变」的形制推导，无过渡器物。

- 红山大玉龙只有 C 型、42.2 厘米、绿玉佩饰品三项，墓葬、年代、出土地与藏地未载；六册对红山玉器的名称（大玉龙／曲体玉龙／玉雕龙／玉龙）不统一，是否同一件未说明。

- 商代玉器三分的数量比例、各器类尺寸、玉料与出土单位未给；礼器只列璧、琮、圭、璋、璜五器、缺玉琥，与同册六器名录不一致；四类名目与西周宝鸡墓三分不对应。
- 妇好墓的玉器数目有 426 件、755 件与近 600 件三种说法，统计口径（是否含残件、工具、礼器、串饰）未明；755 件玉器的玉料判断（岫岩、南阳、和阗）无检测数据与比例。
- 佩璜的实物、尺寸、墓葬与年代全无；人纹、鸟纹、色纹、兽纹璜的演变无序列证据；雕镂镶嵌与职务级别的对应无实例。
- 妇好墓玉人的玉料、藏地、出土编号、同出玉人数量与制作工序未载；妇好墓玉雕人俑（夏燕靖 2016）与本条玉人（田自秉 2010）是否同一件，来源未说明，重复候选待裁。
