# E.6 近代女装与身体改装

## 核心问题

近代女装如何在西方影响、满汉形制遗存与“文明”话语之间被重新剪裁和重新命名？旗袍被说成“满族旗人长袍的延续”，也被说成“民国时期才定型的近代服装”，两种说法指向同一个词却给出不同的起点；短袄套裙被时人称为“文明新装”，时世装被时人称为“Modern Dress”——命名先于形制稳定，还是形制先于命名？

服装的改变与身体的改变（天足运动）是同一过程的两面，还是两条各自独立的路径？放足没有组织、没有章程、没有时间表，却与女学、女权、革命党人和传教士同时在推；这种“无主体的运动”如何被记入设计史，而不是被记入妇女史？

## 边界

- 纳入：旗袍的族属来源、形制改造与命名两说；短袄套裙的“文明新装”称谓与日本女学生校服影响；时世装的“Modern Dress”称谓与上衣下裤形制；天足运动的社会条件与推动者。
- 排除：剪辫易服、服制条例、中山装与国家礼服，归 D.2；本 Theme 只取女装与身体。
- 排除：织绣、染织、服装工艺与面料纹样，归 B.2；本 Theme 只取形制类别、命名与身体观念。
- 排除：胡服与北魏服饰改制，归 E.5；本 Theme 不处理族群身份问题。
- 排除：妇女运动史、女子教育史与女权思想史的整体叙述；本 Theme 只取与服饰、身体直接相关的部分。
- 排除：旗袍的当代复兴、非遗化与流行史；前六册未涉及。
- 边界说明：4 条材料中 3 条为单源单句（夏燕靖 2016），旗袍虽为四源，但“旗人来源／近代定型”与“满汉双向仿效／宽袍大袖吸收汉装”两组异说并存；天足运动 `confidence` 为 low，无组织、无章程、无时间表。本 Theme 只证明“形制与命名被记载、被争论”，不证明实际穿着普及程度，也不证明放足在全国的推进程度。

## 支撑结构

- 理论支撑：以“衣—身”两分处理本组材料。E.6.1 只处理穿在身上的形制与命名，E.6.2 只处理身体本身（缠足与放足）的改装；两轴不合并为“妇女解放”的单一叙事，也不互相解释。
- 实证/材料支撑：4 个 KU 全为术语；旗袍 4 源、短袄套裙／时世装／天足运动各 1 源，且后三条同出夏燕靖 2016 相邻三行。
- 文献支撑：各 KU 的 `sources`；具体行号见条目。

## 未解决问题

- 旗袍的族属与起点两说并存：系于旗人传统 vs 系于近代定型；清代满汉双向仿效（夏燕靖）vs 宽袍大袖吸收汉装（高丰）两说并存。本 Theme 不裁。
- 旗袍“近代紧腰身形制”只有一句概括，无版型、尺寸、开衩高度、面料与年份；1929 年蓝色六纽旗袍为妇女礼装只见一册。
- 赵农记电影明星影响、高跟鞋与烫发连带，未给明星姓名、影片与年份，也未说明是因果还是并置。
- 短袄套裙只有一行：民国初年、受日本女学生校服影响、时称“文明新装”、穿着者为女学生与女教师；无形制细目与流行范围。
- 时世装只有一行：1912 年开始流行、上衣下裤、时称“Modern Dress”；无版型、面料与命名者。
- 天足运动只有一行：辛亥革命前后、思想解放与女权、女学、西方传教士／商人／革命党人办女学；无组织、章程、时间表与推进程度。
- “文明新装”“Modern Dress”是当时称谓还是作者概括，来源未区分。
- 衣与身两轴之间是否有中介（女学、传媒、城市生活），来源未论；本 Theme 只作并列，不写因果。
- 3 条单源材料同出夏燕靖 2016 相邻三行，属同一段落的连续叙述，不能作为三条独立证据互证。
