# C.2 书籍装帧、印刷与出版

## 核心问题

晚清至民国，石印、铅印、铜版与照相制版如何改变书籍的物质形态、图版质量与出版组织？书装家群体又如何把封面、题字、插图与版式确立为独立的设计实践？本 Theme 关注“书刊如何被制作、装帧与出版”，不把商品广告、机构标识或服饰制度作为主问题。

## 边界

- 纳入：成都存古书局、湖南思贤书局、金陵书局、浙江书局与点石斋石印局；石印本、铅字印刷、铜版印刷与照相制版；陈之佛、丰子恺、鲁迅、钱君匋、司徒乔、孙福熙、陶元庆、闻一多、叶灵凤、张光宇；《北平笺谱》《点石斋画报》《坟》《冯小青》《呐喊》《彷徨》《万象》《新青年》。
- 排除：月份牌、报纸广告、书刊广告、招贴、幌子与机构标识，归 C.1；《生活周刊》的实际内容是书刊广告与商品广告，归 C.1.2，不因“刊物”身份塞进 C.2。
- 排除：商务印书馆与伊文思图书公司两条 KU 的实际内容分别是 1920 年广告画家练习生培养与 1926 年打字机霓虹灯、吊灯广告，不因机构名称含“印书馆／图书公司”而纳入 C.2。
- 排除：短版套印属明代创造、清代盛行的传统工艺，丝网印刷只有“现代”一句且 confidence 为 low，均不并入本 Theme 的晚清民国主线。
- 排除：1949 年后的书籍装帧、印刷技术与出版机构；张光宇 KU 跨 1949 年，只取其在民国《万象》封面与书装谱系中的部分。
- 与 C.1 的分工：C.1 解释“商品与机构如何被看见”，C.2 解释“书刊如何被制作、装帧与出版”。两 Theme 同属 C 维度，不合并、不重复计数。

## 支撑结构

- 理论支撑：以“印刷技术—出版组织—书装作者—书籍形态”四层分析近代书籍生产，区分技术条件、机构制度、设计者实践与阅读文化。
- 实证/材料支撑：27 个 KU，覆盖 institution、procedure、person、publication 四类；技术与出版机构 9 个，书装家 10 个，书籍与期刊样本 8 个。
- 文献支撑：高丰 2004、夏燕靖 2009/2016、赵农 2009、田自秉 2010、李立新 2011 的近代印刷、书籍装帧与出版章节；具体行号见各 KU 的 `sources`。

## 未解决问题

- 商务印书馆、伊文思图书公司等条目与 C.2 的名称相近但实际内容错位，需在后续批次决定是否另立广告机构 Topic 或改写条目边界。
- 钱君匋与钱君陶两条 KU 极可能是同一人的异写重复，但来源各自独立、名称用字不同；本批不擅自合并，只挂钱君匋，钱君陶保留为研究债。
- 《点石斋画报》同时被 T3 与 T4 列为代表，本批按其石印画报与书籍形态证据归 C.2.3，并在 scope_note 记录与 C.1.2 的边界。
- 铜版印刷与照相制版的来源只写“现代”，未给具体年代，无法证明属 1840–1949；本批按工序纳入 C.2.1，并保留时段不确定性。
- 四家官书局均只有赵农一条列名，缺设立年份、创办人、刻工、刊刻书目与印量；点石斋也缺设备、工序与停办时间。
- 书装家条目多为风格评语，缺作品清单、图版与出版机构；鲁迅、陶元庆、钱君匋之外的材料密度不均。
