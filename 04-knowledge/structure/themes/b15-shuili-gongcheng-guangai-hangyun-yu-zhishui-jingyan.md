# B.15 水利工程：灌溉、航运与治水经验

## 核心问题

本 Theme 八条规定了一个共同问题：**水利工程在六册里是以「工程」被写，还是以「人物的功绩」被写**。四条工程与四位主持者严格一一对应——李冰与都江堰、郑国与郑国渠、西门豹与西门渠（漳水十二渠）、史禄与灵渠；每条的写法也几乎同构：主持者身份、一个年代、一句效果、至多一句工程结构。工程的结构只有两条写出来：都江堰给鱼嘴、飞沙堰、宝瓶口三个构件名与内外江的关系，灵渠给船闸与分水工程两项机构。郑国渠与西门渠连一句结构也没有——前者只写「在泾水和洛水之间穿凿一条灌溉水渠」与盐碱地变良田，后者只写「兴建了漳水十二渠」与物产丰富、土地肥沃。没有一条写工役、组织、经费、维护与工期（都江堰的「六年」是唯一工期）。

第二个问题是**八条全部出自一册、且分成两处文本**：赵农《中国艺术设计史》2009 的 L2060-L2072 连续一段（都江堰、郑国渠、西门渠与李冰、郑国、西门豹）与 L2723-L2725 另一段（灵渠与史禄）。高丰、夏燕靖两版、田自秉、李立新与夏燕靖 2016 对水利工程零覆盖。因此本 Theme 能回答的不是「中国古代水利怎样设计」，而是「六册在什么层面把水利写成设计」。

第三个问题是**效果语言分成「地」与「路」两类**：三条灌溉渠的效果都落在土地——「使成都平原成为天府之国」「使大量的盐碱地变成了良田」「使邺地成为了物产丰富、土地肥沃的地区」；灵渠的效果落在通路——「使长江和珠江水系连通」「使航运顺畅」「不受河流落差限制而顺利通过」。来源没有给出这一分类，它是本库读四条效果句得出的。

## 边界

- 纳入：灌溉工程三条（都江堰、郑国渠、西门渠／漳水十二渠）与航运工程一条（灵渠），以及四位主持者（李冰、郑国、西门豹、史禄），共八条。
- 排除：提水机具与灌溉器具——翻车、辘轳、桔槔归 B.12.2；水利工程用器具（锸、夯、测量工具）在六册中无条目，不据工程描述补写。
- 排除：农具与耕作技术——耒耜、犁、耧、镰、磨归 B.12；工程与器具的分工以「是否改变水系」为界，本 Theme 只取改变水系的工程。
- 排除：其他土木营造——城墙、宫殿、陵墓、道路归 B.3 与 B.14 之外的营造线；本 Theme 不取非水系的土方工程。
- 排除：漕运、行政与治理制度——秦在桂林、广州、雷州半岛设行政管理机构，魏文侯任邺令，秦任蜀郡太守等行政事实只作背景引用，制度与治理归 D 维度。
- 排除：水利图像与水利图籍——六册无水利图、无《水经注》类文献条目，本 Theme 不建图版证据。
- 排除：治水神话、祭祀与礼俗——西门豹「破除迷信」只有一句概括，未展开具体事件，不另立 KU。
- 排除：简单机械——杠杆、滑轮（`terms/lever`、`terms/pulley`）是力学原理与起重器具，归待建简单机械线；本 Theme 不取。
- 排除：近代水利与水电——六册无相关条目，不存在可挂对象。

## 支撑结构

- 理论支撑：以「工程结构—主持者—效果语言—治水经验」四层读水利。工程结构层最薄：八条中只有都江堰（鱼嘴、飞沙堰、宝瓶口、内外江）与灵渠（船闸、分水工程、33 公里）两句可算结构，郑国渠与西门渠零结构；主持者层最厚：四条工程各有其人，且每条以「某人主持」起句，人物与工程不可分离；效果语言层分成「地」与「路」两类，三条灌溉渠归「地」、灵渠归「路」；治水经验层只有都江堰一条口诀（「深掏滩，低作堰」「水竭不见足，盛不没肩」），其余三条无任何技术判准。四层不互相支撑：有结构的两条中只有都江堰同时有口诀，有口诀的条目没有尺寸，有效果的条目没有灌溉面积。
- 实证/材料支撑：一个 Topic 合计主挂载 8 个 KU（work 4、person 4），无次挂载；role 分布为 `representative_work` 4、`key_person` 4。全部为单册来源（赵农 2009），无一条跨两册及以上；confidence 为 medium 7、low 1（史禄）；consensus 全部 tentative。断代：战国三条工程（都江堰公元前 256 年起、郑国渠公元前 246 年、西门渠无年代）与三位主持者，秦一条工程（灵渠公元前 219 年）与一位主持者。
- 文献支撑：赵农《中国艺术设计史》（2009）是本 Theme 的唯一来源。L2060-L2072 一段提供都江堰、郑国渠、西门渠与李冰、郑国、西门豹；L2723-L2725 一段提供灵渠与史禄。高丰 2004、夏燕靖 2009、田自秉 2010、李立新 2011、夏燕靖 2016 对八条均无关联条目；一手文献（《汉书·沟洫志》引郑国自辩一句、韩愈诗等）全部经赵农转引，原本未见。

## 未解决问题

- 八条全部来自赵农一册，其余五册零覆盖：水利工程在六册中是赵农的叙述对象而非共同对象，本 Theme 的结论无法由第二册交叉确认。
- 四条工程中两条零结构：郑国渠只有「在泾水和洛水之间穿凿一条灌溉水渠」，西门渠只有「兴建了漳水十二渠」；渠首、渠线、断面、比降、闸堰形制全部未载，本 Theme 因此无法回答「工程怎样做」。
- 量化只有四处：都江堰公元前 256 年起与六年工期、郑国渠公元前 246 年、灵渠公元前 219 年与 33 公里；无一条给灌溉面积、渠道长度（灵渠除外）、土方量、工役人数与维护制度。
- 治水经验只有都江堰一条口诀，且口诀是「可记诵的判准」而非可计算参数：「深掏滩，低作堰」「水竭不见足，盛不没肩」两句无出处、无解释、无适用条件；其余三条工程没有任何技术判准。
- 效果语言的两分（「地」与「路」）是本库读法，来源未作此分类：三条灌溉渠的效果句都以土地产出表述，灵渠的效果句以水系连通与航运表述，但来源从未把二者并列比较。
- 四种主持者身份不同却同被写成工程的原因：李冰是蜀郡太守（行政长官）、郑国是韩国间谍身份的工匠（技术人员）、西门豹是邺令（行政长官）、史禄是受派官员（无官职记载）；来源未讨论身份与工程成败的关系。
- 「西门渠／漳水十二渠」名实并列不裁：来源在同一段把二者并称，未说明是同一工程的总名与分名，还是主持者名与渠系名的并称；「十二渠」是否十二条渠也无说明。
- 三处文本异常照录不裁：都江堰条「都江水利」与「都江堰」并存、L2062 与 L2066 之间被页眉隔断（「被后人加以继」／「承」）；郑国渠条「气奄息息」疑为「气息奄奄」、「进入秦国内向秦王嬴政建议」疑脱句读；西门渠条名实问题同上。
- 制度与治理面全部未物化：蜀郡太守、邺令、桂林广州雷州行政机构、秦对岭南治理均指向 D 维度，D 维度前近代线目前只有 D.6 官府手工业六点，水利行政不在其中。
- 六册没有一处把水利与农具、提水机具并读：水系的改变（工程）与水的提取（翻车、辘轳、桔槔）分属 B.15 与 B.12.2，来源从未在同一段讨论二者，本库的分工是结构性的、不是来源的。
- 汉代以后的水利条目在六册中零覆盖（白渠、龙首渠、大运河、圩田、海塘均未立条），本 Theme 只有一个 Topic 不是取舍而是库存限制。
