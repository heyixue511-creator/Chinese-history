# C.1 商业美术与广告

## 核心问题

晚清至民国，月份牌、报纸广告、书刊广告、招贴与机构标识如何把商品、城市生活与国家机构转译为可视图像？本 Theme 关注视觉传达、广告图像与标识语汇，不把印刷工艺、出版机构或服制制度作为主问题。

## 边界

- 纳入：月份牌、月份牌画家、英美烟草公司广告部、《良友》画报广告、《申报》与《上海新报》报纸广告、《中国一日》书籍广告、幌子、招贴、粤汉铁路徽章与北洋机器局标志。
- 排除：书籍装帧、封面设计、印刷技术与出版机构，归 C.2；月份牌的消费市场与广告经营只在涉及 D 维度时作次维度，不主挂 D.2。
- 排除：1949 年后的广告与标识；改革开放后的包装、广告杂志与国徽、铁路标志等条目不在本 Theme 范围。
- 与 C.2 的分工：C.1 解释“商品与机构如何被看见”，C.2 解释“书刊如何被制作与出版”。两 Theme 同属 C 维度，不合并、不重复计数。

## 支撑结构

- 理论支撑：以“广告图像—发布媒介—机构标识”三层分析商业美术，区分图像风格、媒介技术与品牌传播。
- 实证/材料支撑：14 个 KU，覆盖 term、person、institution、publication、work 五类；月份牌与商业广告 7 个，报刊广告与机构标识 7 个。
- 文献支撑：高丰 2004、夏燕靖 2009/2016、赵农 2009、李立新 2011 的近代商业美术章节；具体行号见各 KU 的 `sources`。

## 未解决问题

- 月份牌原稿、广告主档案与发行数量未在现有 KU 中展开；多数画家条目只有列名或一段描述。
- 报纸广告的图像与版面尚未提取为独立 work KU；《申报》《上海新报》目前以 publication 条目承载广告史信息。
- 粤汉铁路徽章、北洋机器局标志只有图注一行，标志构成、设计者与使用场合未载。
- 幌子、招贴是跨时段术语，现代段材料与古代段并置；本 Topic 只取其在近代商业美术中的用法，不把古代部分当作近代证据。
