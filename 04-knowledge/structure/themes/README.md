个 KU。陶与瓷按材料分工：B.5 只收陶器、低温釉陶、建筑用陶与紫砂，瓷器与原始瓷留待 B.6；制陶生产组织（4 条候选）与青铜器形序列（鼎、壶、豆、簋、斝、甗、鬲）尚未物化为 Topic，候选池登记于对应批次 manifest，不预先物化空 Topic。B.5.3 补上第三层“分化的同源性”：商周至六朝陶器同时在材质（灰陶按烧成气氛、白陶按原料、硬陶按火度——三把尺子不能排成演化线）、装饰（绳纹是成型副产品、暗纹仅斜光可见、彩绘为明器专用，构成可见性梯度）与用途（日用／随葬明器／建筑模型）三个方向分化，明器内部又分等身写实（兵马俑 1.75—1.85 米、7000 余件）与缩小模型（陶仓楼 78.2 厘米、陶井、绿釉陶楼）两极；“青铜占礼器位置后陶器重新定位、白陶因此消失”是本库解释框架，六册未如此因果化。B.5.4 补上第四层“低温釉陶的用途分化”：低熔点（铅釉 700—800℃）与二次烧成（素烧 1000—1100℃、釉烧 850—950℃）使同一套釉分出随葬明器（三彩，曾列入官府丧葬明文规定按品级配器）、建筑构件（宋《营造法式》配方、明十样规格与琉璃渠窑场）与陈设供器（元代琉璃香炉、明代法华器）三条用途线；“低温釉陶”不等同于“铅釉陶”（法华器以牙硝助熔、宋三彩加红绿彩再烧），琉璃只取建筑义、第一义（原始玻璃与铅钡玻璃）另处挂载，素三彩与宋三彩之后的明清釉上五彩归 B.6.4。史前部分的年代、文化与类型归属在六册间不一致，“彩陶文化”与“仰韶文化”是否等同、良渚是否属龙山文化四类型、彩陶与彩绘陶的工序定义，本 Theme 均并列保留、不裁；B.5.3 另追加彩绘陶按用途定义而非工序定义、几何印纹硬陶时代与成型法三处冲突、兵马俑窑址未发现、模型明器尺度几乎全缺等研究债务；B.5.4 追加釉料成分与配比、二次烧成温度之外的全部窑炉参数、宋三彩至明清釉上五彩的传承链、琉璃一名两义的分界、法华器谱系、黄釉瓷扁壶材质判定悬置等研究债务。B.5.5 补上第五层“胎面的三种状态”：三条路线共同的不是“不用釉”，而是把装饰面从釉转回胎——宜兴全部露出（不挂釉，以泥色、造型与浅刻立身）、石湾露出一部分（部分上釉、局部露胎，以胎釉色差立身）、荣昌加工胎面（红白双色泥贴花嵌花、两色混合成金黄、铁线划花）；并按“紫砂具名师承（供春—时大彬—陈鸣远—杨彭年—顾景舟）与石湾、荣昌无人名”的不对称立一条记录边界：差别可能来自工艺，也可能只来自文献选择，六册无法区分。B.5.5 追加紫砂北宋起源的诗证问题、泥料两套名单、艺人名单互不一致与陈鸣远三处定位、生产组织全缺、石湾三名并存与分期口径不一、荣昌单源、两件图注级器物不构成器形证据等研究债务。B.5.6 补上第六层“建筑构件的同一次成形”：陶器离开器皿后，结构、连接与图像三项要求落在同一批泥上——瓦当的图像位置由构造确定（挡住木椽与图案装饰是同一构件的两个功能，尺寸由椽径定，形式由观看距离、陶质与模印法三项制约）；瓦钉与瓦身分离是六册中唯一一条“把一体成形拆成两件”的工艺选择；模印则是端头、砖面、砖体与整壁四个尺度共用的成形法（瓦当模印、方砖阴刻花模套印、空心砖四片模印后粘合再封泥片开孔、砖画 200 多块拼合），把图像从一次性绘制变成可复制的产品。B.5.6 另立两条判断：一是砖的结构角色发生过从贴面到砌拱的转变（西周实心砖背面四角有乳钉、贴墙面；汉代才有楔形榫头砖砌垒拱顶），两处相隔数百年而无过渡材料，标为本库解释框架；二是画像砖同时是墙与画，空心砖把“中空故易烧、体轻、可防潮”与“四片泥坯各印花纹再粘合”写在同一段，结构与图像由同一批泥片承担。B.5.6 追加砖瓦窑址与生产组织全缺、尺寸只有三个孤例、瓦钉瓦身分离无年代与强度数据、瓦当两套纹样分类不合并、文字瓦当无统计、方位性瓦当无实例、画像砖尺寸与施彩时序只一例、砖画拼合无单元信息、竹林七贤两条著录疑重复、琉璃瓦在 B.5.4 与 B.5.6 间分工未经来源检验等研究债务。B.5.7 补上第七层“功能如何变成造型”：五件彼此不相接的史前陶器共享一件事——来源都用“功能”解释形制，但证据密度分三档。陶鬶有完整演变链（田自秉：大汶口圆腹小颈、口在腹上→腹扁口前移→三实足变三空足、绳纽把手→龙山“冲天流”），是六册中唯一把仿生与功能写成同一过程的器形链——“以三条肥大中空的款足代替鼎的实心足，扩大受热面积”，空足同时提高受热与形象化程度；陶甑有可数结构（穿孔底）而完全无仿生，功能是“促进煮食向蒸食的过渡”；陶埙有音孔数（一孔、二孔），“模仿鸟鸣”以“诱捕禽兽”，仿的是声不是形，与同段陶号角“模仿牛角的造型和声音”形成“仿形／仿声／形声双仿”三路对照；良渚的鱼鳍形足陶鼎与水鸟形陶壶只有“具有代表性”“摹拟自然形态”的类型判断，无尺寸、足部形态与出土单位。由此立三条判断：一是功能结构的可指认程度决定记载方式（可数结构越多，记载越具体）；二是“像”与“用”的关系有三档——同向（陶鬶）、无关（陶甑）、仿生可辨而功能不可辨（良渚两器），陶埙另立“仿声”一档；三是本 B.16 是 B 维度第十二条前近代 Theme，v1.45 另立，按“原理—文本—器具—证据”materialize，下设 1 个 Topic、主挂载 3 个 KU 与次挂载 4 个 KU：杠杆、滑轮与《墨经》入 B.16.1「省力原理与器具的分置：杠杆、滑轮、桔槔、辘轳与权衡秤器」作主挂载，桔槔与辘轳（主挂 B.12.2）、权衡秤器（主挂 B.13.2）、陶井（主挂 B.5.3）作次挂载，合计 7 条 membership。这是本库首个主挂载少于次挂载的 Theme：六册中“简单机械”从未作为类别出现，可作为主挂载的只有两条声明无实物的原理条与一部力学文本，四条器具分散在提水、计量、明器三条线里。第一个结构事实是**原理条与器具条从不互引**：杠杆条自陈“来源未给实物”并声明“本条不把桔槔、秤器、滑轮的具体构造写入，另见相关条目”，而桔槔只说“杠杆配重”、滑轮只说“改变力的方向”、权衡秤器只说“利用杠杆原理”，无一条反向回指。第二个事实是**“省力”有两种写法**：原理条写“平衡”（杠杆作为平衡的原理、《墨经》“绳直，权重相若，则上矣”），器具条写动作（一升一落、缠绕滑动、改变力的运动方向），二者之间没有换算，无一处给力臂比、配重比、轮径比、起重能力或功率。第三个事实是**唯一的实物证据来自别的线**：同时有实物、文本与术语的只有权衡秤器（长沙楚墓春秋等臂秤具、《墨经》衡木本标权与“力臂”释义），却因目的在计量而主归 B.13.2；滑轮唯一的器物侧证据是东汉陶井模型图注（李立新 2011），而滑轮条引的是汉画像石“泗水捞鼎”，两条不同册、不同证据类型。证据类型三种而不通约：图像（泗水捞鼎）、实物（长沙楚墓等臂秤具、大冶铜绿山辘轳两件）、图注（陶井）。《墨经》在三册中都作“造物的科学知识”而非工艺书，提供术语与命题而不提供器具形制。边界上不收翻车（链式提水，与杠杆、轮轴、滑轮无直接原理关联）、不收农具（B.12）、不收计量标准与货币（B.13）、不收水利工程（B.15）、不收兵器甲胄（B.9.4）、不收其他明器（B.5.3）、不收车轮指南车水碓等轮轴器械、不收近代机械（B.1/B.4）；六册无斜面、楔、螺旋、齿轮条目，故只有一个 Topic 是库存限制而非取舍。研究债务：7 条中 medium 5、low 2（杠杆、陶井），全部 tentative；两条原理条无实物、器具条只写动作，无一处量化；《墨经》引文篇名未给、原本未见；“杠杆原理在石器时期被发现”是推测性回溯。次挂载四条的主归属 Theme（B.12.2、B.13.2、B.5.3）正文与边界仍写“简单机械线尚未物化”，需后续维护同步。

B.18 是 B 维度第十四条前近代 Theme，v1.47 另立，按“等级符号—形制名目—成衣实测—护具关联”四层 materialize，下设 5 个 Topic、主挂载 36 个 KU、无次挂载：冕服制度、冕冠与冕旒、祎衣、晋武帝司马炎冕服、霞帔与燕居服入 B.18.1「冕服与冠服等级：冕服制度、冕冠与冕旒、祎衣、霞帔与燕居服」，原始服装、秦代服饰、汉代袍服、深衣、禅衣、素纱禅衣、马王堆贵夫人辛追服饰、龙凤虎纹绣衣与集宁路刺绣夹衫入 B.18.2「上衣下裳与深衣形制：原始服装、深衣、袍服与汉代成衣」，圆领袍衫、杂裾垂髾服、比甲、袄、辫线袄、襦、衫与两裆衫、衲裆入 B.18.3「袍衫袄襦与两裆：隋唐圆领袍、北朝短衣与元代辫线袄」；裙、襦裙、裥裙、石榴裙、羊肠裙、安乐公主羽裙与晕絰提花锦裙入 B.18.4「裙制：裙、襦裙、裥裙、石榴裙、羊肠裙与两条唐裙」（v1.48 续建）；幅巾、幞头、顾姑冠、假髻、佛妆与帔子入 B.18.5「首服与妆饰：幅巾、幞头、顾姑冠、假髻、佛妆与帔子」（v1.49 续建）。本 Theme 的结构判断是**六册写前近代服饰，按“等级”写还是按“形制”写**，两种写法几乎从不共处一段。等级侧只有三种可数符号：数（南朝冕旒皇帝 12、皇太子 9、三公 8、诸卿 6；霞帔一至七品禽纹）、色（秦代不同等级官员袍色不同而衣料都是绢织；宋代赐佩金银鱼袋者用紫绯、低级官吏只可黑白）、配伍（明代皇后祎衣配素纱中单、玉革带、青色加金饰的袜舄）；三种符号都不与任何一件衣裳的尺寸、裁片或用料同时出现。形制侧只有名目与穿法：深衣五册互证命名、裁法（上下连属与分裁缝合两说）、续衽钩边与礼制依据（规矩权衡），却无衣长与袖宽；汉代袍服给部件名（袖口收紧称祛、全袖称袂）与下摆处理（花饰边缘、密裥、月牙弯曲、曲裾与直裾），也无尺寸；秦代服饰只以兵马俑为形象资料，结论是“与战国无大差别”。**唯一的成衣实测是一件器物**：素纱禅衣衣长 128 厘米、重 49 克、镶缘 5.6 厘米，袖长两册作 190 与 180 厘米相差 10 厘米，它与任何一条等级记载都不共段。**服饰与护具只有一处相接**：两裆衫“形制缘起于铠甲”是六册中唯一把衣裳与甲胄连起来的记载，皮甲条有构造（合甲、七札、皮条串联如竹简）而无尺寸，两条从未互引。划分标准不是朝代而是“这件衣物在六册里回答什么”：B.18.1 回答等级如何被写成可数符号，B.18.2 回答“衣—裳”如何被写成形制名与裁法，B.18.3 回答上身短衣与袍衫如何被写成一组各自命名的名目，B.18.4 回答下身裙制如何被写成“形”与“色料”两条互不接合的谱系，B.18.5 回答头部与面部装饰的等级是“可读”还是“消解”。覆盖上，本 Theme 是继 B.14 之后第二个六册全覆盖的 Theme（夏燕靖 2016 15、赵农 14、夏燕靖 2009 13、田自秉 5、高丰 2、李立新 2），但覆盖方式相反：B.14 靠器物层分散覆盖，本 Theme 靠深衣与素纱禅衣两条多册互证带动，其余条目多为单册来源。两处名实并列不裁：两裆衫（赵农）与衲裆（夏燕靖 2009）描述近同而名称不同；霞帔在夏燕靖两版与赵农之间时代与形态均不一。**裙制另有两条互不接合的谱系**（v1.48 由 B.18.4 补上）：一条是「形」，可数的只有多幅、长裾高腰、百褶三个工序词且都无数量；一条是「色与料」，五色经线、石榴之红与合百鸟毛；两条谱系在六册中没有交集段落，唯一实物（晕絰提花锦裙）只说得出织法、说不出裙式。裙的等级也不靠品级数字，而靠长度（曳地／紧短）与材料（毛羽／染色）两极。**首服与妆饰另把等级分界推到两个极端**（v1.49 由 B.18.5 补上）：一端是工序——幞头是全 Theme 唯一给出构造工序的一条（四角成带、软脚加铜铁丝成硬脚、盛唐加衬木藤皮革），仍无巾幅尺寸；另一端是等级——顾姑冠以冠高与顶部装饰标示身份（翠花或五彩帛对野鸡毛，限有爵命者与已婚女子），佛妆把等级写在头饰材料上（金冠、硬帽、皮帽、毡帽、头巾，头巾要纳马驼才能裹）；而幅巾（两汉冠服制度“已难维持”）、帔子（“以后各朝尊卑都用”）与宋代幞头（“不分贵贱都能佩带”）写的都是等级消解。六条中唯一的数量是顾姑冠“四五尺”的柳条或银枝长度，不是冠高。该 Topic 只出自三册（夏燕靖 2009 四、赵农 三、夏燕靖 2016 二），高丰、田自秉与李立新零覆盖，是 B.18 已建 Topic 中覆盖册数最少、也是唯一全为 term 无 work 的一个；帔子属披饰而非首服，收入该 Topic 的依据是等级表达问题相同而非部位相同。鞋履与甲胄四条仍在库中等候，裙制七条与首服妆饰六条已全部落地。
