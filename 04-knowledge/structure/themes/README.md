# structure/themes

Theme 是五级主干的 Level 3 必要层。当前已有 20 个 `pilot` Theme：`A.1` 中国设计史书写与学科建构、`B.1` 近代造物技术转型、`B.2` 近代织绣与服装工艺、`B.3` 近代建筑、室内与建造技术、`B.4` 传统工艺的近代生产与转型、`B.5` 陶器工艺与陶系传统、`B.6` 瓷器工艺与窑业传统、`C.1` 商业美术与广告、`C.2` 书籍装帧、印刷与出版、`D.1` 洋务企业与近代工业组织、`D.2` 服饰制度与近代生活、`D.3` 近代城市、建筑制度与职业、`D.4` 近代设计教育、职业与机构、`D.5` 传统工艺的近代组织、展赛与政策、`E.1` 跨文化设计交流与展示、`E.2` 外来文明与造物技术的跨文化传入、`E.3` 跨文化形式的命名与类型化、`E.4` 晚清冲击与自强路径、`E.5` 服饰改制与族群身份、`E.6` 近代女装与身体改装；其余代码仍只是示例，不代表本库已有这些主题。

A.1 从 1982–2016 年的工艺美术史与设计史书写 materialize：承接田自秉、王家树、龙宗鑫的工艺美术通史，高丰、夏燕靖、赵农、李立新的设计史／艺术设计史教材与引论，1982 年《中国工艺美术史》编写完成事件，以及大历史观、长时段、轴心时代、阶段性突破推进、变与统、本元特征、六大设计文化区域、南秀北雄等分期与解释框架，以及盘庚迁殷、盘庚、安史之乱、靖康之难四个断代锚点；下设 3 个 Topic，主挂载 29 个 KU。A.1.1 取工艺美术史通史书写，A.1.2 取从工艺美术史到设计史的命名与教材建构，A.1.3 取设计史分期与解释框架；具体设计史内容归 B/C/D，设计教育制度归 D.4。A.1.3 保留各框架的来源与证据强度差异，不合成统一分期体系；断代锚点列为框架之外的最低一层，只提供切口、不构成解释，四个锚点的年代异文并列保留。

B.2 与 D.2 由 T2「纺织、服饰与生活样式」按主维度拆分：B.2 承接织绣、染织图案与服装工艺，D.2 承接剪辫易服、服制条例与中山装的国家礼服制度。旗袍主维度为 E，已由 E.6.1 承接。

B.3 由 T5「建筑、城市与室内设计」的 B 维度部分 materialize：承接上海砖瓦锯木厂、上海汇丰银行、沙逊大厦、中山陵、吕彦直、梁思成、中国固有式建筑与《中国建筑史》；下设 2 个 Topic，挂载 8 个 KU。T5 的城市、机构与规划材料留给后续 D 维度 Theme，外来式建筑术语主维度为 E，暂不并入。

C.1 由 T3「商业美术与广告」materialize：承接月份牌、报刊广告、书刊广告、招贴、幌子与机构标识；下设 2 个 Topic，挂载 14 个晚清民国 KU。月份牌的消费市场属性不强行挂 D.2，书籍装帧与印刷工艺留给 C.2，1949 年后的广告与标志不并入。

C.2 由 T4「书籍装帧、印刷与出版」materialize：承接石印、铅印、铜版与照相制版，清末官书局与点石斋，民国书装家群体，以及《北平笺谱》《点石斋画报》《呐喊》《彷徨》《新青年》《万象》等书籍／期刊样本；下设 3 个 Topic，挂载 27 个 KU。《生活周刊》归 C.1.2，商务印书馆与伊文思图书公司不因机构名并入，钱君陶暂不双挂。

D.3 由 T5「建筑、城市与室内设计」的 D 维度部分 materialize：承接上海、南京、广州、上海市市中心区域规划、中国营造学社、朱启钤、盖茨公司与亚平艺术装饰公司；下设 2 个 Topic，挂载 8 个 KU。B.3 已承接建材、结构、立面与纪念建筑本体，D.3 只取城市制度、研究机构、建材流通与装饰业，不重复计数；外来式建筑术语主维度为 E，暂不并入。

B.4 由 T7「传统工艺的近代命运」的 B 维度部分 materialize：承接景德镇瓷业公司、湖南瓷业公司、延安玻璃厂、桥儿沟陶瓷厂与关中建华瓷厂；下设 2 个 Topic，主挂载 5 个 KU。T7 的太平天国、诸匠营、百工衙、南洋劝业会、广东工艺局、磁州陶瓷研究所留待 D 维度 Theme；巴拿马赛会与 1851 年万国博览会仍留 E 维度；王大凡《富贵寿考瓷板》因证据过薄暂不挂载。

B.5 是 B 维度第一条前近代 Theme，按“成形—烧成—原料”三项技术变量与“日用—明器—建筑—茶器”四种用途两轴 materialize：陶器、制陶、彩陶制作工艺、泥条盘筑法、轮制法、封窑技术、陶轮、新石器时代、仙人洞陶器出土与仙人洞遗址入 B.5.1「陶器的起源与成形、烧成技术」，彩陶、黑陶、蛋壳黑陶、五型彩陶、陶器器形与仰韶、马家窑、大汶口、龙山、良渚、屈家岭、齐家、辛店八个考古学文化入 B.5.2「史前陶系、彩陶类型与文化分区」，灰陶、白陶、暗纹陶、彩绘陶、几何印纹陶、几何印纹硬陶、明器、秦兵马俑、说唱俑、彩绘陶仓楼、陶井、模塑结合制陶俑、绿釉陶楼、魂瓶与茧形壶入 B.5.3「陶器的三重分化：材质、装饰与随葬」；下设 3 个 Topic，主挂载 42 个 KU。陶与瓷按材料分工：B.5 只收陶器、低温釉陶、建筑用陶与紫砂，瓷器与原始瓷留待 B.6；B.5.4、B.5.5（低温釉陶、紫砂与明清陶器）与建筑用陶 Topic 尚未建立，候选池登记于对应批次 manifest，不预先物化空 Topic。B.5.3 补上第三层“分化的同源性”：商周至六朝陶器同时在材质（灰陶按烧成气氛、白陶按原料、硬陶按火度——三把尺子不能排成演化线）、装饰（绳纹是成型副产品、暗纹仅斜光可见、彩绘为明器专用，构成可见性梯度）与用途（日用／随葬明器／建筑模型）三个方向分化，明器内部又分等身写实（兵马俑 1.75—1.85 米、7000 余件）与缩小模型（陶仓楼 78.2 厘米、陶井、绿釉陶楼）两极；“青铜占礼器位置后陶器重新定位、白陶因此消失”是本库解释框架，六册未如此因果化。史前部分的年代、文化与类型归属在六册间不一致，“彩陶文化”与“仰韶文化”是否等同、良渚是否属龙山文化四类型、彩陶与彩绘陶的工序定义，本 Theme 均并列保留、不裁；B.5.3 另追加彩绘陶按用途定义而非工序定义、几何印纹硬陶时代与成型法三处冲突、兵马俑窑址未发现、模型明器尺度几乎全缺等研究债务。

B.6 是 B 维度第二条前近代 Theme，按“材料判据—窑业条件—命名系统”三层 materialize：原始青瓷、青瓷、白瓷、黑瓷、缥瓷、秘色瓷、花釉、唐代著名青瓷窑，越窑、上虞窑址、均山窑、德清窑、瓯窑、婺州窑、岳州窑、邢窑，屯溪西周墓、金坛鳖墩西周墓、绍兴富盛战国窑址、法门寺塔基地宫，青釉瓷尊、东汉青瓷高足碗、青瓷谷仓罐、莲花尊、越窑莲花碗荷叶形托、黑釉四系盘口壶、白釉绿彩四系莲瓣缸、花釉腰鼓与六朝青瓷装饰六法入 B.6.1「由陶到瓷：原始瓷、青瓷与白瓷」；龙窑、馒头窑、葫芦窑、陶窑、匣钵、垫圈、支钉支烧法、覆烧法、支圈覆烧、叠烧、吹釉法、化妆土、绞胎与火石底入 B.6.2「窑炉、窑具与制瓷工艺」，五大名窑、宋代窑系、官窑、哥窑、柴窑、汝窑、钧窑、定窑、董窑、宋代官窑窑址、景德镇窑、龙泉窑、耀州窑、磁州窑、吉州窑、建窑、德化窑、赤峰缸瓦窑屯辽窑、抚顺大官屯窑、漳州平和、何朝宗、舒翁、舒娇、黄卖九与定窑孩儿枕入 B.6.3「窑系、名窑与窑业组织」，宋瓷装饰九法、雕釉、珍珠地划花、木叶与剪纸贴花、瓷绣花、开片、窑变、红釉、黄釉、郎红、影青、甜白、卵白釉瓷、褐彩、釉下彩、釉上彩、明清彩瓷装饰技法、古彩、填彩、素三彩、五彩、斗彩、粉彩、珐琅彩、广彩、赤绘、青花瓷、釉里红与成化斗彩鸡缸杯、宣德青花执壶、青花釉里红盖罐、蓝釉白龙纹梅瓶、蓝釉描金匜、影青执壶、青白釉虎枕、雍正粉彩仕女采桑图盘入 B.6.4「胎装饰、釉装饰与彩绘：瓷器装饰的三层技术」，梅瓶、玉壶春瓶、蒜头瓶、鸡冠壶、凤首壶、鸡腿坛、三足尊、盘口壶、天鸡壶、执壶、高足杯、元代瓷器器形、渣斗、倒流壶、省油灯、夹耳罐、桌器、多子盒、侈口、辽瓷、追韩信图梅瓶与蒙恬将军玉壶春瓶入 B.6.5「器形、器类与成套组合：瓷器形态的四种生成路径」；下设 5 个 Topic，主挂载 126 个 KU。陶与瓷按材料分工：B.6 收原始瓷、色釉瓷、窑系与官窑，陶器与低温釉陶仍归 B.5；原始瓷在来源中同时被称“釉陶”与“瓷器”，本 Theme 只开交叉引用，不做双挂载。B.6.3 补足第三层“命名系统”，按合称—窑系—单窑三级名单、四种命名依据与四级证据强度组织，并把御器厂、浮梁瓷局、瓷窑官与景德镇四条 D 维度条目留作跨维度接口而非跨维度挂载；石湾窑为精陶名窑，留 B.5.5。B.6.4 是四条 Topic 中唯一横跨“窑业条件”与“命名系统”两层的：其装饰工序按胎装饰（刀具、模具、针具与贴片）、釉装饰（釉料配方与窑内气氛）、彩绘（彩料与烧成次数）三个技术时点分层，其品种名按呈色剂、督陶官姓氏、釉面视觉、感官评价、烧造机构、装饰工序、产销地、域外命名八型分布，几乎不依赖地望，故不能像窑口名那样形成稳定分类；斗彩与五彩、填彩之间并存四种互不兼容的谱系结构，本 Theme 只登记不裁。B.6.5 补上第四层“形态的生成”：取象（原型在器物之外：梅、蒜头、鸡冠、皮囊、凤首、青铜尊）、追加（在既有器形上加附件：盘口壶加鸡头、元代壶加流与柄、杯加竹节高足）、用法定形（渣斗的阔沿浅腹、省油灯的夹层、倒流壶的内壁分割、夹耳罐的带孔瓷片）与组合成类（嘉靖桌器一桌二十七件、多子盒一器多格）四条路径并存，四者是同时发生的机制而非四个阶段，且常叠加于同一器物（鸡冠壶＝取象＋追加）；器名则按名随形改（元代以后以有无嘴分壶与瓶）、形存名移（蒜头瓶跨秦代铜陶与元代瓷器、多子盒跨多格食器与宋瓷盒与汉漆套盒）、名多形一（天鸡壶三名、执壶二名、鸡冠壶五名）三种方式与形脱节，故谱系不能画成一棵树。两条谱系链在本 Theme 内分列：盘口壶→天鸡壶→龙耳壶有祖型与中间环节、可判定，玉壶春→蒜头瓶／凤尾瓶与秦代已有蒜头瓶冲突、不可判定。辽瓷以中原式与契丹式两大类器形作族群标识，是全 Topic 唯一以器形回答“谁造的”的材料；侈口作跨陶瓷与金属器的描述语汇，说明器形条目借用的形式语汇并非瓷器专有。唐三彩的二次烧成法属低温釉陶，留 B.5.4，不在 B.6 内双挂。秘色瓷的件数与朝代归属、哥窑与柴窑的存在性、白瓷创始年代，本 Theme 并列保留、不裁。

D.5 由 T7 的 D 维度部分 materialize：承接太平天国、诸匠营、百工衙、广东工艺局、南洋劝业会、磁州解放区陶瓷研究所，以及大生产运动、《解放日报》纺织社论与高阳纺织复兴；下设 4 个 Topic，主挂载 9 个 KU。B.4 已承接瓷业公司与解放区日用工艺生产，D.5 只取组织、展赛、政策与动员报道；桥儿沟陶瓷厂的技术面归 B.4.2，其 1944 年《解放日报》报道作为 D.5.4 的宣传材料交叉引用；巴拿马赛会主维度为 E，暂不并入；王大凡《富贵寿考瓷板》仍不挂载。T7 至此完成 B／D 两个主维度的试点拆分，不表示整体闭合。

D.4 由 T6「设计教育、职业与机构」materialize：承接船政绘事院、江南船政局工艺学堂、两江师范学堂、李瑞清、北平国立艺专、杭州国立艺专、庞薰琹、尚美图案馆与中国商业美术作家协会；下设 3 个 Topic，主挂载 9 个 KU，陈之佛以尚美图案馆创办人身份次挂载 D.4.3。1950 年代中央工艺美术学院、雷圭元、张仃、沈福文、郑可与杭州艺专 1950 年改组只作边界；李有行因主维度为 C 且无 `primary_theme`，本批不制造部分挂载。

E.1 是 E 维度首个 Theme，按“博览会展示—国际评奖—专业会议”三渠道 materialize：承接 1851 年万国博览会、1915 年巴拿马赛会、1793 年马葛尔尼使华与 2010 年上海世博会，以及包豪斯 1989 年香港展、伊夫·圣·洛朗 1985 年回顾展、1995 年计算机艺术研讨会、1997 年中国当代艺术设计展、1999 年中国—意大利工业设计周、2000 年 CAD 国际会议与汉诺威工业设计论坛；下设 2 个 Topic，主挂载 11 个 KU。E.1.1 取世界博览会与中国设计展示，E.1.2 取 20 世纪后期设计观念的国际引入。马葛尔尼使华只作展示体系前史，2010 年上海世博会在来源中只是 2008 年预期表述；包豪斯、伊夫·圣·洛朗等条目只具事件性证据强度。E 维度其余候选（中国风、外来式建筑、旗袍、天足运动等）留待后续 Theme。
