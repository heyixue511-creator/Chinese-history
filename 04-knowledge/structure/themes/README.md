# structure/themes

Theme 是五级主干的 Level 3 必要层。当前已有 8 个 `pilot` Theme：`B.1` 近代造物技术转型、`B.2` 近代织绣与服装工艺、`B.3` 近代建筑、室内与建造技术、`C.1` 商业美术与广告、`C.2` 书籍装帧、印刷与出版、`D.1` 洋务企业与近代工业组织、`D.2` 服饰制度与近代生活、`D.3` 近代城市、建筑制度与职业；其余 A.1 等仍只是代码示例，不代表本库已有这些主题。

B.2 与 D.2 由 T2「纺织、服饰与生活样式」按主维度拆分：B.2 承接织绣、染织图案与服装工艺，D.2 承接剪辫易服、服制条例与中山装的国家礼服制度。旗袍主维度为 E，暂未挂载。

B.3 由 T5「建筑、城市与室内设计」的 B 维度部分 materialize：承接上海砖瓦锯木厂、上海汇丰银行、沙逊大厦、中山陵、吕彦直、梁思成、中国固有式建筑与《中国建筑史》；下设 2 个 Topic，挂载 8 个 KU。T5 的城市、机构与规划材料留给后续 D 维度 Theme，外来式建筑术语主维度为 E，暂不并入。

C.1 由 T3「商业美术与广告」materialize：承接月份牌、报刊广告、书刊广告、招贴、幌子与机构标识；下设 2 个 Topic，挂载 14 个晚清民国 KU。月份牌的消费市场属性不强行挂 D.2，书籍装帧与印刷工艺留给 C.2，1949 年后的广告与标志不并入。

C.2 由 T4「书籍装帧、印刷与出版」materialize：承接石印、铅印、铜版与照相制版，清末官书局与点石斋，民国书装家群体，以及《北平笺谱》《点石斋画报》《呐喊》《彷徨》《新青年》《万象》等书籍／期刊样本；下设 3 个 Topic，挂载 27 个 KU。《生活周刊》归 C.1.2，商务印书馆与伊文思图书公司不因机构名并入，钱君陶暂不双挂。

D.3 由 T5「建筑、城市与室内设计」的 D 维度部分 materialize：承接上海、南京、广州、上海市市中心区域规划、中国营造学社、朱启钤、盖茨公司与亚平艺术装饰公司；下设 2 个 Topic，挂载 8 个 KU。B.3 已承接建材、结构、立面与纪念建筑本体，D.3 只取城市制度、研究机构、建材流通与装饰业，不重复计数；外来式建筑术语主维度为 E，暂不并入。

Theme 必须在首批摄入后由稳定问题群形成，新增、拆分或合并必须经过 `evolve-hierarchy`。Cluster 只能提供发现候选，不得写入本目录。不得为了填满结构而创建空 Theme。
