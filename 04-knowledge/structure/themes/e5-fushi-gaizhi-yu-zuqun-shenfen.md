# E.5 服饰改制与族群身份

## 核心问题

服饰改制为什么总是与族群身份绑定？战国赵武灵王以“便用”为由引入胡服骑射，北魏孝文帝以“华典”为由令群臣皆服汉魏衣冠，孝明帝之后却出现“帽上著笼冠，裤上著朱衣”的胡汉杂糅——同一条时间轴上，服饰先后向游牧与向中原两个方向被改制。

“便用”与“礼制”两种标准如何在同一服饰体系中并存？服饰改制是为了解决功能问题、表明政治归属，还是两者在同一动作中被同时完成？带钩这类附件创新，在“功能移植”中承担什么角色？

## 边界

- 纳入：胡服的族属与形制、胡服骑射的改革过程与带钩附件、孝文改制的汉化措施与“群臣皆服汉魏衣冠”、北魏胡汉杂糅的服饰样式与孝明帝再改制、孝文帝迁都洛阳作为改制的背景。
- 排除：具体服饰的裁剪、面料、纹样与织造工艺，归 B.2；本 Theme 只处理改制的动因、标准与后果。
- 排除：近代剪辫易服、服制条例、中山装与国家礼服，归 D.2；本 Theme 不处理近代服制。
- 排除：近代女装（旗袍、短袄套裙、时世装）与天足运动，留待后续 Theme；它们涉及性别与身体，边界不同。
- 排除：北魏政治制度史、迁都的行政与军事过程；本 Theme 只取迁都作为服饰改制的背景条件。
- 边界说明：五条材料的证据都只有一句或一段，无改制诏令、服制细目与实施范围；本 Theme 只证明“改制被记载、方向被陈述”，不证明改制的实际覆盖面，也不证明服饰变化改变了族群认同。

## 支撑结构

- 理论支撑：以“改制方向”与“正当性依据”两个变量区分三次改制——胡服骑射是向游牧方向改制、依据是“便用”；孝文改制是向中原方向改制、依据是“华典”；孝明帝再改制是在胡汉杂糅之后重新确立“魏法”。方向相反，依据不同，但都把服饰当作可被政治裁定的对象。
- 实证/材料支撑：5 个 KU：2 个术语、3 个事件；胡服与孝文改制为两册来源，胡服骑射、孝明帝服饰改革、孝文帝迁都洛阳多为单册单段。
- 文献支撑：各 KU 的 `sources`；具体行号见条目。

## 未解决问题

- 胡服骑射无具体年份；来源只作“战国时期”。
- 胡服的形制只有“短衣、长裤、靴子”六字，无裁剪、面料与纹样；带钩（钩络带）无实物、年代与考古证据。
- 《史记·赵世家》的引文只有三句，无篇目段落与版本；“力排众议”“说服贵族王室”的过程无细节。
- 孝文改制无诏令、服制细目与实施范围；“群臣皆服汉魏衣冠”只有一句概括。
- 孝明帝服饰改革无诏令、服制细目与年份；《洛阳伽蓝记·城东》与《南齐书·魏虏传》的引文均未给版本。
- 孝文帝迁都洛阳无年份、诏令、反对势力与都城布局；迁都与服饰改制之间的关系，来源未论。
- 三次改制之间的因果未建立：来源没有说明孝明帝改制是否直接回应孝文帝改制后的“胡汉杂糅”。
- “北魏汉化的历史进步意义”是来源的评价，不是本 Theme 的判断；本 Theme 不把“汉化”预设为进步方向。
- 胡服的“设计史意义”（功能优先对礼仪服饰的冲击）是本库的概括，来源未如此表述。
