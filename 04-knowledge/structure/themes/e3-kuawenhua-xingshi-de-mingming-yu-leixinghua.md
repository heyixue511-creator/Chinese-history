# E.3 跨文化形式的命名与类型化

## 核心问题

跨文化的造物与建筑相遇之后，如何被命名、归类和互相参照？“中国风”是一个在欧洲被赋予的风格名，把瓷器、丝织品、漆器、壁纸等差异极大的品类收拢为一种风尚；“外来式建筑”与“中西混合式建筑”是清末民初被并列的两个建筑类型名，与已经挂载在 B.3.2 的“中国固有式建筑”共处同一组三分法；“香港”则被定位为“西方文化和技术的参照”，是一种城市尺度的参照名。

这三种命名操作分别把跨文化关系固化为风格、类型与参照系。它们共享同一套命名逻辑吗？命名是为了描述实体差异，还是为了在文化之间划出可辨认的边界？

## 边界

- 纳入：中国风、外来式建筑、中西混合式建筑、香港。
- 排除：具体建筑的材料、结构、立面与内部空间分析，归 B.3；本 Theme 只处理“类型名如何被提出与并列”。
- 排除：中国固有式建筑已在 B.3.2 挂载，本 Theme 不重复挂载，只把它作为三分法中的对照项引用。
- 排除：传入通道、载体与器物本体，归 E.2；本 Theme 不重复传入史。
- 排除：晚清战争冲击、洋务运动与辛亥革命，留待 E.4。
- 排除：旗袍、胡服、天足运动等跨文化服饰条目，留待 E.5；它们需要各自的族群身份边界审查。
- 边界说明：四个条目都只有命名层面的证据，没有形制谱系、设计师、建造年份或具体案例清单；本 Theme 只证明“这类命名在来源中存在”，不证明命名对应稳定的实体类型，也不证明命名被当时的设计实践普遍接受。

## 支撑结构

- 理论支撑：以“命名方向”区分两类操作——西方对中国形式的命名（中国风）与中国对西方形式的命名（外来式、中西混合式、香港参照）。两种方向不写成影响与被影响的等级，也不写成同一机制的两端。
- 实证/材料支撑：4 个 KU：3 个术语、1 个地点；中国风与香港各只有赵农一册一段，外来式建筑与中西混合式建筑只有夏燕靖 2016 一册一段，四条都不是多册互证材料。
- 文献支撑：各 KU 的 `sources`；具体行号见条目。

## 未解决问题

- 中国风只有赵农一册一段的宏观判断，具体国家、年代分段、代表人物、器物谱系与设计影响案例均未载。
- 外来式建筑列了上海汇丰银行、沙逊大厦、百老汇大厦、雅斯脱饭店、天津德界市议会、英界戈登堂、南通商会大厦等实例，但未给各建筑的设计者、建造年份与图版逐一核对。
- 中西混合式建筑只有类型名与别称“现代中国式”一句，无形制、实例、设计师与建造年份，confidence 为 low。
- 三分法（外来式／中国固有式／中西混合式）只有一句并列，来源未说明三类的判别标准，也未说明为何民初以前两种为多见。
- 香港只有“近百年发展历史”“东方明珠”与“西方文化和技术的参照”三项信息，参照的具体内容未载；图 10-14 给出中银大厦，正文未提及其设计者与年代。
- 中国风与香港分处两个方向，来源没有任何文本把它们并置；本 Theme 的“命名方向”是解释框架，不是来源本人的论点。
- 命名的施动者缺失：谁提出“中国风”、谁提出“外来式建筑”，来源均未交代；本 Theme 不代为指定命名者。
