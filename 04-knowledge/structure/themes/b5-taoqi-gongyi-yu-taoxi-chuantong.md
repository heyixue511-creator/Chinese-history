# B.5 陶器工艺与陶系传统

## 核心问题

陶器是六册设计史叙述中第一条完整的“材料—工艺—器形”链条。六册都从陶器起源写起，但对起源只给“藤器粘附泥胎被烘烤”一类推测；真正可比较的是三项技术：成形（手制、泥条盘筑、轮制）、烧成（氧化焰、封窑还原、控制末期窑内空气）与原料（普通黏土、羼和料、瓷土）。这三项技术各自解决了什么问题，又各自要求什么条件？为什么慢轮修整、快轮制陶与封窑技术集中出现在新石器时代晚期？

陶器在瓷器成熟之后并未被取代，而是分化为日用器、明器、建筑用陶与茶器四条支线。这种分化是技术选择的结果，还是用途与制度选择的结果？同一件“陶器”在史前墓葬、汉代陪葬与明代茶席中的功能差异，是否足以说明它属于不同的设计传统？

六册之间还有三处未裁的分歧：一是“彩陶文化是否等同仰韶文化”，二是田自秉五型彩陶（半坡、庙底沟、马家窑、半山、马厂）的划分依据，三是良渚文化应归入龙山文化四类型还是作为独立文化。本 Theme 并列保留，不代为统一。

第四条线索是「用」如何变成「形」。六册对史前陶器的功能解释分四种：受热（陶鬶的中空款足）、蒸汽（陶甑的穿孔底）、发声（陶埙的音孔）、仿生（良渚的鱼鳍形足陶鼎与水鸟形陶壶）。四者的证据密度并不相同——前三者各有可数的结构，后两者只有「具有代表性」「摹拟自然形态」的类型判断。本 Theme 因此把「功能陶器」限定为有可指认功能结构的陶器，并追问：**功能结构的可指认程度是否决定了器物的记载方式；「像」是功能的产物，还是与功能无关的造型选择。** 陶尊（刻画符号）与纯装饰陶器据此排除在功能线之外。

## 边界

- 纳入：陶器的原料与羼和料、手制／泥条盘筑／轮制的成形、封窑还原与陶窑、陶轮工具、彩陶的绘彩与烧成、史前陶系（彩陶、黑陶、灰陶、白陶、几何印纹陶）与彩陶五型、史前陶器文化分区、史前功能陶器（陶鬶、陶甑、陶埙、鱼鳍形足陶鼎、水鸟形陶壶）、商周至秦汉的陶器与明器、低温釉陶（铅釉陶、唐三彩、辽三彩、宋三彩）、建筑用陶与琉璃、紫砂与明清陶器、陶制乐器与工具、代表陶器与陶器著作中的工艺记载。
- 排除：瓷器（原始瓷、青瓷、白瓷、青花、彩瓷等）归 B.6；陶器与瓷器的分界标准在来源中不一致，本 Theme 只在必要时交叉引用。
- 排除：陶俑、陶楼、陶仓等明器的丧葬制度与社会史解释归 D；本 Theme 只取制作技术与器形。
- 排除：陶瓷贸易、外销、外来釉料与跨文化流通归 E.1／E.2；本 Theme 不处理市场与流通。
- 排除：陶器纹样的母题、图像与符号解释归 C；本 Theme 只把纹样作为工艺与器表的组成部分。
- 排除：陶瓷文献（《陶说》《阳羡名陶录》《景德镇陶录》等）的文本、版本与著录问题归 A／C；本 Theme 只在文献记载工艺时引用。
- 边界说明：史前部分的年代、文化与类型归属在六册间不一致，本 Theme 并列保留；来源未给的尺寸、出土单位与检测报告，本库不据来源外材料补写。

## 支撑结构

- 理论支撑：以“成形—烧成—原料”三项技术变量与“日用—明器—建筑—茶器”四种用途两条轴组织陶器材料。技术变量用于解释工艺选择，用途变量用于解释同一工艺为何在不同时期产出不同器物；两条轴交叉，避免按朝代罗列。B.5.3 补上第三层“分化的同源性”：青铜器占据礼器位置后，陶器在日用（灰陶）、仿铜（白陶刻饕餮、夔、回纹）、随葬（明器）三个方向重新定位，白陶“商代以后不复发现”是这条假说的检验点。这一层把 B.5.1 的技术变量与 B.5.2 的类型变量接到用途轴上，但它是本库的解释框架——六册没有把材质、装饰、用途放在一个因果链上讨论。B.5.3 另把材质命名分成三把尺子（灰陶按烧成气氛、白陶按原料、硬陶按火度），因此三者不能排成演化线；装饰按可见性分成三档（绳纹是成型副产品、暗纹仅斜光可见、彩绘为明器专用）；明器尺度分成两极（兵马俑等身写实、仓楼与井为缩小模型），两极对应被替代对象不同（人／物），而非工艺水平高低。B.5.4 补上第四层“低温釉陶的用途分化”：低熔点（铅釉 700—800℃）是可烧、可薄挂、可由金属氧化物定色的物性前提；二次烧成（素烧 1000—1100℃、釉烧 850—950℃）把“胎要硬、釉要亮、色要稳”拆到两道工序，辽三彩与宋三彩沿用同一结构而第二次烧的对象从釉变成彩；用途上分出随葬明器（三彩，曾列入官府丧葬明文规定）、建筑构件（琉璃瓦、琉璃砖塔、琉璃照壁）与陈设供器（元代琉璃香炉、明代法华器）三条线，三条线共用一套釉而各自发展胎料、规格与生产组织。B.5.4 同时立一条判断：“低温釉陶”不等同于“铅釉陶”——法华器以牙硝助熔、宋三彩在白釉上加红绿彩再低温烧，两者都在低温呈色而都不属铅釉一次挂彩。B.5.5 补上第五层“胎面的三种状态”：三条路线共同的不是“不用釉”，而是把装饰面从釉转回胎——宜兴全部露出（不挂釉，以泥色、造型与浅刻立身）、石湾露出一部分（部分上釉、局部露胎，以胎釉色差立身）、荣昌加工胎面（红白双色泥贴花嵌花、两色混合成金黄、铁线划花）。B.5.5 另立两条判断：其一，紫砂的具名师承（供春—时大彬—陈鸣远—杨彭年—顾景舟）承担了作坊、行会与官营制度缺位时的位置，可追踪的只有师徒、文人延揽、文人设计艺人制作、艺人加学院四种关系，是关系史而非制度史；其二，紫砂有具名谱系而石湾、荣昌全无名姓，差别可能来自工艺水平，也可能只来自文献选择（紫砂有文人品题，石湾与荣昌只见于通史综述），六册无法区分，故登记为记录问题而非工艺高低的证据。B.5.6 补上第六层“建筑构件的同一次成形”：陶器离开器皿成为构件后，结构、连接与图像三项要求落在同一批泥上。瓦当的图像位置由构造确定——它是筒瓦的瓦头，“挡住木椽”与“进行图案装饰”是同一构件的两个功能，尺寸由椽径定，形式由观看距离、陶质与模印法三项制约（高丰）。连接件独立化是六册中唯一一条“把一体成形拆成两件”的工艺选择——瓦钉与瓦身分离，使固定连接增强、瓦坯制作较易。模印则是端头、砖面、砖体与整壁四个尺度共用的成形法：瓦当模印、方砖阴刻花模套印、空心砖四片模印后粘合再封泥片开孔、砖画用 200 多块砖拼合，同一技术把图像从一次性绘制变成可复制的产品。B.5.6 另立两条判断：其一，砖的结构角色发生过一次从贴面到砌拱的转变——西周实心砖“背面四角有乳钉”贴于墙面，是饰面；汉代才有“楔形和榫头形”异形砖“砌垒拱形的顶部”，两处相隔数百年而无过渡材料，此判断标为本库解释框架；其二，画像砖同时是墙与画，空心砖把“中空故易烧、体轻、可防潮”与“四片泥坯各印花纹再粘合”写在同一段，结构与图像由同一批泥片承担，不是先做构件再装饰。

## 未解决问题

- 陶器起源只有“藤器粘附泥胎被烘烤”一类推测，六册均未给实验考古、年代序列或最早陶器的完整器物描述。
- 仙人洞“最早陶器”的年代在六册中统一为距今 8000 多年；来源外的新测年不在本库证据范围内，本 Theme 不据以改写，但记录该边界。
- “彩陶文化”与“仰韶文化”是否等同，来源自相矛盾（一册等同、另一册分设两条并加注说明倒置），本 Theme 不裁。
- 田自秉五型彩陶的划分依据（器形、纹样、分布、年代）未统一说明；五型之间的先后与承继关系只有“由某型发展而来”一句。
- 良渚文化的归属三说并存：龙山文化四类型之一、独立考古学文化、六大原生设计区之一。
- 彩陶与彩绘陶的工序定义在四册间相反：田自秉、高丰为烧后绘，夏燕靖两版为烧前绘；本 Theme 并列，不裁定。
- 陶器与瓷器的分界标准（原始瓷、几何印纹硬陶、釉陶）在来源中不一致，B.5 与 B.6 的边界需在 B.6 建立后复审。
- 建筑用陶、琉璃与陶器工艺的关系，来源未论；本 Theme 暂按低温铅釉技术归入 B.5.4，待该 Topic 挂载后检验。
- 陶器纹样的工艺属性与视觉符号属性如何分工，B 与 C 的边界尚未在陶器材料上检验。
- 三重分化是否同源：B.5.3 的“青铜占礼器位置后陶器重新定位”是本库解释框架，六册没有任何一处把材质、装饰、用途放在一个因果链上；白陶消失只有“商代以后，不复发现”一句，且“北方制陶工人模仿南方硬陶”是来源转述的推测，未被验证。
- 白陶（`terms/bai-tao`）与商代白陶（`terms/shangdai-baitao`）为同一对象的两个条目，合并前“白陶”的证据仍不完整（只有田自秉一册）。
- 彩绘陶的工序定义相反但用途一致：四册对烧后绘花与绘花后烧分成相反两组，而“主要用作明器陪葬”四册一致；B.5.3 据此判定该类别按用途定义，但若按夏燕靖两版的工序说，彩绘陶与彩陶将无法在工序上区分。
- 几何印纹硬陶的时代三说（春秋／战国／商周）、成型法两作（泥条盘筑／泥条圈叠）、纹样一作装饰目的、一作成型的副产品，三处冲突并存，本 Theme 不裁。
- 明器的等级规定与材质分类，六册均未给；本 Theme 只能判断“随葬了什么”，不能判断“谁能随葬什么”。明器与实物之间的比例关系只有“按比例缩小”一句，六册未给任何比例数据。
- 兵马俑的窑址未发现（田自秉称“窑址实物至今尚在探寻”），件数 7000 余与约 8000 余两说，“先烧后接”与“先接后烧”两法并存而无各自适用条件、粘接材料与成品率；陶模材质、分模块数、细泥层厚度、烧成温度与彩绘颜料成分均缺。
- 模型明器的绝对尺度几乎全缺：彩绘陶仓楼 78.2 厘米是唯一一例，说唱俑、陶井、绿釉陶楼均无尺寸；陶井只有图注一条（`confidence: low`），井架结构与滑轮形制未载。
- 魂瓶的“谷仓”别名不能推定储存功能，来源本身把它与魂亭、神亭并列；无高度、腹径、墓葬、窑口与纪年。茧形壶用途未载，不能据器名或蚕茧形推定其为明器或酒器。
- 史前功能陶器（B.5.7）与商周至六朝的三重分化之间是否有连续关系，六册未作过渡叙述；B.5.7 已与 B.5.3 划清“功能决定形”与“用途决定类别”的边界，但该边界是本库分析框架，来源未作区分。
- B.5.7 的“功能陶器”定义（有可指认的功能结构）是本库分析框架：六册从未使用这一分类，陶尊被排除、陶埙被纳入的取舍也不由来源支持。
- B.5.7 的五件器物证据密度相差极大：陶鬶有完整演变链，陶甑、陶埙有结构描述，良渚两器只有“具有代表性”的类型判断；良渚两器同出一段，不能互证。
- 陶鬶的“陶鬻”讹字只在 2016 册出现，2009 册用字未逐字核对；演变链四步无遗址或层位支撑；三条款足的内部结构、容量与倾流角度全无。
- 陶甑的孔径、孔数、孔位分布全无，与鬲、釜的套接方式未说明；陶埙的测音数据、音阶、孔位与早晚关系全无，“仿鸟鸣诱捕”是功能解释而非使用证据。
- 良渚两器的尺寸、足部形态、出土单位与陶土成分全无；鱼鳍形足是支撑还是装饰、水鸟形是否影响盛水或倾倒，来源均未说明。
- 低温釉陶的釉料成分几乎全缺：铅釉陶只有“铅为盐基”一句，唐三彩只记铜铁钴锰着色，辽三彩、宋三彩、琉璃配方均未记铅含量；宋《营造法式》的黄丹—洛河石—铜末配方是六册中唯一的定量记载，但未给配比。
- 二次烧成的温度只有一组区间（素烧 1000—1100℃、釉烧 850—950℃，2009 版作 900℃），六册未给窑炉类型、升温速率、釉层厚度与成品率；“釉汁与胎体膨胀系数均衡”只有一句质量条件，未给数据。
- 宋三彩“开启了明清时代釉上五彩的发展”只有田自秉一句，且产地仅记禹县扒村与鲁山；宋三彩与明清釉上五彩之间的工艺传承链（彩料、烧成温度、施彩工序）六册未接。
- 琉璃一名两义：建筑铅釉陶与原始玻璃共用一名，六册交叉使用；本 Theme 只取建筑义，第一义（战国琉璃璧、铅钡与钠钡玻璃、李立新“玻璃器沉浮”）已由 B.7.1 以次挂载承接，两义的分界仍需在玻璃材料线复审。
- 琉璃烧造的窑场组织只有明代一段（南京琉璃窑 72 座后移门头沟琉璃渠村、高岭土制胎、十样规格），元代以前的窑场、工匠来源与行会制度未载；任塘的“琉璃待诏”职名所属机构与品秩亦未载。
- 法华器的助熔剂记为牙硝，但胎料、烧成温度、釉料配比与“凸线轮廓”的成形方法六册均未记；法华器与琉璃、与景德镇瓷胎仿烧三者之间的工艺谱系未接。
- 黄釉瓷扁壶的材质判定悬置：器名作“瓷”而胎质、釉料与烧成温度均未载，本库不作材质判定，只取北朝过渡节点的器形与浮雕证据。
- 辽三彩与唐三彩的关系只有“单色黄绿白、质地松脆、釉面粗糙”的对比描述，三册均未记辽三彩的铅含量与烧成温度；辽三彩是否直接承袭唐三彩的二次烧成结构，来源未明言。
- 紫砂起源的北宋说只有梅尧臣“小石冷泉留早味，紫泥新品泛春华”一句诗证，无窑址、纪年器或地层证据；宋始烧、明闻名、清高峰的三段分期中间全无过渡材料。
- 紫砂泥料名单两套并存（白泥绿泥大红泥／紫泥红泥黄泥白泥黑泥花泥），两套关系未交代；配比、收缩率、烧成曲线全缺，“1000 多度”是唯一的温度表述。
- 紫砂艺人名单互不一致：田自秉给“四大家”与供春三徒两份名单，李立新只给四大家，2009 把时大彬、陈鸣远与“供寿”并列；陈鸣远三处定位（供春三徒／康熙／明代）相隔百余年，供春／供寿／龚春三名并存，六册无生卒或纪年器可裁。
- 紫砂的生产组织全缺：作坊、行会、御用、外销商号、学徒制度六册均无；“蜀山约有 10 多条龙窑专烧紫砂器”是唯一的聚落级描述。顾景舟与高庄“提璧茶具”的设计分工与成果归属未载，这条“艺人＋学院”线索只有一句。
- 石湾仿钧产品三名并存（泥钧／广钧／佛山钧）且关系未交代；釉料与呈色机理、烧成温度全缺；贝丘遗址与唐代窑址无具体地点、年代与发掘信息；田自秉把特色系于“现代”而 2016 系于“入清后”，两书分期口径不一致。
- 石湾陶塑无一位具名艺人：瘦骨仙、弥勒佛、金蟾、福狮四件名品只有名目；“部分上釉、局部露胎”是唯一工艺描述，施釉范围与露胎部位的选择依据未载。“陶艺依存于大宗日用陶器”是六册唯一的经济依存判断，但无产量、产值或从业人数。
- 荣昌为单源：窑场数、产量、温度、陶土成分、铁线划花的工具与工序全缺；“两色泥混合成金黄色”是配色而非釉色，配比未载；“泡菜坛闻名中外”是评价而非产销数据。
- 宜兴“五朵金花”中的钧陶、精陶、青瓷、陶塑四类只有田自秉一段；宜兴钧陶与石湾“泥钧”同名而异实，两处钧陶的关系未论；“精陶”是来源的品类别而非陶瓷学 fine earthenware 专名，本库照录不代换。
- 两件图注级紫砂器物（明代瓜形壶、清代东陵瓜）都只有图注一行，图版未核，制作者、尺寸、藏地与递藏全缺；东陵瓜的器名所指原文未释。二者只证明“明代与清代各有紫砂器”，不构成器形证据。
- 三条路线的取材是记录的结果而非材料结论：六册在近现代产陶区并列了建水、钦县、界首、铜官、麻城、绥棱、洛阳七处，各只有一句、未立条；B.5.5 不据一句扩张，因此“三条路线”不等于“近代陶器只有三条路线”。
- 建筑用陶的窑址与生产组织全缺。“杜陵南山下，有成瓦窑数千处”是《三国志》的转引，成书晚于所记的汉武帝事，来源未说明能否直接征信；“渭河一带有官营的陶窑成片”只有一句。二者之外无窑址名称、窑主、工匠、产量、成本与销售记载。
- 砖瓦尺寸只有三个孤例且分属不同构件与时代：西周板瓦 40×20×1.3 厘米、始皇陵大瓦当直径约 40 厘米、方砖通例高约 42 宽约 48 厘米，不构成规格序列。琉璃瓦的“十样”规格是本库唯一成序列的规格记载；砖瓦没有对应的序列，无法判断汉代砖瓦是否已标准化。
- “瓦钉与瓦身分离”只有一句，未给分离前后的形制、连接方式、强度数据与出现年代；西周板瓦“上下有瓦钉和瓦环”与同册另一处“瓦上还有瓦钉或瓦环”在“和／或”上不一致，瓦钉与瓦环是否同时存在、各自分工如何，六册未载。
- 瓦当的模印工艺只有“模印法”三字（高丰），未给模与范的材质、一次成形还是分件成形、修坯与接胎方式；范的复用次数与磨损对纹样一致性的影响未载。战国“30 余种”纹样是种类计数，不是产量或分布统计。
- 瓦当纹样分类两套不合并：高丰分画像、文字、文字兼画像三类，田自秉分卷云纹、动物纹、四神纹、文字四类；高丰的“画像”涵盖后三者，且另有“文字兼画像”一类为田自秉所无，来源未说明各自依据。文字瓦当的四类内容（宫殿、寺庙、墓葬、吉祥语）只有田自秉，“大量的都是吉祥语”是评价而非统计；李立新的观念解释未落到任何一件具体瓦当。
- 瓦当的方位性只有赵农一句“方位性的瓦当纹样是汉代建筑的一种奇异标志”，未给实例、方位与纹样的对应表；四神与四方的对应来自同册“方位”段的一般叙述，不是瓦当实例的证据。燕下都黼黻纹大瓦（赵农）与“长达一米”的巨型印花瓦当（夏燕靖两版）是否同一批器物，来源未交代。
- 画像砖的实测尺寸只有方砖通例，“70 余种”（田自秉）与“80 多种”（高丰）两个计数并存而统计口径未说明；七件具体器物全部无尺寸、无厚度、无墓属、无藏地。空心砖的三项功能判断（易烧、体轻、防潮）没有壁厚、空腔尺寸与烧成温度数据，“两头加封泥片各开一孔以便烧制”是唯一的排气构造说明，但孔位、孔径与封泥厚度未载。
- 画像砖的施彩时序只有邓县一墓（“烧成后在部分画面上填染颜色，有的多达七种”），七色色名未记，其余六件是否施彩、施彩在烧前或烧后均未载；高丰另记“浅浮雕施彩与阳刻线条两种”，与邓县的“烧成后填染”是否同一工序，两册未交代。高丰说“预先把画面阴刻于木板”，田自秉说“用阴刻的花模套印”，两册都说阴刻模而高丰又列“阳刻线条”一种，阴刻模与阳刻线条的对应关系未说明。
- 砖画“用 200 多块砖拼合而成”只有一句，未给每砖画面单元、拼合顺序、编号方式、砖缝处理与整壁尺度；“200 多块”不能推定每块一图，也不能推定砖尺寸与画面分配的对应。来源对它的评价“制陶工艺的一种杰作……进入到一个新的阶段”是一句阶段判断，不是工艺数据。
- 竹林七贤有两条著录：一条作“晋代”图注且无出土地，一条作六朝三处发现（南京西善桥、丹阳胡桥、丹阳建山）。二者疑为同一对象的不同著录，日期一作晋一作六朝；本 Theme 只挂后者，前者登记为重复候选待 reconcile。
- 砖从贴面到砌拱的转变是本库解释框架，不是来源结论：赵农分别记西周实心砖贴面与汉代楔形榫头砖砌拱，两处相隔数百年而无过渡材料，六册未把二者连成结构角色的转变。
- 建筑用陶与琉璃瓦的分工未经来源检验：B.5.4 取釉面、B.5.6 取胎体与构件形制，同一件琉璃瓦被两处分别取用；该分工是本库为避免重复挂载所作的取舍，来源中没有对应的区分，须在 B.5 整体复审时重新检验。
- 瓦纹的命名先后未载：田自秉只说瓦纹“组成一条条平行的横条，如同屋上的覆瓦”，未说明纹样名是否取自瓦、也未给瓦与瓦纹的年代先后；B.5.6 只用它证明“瓦面排列”在周代已是可见的形式参照，不推定命名方向。
