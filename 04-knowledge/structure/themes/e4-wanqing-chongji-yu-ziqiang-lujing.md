# E.4 晚清冲击与自强路径

## 核心问题

1840 年之后，外部冲击如何被转写为设计史的分期起点，又如何在“师夷长技”的话语中被转化为可操作的仿造清单与工业机构？从魏源、冯桂芬到洋务派，从《海国图志》到船政局与制造局，“自强”这条路径为什么在甲午海战被判定为失败？辛亥革命之后的体制转换，是否改变了设计知识的取用方向？

本 Theme 关心的不是战争史与政治史本身，而是**冲击如何被翻译成设计史的语言**：谁把 1840 年定为起点，谁把“师夷”拆成具体器物，谁判定这条路径失败，以及这些判断各自的证据基础。

## 边界

- 纳入：鸦片战争、早期工业化、林则徐、魏源、《海国图志》、冯桂芬、洋务运动、甲午海战、辛亥革命、康有为。
- 排除：具体军工企业、造船厂、纺织企业与实业家的组织史，归 D.1；本 Theme 只取“自强路径”的话语与分期判断。
- 排除：西方机器与技术的具体形制、材料与工艺，归 B.1；本 Theme 不重复技术史。
- 排除：晚清工艺生产的具体门类与产区，归 B.4；本 Theme 只处理冲击与回应的整体判断。
- 排除：外来文明传入的通道与载体，归 E.2；跨文化风格的命名，归 E.3。
- 排除：服饰改制与族群身份，留待后续 Theme。
- 边界说明：本 Theme 的多条判断来自不同册的不同立场（高丰的分期、田自秉的工艺摧残论、赵农的“强政府”批判、李立新的冲击论修正、夏燕靖 2016 的正面定位）；本 Theme 并列这些立场，不合成统一叙事，也不判定哪一册正确。

## 支撑结构

- 理论支撑：以“冲击—分期—回应—失败判定—体制转换”五个环节串联晚清设计史叙事，并把每一环节的立场归属到具体册与具体作者。冲击与回应不写成单向因果，也不写成“西方先进／中国落后”的进步序列。
- 实证/材料支撑：10 个 KU：5 个事件、3 位人物、1 部著作、1 个术语；鸦片战争与洋务运动为多册来源，甲午海战、林则徐、魏源、冯桂芬、康有为、早期工业化多为单册单段。
- 文献支撑：各 KU 的 `sources`；具体行号见条目。

## 未解决问题

- 1840 年作为近代设计起点，六册立场不一：高丰据此分期并判定设计衰退，田自秉判定工艺美术“全面受摧残”，赵农强调白银回流与租界格局，夏燕靖把它作手工业转型分界。来源未说明这些判断的经验依据。
- 赵农一册内部对鸦片战争年份有 1840 与 1842 两说，来源未裁；本 Theme 并存不裁。
- 早期工业化是李立新对“冲击论”的修正，主张明代中后期已有工场手工业基础；来源未给起止年代、地区差异、产量与资本统计，也未与欧洲早期工业化逐项比较。
- 洋务运动的评价在两册间相反：2016 版称其“开启我国近代工业，是工业设计和现代设计孕育的土壤”，赵农称其“旧学为体、西学为用”“强国实为强政府”。来源未提供可比较的成效指标。
- 甲午海战在来源中只有一句“洋务运动失败的军事标志”，缺交战方、战场、舰船、兵力、公历年份与战役过程。
- 林则徐、魏源、冯桂芬、康有为四条都只有赵农一册的一段人物素描，缺仕途、著述书目与思想分期；林则徐 confidence 为 low。
- 《海国图志》的仿造清单（量天尺、千里镜、龙尾车、风锯、水锯、火轮机、火轮舟、自来火、自转礁、千斤秤）来自李立新，政治制度介绍来自赵农，两册未交叉印证。
- 辛亥革命在 2016 版有政治与经济后果判断，在赵农册只作《建国方略》的起点；来源未给革命与设计制度之间的中介。
- 康有为只有画学主张一句，与设计实践的关系未载；本 Theme 只把它作知识取向的样本，不作设计主张。
- 从“冲击”到“设计实践改变”之间缺中介证据；本 Theme 不把战争、条约或口号直接写成设计变化的充分原因。
