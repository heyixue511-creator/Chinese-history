# B.7 玻璃与料器：仿玉、输入与本土生产

## 核心问题

六册中没有第二种材料像玻璃这样反复被命名、又反复被误认。田自秉给琉璃两个义项：战国至汉的「原始玻璃」，与建筑砖瓦上的「铅釉陶」；并明言古时琉璃与玻璃混用，后来玻璃制品称料器，琉璃专指建筑品种。B.5.4 已取第二义，本 Theme 取第一义，并把它与「玻璃」「料器」两名并置——三名指同一材料的不同阶段与用途，名称的分裂本身就是用途分化的记录。

第二个问题是仿玉。战国琉璃已能作大件：琉璃璧最大直径 16 厘米，剑饰、印章多仿玉器作代用品，长沙 100 多座楚墓中 80 多座出琉璃璧；两汉玻璃器有碗、带钩、璧、耳珰、珠等 6500 余件，并模仿「金缕玉衣」作玻璃衣片。玻璃进入设计史的方式不是以自身材料立身，而是以「代玉」立身：器形由被仿对象决定，铸造成型法也由仿件要求决定。这条代用路线能走多远，取决于玉的礼制需求，还是玻璃的成本与技术？

第三个问题是沉浮。李立新把玻璃器作为「几经起落而从未被淘汰」的例证：春秋末已有制造，战国西汉具规模，东汉魏晋衰落，隋唐再兴，唐后低潮，元末明初博山出现作坊，清康熙设宫廷玻璃厂，近代设厂转向新式生产。田自秉给的解释是铜器、漆器、瓷器大量生产，加上玻璃「质地没有过关」——「虚脆不贞」、不耐高温而易碎。那么本土玻璃的兴衰由替代材料的竞争决定，还是由技术与原料决定？输入在其中扮演什么角色：东汉魏晋的衰落被联系到萨珊玻璃的引进，唐代法门寺地宫出 20 件伊斯兰玻璃器，而北魏景县封氏墓网纹玻璃杯又被用来反驳「古玻璃都来自西方」。

第四个问题是成分命名的冲突。田自秉记中国古代玻璃属铅钡玻璃、西方属钠钙玻璃；李立新记春秋、西汉的玻璃为钠钡玻璃，与西方钠钙玻璃截然不同；高丰经带钩条记两汉玻璃属铅钡玻璃。两套成分名指同一批器物而互不相容，六册均未给检测数据。本 Theme 并列照录，不裁。

## 边界

- 纳入：玻璃与琉璃的第一义（原始玻璃、铅钡与钠钡玻璃）、战国至两汉的琉璃璧与仿玉器、玻璃带钩等以玻璃为材质扩展的器物、魏晋至隋唐的本土玻璃器与输入玻璃器、料器、山东博山玻璃作坊、造办处玻璃厂、近代玻璃工厂与玻璃材料工艺。
- 排除：建筑琉璃与低温釉陶（铅釉陶、唐三彩、辽三彩、宋三彩、琉璃瓦、琉璃塔等）归 B.5.4；本 Theme 只在「琉璃」一名两义处交叉引用，不重复挂载。
- 排除：玉璧与玉器本体归 B.8（玉石与治玉）；本 Theme 只取玻璃仿玉的代用关系，不把玉器挂入。
- 排除：玻璃器的纹样母题与造型风格解释归 C；本 Theme 只取材料、工艺、器形与生产组织。
- 排除：伊斯兰玻璃、萨珊玻璃的跨文化流通与风格影响归 E.2；本 Theme 只在判断本土制造与输入时引用，不重复挂载。
- 排除：造办处的机构沿革、编制与匠役管理归 D.6.6；本 Theme 只取玻璃厂作为玻璃生产组织的一环。
- 排除：近代玻璃工厂的资本、市场与产业制度归 D.1／B.4；本 Theme 只取材料与成型工艺的转变。
- 边界说明：玻璃、琉璃、料器三名在六册中混用，本 Theme 不统一名称，按来源用词照录并注明所指；成分命名（铅钡／钠钡）两说并列，不裁；来源未给的成分数据、窑炉参数与产量，本库不据来源外材料补写。

## 支撑结构

- 理论支撑：以「代用—输入—工业」三层组织玻璃材料。代用层回答「玻璃做成什么」，其答案是仿玉的器形（璧、剑饰、印章、衣片、带钩）与由此决定的铸造成型法；输入层回答「玻璃从哪里来」，其答案是本土制造与进口并行，两方面的证据都是出土品而非成分或窑址；工业层回答「玻璃为谁生产」，其答案是宫廷玻璃厂、博山作坊群与近代工厂三种组织形态。三层各有一个无法闭合的证据缺口——代用层缺成分数据，输入层缺窑址与工艺痕迹，工业层缺产量与配方——因此本 Theme 不写「中国玻璃发展史」，只写三种进入方式各自能证到什么程度。
- 实证/材料支撑：三个 Topic 合计挂载 10 个 KU（B.7.1 三个、B.7.2 两个、B.7.3 五个），覆盖 term、place、work、procedure 四类；`term_anchor` 3（琉璃、料器、玻璃）、`geographical_context` 2（长沙楚墓群、山东博山）、`boundary_case` 1（带钩）、`representative_work` 2（网纹玻璃杯、荷花纹套红料缸）、`evidence_event` 1（法门寺塔基地宫）、`procedure` 1（套料）。其中琉璃以 B.5.4 为主挂载、法门寺塔基地宫以 B.6.1 为主挂载，本 Theme 各取一条次挂载；荷花纹套红料缸为图注级单器（confidence low）。
- 文献支撑：田自秉提供琉璃两义、铅钡说、琉璃璧尺寸与楚墓比例、玻璃易碎与技术限制、料器定义与清代品种装饰；李立新提供玻璃器沉浮序列、钠钡说、博山与宫廷玻璃厂、近代设厂、法门寺伊斯兰玻璃、景县网纹玻璃杯与「不能认为古玻璃都来自西方」的论辩；高丰提供两汉玻璃器 6500 余件、铸造成型法与造办处玻璃厂；赵农提供玻璃原料、工序与当代产业布局；夏燕靖两版在长沙楚墓与带钩处提供旁证。具体行号见各 KU 的 `sources`。

## 未解决问题

- 成分命名冲突不可裁：田自秉「铅钡玻璃」、李立新「钠钡玻璃」、高丰「铅钡玻璃」，三处均无检测数据、样本量与检测机构；「铅钡」「钠钡」是否指同一配方体系，六册未说明。
- 玻璃的起源与最早制造：李立新记「最迟春秋末期已有制造」，引越王句践与吴王夫差剑格嵌玻璃块、河南固始侯古堆 1 号春秋墓玻璃珠；器物的具体年代、成分与制作地点全无。
- 琉璃璧的尺寸只有「最大直径 16 厘米」一个上限，无最小直径、厚度、重量与穿孔数据；楚墓「100 多座中 80 多座」是单源比例，未给墓葬清单与统计口径。
- 战国琉璃的窑址未发现；琉璃璧、剑饰、印章是铸造还是模压，来源只说「铸造成型法」，无工艺痕迹描述。
- 两汉玻璃「6500 余件」是单源统计，未给件数构成（碗、带钩、璧、耳珰、珠各多少）、出土地点分布与收藏单位。
- 玻璃衣片只见于李立新一句「模仿『金缕玉衣』的玻璃『玉衣』片」，无出土墓葬、件数与复原研究。
- 本土制造与输入的分界无成分依据：北魏四批出土被用来证明本土制造，但来源未给成分对比；法门寺 20 件伊斯兰玻璃器如何与本土器区分，来源未说明。
- 田自秉用法门寺「琉璃」、李立新用「玻璃」，两册指同一批器物而用词不同；本 Theme 照录，不统一。
- 料器的铅含量、烧成温度、套料与磨花工序细节全无；「料器即玻璃器」与「料器是含铅量较高的玻璃」两种表述的边界未说明。
- 博山玻璃的原料、炉窑结构、产品谱系、工匠姓名与产量数据全无；「百余家」是清代某一时点还是整个清代，来源未说明。
- 宫廷玻璃厂的设立年份、隶属关系（是否属造办处）、工匠来源与产品清单未定；李立新只称「宫廷玻璃厂」，未说隶属。
- 近代玻璃工厂只有城市名单，无厂名、设立年份、设备、产量与产品；1949 年后「北京、上海、大连、山东、四川北碚」的布局也只有名单。
- 玻璃与瓷器、漆器、铜器的替代关系只有田自秉一句「铜器、漆器、瓷器大量生产」与「质地没有过关」，无产量、价格或使用场景的比较。
