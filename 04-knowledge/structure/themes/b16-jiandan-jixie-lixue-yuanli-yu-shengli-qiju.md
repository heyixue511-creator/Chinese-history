# B.16 简单机械与力学原理：杠杆、滑轮与省力器具

## 核心问题

本 Theme 七条规定了一个共同问题：**「省力」在六册里被写成一条可推演的原理，还是一组各自使力气的器具**。

第一个事实是**原理条与器具条从不互引**。杠杆条（赵农 L1994）明写「本条只记原理与概念雏形，来源未给实物」，并声明「本条不把桔槔、秤器、滑轮的具体构造写入，另见相关条目」；但桔槔条（L1998-L2002）只说「杠杆配重的一升一落」，不点名杠杆条；滑轮条（L2004）只说「利用一个固定的滑轮改变力的运动方向，节省人力」，也不回引。三条在同一册的相邻章节，却各自成立。本 Theme 的成员因此分属三个既有 Theme：桔槔、辘轳主挂载在 B.12.2（提水），权衡秤器在 B.13.2（计量），陶井在 B.5.3（明器模型）——「简单机械」这个类别在六册中从未出现，它是本库为安置两条无器物的原理条而设的结构。

第二个事实是**「省力」在两种文本里是两种写法**。原理条写「平衡」：杠杆「作为一种平衡的原理，有着省力的作用」，滑轮引《墨子·墨经》「绳直，权重相若，则上矣」。器具条写动作：桔槔「一端水桶，一端重物，一升一落」，辘轳「绳缠绕其上，滑动省力」，滑轮「改变力的运动方向」。没有一条给力臂比、配重比、轮径比、起重能力或功率，因此「哪种器具更省力」在本 Theme 内不可比较。

第三个事实是**唯一的实物证据来自别的线**。同时具备实物、理论文本与术语解释的只有权衡秤器：长沙楚墓春秋等臂秤具实物，《墨经》衡木、本、标、权四术语的长引文，以及「力臂」的释义；但它主挂载在计量线，理由是秤的目的在计量而非省力。唯一的滑轮器物证据是东汉陶井模型的图注「井架的设计和滑轮的安装与使用方法」（李立新），而滑轮条引的是汉画像石「泗水捞鼎」——两条不同册、不同证据类型（图注／画像石），互不引用。

## 边界

- 纳入：两条无器物的原理条（杠杆、滑轮）与力学文本《墨经》，作主挂载；四条有杠杆、轮轴或滑轮原理关联的器具（桔槔、辘轳、权衡秤器、陶井模型）作次挂载，主归属保持在原 Theme。
- 排除：农具与耕作——耒耜、骨耜、犁、耧归 B.12.1；本 Theme 不取翻土器具。
- 排除：收割与加工器具的主归属——石镰、青铜镰、石磨盘和磨棒、石磨、翻车主挂载仍在 B.12.2；翻车为链式提水，与杠杆、轮轴、滑轮三者无直接原理关联，本 Theme 不收其次挂载。
- 排除：计量标准与货币——秦量、秦权、商鞅方升、交钞、银元归 B.13；本 Theme 只取权衡秤器一条作次挂载，不取制度、诏书与器物序列。
- 排除：水利工程——都江堰、郑国渠、西门渠、灵渠归 B.15；渠堰改变水系，不是单件器具。
- 排除：兵器、甲胄与远射器具——归 B.9.4。
- 排除：其他陶质明器——陶仓楼、绿釉陶楼、说唱俑归 B.5.3；陶井只因图注记「井架与滑轮的安装与使用方法」而入次挂载，本 Theme 不取明器类型学。
- 排除：车轮、指南车、水碓等轮轴或机械装置——六册没有把它们与杠杆、滑轮并读，本 Theme 不据原理相似性扩收。
- 排除：近代机械与动力——蒸汽机、纺织机械、机床与抽水机归 B.1、B.4；六册无「简单机械向近代机械过渡」的叙述。

## 支撑结构

- 理论支撑：以「原理—文本—器具—证据」四层读简单机械。原理层只有两条，且两条都声明无实物；文本层只有《墨经》，三册（夏燕靖 2009、赵农 2009、夏燕靖 2016）都把它作为「造物的科学知识」而非工艺专著，赵农引其衡木、本、标、权与「绳制挈之也」，夏燕靖两版给几何与力学条目；器具层四条分属提水、计量、明器三条线，各有来源而互不引用；证据层是三种不通约的类型——画像石（泗水捞鼎）、实物（长沙楚墓等臂秤具、大冶铜绿山辘轳两件）、图注（陶井）。四层不互相支撑：有实物的一条没有原理出处，有原理的两条没有实物，有图注的一条没有尺寸。
- 实证/材料支撑：一个 Topic 合计 7 条 membership——主挂载 3（杠杆、滑轮、《墨经》），次挂载 4（桔槔、辘轳、权衡秤器、陶井）。type 为 term 5、publication 1、work 1；role 为 `term_anchor` 5、`supporting_source` 1、`representative_work` 1。confidence 为 medium 5、low 2（杠杆、陶井）；consensus 全部 tentative。断代（按每条所记最早时点）：石器时期 1（杠杆的推测性回溯）、春秋 2（权衡秤器的等臂秤具、桔槔）、战国 3（滑轮、《墨经》、辘轳所记大冶铜绿山实物）、东汉 1（陶井）。
- 文献支撑：赵农《中国艺术设计史》（2009）第三章「工具」一节提供五条（杠杆 L1994、权衡秤器 L1996、桔槔 L1998-L2002、滑轮 L2004 与 L2011、《墨经》L1809/L1996/L2011/L2017）；夏燕靖《中国设计史》（2009）L1255、L1257 与《中国艺术设计史（升级版）》（2016）L1581、L1583、L6149 经《墨经》一条进入；李立新《中国设计艺术史论》（2011）L269、L273 提供陶井图版与图注。高丰 2004、田自秉 2010 对本 Theme 七条无关联条目。

## 未解决问题

- 「简单机械」不是六册的类别，而是本库为安置两条原理条而设的结构：杠杆条与滑轮条在来源中各占一段，前后相隔十行，彼此不引；本 Theme 把它们与器具条并置，是结构性判断而非来源判断。
- 原理条无实物、器具条无原理：杠杆条自陈「来源未给实物」，滑轮条只有《墨经》引文与一条画像石，二者都不给支点位置、力臂长度、轮径或绳径；器具条只写动作。
- 无一处量化：「省力」没有比值，「平衡」没有配重比与力臂比，「起重」没有能力上限；全 Theme 唯一的数值级信息是「大冶铜绿山出两件战国至西汉辘轳」的件数与「汉画像石泗水捞鼎」的图名。
- 三条器具分属三个 Theme 的次挂载是本库安排，不是来源安排：桔槔、辘轳在提水线，权衡秤器在计量线，陶井在明器线；六册从未把这四条并读，也未出现「杠杆系器具」的说法。
- 权衡秤器同时有实物、《墨经》文本与术语解释，是全库唯一「实物—文本—术语」三层齐备的力学条目，却因目的在计量而被归入 B.13.2；其省力含义只能经本 Theme 的次挂载读出，主挂载侧不写这一层。
- 陶井的图注是滑轮唯一的器物证据，但图版未核、尺寸与出土地点未载、明器是否反映实物的井架形制也无说明；本 Theme 只用它作「滑轮在东汉已被画进井架」的最低证据，不据此复原构件。
- 《墨经》引文未给篇名，《经上》《经下》《经说》的层次未分；「绳制挈之也」「挈，长重者下，短轻者上」两句来源只作平衡原理的解释，未逐句训释，本库照录不训。
- 名实不统一照录：「滑车亦称滑轮」是同物两名；杠杆条把「权衡」与「衡器」并列为概念雏形而未区分所指；桔槔与辘轳同是井上装置而原理不同（配重／轮轴），来源未作对比。
- 「杠杆原理在石器时期被体验和发现」是来源的推测性回溯，无考古器物或图像支持；本 Theme 照录并标为 low confidence，不把石器时期的木棒当作杠杆实物。
- 六册没有斜面、楔、螺旋、齿轮的条目，也没有把「简单机械」提升为分类或计算方法的文本：本 Theme 能回答的是「六册怎样写省力」，不是「中国古代简单机械如何发展」。
